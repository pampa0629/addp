## 跨平台支持

### CPU 架构自动检测

标准 `up.sh` 在加载部署环境后，仅当 `POSTGRES_IMAGE` 为空时自动检测 CPU 架构：

| 检测到的架构 | PostgreSQL 镜像 | 缺少镜像时的处理 |
| --- | --- | --- |
| `x86_64` | `addp-postgres-pgvector:latest` | 从仓库 `scripts/infra/Dockerfile.postgres` 构建，包含 PostGIS 与 pgvector |
| `aarch64` / `arm64` | `pampa0629/addp-postgres:15-arm64` | 拉取预构建镜像 |

其他架构在未显式指定镜像时拒绝继续。显式填写 `POSTGRES_IMAGE` 会跳过这段自动选择；部署方须准备适配目标架构及所需扩展的镜像。裸 Compose 的镜像缺省值不等于标准入口的架构选择结果，基础设施仍通过 `up.sh` 管理。

**手动覆盖**：在根 `.env` 中填写已准备好的镜像，例如 ARM64：

```bash
POSTGRES_IMAGE=pampa0629/addp-postgres:15-arm64
```

保留自动选择时将该值留空：

```bash
POSTGRES_IMAGE=
```

## 环境变量配置

### 配置文件说明

- 根 `.env.example` 是部署环境变量模板，记录开发首选值、可选字段及敏感项提示；它不包含所有 Owner 普通运行配置的定义默认值。
- 普通开发和部署使用根 `.env` 或受控部署注入，不维护另一套 `.env.prod`；实际密码和密钥不提交到 Git。Online 独占部署沿标准入口使用仓库外 `ADDP_ONLINE_ENV_FILE`，边界见[日志部署说明](运行日志.md#模块实例运行日志)。
- Compose 和启动脚本可以定义部署缺省值。例如 `docker-compose.infra.yml` 的 `POSTGRES_PORT` 缺省为 `15432`，PostgreSQL 镜像由前述启动逻辑选择；这不表示全部参数都可省略。数据库与 MinIO 凭据、独立服务 Secret 等仍按模板和各自预检要求提供，生产环境不得沿用模板开发口令。
- 根 `.env` 中的宿主机端口是首选值。标准入口解析冲突并注入实际映射，运行连接以 `bash scripts/infra/status.sh` 为准，不将运行结果写回根 `.env`。
- “单一事实来源”要求配置归属清晰：Owner 普通运行配置从持久化事实及定义默认值解析，不能失败后回退环境变量；部署缺省值也不能成为可并行编辑的另一份运行配置。完整规则见[配置归属与生效](../../../docs/spec/configuration/配置归属与生效.md)及[部署环境与密钥](../../../docs/spec/configuration/部署环境与密钥.md)。

### 关键环境变量

```bash
# PostgreSQL（必填）
POSTGRES_USER=addp
POSTGRES_PASSWORD=addp_password          # ⚠️ 生产环境必须修改
POSTGRES_DB=addp

# Redis（必填）
REDIS_PASSWORD=addp_redis                # ⚠️ 生产环境必须修改

# MinIO（必填）
MINIO_ROOT_USER=minioadmin
MINIO_ROOT_PASSWORD=minioadmin           # ⚠️ 生产环境必须修改
MINIO_API_PORT=19000
MINIO_CONSOLE_PORT=19001

# FalkorDB（必填；必须独立于 Redis 密码）
INFRA_FALKORDB_PASSWORD=

# Meilisearch（必填）
MEILISEARCH_MASTER_KEY=your-master-key-change-in-production   # ⚠️ 生产环境必须修改
MEILISEARCH_URL_LOCAL=http://localhost:17700

# Infra Kafka / Kafka Connect（CDC 内部基础设施）
REDPANDA_IMAGE=docker.redpanda.com/redpandadata/redpanda:v24.3.18
REDPANDA_MEMORY=1G
INFRA_KAFKA_PORT=19092
INFRA_KAFKA_ADMIN_PASSWORD=change-in-production
INFRA_KAFKA_CONNECT_PASSWORD=change-in-production
INFRA_KAFKA_TRANSFER_PASSWORD=change-in-production
INFRA_KAFKA_SASL_MECHANISM=scram-sha-256
INFRA_KAFKA_INTERNAL_REPLICATION_FACTOR=1
REDPANDA_HA_MEMORY=1G
REDPANDA_HA_KAFKA_2_PORT=19093
REDPANDA_HA_KAFKA_3_PORT=19094
KAFKA_CONNECT_IMAGE=quay.io/debezium/connect:3.6.0.Final
KAFKA_CONNECT_PORT=18083
KAFKA_CONNECT_BOOTSTRAP_SERVERS=redpanda:29092

# PostgreSQL 镜像（可选；留空时按架构选择）
POSTGRES_IMAGE=
# ARM64 缺省: pampa0629/addp-postgres:15-arm64

# 仅跳过对应初始化步骤；不表示只启动容器，也不跳过服务健康检查。
SKIP_POSTGRESQL_INIT=0
SKIP_MINIO_INIT=0
SKIP_MEILISEARCH_INIT=0
```
