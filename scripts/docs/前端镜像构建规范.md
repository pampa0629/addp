# Frontend Docker 构建规范

本文档规定了 ADDP 平台所有前端模块的 Docker 镜像构建标准。

## 核心要求

所有前端 Dockerfile 必须满足以下要求：

1. **根目录构建上下文** — 构建脚本统一从项目根目录执行 `docker build`，Dockerfile 中所有路径必须以模块路径为前缀
2. **本地镜像源** — 基础镜像必须使用 `localhost:5001/` 前缀，不得直接使用 Docker Hub
3. **ARM64 兼容** — 必须显式安装 `@rollup/rollup-linux-arm64-musl`
4. **common-frontend 符号链接** — 复制 common-frontend 后必须创建 node_modules 符号链接
5. **nginx.conf** — 必须提供 nginx.conf 并在 Dockerfile 中 COPY，支持 Vue Router history 模式

## 标准 Dockerfile 模板

```dockerfile
FROM localhost:5001/node:18.20.5-alpine AS builder

WORKDIR /app

# 复制 package.json（路径前缀为模块路径）
COPY <module>/frontend/package.json ./

# 安装依赖，显式安装 rollup ARM64 本地依赖
RUN npm install --no-package-lock && \
    npm install --no-save @rollup/rollup-linux-arm64-musl && \
    npm cache clean --force

# 复制 common-frontend，创建符号链接让其能访问 node_modules
COPY common-frontend /common-frontend
RUN ln -s /app/node_modules /common-frontend/node_modules

# 复制源代码
COPY <module>/frontend .

# 构建
RUN npm run build

# 运行阶段
FROM localhost:5001/nginx:alpine

COPY --from=builder /app/dist /usr/share/nginx/html
COPY <module>/frontend/nginx.conf /etc/nginx/conf.d/default.conf

EXPOSE 80

CMD ["nginx", "-g", "daemon off;"]
```

将 `<module>` 替换为实际模块名，例如 `manager`、`system`、`quality` 等。

## nginx.conf 规范

每个前端模块目录下必须有 `nginx.conf`，内容如下：

```nginx
server {
    listen 80;
    server_name localhost;
    root /usr/share/nginx/html;
    index index.html;

    # SPA fallback — Vue Router history 模式必须
    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

## 常见错误

### `nginx.conf: not found`

**原因**：Dockerfile 中 `COPY nginx.conf` 使用了相对路径，但构建上下文是项目根目录。

**修复**：将 `COPY nginx.conf` 改为 `COPY <module>/frontend/nginx.conf`。

### `@rollup/rollup-linux-arm64-musl` 相关错误

**原因**：缺少 ARM64 平台的 rollup 本地依赖。

**修复**：确保 RUN 步骤中包含 `npm install --no-save @rollup/rollup-linux-arm64-musl`。

### `common-frontend` 模块找不到

**原因**：缺少 node_modules 符号链接，common-frontend 内部无法解析依赖。

**修复**：确保 `COPY common-frontend /common-frontend` 之后有 `RUN ln -s /app/node_modules /common-frontend/node_modules`。

### 使用了旧格式 Dockerfile

**症状**：Dockerfile 中使用 `node:20-alpine`（无 `localhost:5001/` 前缀）、`COPY package.json ./`（无模块路径前缀）、`COPY nginx.conf`（无模块路径前缀）。

**原因**：该模块 Dockerfile 是按旧规范（模块目录为构建上下文）创建的。

**修复**：按本文档标准模板重写整个 Dockerfile。

## 新增前端模块 Checklist

- [ ] 创建 `<module>/frontend/Dockerfile`（使用上方标准模板）
- [ ] 创建 `<module>/frontend/nginx.conf`（使用上方 nginx 模板）
- [ ] 确保 `package.json` 包含 `build` 脚本
- [ ] 在 `scripts/build/build-images.sh` 中注册该模块
