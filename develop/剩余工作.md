### Phase 6: 实现 ExecutionMonitor.vue + ExecutionDetail.vue（执行监控）

#### 6.1 ExecutionMonitor.vue（执行历史列表）

**功能需求:**
1. **执行列表展示**
   - 显示所有 dev_executions（SQL 执行 + 工作流执行）
   - 表格列: 执行ID、任务名称、类型、状态、进度、开始时间、执行时长、操作按钮

2. **过滤和搜索**
   - 类型过滤: 'sql' / 'workflow' / 'all'
   - 状态过滤: 'pending' / 'running' / 'success' / 'failed' / 'timeout' / 'cancelled' / 'all'
   - 触发方式过滤: 'manual' / 'schedule' / 'orchestrator' / 'api' / 'all'
   - 时间范围选择: `<el-date-picker type="datetimerange">`
   - 关联任务过滤: `<el-select>` 选择 dev_item

3. **状态展示**
   - 使用 `<el-tag>` 显示状态:
     - pending: `<el-tag type="info">待执行</el-tag>`
     - running: `<el-tag type="warning">执行中</el-tag>`
     - success: `<el-tag type="success">成功</el-tag>`
     - failed: `<el-tag type="danger">失败</el-tag>`
     - timeout: `<el-tag type="danger">超时</el-tag>`
     - cancelled: `<el-tag type="info">已取消</el-tag>`

4. **进度显示**
   - 使用 `<el-progress :percentage="row.progress" />`
   - running 状态时实时轮询更新进度

5. **操作功能**
   - 查看详情: 点击行跳转到 `/executions/:id`
   - 取消执行: 仅 running 状态可用，调用 `cancelExecution(id)` API
   - 重试执行: failed/timeout 状态可用，调用 `retryExecution(id)` API
   - 查看日志: 跳转到详情页的日志 Tab

6. **统计信息卡片**
   - 顶部显示统计卡片:
     - 总执行次数
     - 成功率
     - 平均执行时长
     - 今日执行次数

**API 调用:**
```javascript
import { listExecutions, cancelExecution, retryExecution, getExecutionStatistics } from '@/api/devExecution'
```

**轮询逻辑:**
```javascript
import { onMounted, onUnmounted, ref } from 'vue'

let pollingTimer = null

const startPolling = () => {
  pollingTimer = setInterval(() => {
    // 仅刷新 running 状态的执行
    loadExecutions(false) // false 表示静默刷新
  }, 3000) // 每 3 秒刷新一次
}

onMounted(() => {
  loadExecutions()
  startPolling()
})

onUnmounted(() => {
  if (pollingTimer) {
    clearInterval(pollingTimer)
  }
})
```

**文件路径:** `develop/frontend/src/views/ExecutionMonitor.vue`

**API 调用:**
```javascript
import { getExecution, getExecutionLogs, cancelExecution, retryExecution } from '@/api/devExecution'
```

**轮询逻辑:**
```javascript
// 仅 running 状态时轮询
const startPolling = () => {
  if (execution.value?.status === 'running') {
    pollingTimer = setInterval(() => {
      loadExecutionDetail(false) // 静默刷新
    }, 2000)
  }
}

watch(() => execution.value?.status, (newStatus) => {
  if (newStatus !== 'running' && pollingTimer) {
    clearInterval(pollingTimer)
  } else if (newStatus === 'running' && !pollingTimer) {
    startPolling()
  }
})
```

### Phase 7: 实现 WorkflowEditor.vue（工作流编辑器）

**⚠️ 这是最复杂的页面，建议最后实现**

**功能需求:**
1. **三栏布局**
   - 左侧: 算子面板（复用 `OperatorPalette.vue`）
   - 中间: DAG 工作流画布（可拖拽节点、连线）
   - 右侧: 参数配置面板（选中节点时显示参数表单）

2. **算子面板**
   - 使用现有的 `<OperatorPalette />` 组件
   - 按模块分组显示算子（GeoPandas、Meta、Transfer、Manager）
   - 支持拖拽算子到画布

3. **工作流画布**
   - 推荐使用 **@antv/x6** 或 **vue-flow** 库
   - 支持拖拽创建节点
   - 支持节点连线（输出端口 → 输入端口）
   - 节点样式: 显示算子名称、图标、状态
   - 支持多选、删除、复制节点
   - 支持缩放、平移画布

4. **参数配置面板**
   - 选中节点时，右侧显示参数表单
   - 动态生成表单（根据算子的 input_schema）
   - 支持参数验证
   - 支持参数引用（使用上游节点的输出）

5. **工具栏功能**
   - 保存工作流: 调用 `createDevItem` 或 `updateDevItem` API（dev_type='workflow'）
   - 执行工作流: 调用 `executeDevItem` API
   - 另存为: 复制当前工作流并创建新任务
   - 清空画布
   - 导入/导出 JSON

6. **工作流数据结构**
```javascript
const workflowDef = ref({

    {
      id: 'edge_1',
      source: 'node_1',
      target: 'node_2',
      source_port: 'output',
      target_port: 'input'
    }
  ]
})
```

**推荐技术方案:**
- 使用 **@antv/x6** 作为图编辑器库
- 安装: `npm install @antv/x6 @antv/x6-vue-shape`
- 参考文档: https://x6.antv.antgroup.com/

**API 调用:**

## ❓ 常见问题

### Q1: 后端 API 返回 401 Unauthorized
**原因**: 未携带 JWT token 或 token 过期
**解决**: 检查 `localStorage` 中的 token，必要时重新登录

### Q2: 执行监控页面如何实现实时更新？
**方案**: 使用 `setInterval` 每 3 秒轮询 `listExecutions` API，仅刷新 `running` 状态的执行

### Q3: 工作流编辑器用什么库？
**推荐**: @antv/x6（阿里开源图编辑器）或 vue-flow（Vue 3 原生）

### Q4: 如何测试算子发现功能？
**步骤**:
1. 确保 GeoPandas Engine 服务运行（:8099）
2. 访问 `/api/develop/operators` 查看算子列表
3. 使用 `POST /api/develop/operators/refresh` 刷新缓存
