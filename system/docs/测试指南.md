## 运行测试

### 后端单元测试

#### 1. 运行所有测试

```bash
# 在项目根目录
go test ./common/... ./system/backend/...
```

#### 2. 运行特定模块测试

```bash
# 测试 common/api 模块
go test -v github.com/addp/common/api

# 测试 common/service 模块
go test -v github.com/addp/common/service

# 测试 system/backend/internal/service 模块
go test -v github.com/addp/system/backend/internal/service
```

#### 3. 查看测试覆盖率

```bash
# 带覆盖率报告
go test -cover ./common/api ./common/service

# 生成详细覆盖率报告
go test -coverprofile=coverage.out ./common/...
go tool cover -html=coverage.out -o coverage.html
```

#### 4. 运行特定测试用例

```bash
# 运行包含 "AuthService" 的测试
go test -v -run AuthService github.com/addp/common/service

# 运行包含 "BindIDParam" 的测试
go test -v -run BindIDParam github.com/addp/common/api
```

## 编写新测试

### 后端测试示例

```go
package service_test

import (
	"testing"
	"github.com/stretchr/testify/assert"
	"github.com/addp/common/service"
)

func TestYourFunction(t *testing.T) {
	// 准备测试数据
	svc := service.NewYourService()

	// 执行测试
	result := svc.YourMethod(input)

	// 断言结果
	assert.NoError(t, err)
	assert.Equal(t, expected, result)
}
```

### 表格驱动测试示例

```go
func TestWithMultipleCases(t *testing.T) {
	tests := []struct {
		name        string
		input       string
		expected    string
		expectError bool
	}{
		{
			name:        "Valid case",
			input:       "test",
			expected:    "TEST",
			expectError: false,
		},
		{
			name:        "Error case",
			input:       "",
			expectError: true,
		},
	}

	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			result, err := YourFunction(tt.input)

			if tt.expectError {
				assert.Error(t, err)
			} else {
				assert.NoError(t, err)
				assert.Equal(t, tt.expected, result)
			}
		})
	}
}
```

## 常见问题

### Q: 测试失败但本地运行正常？

A: 检查以下几点：
- 确保测试隔离，不依赖外部状态
- 使用 `gin.SetMode(gin.TestMode)` 避免 Gin 日志干扰
- Mock 外部依赖（数据库、Redis、HTTP 请求）

### Q: 如何 Mock 数据库？

A: 使用 Repository 接口：
```go
type MockUserRepository struct {
    mock.Mock
}

func (m *MockUserRepository) GetByID(id uint) (*User, error) {
    args := m.Called(id)
    return args.Get(0).(*User), args.Error(1)
}
```
