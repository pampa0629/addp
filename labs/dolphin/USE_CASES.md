# 空间算子编排的实际应用场景

## 场景 1: 城市热岛效应分析（环保部门）

**业务需求**: 每月分析城市热岛分布，生成报告

**传统方式**:
- 下载遥感影像 → 导入 ArcGIS → 手动分类 → 统计分析 → 制图
- 耗时: 2-3 天

**算子编排方式**:
```
[加载遥感影像] → [温度分类] → [缓冲区分析] → [叠加行政区划] → [统计聚合] → [生成热力图]
```
- 首次配置: 1 小时
- 后续执行: 自动化（定时每月 1 号运行）
- **效率提升**: 20 倍

## 场景 2: POI 密度分析（商业选址）

**业务需求**: 分析某商圈 1km 内餐厅、便利店、地铁站密度

**工作流**:
```
[加载商圈边界]
       ↓
[创建 1km 缓冲区]
       ↓
    ┌──┴──┬──────────┬──────────┐
    ↓     ↓          ↓          ↓
[空间连接] [空间连接] [空间连接] [空间连接]
餐厅表   便利店表  地铁站表  公交站表
    ↓     ↓          ↓          ↓
    └──┬──┴──────────┴──────────┘
       ↓
[聚合统计 + 评分模型]
       ↓
[输出选址建议报告]
```

**优势**:
- 并行查询 4 个 POI 表（性能提升 4 倍）
- 修改缓冲距离参数 → 重新运行即可对比
- 保存为模板 → 新商圈复用

---

## 场景 3: 洪水影响范围评估（应急管理）

**业务需求**: 暴雨预警时，快速评估影响范围和受灾人口

**工作流**:
```
[加载河流数据] → [根据水位创建淹没范围] → [叠加建筑物数据]
                                              ↓
                          [空间连接人口网格数据] → [统计受影响人口]
                                              ↓
                          [叠加关键基础设施] → [标记高危区域]
                                              ↓
                                     [生成应急响应地图]
```

**关键价值**:
- **速度**: 5 分钟内出结果（传统方式需 1-2 小时）
- **自动化**: 接入气象数据 API，自动触发分析
- **可重复**: 不同降雨情景快速模拟

## 场景 4: 土地利用变化监测（自然资源部门）

**业务需求**: 对比 2020 年和 2024 年土地利用变化

**工作流**:
```
[加载 2020 年土地数据]
       ↓
[加载 2024 年土地数据]
       ↓
[几何差异计算]
       ↓
[分类变化类型]（耕地→建设用地、林地→耕地等）
       ↓
[叠加行政区划] → [按区县统计变化面积]
       ↓
[生成变化热力图 + Excel 报表]
```

**价值**:
- 定期执行（每季度）
- 历史记录（每次执行结果存档）
- 趋势分析（对比多个时期）

## 场景 5: 交通可达性分析（交通规划）

**业务需求**: 评估新地铁站对周边社区的影响

**工作流**:
```
[加载现有地铁站] → [创建 500m/1km/2km 缓冲区]
                            ↓
[加载新规划地铁站] → [创建服务范围]
                            ↓
                    [计算新增覆盖区域]（Difference 算子）
                            ↓
              [空间连接小区数据] → [统计受益人口]
                            ↓
              [叠加房价数据] → [预测房价影响]
                            ↓
                   [生成影响评估报告]
```

---

## 场景 6: 野生动物栖息地分析（生态保护）

**业务需求**: 评估高速公路建设对野生动物栖息地的影响

**工作流**:
```
[加载栖息地边界]
       ↓
[加载规划高速公路路线] → [创建 500m 噪音影响区]
                                ↓
                        [与栖息地相交]
                                ↓
                        [计算破碎化程度]
                                ↓
              [标记核心栖息地] → [评估影响等级]
                                ↓
                        [提出缓解措施建议]
                     （如建设生态廊道）
```

## 关键特点总结

### 1. 重复性任务 → 自动化
- 每月/每季度的定期报告
- 相同流程用于不同区域
- 参数化模板快速复用

### 2. 多数据源整合 → 并行处理
- 同时查询多个数据库/表
- DolphinScheduler 自动优化执行顺序
- 大幅缩短总耗时

### 3. 复杂流程 → 可视化
- DAG 图清晰展示逻辑
- 便于团队协作和审查
- 降低出错概率

### 4. 专业门槛 → 平民化
- 业务专家无需学编程
- IT 人员配置好算子后，业务人员自助使用
- 知识沉淀（工作流即文档）
