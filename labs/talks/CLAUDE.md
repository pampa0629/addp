# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## 目录说明

本目录（`labs/talks`）是一个**独立的AI交流讨论工作区**，用于：
- 与AI进行技术探讨和思想交流
- 保存重要的对话结果和讨论记录
- 实验性的代码片段和概念验证

**重要**: 本目录与父目录的ADDP项目完全独立，没有任何关联。

## 工作原则

1. **自由探索**: 这是一个自由的讨论空间，不受项目规范约束
2. **记录保存**: 重要的讨论结果应保存为markdown文档
3. **独立性**: 不要引用或依赖ADDP项目的任何代码或配置

## 目录结构

```
talks/
├── CLAUDE.md           # 本文件
├── readme.md           # 目录说明
└── [讨论主题]/         # 按主题组织的讨论内容
    ├── notes.md        # 讨论笔记
    └── code/           # 相关代码片段（如有）
```

## 使用方式

当用户需要讨论技术问题时：
- 直接开始对话，无需遵循特定格式
- 可以使用中文或英文交流
- 讨论完成后，根据需要整理成markdown文档保存
- 代码示例应该是独立的、可运行的片段

## 注意事项

- 不要假设任何外部依赖或环境配置
- 每个讨论主题应该是自包含的
- 代码示例应包含必要的说明和上下文
