# Agent 请求时序与上下文边界

本文说明当前实现，不另设架构契约。设计以[模块设计共识](agent模块设计共识.md)、[交互协议规范](../../docs/spec/addp智能体交互协议规范.md)为准。

## 普通 Skill 请求

```mermaid
sequenceDiagram
    actor U as 用户
    participant API as Agent HTTP / AG-UI
    participant DB as Agent 持久化
    participant R as Agent 路由
    participant I as Inference Runtime
    participant H as DeerFlow Harness
    participant T as Manifest Adapter / ToolExecutor
    participant O as 业务 Owner
    U->>API: POST /api/v1/agent/chat (RunAgentInput)
    API->>DB: 核对身份、会话和运行，读取服务端历史
    API->>R: 当前请求、有界历史、摘要及语义检查点
    R->>I: 结构化路由决定（不生成正文）
    I-->>R: 普通 Skill / 平台领域 / 无 Skill / 历史草稿动作
    R->>H: Skill 正文、白名单、原模型预算
    loop 原预算内的工具决策
        H->>I: 模型决策
        I-->>H: Tool 调用或私有 answer_ready
        opt 返回平台 Tool
            H->>T: 稳定 Tool、AgentRun / ToolCall 审计身份
            T->>O: System 委托后调用 Owner
            O-->>H: 正式结果或待处理交互
        end
        Note over H: 私有计划、澄清及 answer_ready 由 Runtime 处理，不走 Owner Tool
        H-->>API: 受限步骤、计划、Presentation / 检查点
        API->>DB: 持久化安全投影
        API-->>U: AG-UI 事件
    end
    H->>I: 回答阶段（移除工具，仍消耗原预算）
    I-->>H: 真实正文增量
    H-->>API: text 事件
    API->>DB: 按协议批次提交正文和安全事件
    API-->>U: TEXT_MESSAGE_CONTENT
    API->>DB: 正文完成标记、运行终态
```

平台语义领域在进入 Harness 前增加 `platform.capabilities.list` 和目录选择；目录失败不得回退旧路由。没有 Skill 时直接进入禁止工具的回答阶段。澄清或 Owner 审批暂停后，从 ADDP 语义检查点恢复同一 AgentRun，不恢复框架消息快照；审批权始终属于业务 Owner。

## 历史草稿说明

```mermaid
sequenceDiagram
    actor U as 用户
    participant R as Agent 路由
    participant D as 当前身份和会话的草稿读取器
    participant I as Inference Runtime
    U->>R: 解释已有草稿（新 Run）
    R->>I: 根据受信任草稿目录选择 inspect 和引用
    R->>D: 私有 draft.inspect
    D-->>R: 校验后的精确历史参数与同参报告
    R-->>U: 历史提示、只读草稿、原报告
    R-->>U: 按解释范围固定说明状态、策略、执行边界及授权区别
    opt 用户明确问及其他字段、映射或已有查询表达式
        R->>I: 只传选中的受限片段，禁止工具
        I-->>U: 补充解释的真实正文增量
    end
```

该路径不重新预检、不读取当前资源，不把历史报告变成当前批准或可运行结论。候选生成、修改、创建与运行仍走各自的正式路径。

解释范围由同一次内部路由声明，纯关键主题不调用正文模型；不再把完整原请求和完整快照交给自由解释。引用解析仍按原模型选择／服务端核验路径，不自动选首项。固定文字与模型增量分别计量；同一回复取消后仍保留已显示内容，并按原协议标记未完成。

## 上下文、取消与耗时

- 历史由后端读取，先按最近 20 条、单条 6000 字符、合计 24000 字符构建上下文，历史摘要上限 2000 字符；Skill 背景再组合摘要与近期对话，不意味着模型拥有完整历史或长期记忆。
- Harness 不启用框架持久记忆或子代理，`checkpointer=None`；会话摘要和语义检查点由 ADDP 持有。
- 取消只停止 Agent Runtime 与待处理交互，不取消 Owner execution。失败或取消保留已提交的部分正文，标为未完成，并排除出后续模型上下文与摘要。
- 客户端断连由当前请求收敛生成和持久状态；安全事件可按 sequence 回放，回放不重新执行工具。归档不停止已经接纳的运行。
- 路由、平台目录选择、工具决策和回答阶段都可能消耗模型调用。不可再用固定的“工具数加常数”推断总调用数，也不承诺增量正文降低总耗时。
