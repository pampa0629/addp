# 051 时空数据的质量治理与普通表格数据有什么不同？

## 一句话回答

> 时空数据首先要满足普通数据的完整性、唯一性、准确性和一致性要求，还要进一步检查几何是否合法、位置是否准确、空间对象之间的拓扑和业务关系是否成立，以及不同时间版本是否连续一致。空间质量规则应采用“通用规则模板加业务配置”的方式，把参与检查的数据集、空间关系、数量约束、容差、时间版本和处置级别组合起来，而不是把每个行业场景硬编码成一条专用程序。

普通表格质量检查经常以单个字段、单条记录或表间关联为中心；时空数据还必须判断对象在空间中是否处于正确位置、与其他对象保持什么关系，以及这种关系在特定时间是否有效。

## 一、时空数据同样需要普通质量规则

空间数据并不会因为包含几何图形，就不再需要普通数据质量治理。一条地块、道路或设施记录，仍然需要检查：

- 业务标识是否为空；
- 编码是否唯一；
- 名称、类型和状态是否符合标准；
- 码值是否处于允许范围；
- 面积、长度和数量是否符合合理范围；
- 责任单位、数据来源和更新时间是否完整；
- 外键和关联标识是否能够找到对应对象；
- 数据是否按要求更新并保持鲜活。

例如，一个收费站点的位置完全正确，但收费站编码重复，仍然会导致收费、统计和设施管理混乱；一个地块几何合法，但地类码不符合当前分类标准，同样不能直接用于国土调查统计。

因此，时空数据质量不是替代普通质量规则，而是在普通规则之上增加空间和时间特有的检查。

## 二、时空数据质量可以分为哪些层次

为了便于理解，可以把时空数据质量分为五个相互关联的层次。

| 层次 | 主要检查内容 | 示例 |
| --- | --- | --- |
| 普通属性质量 | 完整性、唯一性、值域、格式和业务一致性 | 地块编码唯一、道路等级有效 |
| 几何有效性 | 几何结构本身是否能够被正确计算 | 面不自相交、线不少于两个有效节点 |
| 空间参考与位置质量 | 坐标、精度、比例尺和实际位置是否可靠 | 收费站位置误差不超过允许范围 |
| 空间拓扑与业务关系 | 同类或不同类对象之间的空间关系是否符合业务 | 地块不重叠、省域内只有一个对应省会点 |
| 时间与时空一致性 | 时间顺序、有效期、版本和空间变化是否合理 | 变更后的地块版本与前一版本能够衔接 |

这五层不能互相替代。一个面可能几何有效，却位于错误省份；两个地块可能各自合法，却相互重叠；一组当前数据可能完全正确，却无法解释上一年度的统计结果。

## 三、几何有效不等于空间位置正确

空间质量检查首先要区分“几何是否有效”和“位置是否准确”。

### 1. 几何有效性

几何有效性关注数据结构是否符合相应几何类型的基本要求，例如：

- 点是否具有有效坐标；
- 线是否具有足够节点，是否存在异常零长度；
- 面是否闭合，边界是否自相交；
- 多部件几何的组成是否符合格式要求；
- 几何类型是否与业务定义一致；
- 坐标值是否位于声明的坐标参考系范围内。

几何无效可能导致面积、长度、相交和缓冲分析失败，是很多空间计算的基础质量问题。

### 2. 空间位置准确性

几何结构合法，并不表示对象就在正确位置。例如：

- 道路整体偏移了数十米；
- 监测站点落在另一个区县；
- 地块边界与权威调查边界不一致；
- 坐标系标注错误，但坐标数值本身仍能形成合法图形；
- 低精度数据被用于需要高精度的工程分析。

位置准确性需要与权威基准、采集精度、比例尺、分辨率和目标用途共同判断。仅运行几何合法性检查，无法发现这些问题。

## 四、什么是空间拓扑规则

空间拓扑关注对象在连续变形下仍然保持的连接、邻接、包含和相交关系。在实际数据质量工作中，人们也经常把同类数据之间的空间结构约束称为拓扑规则。

常见规则包括：

- 同一行政层级的区域不应无故重叠；
- 需要完整覆盖的调查区域不应存在非预期缝隙；
- 道路或管线应按业务要求连通；
- 管线端点应在允许容差内衔接；
- 面边界不应自相交；
- 同一调查期、同一管理层级的地块不应重复覆盖；
- 河流中心线应保持必要的连续性和流向关系。

并非所有重叠、缝隙和悬挂点都是错误。例如：

- 飞地可能造成行政区域看起来不连续；
- 立交道路在平面上相交，但业务上并不连通；
- 地下管线可能在平面上交叉，却位于不同高程；
- 不同权利类型可能合法地存在空间重叠；
- 水域、争议区和数据范围边缘可能允许特定缝隙。

因此，拓扑规则必须包含业务适用条件，不能把所有几何关系都按一套固定规则处理。

## 五、什么是空间业务关系规则

有些规则不只是检查几何结构，而是把业务定义转化为空间关系、数量约束和属性条件。这类规则更准确地称为“空间拓扑与业务关系规则”。

### 1. 一个区域包含且只包含一个指定对象

例如，在适用的数据范围和行政层级内：

> 一个省级行政区面应包含且只关联一个对应的省会城市点。

这条规则实际包含多个条件：

- 省级行政区面与省会城市点使用可比较的空间参考；
- 城市点位于省域内部或符合边界处理约定；
- 城市点的行政区编码与省域编码匹配；
- 满足条件的城市点数量必须等于一；
- 特殊行政单元或例外情况需要有明确适用范围。

它不是简单运行一次“点在面内”计算，而是空间包含关系、属性一致性和数量约束的组合。

### 2. 点状设施必须位于对应线状网络上

例如：

> 收费站点应位于对应的收费道路上，或者在允许的位置误差范围内邻近道路，同时道路编码必须一致。

现实采集数据通常存在精度差异，不能机械要求点坐标与道路中心线绝对重合。规则可能需要配置：

- 允许距离，例如5米或其他业务认可范围；
- 适用的道路类型；
- 收费站和道路的关联编码；
- 上下行方向或出入口关系；
- 数据采集比例尺和位置精度；
- 不同时间版本是否一致。

### 3. 业务范围不得与限制范围相交

例如，建设项目红线不得与禁止建设区相交，或者相交面积不得超过允许阈值。这需要明确：

- 使用哪个版本的项目红线和限制范围；
- 边界接触是否算作相交；
- 面积小于某个容差是否属于数据误差；
- 哪些项目类型允许例外；
- 发现相交后是阻断审批还是进入人工核查。

### 4. 对象必须落在其业务归属范围内

例如：

- 建筑物应位于对应宗地范围内；
- 排水口应与排水管线或河道关联；
- 监测站应位于登记的管理区域内；
- 项目范围应与申报的行政区一致；
- 学校服务点应位于其服务区域或允许的邻近范围内。

这些规则体现了空间数据质量的一个重要特点：质量要求往往来自业务模型，而不是从几何字段本身自动推导出来。

## 六、为什么空间规则必须考虑容差、尺度和基准

空间关系很少能脱离精度和尺度进行绝对判断。

### 1. 容差

来自不同测绘、定位和业务系统的数据，可能存在合理的位置误差。收费站距离道路中心线0.5米通常不应立即判定为错误，但偏移500米显然需要核查。

容差应由业务用途、采集精度和数据尺度决定，不能为了让检查通过而随意放宽。

### 2. 比例尺和分辨率

小比例尺区域边界适合宏观统计，不一定适合工程放样；低分辨率遥感影像可以观察区域变化，却未必能识别细小建筑。

将不同尺度的数据叠加后看到边界不一致，并不能立即判断哪一方错误。

### 3. 坐标参考系和单位

参与空间检查的数据必须具有明确且可比较的坐标参考系。距离和面积规则还要明确计算单位和计算方法。

仅仅让数据在地图软件中“显示到一起”，不能证明它们已经具有一致的空间基准。

### 4. 权威基准和业务适用性

位置准确性必须说明与什么基准比较。道路导航数据、工程测量数据和国土调查数据面向不同用途，不能只凭图形细节多少判断谁更权威。

## 七、时间质量和时空一致性怎样检查

时空数据质量还要判断数据在时间上是否正确、连续并与空间版本匹配。

### 1. 时间字段的业务含义是否清楚

需要区分事件发生时间、观测时间、有效时间、入库时间和发布时间。使用处理时间代替业务发生时间，可能造成事件顺序和指标窗口错误。

### 2. 时间顺序是否合理

例如：

- 设施停用时间不应早于启用时间；
- 土地变更审核时间不应早于调查时间；
- 维修完成时间不应早于故障发生时间；
- 轨迹点的时间顺序应符合采集和移动过程。

### 3. 有效期是否重叠或断裂

同一业务对象的两个互斥状态不应在同一时间同时有效；需要连续管理的状态版本也不应出现无法解释的时间空档。

### 4. 空间版本与时间版本是否匹配

使用2025年的行政区边界统计2020年调查数据，可能改变历史统计结果。空间边界、地类标准、行政区划和业务状态必须按适用时间正确组合。

### 5. 对象变化是否能够衔接

地块分割、合并和边界调整后，应能够追溯变化前后的对象。不能只看到旧对象消失、新对象出现，却不知道面积和业务关系如何继承。

## 八、空间质量规则应该怎样设计

空间质量规则不宜为每个数据集单独编写一段固定程序。更可维护的方式，是把规则拆分为“规则模板”和“业务配置”。

### 1. 预定义通用规则模板

可预定义的能力包括：

- 几何有效、类型一致和坐标范围检查；
- 点在线上、点在面内、线在面内；
- 相交、包含、覆盖、邻接和接触；
- 距离不得超过或小于某个阈值；
- 面不得重叠、不得存在缝隙；
- 线必须连通、端点必须衔接；
- 一个对象包含指定数量的另一类对象；
- 属性面积与空间计算面积差异检查；
- 不同时间版本之间的变化和连续性检查。

这些模板只定义通用检查能力，不预设某个具体行业的数据名称和业务结论。

### 2. 将具体数据集绑定到规则模板

使用规则时，需要配置：

| 配置项 | 需要说明什么 |
| --- | --- |
| 主数据集 | 以哪个数据集作为主要检查对象 |
| 参照数据集 | 与哪个数据集比较或建立关系 |
| 空间字段 | 使用哪个几何或位置字段 |
| 空间关系 | 包含、相交、邻接、距离还是连通 |
| 数量约束 | 必须为一个、至少一个、不得存在或其他数量 |
| 属性条件 | 适用于哪些类型、状态、区域或业务编码 |
| 时间条件 | 使用哪个调查期、有效期或数据版本 |
| 容差和单位 | 允许多大距离、面积或边界误差 |
| 严重程度 | 失败后阻断、隔离、告警还是记录 |
| 责任与依据 | 规则由谁确认，来源于什么业务要求 |

“省级行政区包含一个省会城市”和“收费站位于收费道路上”，可以复用包含、数量和邻近等通用空间算子，但使用不同的数据集、条件、容差和处置策略。

### 3. 允许扩展行业规则

预定义模板不可能覆盖所有行业算法。例如，河网流向、管网连通、航道通航条件、矿区空间约束和复杂三维关系，可能需要专门算法。

扩展规则仍应纳入统一管理，至少记录：

- 规则名称、业务定义和适用范围；
- 输入数据类型和必要参数；
- 使用的算法或算子版本；
- 输出问题的结构和定位方式；
- 规则责任人、严重程度和处置策略；
- 测试样本和预期结果。

规则可以扩展，但不能成为无人理解、无法验证的黑盒程序。

## 九、质量检查结果应该保留哪些证据

空间质量检查不能只返回一个“通过率”或综合分数。每个问题至少应尽量记录：

- 违反了哪条规则；
- 规则的业务依据和版本；
- 涉及的数据集、数据版本和执行时间；
- 问题对象的业务标识和几何位置；
- 关联的参照对象；
- 实际距离、重叠面积、缝隙面积或对象数量；
- 使用的坐标参考系、容差和计算方法；
- 问题严重程度和影响范围；
- 处理状态、责任人和修复依据。

问题结果最好能够在地图上定位，但地图展示只是辅助。业务人员还需要知道为什么判错、影响什么统计或流程，以及应该由谁确认。

## 十、发现空间质量问题后应该怎样处理

处理原则与普通数据质量闭环一致，但空间问题需要特别避免“为了图形好看而直接修图”。

### 1. 先判断问题来自哪里

常见根因包括：

- 源头调查、测量或录入错误；
- 坐标参考系声明或转换错误；
- 不同精度和尺度数据被错误比较；
- 汇聚、格式转换或空间计算过程出错；
- 参与检查的数据版本或时间不匹配；
- 业务对象映射错误；
- 质量规则、容差或例外条件配置不当；
- 现实中确实存在需要业务确认的特殊情况。

### 2. 一般不要直接覆盖原始数据

技术人员可以生成标准化、修复或分析版本，但应保留原始数据、处理规则、前后差异和审批依据。涉及权属、规划、调查和审批事实的数据，更不能仅凭自动拓扑修复直接修改权威记录。

### 3. 根据业务影响分级处置

| 问题 | 可能处置 |
| --- | --- |
| 坐标系错误导致整批数据错位 | 隔离数据并阻断使用 |
| 地块重叠将造成面积重复统计 | 阻断正式统计成果发布并核查 |
| 关键设施落入错误行政区 | 阻断相关业务结果或转人工确认 |
| 点与道路存在小幅可解释偏差 | 告警、记录并按容差判断 |
| 低风险图形细节问题 | 记录并进入后续整改计划 |
| 规则误报或例外情况 | 调整规则或登记有期限的例外依据 |

### 4. 修复后重新验证下游影响

空间边界改变后，面积、空间关联、区域统计、指标和专题分析都可能变化。修复不能只重新运行原来的单条规则，还要根据血缘重新计算受影响的结果。

## 十一、案例：土地调查数据的质量规则怎样组合

某地区需要基于土地调查和年度变更数据统计各类用地面积，并支持后续用途管制和低效用地识别。

### 1. 普通属性规则

- 调查地块编码不能为空且在规定范围内唯一；
- 地类编码必须符合对应调查期的分类标准；
- 调查时间、来源和审核状态必须完整；
- 属性面积不能为负数；
- 行政区编码必须能够关联到有效行政区。

### 2. 几何与空间参考规则

- 地块必须为有效面几何；
- 坐标参考系必须明确；
- 几何应位于目标调查区域内；
- 空间计算面积与登记面积的差异不得超过业务容差。

### 3. 拓扑规则

- 同一调查期、同一管理层级的地块不应无故重叠；
- 要求完整覆盖的调查范围不应存在非预期缝隙；
- 地块不得超出对应行政区边界，边界接合误差应在允许范围内。

### 4. 业务空间关系规则

- 建设项目范围应与批准用地范围保持合理关系；
- 实际建设范围与禁止建设区相交时必须进入核查；
- 土地利用状态应与相关调查影像、项目和审批记录建立对应关系；
- 低效用地评价对象必须能够关联到明确地块和有效空间版本。

### 5. 时间与版本规则

- 年度变更数据必须说明相对哪个基准版本发生变化；
- 变更调查、审核和生效时间应符合业务顺序；
- 分割、合并后的新旧地块应保留演化关系；
- 历史统计必须使用当时有效的地类标准和空间边界。

这些规则共同决定统计结果是否可信。只检查地类字段非空，或者只运行面重叠检查，都不足以保证土地调查数据能够正确服务管理。

## 十二、与普通表格数据质量治理的异同

| 比较维度 | 普通表格数据 | 时空数据 |
| --- | --- | --- |
| 共同基础 | 完整性、准确性、一致性、唯一性、及时性和有效性 | 同样需要全部通用质量维度 |
| 单条记录 | 重点检查字段、值域和业务逻辑 | 还要检查几何结构和空间参考 |
| 数据间关系 | 主外键、编码和跨表勾稽 | 还要检查包含、相交、邻接、距离和连通 |
| 精度 | 数值精度和业务容差 | 还包括位置精度、比例尺和空间分辨率 |
| 时间 | 时间格式、顺序和鲜活度 | 还要关联空间版本、有效期和对象演化 |
| 问题定位 | 通常定位到表、字段和记录 | 还要定位到空间范围、关系对象和地图位置 |
| 修复影响 | 影响字段、记录、指标和下游任务 | 还可能改变面积、空间关系、区域统计和分析结果 |

两者使用的是同一套数据质量治理原则：从业务用途定义要求，形成可执行规则，保留问题证据，判断影响，修复根因并重新验证。时空数据只是增加了几何、空间关系和历史演化等专业维度。

## 十三、常见误区

### 误区一：空间质量就是检查坐标是否为空

坐标存在不代表位置正确，更不能说明对象之间的空间关系符合业务要求。

### 误区二：几何合法就代表数据正确

合法几何仍可能整体偏移、比例尺不适用、落在错误区域或关联错误业务对象。

### 误区三：所有重叠和缝隙都必须自动修复

部分关系可能是真实业务情况或合法例外。自动裁切可能改变权属、面积和历史事实。

### 误区四：空间规则可以脱离容差运行

不同来源和精度的数据通常不能要求坐标绝对一致。容差应由业务用途和采集精度决定。

### 误区五：通用空间算子就是完整业务规则

“包含”和“相交”只是计算能力。完整规则还需要数据角色、属性条件、数量、时间、容差和处置策略。

### 误区六：把数据绑定到规则以后永远不用调整

数据标准、调查范围、业务政策、数据版本和精度都会变化，规则配置同样需要版本和影响分析。

### 误区七：质量问题都由空间技术人员修复

空间技术人员可以定位和处理技术问题，但权属、规划、调查和业务关系是否正确，需要相应业务责任人确认。

### 误区八：地图上看不出问题就代表质量合格

细小重叠、时间版本错误、属性关联错误和空间基准差异，可能难以通过目视发现，却会显著影响计算结果。

## 十四、实践检查清单

1. 时空数据是否同时执行普通属性规则和空间专业规则？
2. 是否区分几何有效、位置准确、拓扑正确和业务关系正确？
3. 空间规则是否明确数据角色、关系、数量、属性条件、容差和适用时间？
4. 通用规则是否通过模板复用，行业特殊规则是否能够受控扩展？
5. 参与比较的数据是否使用可比较的空间参考、尺度、精度和版本？
6. 问题结果是否保留业务标识、空间位置、计算值、规则版本和影响范围？
7. 是否避免直接覆盖原始和权威数据，并保留修复依据与前后血缘？
8. 修复空间问题后是否重新计算受影响的关联、面积、指标和业务成果？

## 小结

时空数据质量建立在普通数据质量之上，但不能停留在字段非空、编码唯一和类型正确。几何是否合法、位置是否准确、对象之间是否符合空间拓扑和业务关系、历史版本是否连续，都会直接影响统计、分析和管理决策。

空间质量规则的关键，也不是预置尽可能多的检查名称，而是把业务要求拆解为可复用的空间算子和可配置的业务条件。规则模板提供包含、相交、邻接、距离、数量和连通等能力，具体场景再绑定数据集、属性条件、时间版本、容差和处置策略。

只有业务规则能够被准确配置、持续执行，问题能够被空间定位、追溯和闭环，时空数据才不仅“能够显示”，而是真正能够被可靠地用于面积统计、规划审批、设施管理、风险识别和业务决策。
