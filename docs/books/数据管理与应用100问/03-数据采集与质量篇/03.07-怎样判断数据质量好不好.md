# 怎样判断数据质量好不好？

判断数据质量好不好，很多人会先看检测报告：字段是否填全，编码有没有重复，各项检查通过了多少。这些结果当然有用。不过，有时报告里的通过率很高，业务人员拿到数据后，仍然不敢据此作出判断。这是为什么呢？

一个常见原因是，检查的内容没有覆盖业务真正关心的问题。因此，评价数据质量，可以先把业务人员需要作出的判断讲清楚，再确定哪些数据必须可靠、怎样检查，以及发现问题后会影响什么工作。

以下用一个地下管线数据质量评价的典型情境说明。一个项目已经汇集了多个提供方的管线和管点资料，准备分别供管理人员了解管线分布、供业务人员开展施工前的资料核查。项目团队配置了编码、字段和几何检查，检测报告显示，大部分记录都通过了检查。

业务人员复核时却发现，一段拟施工道路附近的资料可能没有收齐，有些管线虽然填写了埋深，但数值来源不明，还有一部分记录没有反映近期改迁情况。管理人员可以利用已确认范围内的数据了解分布，核查人员却无法仅凭这份报告，判断拟施工区域的管线资料是否可靠。

问题由此变得具体了：同一批数据用于不同工作，需要满足的条件不同；检查通过，也只说明通过了已经配置的那些规则。下面先说明怎样确定质量要求，再讨论检查哪些方面、怎样验证，以及如何把检测结果变成有明确范围的质量结论。

## 一、根据业务用途确定质量要求

“这批数据质量要好”还不足以指导检查。需要进一步说明，谁要用数据完成什么工作，哪些错误会影响判断。例如，了解已收集管线的大致分布，重点是把覆盖范围和管线类别说清楚；施工前的资料核查，还需要关注拟施工范围内是否漏收资料、位置和埋深是否有可信依据，以及改迁信息是否已经反映到数据中。

用途明确以后，应由业务人员与数据、技术人员共同确定检查要求。业务人员说明哪些信息影响判断，数据人员整理检查对象和依据，技术人员确认哪些可以自动检查、哪些需要另行核实。涉及位置精度等专业要求时，还应由相应专业人员确认，不能由平台团队随意设置一个阈值。

有些问题允许在说明限制后继续使用，有些问题会使当前用途无法成立。例如，缺少建设年份可能不影响浏览分布，却会影响按使用年限分析；关键区域的资料覆盖情况未核实，则不能因为其他区域数据齐全，就认定这一区域也没有遗漏。已有的专业要求仍需遵守，不能为了让检测通过而降低要求。

## 二、从不同方面检查数据，避免只看字段是否齐全

数据质量包含不同方面。一条记录可以填写完整、格式正确，同时又与实际情况不符。为了避免漏查，可以结合管线情境，把常见的检查重点列出来。

| 检查方面 | 要回答的问题 | 管线情境中的例子 |
| --- | --- | --- |
| 完整性 | 应有的记录、字段和关系是否齐全？ | 字段都填了，但某个提供方的一批资料没有汇入。 |
| 准确性 | 记录是否符合实际情况？ | 埋深有数值，但还需要核对测量依据。 |
| 一致性 | 同一对象的相关记录是否矛盾？ | 同一管段在两份资料中的材质不同，需要核对各自对应的时间和来源。 |
| 时效性 | 数据是否反映业务所需时点的情况？ | 文件刚上传，里面仍是改迁前的管线记录。 |
| 有效性 | 数据是否符合约定的格式和取值要求？ | 管线类别使用了约定之外的代码。 |
| 唯一性 | 应当唯一的对象或记录是否被重复登记？ | 同一管段被重复导入，统计长度因此增加。 |

这些方面相互补充，不能互相替代。两个系统中的埋深完全相同，可能只是共同复制了同一个错误值；类别代码都在允许范围内，也不能证明每条管线的类别填得正确。类似地，编号不同不一定就是不同管段，判断重复还需要核对对象身份。

表里的分类是为了帮助思考，不要求每个项目机械地配置相同数量的规则。对于当前业务不使用的字段，可以暂缓细查；对于会直接影响判断的对象、位置和状态，则应重点核实。空间位置、几何和连通关系的具体检查方法，后面的空间数据专题再展开。

## 三、把质量要求写成能够核对的检查规则

确定要检查完整性以后，还要说明“完整到什么范围”。如果只检查已收到的管线记录是否填写类别，就无法发现整批资料缺失。要检查资料是否收齐，团队还需要一份经确认的应交清单，逐一核对提供方、范围和批次。

一条可执行的规则，应说明检查哪些数据、依据什么要求、怎样判断，以及发现异常后交给谁核实。例如，某类管线必须填写埋深，规则就要限定适用类别，说明单位，以及什么情况下允许暂缺。不能把空白统一改成零，再把“字段已填写”当成合格。

自动检查适合发现缺项、非法代码、重复标识和明显矛盾，但对事实是否准确，往往还需要其他证据。一个埋深数值落在设定范围内，只能说明没有触发这条范围规则；是否符合实际，仍需结合测量记录或按业务要求开展的专业核验。原始资料本身是否可靠，也需要考虑。

同样，超出设定范围的数值也不一定就是错误。发现异常后，应先核对来源和适用条件。真实存在的特殊情况，应当说明原因并保留；规则不适用的，则应调整规则。不能为了减少异常数量，直接把数值改到允许范围内。

## 四、说明检测范围，谨慎解释通过率

自动化规则可以对约定范围内的数据逐条运行，需要人工查证的内容则往往采用抽查。抽查时，应覆盖不同提供方、资料年代和业务关注区域，不能只挑容易核对的记录。关键区域还可以增加针对性核查，但这种抽查结果不能直接当作全体数据的错误比例。

报告中应分清哪些内容查了全量、哪些只查了样本，以及哪些事实尚未核实。即使所有记录都通过了自动规则，也不能据此保证数据没有其他问题；某一批样本核对无误，也不能替其他批次作出保证。

通过率还要说明怎样计算。例如，“类别非空的记录占受检记录的比例”，与“全部规则都通过的记录占比”，反映的不是同一件事。前者甚至无法告诉读者，未收到的资料有多少。计算范围不清楚，一个很高的百分比也难以解释。

因此，整体比例之外，还要列出关键问题的位置和影响。拟施工范围内的一段管线信息未核实，即使只占全量数据很小的一部分，也可能影响本次资料核查。大量普通字段检查通过，不能抵消这一关键问题。

## 五、给出与用途对应的质量结论

质量报告最终应帮助使用者决定数据怎样使用。对管线情境，可以分别说明：哪些范围和类别已经确认，哪些记录可用于分布浏览，哪些区域仍缺少资料，哪些位置或埋深还需核验，以及这些限制会影响什么工作。这样的结论比笼统写“总体质量良好”更有用。

结论还应写明数据批次、检查时间和规则版本，并由相应责任人确认。业务人员看到“可用于分布浏览”，就不应把它理解成“已满足施工判断要求”。对于超出已确认用途的使用，需要重新核对条件。

后续补入资料、调整规则或更新管线状态时，原结论也要相应复核。这里先把质量要求和判断依据讲清楚；发现的问题如何修复、怎样防止再次发生，下一问再具体讨论。
