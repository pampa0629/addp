# 机器学习按学习信号可以怎样分类？

训练模型时，“给模型什么反馈”与“选什么模型”是两件事。业务人员要识别垃圾邮件，可以提供已经标好类别的邮件；如果业务人员还不知道邮件里有哪些类型的问题，就可能先让程序寻找相似邮件的分组。两种工作都在使用数据，却没有使用同一种学习信号。

## 已知答案与没有现成答案

**监督学习**利用带有目标结果的样本训练模型。垃圾邮件的类别、历史订单的实际配送时长，都是已知结果。模型先给出预测，训练程序再比较预测与已知结果，并调整模型。监督学习适合目标明确、可以取得可靠结果记录或人工标注的任务。

**无监督学习**没有为每个样本预先给出要预测的目标。聚类程序可以依据邮件的内容和行为特征，把相似邮件归到一起。程序找到的分组并不会自动变成“诈骗邮件”“促销邮件”等业务类别；业务人员仍要查看各组的内容，判断分组有没有用。没有标签不等于没有目标，开发者仍要定义要寻找什么结构、如何检查结果。

## 标签有限时怎样继续学习

**半监督学习**同时利用少量有标签数据和较多无标签数据。假如管理员只能认真标注一小部分邮件，模型可以先利用这些已标注邮件建立判断依据，再从大量未标注邮件中寻找更多有用信息。未标注数据如果与实际任务差异很大，或者模型把错误判断当作新标签，半监督方法也可能扩大错误。

**自监督学习**从原始数据本身构造训练目标。例如，训练程序遮住句子的一部分，让模型根据其余文字预测被遮住的内容；原始句子就提供了对照答案。这种训练不需要人为给每句话标上业务标签，但仍然有明确的预测目标和误差反馈。模型由此学到的表示，可以再用于后续的分类、检索或生成任务。自监督与无监督的术语边界在不同资料中并不完全一致；关键区别是训练信号来自人工给出的标签，还是来自数据自身构造的目标。

## 通过行动后的反馈学习

**强化学习**关注系统连续采取行动后得到的反馈。比如，在受控模拟环境中，调度系统尝试不同派车方案，环境根据送达效率和约束是否满足给出奖励或惩罚。系统要考虑一次选择对后续状态的影响。现实中的配送调度不能让系统随意试错；模拟环境是否可信、安全约束是否有效，决定了这种方法能否用于实际业务。

这些名称描述的是学习信号的来源，不是一套只能二选一的产品标签。同一个系统可以先用自监督方法学习表示，再用人工标注的数据调整模型；强化学习系统也可以使用神经网络表示策略。具体选择仍取决于任务、可用数据和错误代价。
