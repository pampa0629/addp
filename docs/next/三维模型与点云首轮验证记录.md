# 三维模型与点云首轮验证记录

## 范围

本记录用于沉淀 `model_3d` / `point_cloud` 首轮代表格式闭环结果，并作为后续 3D Tiles、OSGB、LAZ / COPC 等格式接入的基线。

## 已验证样例

| 样例 | 期望语义 | 验证结果 |
|---|---|---|
| `addp/3d/ABeautifulGame.glb` | `data_type=model_3d`、`layout=single`、`format=glb` | Manager 三维预览可渲染；属性页显示 `type_info.model_3d`、`format_info.glb` |
| `addp/pointcloud/简单房屋.las` | `data_type=point_cloud`、`layout=single`、`format=las` | 属性页显示 `type_info.point_cloud`、`capabilities.spatial`；Manager 点云预览链路具备 LAS 抽样能力 |

## 后续基线

- 3D Tiles 应按 `data_type=model_3d`、`layout=whole`、`format=3dtiles` 接入，`tileset.json` 只作为 manifest ref，不作为普通 JSON data item。
- OSGB 倾斜摄影仍归入 `model_3d`，通过 `model_kind=photogrammetry_scene` 和 `format=osgb` 区分，不新增平行 data type。
- LAZ / COPC、EPT / Potree 等点云格式仍归入 `point_cloud`，通过 format、layout、point_cloud_kind 和 capabilities 区分。
