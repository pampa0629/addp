# 三维、点云与高斯后续路线

已实现的格式身份、GLB/COPC/KSplat 快显、受控内容和相机生命周期已归入[内置格式规范](../spec/addp内置数据类型与文件格式规范.md)、[Manager 三维预览说明](../../manager/docs/三维模型、点云与高斯泼溅预览说明.md)及[快显规范](../../manager/docs/快显实现规范.md)。本文只保留新能力及未闭合验收，不重复当前能力或逐轮样例/镜像/CI 记录。

## 后续能力

| 方向 | 进入实现前的条件与未完成范围 |
| --- | --- |
| SGM | 已支持静态几何与基础像素 alpha；正式许可 Linux T4 由[格式待办](common-format格式完善矩阵.md)唯一跟踪。其他材质封装、目录布局、源 AlphaFunc/颜色因子、透明排序与朝向/CRS 不外推 |
| 普通模型 | DAE/3DS 首期静态基础贴图已落地；更多版本、动画/复杂材质、未知 MAX/SKP 输入须独立样例和失败语义，不另建转换服务 |
| IFC / BIM | 构件标识、属性、空间/楼层树、选择查询及属性服务；不由 IFC→GLB 几何快显推断语义保真 |
| 3MX | 先确定 refs/目录 manifest、whole scope、几何/贴图和源资源生命周期，再决定原生预览或通用转换 |
| SLPK / I3S | 明确 ZIP/container 与场景层类型、属性/贴图、range、版本/许可和稳定 whole 身份 |
| STL 包 | 明确多文件组合、单位/坐标与属性资源关系；单体几何成功不代表项目包支持 |
| 原始点云 | LAS/LAZ/E57/PCD/XYZ→受管 COPC 主线已有；继续按实际样例补字段、坐标、容量和异常边界，不恢复普通 LAZ/E57 浏览器解析旁路 |
| EPT / Potree | 定义 whole manifest、分块边界与真实样例，明确原生预览/转 COPC 的唯一选择；不得伪装为单个 JSON 或 COPC |
| 城市级点云 / 3D Tiles | 有明确规模、坐标、分层与发布场景后再推进，不以单文件快显扩张为城市数据集认证 |
| SPZ | 完成版本/压缩语义、必要 reader 或转换与真实样例前只承认格式身份 |
| KSplat / Gaussian 优化 | 渐进加载、可见性与大场景预算有真实需求后定义；不因能打开小样例宣称流式能力 |

## 统一约束

模型、点云、高斯各自保持唯一通用转换和 renderer 路线，Runtime 输入/输出契约不解析 ADDP locator；Manager 拥有结果任务、权限、缓存及清理。公开样例和私有 SDK 资源分开，厂商文件不进入公开仓库或无许可 Hosted。

新增格式或依赖先核对 common/format、Meta、Manager、Transfer 和 Runtime 的已有能力，避免后缀/引擎特例；新实现完成时删除旧路径并同步构建、镜像、测试和 CI 自动发现。

## 验证与维护

采用 `make test-module MODULE=manager`、相应 Runtime 标准入口与已登记 Manager Hosted suite；涉及 Three.js/共享 renderer 时扩散实际消费者。完整门禁、分项、本地样例、许可 SDK 测试及真实 Hosted 分别记录，产物可打开不代替几何/贴图/透明度/源字节/物理清理验证。

当前优先补许可环境 SGM 跨模块验收，再按真实需求选择 BIM 或 EPT，不继续追踪已解决的秋树/Assimp 旧故障。完成约定回写正式文档并从本清单移除。
