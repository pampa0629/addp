# 栅格算子后续事项与验收

已实现的算子、资源对象、切片、失败成果及额度管理迁入[栅格计算与成果契约规范](../spec/addp栅格计算与成果契约规范.md)。本专题只保留进行中切片、最终验收及缺口，不再保存逐场景像元值、字节数、性能采样和 CI 流水。

## 一、DEM 基础地形分析（实施中）

新增 `raster_slope`、`raster_aspect`、`raster_hillshade`、`raster_contour` 四项，仍由 GeoPython Workflow 执行。前三项输出 raster，沿原 COG 保存主路径；等值线输出已有 GeoDataFrame，可接现有矢量保存节点。仅支持明确高程单位的投影北向无旋转网格，单位、Horn 邻域、边缘、无效覆盖、平坦坡向及空等值线规则以正式契约为准。

Native 使用独立倾斜平面、横纵不等分辨率、米／国际英尺／美制测量英尺、NoData／mask／alpha、跨块邻域和矢量几何验证；四项包含真实异步 DAG、保存与工作目录清理回归。Hosted 在全部原场景之后追加三份 COG 和等值线 JSON 预览，保存原 45 个对象的哈希，逐一核对原成果、新成果及源不可变，不把预览算作等值线持久化扫描。当前新增 Hosted 结果尚未取得，不计为验收完成。
