## 一、DEM 基础地形分析的验收范围

已实现 `raster_slope`、`raster_aspect`、`raster_hillshade`、`raster_contour` 四项，由 GeoPython Workflow 执行。前三项输出 raster，沿原 COG 保存主路径；等值线输出已有 GeoDataFrame，可接现有矢量保存节点。仅支持明确高程单位的投影北向无旋转网格，单位、Horn 邻域、边缘、无效覆盖、平坦坡向及空等值线规则以正式契约为准。

Native 使用独立倾斜平面、横纵不等分辨率、米／国际英尺／美制测量英尺、NoData／mask／alpha、跨块邻域和矢量几何验证；四项包含真实异步 DAG、保存与工作目录清理回归。Hosted 在全部原场景之后追加三份 COG 和等值线 JSON 预览，保存原 45 个对象的哈希，逐一核对原成果、新成果及源不可变，不把预览算作等值线持久化扫描。原 Raster Hosted T4 已完整通过，四项均实际执行；页面逐项配置高程单位、波段及指定等值线高程，并核对真实画布参数，无任务创建或更新。前三项完成 COG 保存、自动扫描和资源级血缘，等值线完成计算及 JSON 预览；等值线另由独立 Hosted 套件完成 NFS 单文件 GeoPackage 保存、自动扫描和资源级血缘，两类入口的验收范围分别记账。
