# 栅格算子：当前能力与待验事项

本专题只维护当前结论、未完成事项和必要的固定版本证据。算法、参数及边界以[栅格算子契约](../spec/workflow/栅格算子契约.md)为准；成果与资源管理见[成果契约](../spec/addp栅格计算与成果契约规范.md)，算子清单见[Runtime目录](../../engines/geopython-workflow/operators/README.md)，独立验收范围见[测试场景](../spec/testing/scenarios/Manager与空间成果.md)。

## 一、当前能力

当前主线已有65个工作流栅格算子，分14个二级目录，每个算子只保留一个入口。分类由Runtime声明，Develop直接消费；不按名称重新归类或复制入口。

| 能力 | 已实现范围 |
| --- | --- |
| 数据与网格 | 读写、切片、多选构图、裁剪、镶嵌、局部更新、重投影、重采样、网格对齐、波段组合与选择、COG及金字塔。 |
| 分类与统计 | 波段表达式、重分类、众数、蚕食、边界清理、小斑块筛除、连通斑块编号、细化、聚合、点位／沿线栅格采样、栅格／矢量面分区分类频数、整幅／邻域与栅格／矢量分区统计、线性百分位及矢量面覆盖面积加权、邻域分类种类数、直方图、OIF三波段建议。 |
| 距离与连续面 | 方形／矩形像元邻近距离、点数据IDW插值及米制圆形点密度／四次核密度；IDW模板仅定义网格与CRS，不继承像元／mask／alpha，幂次1／2／3（默认2）与显式米制半径。 |

## 分类蚕食容量验收

最新固定`2548622bc`的[容量运行39451034097](https://github.com/pampa0629/addp/actions/runs/39451034097/job/118725574629)已审计通过：4096²／10980²、稀疏／密集供体、串行／双任务，共8组16条保存链；默认入口Runtime限4CPU／2GiB、无额外swap、缓存64MiB，原普通用户12权限。业务1748336毫秒，小于10800秒预算；完整核对1098700928个像元及mask，三方大小、扫描血缘、策略恢复和清理通过。

OOM／OOM kill／swap使用均为0，但10980²各组触及内存上限，记录峰值2048.004MiB；双任务未表现一致加速，不提高默认并发、不承诺稳定吞吐或任意输入。双任务私有逻辑／分配峰值约7.186／7.190GiB；当前保守预检为运行任务数×像元数×64字节＋2GiB，10980²双任务约需16.37GiB可用空间。较早`d12960c06`的独立固定结果见[测试场景](../spec/testing/scenarios/Manager与空间成果.md#分类蚕食容量的固定版本证据)，不混用资源口径。

## 距离计算的临时磁盘保护验收

蚕食／邻近距离共用按文件系统区分的进程内空间账本，每个文件系统保留2GiB；距离计算和受保护编码前检查，不足或容量不可读明确失败，COG临时目录限制在当前执行工作区并线程局部还原。它不是配额、物理预分配或跨进程锁，不保证外部写入及全DAG永不耗尽空间。

固定`2548622bc`的[Linux Native](https://github.com/pampa0629/addp/actions/runs/39450992979/job/118725425365)全量1705项和[Platform一致性](https://github.com/pampa0629/addp/actions/runs/39450992979/job/118725425201)已通过；[邻近距离Hosted](https://github.com/pampa0629/addp/actions/runs/39451009799/job/118725491900)、[蚕食保存Hosted](https://github.com/pampa0629/addp/actions/runs/39451024248/job/118725539082)及上述容量验收已完成严格原始归档审计。真实低磁盘拒绝与释放恢复属于单独`raster-disk-pressure`，尚无本文已审计通过的Hosted终态，不能用容量成功或Native注入替代。
