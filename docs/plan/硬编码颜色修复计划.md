## 🆕 v2.0 更新说明

### 核心改进

相比 v1.0 版本，本次优化重新组织了修复策略，实现了：

1. **效率提升 20%**: 29h → 27h
   - 按技术难度分层，而非按模块逐个修复
   - 批量替换优先，快速消除 63% 硬编码

2. **可操作性增强**:
   - 增加详细的 VSCode 批量替换指南
   - 提供自动化脚本（审计、提交、测试）
   - 明确的验收标准和检查清单

3. **风险可控**:
   - 分支隔离 + Git tag 备份
   - 每个阶段有独立的回滚方案
   - 分模块提交，便于局部回滚

4. **自动化程度提升**:
   - 批量提交脚本
   - Git pre-commit hook 阻止新增硬编码
   - 主题测试工具和进度仪表板

## 📝 六、注意事项

### 6.1 不需要替换的颜色

以下颜色**不需要**替换为 CSS 变量：

1. **透明度相关** - `rgba()` 中的基础色可能需要保留
2. **特定语义颜色** - 如状态指示灯的红/绿/黄（不受主题影响）
3. **数据可视化** - 图表中的数据系列颜色（除非影响可读性）
4. **地图标记** - OpenLayers/高德地图的标记颜色
5. **Logo 和品牌色** - 固定的品牌标识颜色

### 6.2 特殊组件处理

#### Canvas/SVG 组件
- 需要监听主题变化事件
- 主题切换时重新绘制
- 使用 `getComputedStyle` 动态获取颜色

#### 第三方库
- Echarts - 使用主题模式 (`init(dom, 'dark')`)
- OpenLayers - 需要修改 Style 配置
- 高德地图 - 需要修改 marker/polyline 配置

### 6.3 测试要点

修复后需要测试：

 * 主题切换测试工具

export const testAllThemes = async () => {
  const themes = ['light', 'dark', 'blue']
  const results = []

  for (const theme of themes) {
    console.log(`🎨 测试主题: ${theme}`)

    // 切换主题
    document.documentElement.setAttribute('data-theme', theme)
    if (theme === 'dark') {
      document.documentElement.classList.add('dark')
    } else {
      document.documentElement.classList.remove('dark')
    }

    // 等待 CSS 过渡完成
    await new Promise(resolve => setTimeout(resolve, 300))

    // 检查关键 CSS 变量
    const checks = {
      textPrimary: getCssVar('--addp-text-primary'),
      textSecondary: getCssVar('--addp-text-secondary'),
      bgPrimary: getCssVar('--addp-bg-primary'),
      bgSecondary: getCssVar('--addp-bg-secondary'),
      borderColor: getCssVar('--addp-border-color'),

    )

### 8.5 Git Hook - 阻止新增硬编码

**创建文件**: `.git/hooks/pre-commit`

```bash
#!/bin/bash
# 检查暂存区是否有新增硬编码颜色

echo "🔍 检查硬编码颜色..."

# 检查 .vue 文件中的硬编码颜色（排除 CSS 变量）
HARDCODED=$(git diff --cached --name-only | grep -E '\.(vue|js|ts)$' | xargs grep -Hn '#[0-9a-fA-F]\{3,6\}' | grep -v 'var(--' | grep -v '//.*#' || true)

if [ -n "$HARDCODED" ]; then
  echo "❌ 发现新增硬编码颜色:"
  echo "$HARDCODED"
  echo ""
  echo "请使用 CSS 变量代替硬编码颜色:"
  echo "  文本: var(--addp-text-primary/secondary/tertiary)"
  echo "  背景: var(--addp-bg-primary/secondary)"
  echo "  边框: var(--addp-border-color)"
  echo "  主题色: var(--el-color-primary/success/danger/warning)"
  echo ""
  echo "如需强制提交，请使用: git commit --no-verify"
  exit 1
fi

echo "✅ 无硬编码颜色"
exit 0
```
