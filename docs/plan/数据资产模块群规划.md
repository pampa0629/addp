# 数据资产模块群规划（历史入口）

原规划形成于企业资源目录模块建立之前，其中“Asset 直接从 Meta / Service / Standard / Develop 发现来源”的设计已经废止，不能作为当前实现依据。

当前唯一有效路线是：专业模块 owner → CatalogEntry → AssetComponent → Asset → Portal。业务元数据、稳定关联、模块边界和迁移决策见：

- [ADDP 企业资源目录能力专题](../next/ADDP企业资源目录能力专题.md)
- [ADDP 企业资源目录实现规范](../spec/addp企业资源目录实现规范.md)

Asset 负责可申请、可授权、可运营的数据产品；Portal 只消费已发布 Asset。两者都不直接调用专业模块发现或解析来源引用。
