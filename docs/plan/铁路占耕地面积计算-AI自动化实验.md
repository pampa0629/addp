# 铁路两侧耕地面积计算的 AI 自动化实验

状态：业务验收设想，尚未形成本文可追溯的完成证据。

## 原始目标

用户用自然语言指定已管理的数据，计算铁路两侧各五十米范围内的耕地面积；先分析现有 ADDP 能力和不足，再在确认范围后补齐能力并提供自然语言入口。

## 实施前需确定

- 铁路与耕地的真实来源身份、版本、访问权限和完整范围，不从 data 目录中的相似文件名猜选。
- CRS、距离/面积单位、两侧缓冲的范围与端点处理、重复面及无效几何口径；先确定统一计算语义，再选实际支持该语义的 Runtime。
- 输出粒度、面积精度、保存位置、覆盖策略，以及用户只要计算草稿还是授权真实执行。

## 两个阶段

1. 用正式 Meta/Manager 事实核对数据和能力；明确缓冲、相交、去重与面积计算所需的实际算子契约，复用现有 Develop 工作流，不新增本地文件读取或业务专用计算旁路。
2. 确认后由 Agent 沿 Skill → ToolExecutor → SDK → owner API 生成并核对任务，再按用户当次授权运行；身份、参数、执行和结果证据可追溯，不以模型文本代替真实计算。

## 验收与维护

固定小型夹具独立核对缓冲、几何处理与面积，再验证同一真实 User 的数据选择、工作流执行、结果与清理。Agent 验证遵循[智能体评测规范](../spec/addp智能体评测规范.md)，计算与部署使用实际 owner 的标准门禁。完成的通用能力回写正式规范，本文件仅保留尚未闭合的业务场景，不追加对话和操作流水。
