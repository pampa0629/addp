# ADDP 数据库插件系统

## 概述

ADDP 平台采用插件化架构支持多种数据库和存储引擎。通过统一的接口抽象，可以轻松扩展新的数据库类型，实现"简单不重复"的改动即可支持新数据库。

---

## 当前支持的数据库类型

截至 **v0.0.18** (2025-12-25)，ADDP 平台支持 **8 种**数据库/存储引擎：

### 关系型数据库 (OLTP/OLAP)

| 数据库 | 类型 | 默认端口 | 驱动 | 用途 |
|--------|------|----------|------|------|
| **PostgreSQL** | OLTP | 5432 | github.com/lib/pq | 系统主数据库，存储用户、资源、元数据等 |
| **MySQL** | OLTP | 3306 | github.com/go-sql-driver/mysql | 通用关系型数据库 |
| **Apache Doris** | HTAP | 9030 | go-sql-driver (MySQL兼容) | 实时分析数据库，支持OLAP查询 |
| **ClickHouse** 🆕 | OLAP | 9000 | github.com/ClickHouse/clickhouse-go/v2 | 高性能列式存储，适合大数据量分析 |

### NoSQL 数据库

| 数据库 | 类型 | 默认端口 | 驱动 | 用途 |
|--------|------|----------|------|------|
| **MongoDB** 🆕 | 文档型 | 27017 | go.mongodb.org/mongo-driver | 文档型NoSQL数据库，支持灵活Schema |

### 计算引擎

| 引擎 | 类型 | 默认端口 | 驱动 | 用途 |
|------|------|----------|------|------|
| **Spark SQL** | 分布式计算 | 10000 | github.com/beltran/gohive | 大数据分布式查询引擎 |

### 对象存储

| 存储 | 类型 | 默认端口 | 驱动 | 用途 |
|------|------|----------|------|------|
| **MinIO** | 对象存储 | 9000 | github.com/minio/minio-go | S3兼容的对象存储，存储文件和二进制数据 |
| **Amazon S3** | 对象存储 | 443 | github.com/minio/minio-go | AWS云对象存储 |

## 架构设计

### 三层架构

```
┌─────────────────────────────────────────┐
│   应用层 (Manager/Meta/Develop模块)      │
│   - 调用 dbbridge 统一接口              │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│   DBBridge Facade (common/dbbridge/)    │
│   - 提供统一的API封装                   │
│   - 自动导入所有插件                    │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│   Plugin Factory & Registry             │
│   (common/database/plugin/)             │
│   - 插件注册表（线程安全）               │
│   - 统一工厂方法                        │
│   - 连接池管理                          │
└──────────────┬──────────────────────────┘
               │
┌──────────────▼──────────────────────────┐
│   具体插件实现                           │
│   (common/database/plugins/*)           │
│   - PostgreSQL、MySQL、Doris...         │
│   - 每个插件独立实现接口                 │
└─────────────────────────────────────────┘
```

### 核心接口

#### 1. DatabasePlugin (基础接口，所有插件必须实现)

```go
type DatabasePlugin interface {
    Type() string                                    // 类型标识 (如 "clickhouse")
    DisplayName() string                             // 显示名称 (如 "ClickHouse")
    ConnectionCategory() string                      // 分类 (relational_db/compute_engine/object_storage)
    TestConnection(ctx, connInfo) error             // 测试连接
    BuildConnectionString(connInfo) (string, error) // 构建DSN
    ValidateConnectionInfo(connInfo) error          // 验证连接信息
    DefaultPort() int                               // 默认端口
    RequiredFields() []string                       // 必填字段
    SensitiveFields() []string                      // 敏感字段
    GenerateCapabilities() string                   // 能力描述JSON
}
```

#### 2. ConnectionPoolPlugin (连接池支持，SQL数据库实现)

```go
type ConnectionPoolPlugin interface {
    DatabasePlugin
    CreateConnectionPool(connInfo, poolConfig) (*gorm.DB, error)
    GetDialect() string
}
```

#### 3. MetadataPlugin (元数据查询，扩展 ConnectionPoolPlugin)

```go
type MetadataPlugin interface {
    ConnectionPoolPlugin
    ListSchemas(ctx, db) ([]SchemaInfo, error)
    ListTables(ctx, db, schema) ([]TableInfo, error)
    ListColumns(ctx, db, schema, table) ([]ColumnInfo, error)
    GetTableRowCount(ctx, db, schema, table) (int64, error)
}
```

#### 4. ObjectStoragePlugin (对象存储)

```go
type ObjectStoragePlugin interface {
    DatabasePlugin
    DefaultBucket() string
    SupportsSSL() bool
}
```

1. **必改文件** (3个):

   - `/common/database/plugins/<dbtype>/type_mapper.go` - 自定义类型映射

## 数据库选型建议

根据不同场景选择合适的数据库：

| 场景 | 推荐数据库 | 原因 |
|------|-----------|------|
| 系统元数据存储 | **PostgreSQL** | 事务支持、可靠性高、功能完善 |
| 用户上传的结构化数据 | **PostgreSQL** / **MySQL** | 兼容性好、生态成熟 |
| 实时数据分析 | **ClickHouse** | 列式存储、查询速度快、适合大数据量 |
| 即席查询 (Ad-hoc) | **Doris** | HTAP能力、支持实时写入和查询 |
| 大数据批处理 | **Spark SQL** | 分布式计算、支持海量数据 |
| 文件存储 (Shapefile/GeoJSON) | **MinIO** | S3兼容、开源、易部署 |
| 半结构化数据 | **MongoDB** (待支持) | 文档型、灵活schema |

## 工具函数

### 1. 类型映射

```go
// 使用通用映射表（推荐）
stdType := plugin.MapToStandardType("varchar")  // 返回 "string"
stdType := plugin.MapToStandardType("bigint")   // 返回 "integer"

// 使用自定义映射表
customMappings := []plugin.TypeMapping{
    {DBTypes: []string{"hll", "bitmap"}, StdType: plugin.StdTypeBinary},
}
stdType := plugin.MapToStandardTypeWithCustom("hll", customMappings)
```

### 2. DSN 构建

```go
// MySQL 风格（MySQL、Doris、TiDB）
dsn := plugin.MySQLStyleDSN(user, password, host, port, database, map[string]string{
    "parseTime": "true",
    "timeout":   "10s",
})

// PostgreSQL 风格
dsn := plugin.PostgreSQLStyleDSN(user, password, host, port, database, "disable")

// ClickHouse 风格
dsn := plugin.ClickHouseStyleDSN(user, password, host, port, database, map[string]string{
    "dial_timeout": "10s",
})

// MongoDB 风格
dsn := plugin.MongoDBStyleDSN(user, password, host, port, database)
```

### 3. 连接信息提取

```go
host := plugin.NormalizeHost(plugin.GetString(connInfo, "host"))
port := plugin.GetInt(connInfo, "port")
user := plugin.GetString(connInfo, "user")
password := plugin.GetString(connInfo, "password")
```

## 开发指南

### 如何添加新的数据库类型

详细步骤请参考：[docs/如何添加新数据库类型.md](./如何添加新数据库类型.md)

**快速步骤**:

1. 创建插件目录和实现文件
   ```bash
   mkdir -p /common/database/plugins/<dbtype>
   # 编写 plugin.go，实现 DatabasePlugin 接口
   ```

2. 在 dbbridge 中注册
   ```go
   // /common/dbbridge/bridge.go
   import _ "github.com/addp/common/database/plugins/<dbtype>"
   ```

3. 添加测试用例
   ```go
   // /common/database/plugins/integration_test.go
   {"<dbtype>", "Display Name"},
   ```

4. 构建和测试
   ```bash
   cd common
   go mod tidy
   go build ./...
   go test ./database/plugins/integration_test.go -v
   ```
