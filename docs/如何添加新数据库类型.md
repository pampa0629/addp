# 如何添加新的数据库类型

本文档指导如何在 ADDP 平台中添加新的数据库类型支持。

## 📋 快速概览

添加新数据库类型通常只需要以下几步：

1. **创建插件目录和实现文件**（150-400 行代码）
2. **在 dbbridge 中注册导入**（1 行代码）
3. **添加集成测试**（6-10 行代码）
4. **更新文档**（可选）

**总工作量：2-6 小时**

---

## 🏗️ 架构概览

ADDP 的数据库抽象基于插件化架构：

```
应用层 (System/Manager/Meta模块)
    ↓ 调用
DBBridge Facade (/common/dbbridge/)
    ↓ 委托
Plugin Factory & Registry (/common/database/plugin/)
    ↓ 实例化
具体插件实现 (/common/database/plugins/*)
```

### 核心接口

所有插件必须实现 `DatabasePlugin` 接口（10个基础方法）：

```go
type DatabasePlugin interface {
    Type() string                                    // 数据库类型标识（如 "clickhouse"）
    DisplayName() string                             // 显示名称（如 "ClickHouse"）
    ConnectionCategory() string                      // 连接类别（relational_db/compute_engine/object_storage）
    TestConnection(ctx, connInfo) error             // 测试连接
    BuildConnectionString(connInfo) (string, error) // 构建连接字符串
    ValidateConnectionInfo(connInfo) error          // 验证连接信息
    DefaultPort() int                               // 默认端口
    RequiredFields() []string                       // 必填字段
    SensitiveFields() []string                      // 敏感字段（如password）
    GenerateCapabilities() string                   // 生成能力描述JSON
}
```

### 可选接口（根据数据库类型选择实现）

**1. SQLDatabasePlugin**（SQL 数据库标记接口）
```go
type SQLDatabasePlugin interface {
    DatabasePlugin
    SupportsTransactions() bool
    DefaultDialect() string
}
```

**2. ConnectionPoolPlugin**（连接池支持）
```go
type ConnectionPoolPlugin interface {
    DatabasePlugin
    CreateConnectionPool(connInfo, poolConfig) (*gorm.DB, error)
    GetDialect() string
}
```

**3. MetadataPlugin**（元数据查询，扩展 ConnectionPoolPlugin）
```go
type MetadataPlugin interface {
    ConnectionPoolPlugin
    ListSchemas(ctx, db) ([]SchemaInfo, error)
    ListTables(ctx, db, schema) ([]TableInfo, error)
    ListColumns(ctx, db, schema, table) ([]ColumnInfo, error)
    GetTableRowCount(ctx, db, schema, table) (int64, error)
}
```

**4. ObjectStoragePlugin**（对象存储）
```go
type ObjectStoragePlugin interface {
    DatabasePlugin
    DefaultBucket() string
    SupportsSSL() bool
}
```

## 🚀 实施步骤

### 步骤 1：创建插件目录结构

在 `/common/database/plugins/` 下创建新目录：

```bash
mkdir -p /common/database/plugins/<dbtype>/
cd /common/database/plugins/<dbtype>/
```

### 步骤 2：实现插件文件

创建 `plugin.go`，参考以下模板：

```go
package <dbtype>

import (
    "context"
    "database/sql"
    "fmt"
    "time"

    "github.com/addp/common/database/plugin"
    _ "<driver_import>" // 导入数据库驱动
    "<gorm_driver_import>" // 导入 GORM 驱动（如果支持）
    "gorm.io/gorm"
)

// <DBType>Plugin 实现
type <DBType>Plugin struct{}

// init 函数自动注册插件
func init() {
    plugin.Register(&<DBType>Plugin{})
}

// ========== 实现 DatabasePlugin 接口 ==========

func (p *<DBType>Plugin) Type() string {
    return "<dbtype>"
}

func (p *<DBType>Plugin) DisplayName() string {
    return "<Display Name>"
}

func (p *<DBType>Plugin) ConnectionCategory() string {
    // 选择：relational_db / compute_engine / object_storage
    return "relational_db"
}

func (p *<DBType>Plugin) DefaultPort() int {
    return <默认端口>
}

func (p *<DBType>Plugin) RequiredFields() []string {
    return []string{"host", "user", "database"}
}

func (p *<DBType>Plugin) SensitiveFields() []string {
    return []string{"password"}
}

func (p *<DBType>Plugin) GenerateCapabilities() string {
    return `{"storage":[{"type":"relational_db","engine":"<dbtype>","supports_query":true}],"compute":[{"type":"sql_query","description":"SQL查询","dev_modes":["sql"]}]}`
}

func (p *<DBType>Plugin) ValidateConnectionInfo(connInfo plugin.ConnectionInfo) error {
    return plugin.ValidateRequiredFields(connInfo, p.RequiredFields())
}

func (p *<DBType>Plugin) BuildConnectionString(connInfo plugin.ConnectionInfo) (string, error) {
    host := plugin.NormalizeHost(plugin.GetString(connInfo, "host"))
    port := plugin.GetInt(connInfo, "port")
    if port == 0 {
        port = p.DefaultPort()
    }

    user := plugin.GetString(connInfo, "user")
    password := plugin.GetString(connInfo, "password")
    database := plugin.GetString(connInfo, "database")

    if host == "" || user == "" {
        return "", fmt.Errorf("missing required connection info")
    }

    // 根据数据库类型构建 DSN
    // 可使用 plugin.MySQLStyleDSN / plugin.PostgreSQLStyleDSN 等工具函数
    return fmt.Sprintf("<DSN格式>"), nil
}

func (p *<DBType>Plugin) TestConnection(ctx context.Context, connInfo plugin.ConnectionInfo) error {
    connStr, err := p.BuildConnectionString(connInfo)
    if err != nil {
        return fmt.Errorf("failed to build connection string: %w", err)
    }

    db, err := sql.Open("<driver_name>", connStr)
    if err != nil {
        return fmt.Errorf("failed to open connection: %w", err)
    }
    defer db.Close()

    testCtx, cancel := context.WithTimeout(ctx, 10*time.Second)
    defer cancel()

    if err := db.PingContext(testCtx); err != nil {
        return fmt.Errorf("failed to ping database: %w", err)
    }

    return nil
}

// ========== 实现可选接口（根据需要） ==========

// ConnectionPoolPlugin 接口
func (p *<DBType>Plugin) CreateConnectionPool(connInfo plugin.ConnectionInfo, poolConfig *plugin.PoolConfig) (*gorm.DB, error) {
    connStr, err := p.BuildConnectionString(connInfo)
    if err != nil {
        return nil, fmt.Errorf("failed to build connection string: %w", err)
    }

    db, err := gorm.Open(<gorm_driver>.Open(connStr), &gorm.Config{
        DisableAutomaticPing: false,
    })
    if err != nil {
        return nil, fmt.Errorf("failed to create gorm connection: %w", err)
    }

    sqlDB, err := db.DB()
    if err != nil {
        return nil, fmt.Errorf("failed to get underlying sql.DB: %w", err)
    }

    sqlDB.SetMaxOpenConns(poolConfig.MaxOpenConns)
    sqlDB.SetMaxIdleConns(poolConfig.MaxIdleConns)
    sqlDB.SetConnMaxLifetime(poolConfig.ConnMaxLifetime)

    return db, nil
}

func (p *<DBType>Plugin) GetDialect() string {
    return "<dialect_name>"
}

// MetadataPlugin 接口（参考 postgresql/plugin.go 实现）
func (p *<DBType>Plugin) ListSchemas(ctx context.Context, db *gorm.DB) ([]plugin.SchemaInfo, error) {
    // 实现 schema 列表查询
}

func (p *<DBType>Plugin) ListTables(ctx context.Context, db *gorm.DB, schema string) ([]plugin.TableInfo, error) {
    // 实现表列表查询
}

func (p *<DBType>Plugin) ListColumns(ctx context.Context, db *gorm.DB, schema, table string) ([]plugin.ColumnInfo, error) {
    var columns []plugin.ColumnInfo

    // 查询列信息...

    // 使用通用类型映射工具
    for i := range columns {
        columns[i].StdType = plugin.MapToStandardType(columns[i].DataType)
    }

    return columns, nil
}

func (p *<DBType>Plugin) GetTableRowCount(ctx context.Context, db *gorm.DB, schema, table string) (int64, error) {
    // 实现行数统计查询
}
```

### 步骤 5：类型映射（可选）

如果数据库有特殊类型，可以：

**选项 A：使用通用映射工具**（推荐）
```go
columns[i].StdType = plugin.MapToStandardType(columns[i].DataType)
```

**选项 B：自定义映射表**
```go
customMappings := []plugin.TypeMapping{
    {DBTypes: []string{"特殊类型1", "特殊类型2"}, StdType: plugin.StdTypeString},
}
columns[i].StdType = plugin.MapToStandardTypeWithCustom(columns[i].DataType, customMappings)
```

## 🛠️ 常用工具函数

### 1. 连接信息提取

```go
host := plugin.NormalizeHost(plugin.GetString(connInfo, "host"))
port := plugin.GetInt(connInfo, "port")

password := plugin.GetString(connInfo, "password")

```

### 2. 字段验证

```go
err := plugin.ValidateRequiredFields(connInfo, p.RequiredFields())
```

### 3. DSN 构建

```go
// MySQL 风格（MySQL、Doris、TiDB）
dsn := plugin.MySQLStyleDSN(user, password, host, port, database, map[string]string{
    "parseTime": "true",
    "timeout": "10s",
})

// PostgreSQL 风格
dsn := plugin.PostgreSQLStyleDSN(user, password, host, port, database, "disable")

// ClickHouse 风格
dsn := plugin.ClickHouseStyleDSN(user, password, host, port, database, map[string]string{
    "dial_timeout": "10s",
})
```

### 4. 类型映射

```go
// 使用通用映射表（推荐）
stdType := plugin.MapToStandardType("varchar")  // 返回 "string"

// 使用自定义映射表
customMappings := []plugin.TypeMapping{
    {DBTypes: []string{"hll", "bitmap"}, StdType: plugin.StdTypeBinary},
}
stdType := plugin.MapToStandardTypeWithCustom("hll", customMappings)
```

## ⚠️ 注意事项

### 1. 安全性

- **不要打印敏感信息**：避免在日志中打印密码等敏感字段
- **使用 SensitiveFields()**：标记敏感字段供上层处理
- **SQL 注入防护**：使用参数化查询而非字符串拼接

### 2. 错误处理

- **使用 fmt.Errorf() 包装错误**：保留错误链
- **提供清晰的错误消息**：帮助用户排查问题
- **设置超时**：避免长时间阻塞（推荐 10-30 秒）

### 3. 性能优化

- **使用统计信息而非实际查询**：获取行数时优先使用 INFORMATION_SCHEMA
- **避免 SELECT ***：只查询需要的列
- **合理设置连接池**：参考 poolConfig 配置

### 4. 兼容性

- **支持多种字段名**：如同时支持 `user` 和 `username`
- **处理空密码**：某些数据库（如 Doris）默认无密码
- **处理默认值**：如数据库名默认为 `default`

### ClickHouse（推荐新增）

```go
// 驱动：github.com/ClickHouse/clickhouse-go/v2
// GORM 驱动：gorm.io/driver/clickhouse
// 默认端口：9000（Native）或 8123（HTTP）
// DSN 格式：tcp://host:port?username=xxx&password=xxx&database=xxx

func (p *ClickHousePlugin) DefaultPort() int {
    return 9000
}

func (p *ClickHousePlugin) BuildConnectionString(connInfo plugin.ConnectionInfo) (string, error) {
    // 使用工具函数
    return plugin.ClickHouseStyleDSN(user, password, host, port, database, nil), nil
}
```

### MongoDB

```go
// 驱动：go.mongodb.org/mongo-driver/mongo
// GORM 不直接支持，需要自行封装
// 默认端口：27017
// DSN 格式：mongodb://user:password@host:port/database

    return "nosql_db"  // 或 "document_db"
```

## 🆘 故障排查

### 问题 1：插件未注册

**症状：** `plugin.Get("<dbtype>")` 返回 nil

**解决方案：**
1. 确认 `init()` 函数调用了 `plugin.Register()`
2. 确认在 `dbbridge/bridge.go` 中添加了 `import _ "..."`
3. 重新编译 `go build ./...`

### 问题 2：连接测试失败

**症状：** TestConnection 返回超时或连接拒绝

**解决方案：**
1. 检查 DSN 格式是否正确（打印到日志查看）
2. 确认数据库服务正在运行
3. 检查防火墙和网络配置
4. 增加连接超时时间

### 问题 3：类型映射错误

**症状：** 列类型显示为 "string" 而不是预期类型

**解决方案：**
1. 检查数据库返回的原生类型名称（打印 `dataType` 调试）
2. 确认使用了 `plugin.MapToStandardType()`
3. 如需自定义映射，使用 `MapToStandardTypeWithCustom()`
