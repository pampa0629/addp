# API 客户端集成规范

[返回 API 设计规范](../addp-API设计规范.md)

定义共享前端与 Python HTTP 客户端的边界。后端响应仍遵循[响应与错误规范](响应与错误.md)，身份边界见[认证授权](认证授权.md)。

阅读导航：[前端客户端规范](#前端客户端规范)、[Python Client 规范](#python-client-规范)。

## 前端客户端规范

Vue 模块的 JSON API 请求复用 `common-frontend` 的 `createAPIClient()`；SSE、流式及无法使用 Axios 的场景复用 `createAuthenticatedFetch()`。认证、内存 Token、刷新及单次重试按[共享认证要求](../addp登录认证的统一要求.md#七前端共享能力要求)接入，不另建客户端认证流程。

客户端消费后端已声明的响应，不为特定 UI 框架要求后端增加包装。模块接入见[新模块前后端连接说明](../addp新模块开发指南.md#开发中的前端-后端连接)，共用能力见[共享前端说明](../../../common-frontend/README.md)。

## Python Client 规范

ADDP Python HTTP 客户端统一来自 `common-python/addp_common/client`，共享 SDK 的能力开放边界见[Tool 开放规范](../addp智能体Tool开放规范.md#五adapter-边界)。

### 基类定义

共享基类是 [`BaseClient`](../../../common-python/addp_common/client/base.py)，模块客户端与使用方式见[共享 SDK](../../../common-python/README.md#客户端列表)。

共享基类负责 HTTP 请求、认证头、错误抛出、连接关闭和异步上下文生命周期；复用其实现。

### 子类示例

调用与模块客户端清单见[共享 Python SDK 使用示例](../../../common-python/README.md#使用示例)和[客户端列表](../../../common-python/README.md#客户端列表)；新增 owner API 调用在共享客户端中维护。

### 规范要求

- 模块 HTTP client 复用共享 `BaseClient`。
- Agent 的 owner 调用使用 Delegated Access Token，服务自身调用使用 Service Access Token；原始 User Access Token 不进入 Agent Tool 的 owner Client。普通用户 SDK 请求按共享 SDK 的认证契约处理。
- 方法名使用 snake_case，与 API 路径语义对应
- 不在 client 中处理业务逻辑，只做 HTTP 调用和基本的参数组装
- 使用 `httpx.HTTPStatusError` 处理 HTTP 错误，不吞掉异常
