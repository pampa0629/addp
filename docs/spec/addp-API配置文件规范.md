# API 配置文件规范 (api-manifest.json)

> **⚠️ 已废弃**
>
> api-manifest.json 机制已全面废弃，由 Swagger/OpenAPI 自动生成替代。
>
> - Go 模块使用 `swaggo/swag` 自动生成，访问 `/swagger/index.html`
> - Python 模块（FastAPI）天然生成 OpenAPI，访问 `/docs`
>
> 详见 [addp-API设计规范.md](./addp-API设计规范.md) 第九章。
>
> 各模块现有的 `docs/api-manifest.json` 文件可直接删除。
