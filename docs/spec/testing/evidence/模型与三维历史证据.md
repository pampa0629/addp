## SKP：部分实现，完整组成准入暂缓

**最终状态**：2026-11-14 固定 `46fed85d1034309e22cf06f6eea832b20d858028` 收口为部分实现，后续分类／XSD 逐项扩展暂缓。静态格式身份、OpenSKP→GLB 转换与局部事实读取已有成果；**`Model3DCompositionProvider` 未注册，FTP／NFS／MinIO 的新精确组成授权继续关闭**。转换成功、镜像构建或旧契约下的 Hosted 均不能改变该边界。现行正文见[SKP](../../builtin-formats/三维模型与场景.md#skp)和[尚未通过的组成条件](../../builtin-formats/三维模型与场景.md#skp-精确组成准入核对条件当前未通过)。

**已有证明**：有界 VFF／SKC 容器、部分 XML／XSD 依赖、精确声明绑定和部分分类值已有局部校验。几何范围、表面积或像元一致只证明所测指标，不证明全部模型记录、材质、可见性、引用闭包或完整实例语义。现代 VFF 的局部证据不能认证旧 MFC/CArchive；同包多个副本不按独立结构计数。

## SKP Runtime：已修正材质绑定，未开放新授权

**结论**：固定 OpenSKP 1.3.0 唯一路线已修正精确贴图读取、完整图片身份与材质登记／引用绑定。不同图片不能因长度和前缀相同而合并；重复、冲突、悬空材质或必需图片缺失须失败且保留源与旧 GLB。验证实际像元、alpha、UV 和对应面，不能只看两个 image 条目或转换退出码。

**最小证据**：修复 `60da3691404ee74d3b6789d2948f575be1edef9c` 的 [Model3D Linux Job 122764481288](https://github.com/pampa0629/addp/actions/runs/40673069424/job/122764481288)和[产品构建 Job 122764481292](https://github.com/pampa0629/addp/actions/runs/40673069424/job/122764481292)通过相关用例与镜像 smoke；原 8 项 FBX／glTF 原生工具测试跳过，不计通过。用户重启后实际 HTTP 另验证正常双图及七项绑定拒绝，拒绝时源和旧成果不变，仅覆盖 Runtime direct。

**边界**：这些修复没有证明全部资源闭包、所有材质／版本或 Manager 新授权链。旧源契约下的 SKP Manager 转换／缓存／血缘验收保留其历史范围，不能冒充新三来源精确组成验收。第三方许可未证和私有样例不作为仓库或公共镜像的分发夹具。

## 后续待办

1. **SKP 保持暂缓及授权关闭**。确需续接时，先明确可完整证明的容器／profile，再补全部资源闭包、Common／Runtime 一致性和新契约三来源验收，不继续靠零散 XSD 子项累加宣称完成。
2. **NL-SfB 原生语义仍未验**。四组 filter／XSD 名称尾随空格对照只完成方案；八次调用／读回和十六个 Simplify 截图均未执行。后续须有合适 SketchUp 环境，使用未修补原件分别核对加载／应用返回值、真实分类值和页面，不从插件源码、选项可见或模拟调用推定成功。
3. **SGM 缺正式 T4 与自然过期回收证据**。既有本机技术闭环不替代正式产品链路，临时对象即时删除或七天生命周期配置不等于真实七天过期已验收。

其他格式变体、生产 T5 和未执行的权限／崩溃／租约故障矩阵按独立范围取证，不以本页局部通过扩大能力声明。已解决的前置失败与重复复验不再列为待办。
