## 细化与默认一轮边界清理共同核验

仅细化与默认一轮适用，不扩大到其他五项：独立手工 Hosted Linux x86_64、同源默认入口产品 Runtime、隔离 NFS、普通 User 原 12 权限，各自独立预检与业务预算 600 秒。不改产品策略、算法、权限或原套件；仅验 API 持久化，不计页面、容量或任意影像认证。

- 逐成果核完整像元／mask、原尺寸／完整仿射／CRS、Float64／NaN、COG 全布局／实际概览，不继承源色表或 scale／offset；artifact／物理／Meta 为相等正整数大小。精确核扫描父执行／User／Tenant／Engine、当前执行全部实际源血缘及 Monitor；每步重核源物理／Meta 与先前成果不变。
- 失败零发布、零新增扫描与派生血缘。成功、失败、超时及部分启动均核所属工作目录、NFS、Runtime、应用部署与 Infra 清理，清理失败即验收失败；默认一轮另核其专节列出的归属资源。
