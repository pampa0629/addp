## 共同验收要求

仅本页两套独立手工 Hosted 只读场景适用：NFS、同源产品默认入口 Runtime、普通 User 原 12 权限，各自业务预算 600 秒。不改产品算法、权限、原统计或原 Raster／OIF／邻域套件；保留单元素套件。实际 Linux 全量与 Hosted 由 CI 会话协调，不因文档整理触发、重跑或扩预算；准备／本地通过不计 Hosted，通过范围不外推页面、容量或任意影像。

- **身份与只读**：初始化扫描核精确目标、当前执行、无父执行、同租户／普通 User／引擎；后续业务执行全部零资源发布、零新增扫描和零派生血缘。专业详情与 Monitor 核当前身份、状态及提交 DAG／语言快照，不虚构成果声明大小。
- **完整复核与归档**：每次重新全读 11 份源原件的全部像元／mask／类型／NoData／网格／CRS／scale-offset，并核 Runtime 执行工作区零残留；源、归档及先前成功结果逐次复核，不缓存实际结果。仅缓存独立期望，首次生成计入预算。归档源原字节、独立期望、专业详情／Monitor 原始终态响应及大小／hash 清单；禁止覆盖、重建或静默修复，漂移即失败。
- **语言**：新增百分位／列表诊断按中英文提交语言核验；既有波段／复数沿各节原诊断契约。双语提交不等于全部诊断已翻译，反向查询不得改写冻结失败。
- **计时与清理**：业务计时覆盖源初始化、oracle、执行／查询、物理复核、归档和执行工作区清理；Hosted 部署／NFS／Infra 退出按既有生命周期单独核验，多项套件另核容器／镜像退出。超时或清理失败整套失败。

入口拒绝核原始 HTTP 400、双语响应和精确字段路径。用原普通 User 的专业执行列表核完整的本轮 ID 清单，确认入口拒绝零新增执行。分析节点拒绝仍核同次详情、Monitor 和冻结语言。两层均回读完整来源与先前成功结果，并核无新增扫描及派生血缘。

## 整幅栅格百分位统计独立 Hosted 验收

`raster-statistics-percentile-workflow`，沿[共同要求](#共同验收要求)。

该既有矩阵已随产品统一接口改为percentiles单元素列表及嵌套结果核验；不新增执行数或预算，不作为多项同次请求的Hosted证据。固定16条成功链：原统计不带百分位1条，0／100端点2条，奇偶总体50百分位2条，25／75插值2条，33.3跨六块及像元逆序2条，重分类接90百分位1条，Int64／UInt64 NoData邻接值2条，显式第二波段的mask／alpha／scale-offset覆盖1条，单有效／全无效2条，缺失定位1条；跨块源保留旋转网格。固定12类非法参数各按中英文提交，共24次准确失败：列表null／布尔项／字符串项／嵌套数组项／对象项／低于0项／高于100项，波段0／越界／布尔／字符串及所选复数数据。既有波段／复数原因仍按当前英文契约核验。NaN／Infinity、复数alpha混合类型、极端插值／原统计矩范围、IO注入及真实低盘边界分别沿Native或既有独立套件记账。

独立oracle按源原生有效性取完整总体，使用Python标量排序与Fraction的确切二进制百分位位置；不调用产品函数或NumPy百分位。原统计全字段、计数／null／合法零、端点及中位数严格核对，其他插值固定rtol=4e-15／atol=0，原mean／stddev采用rtol=1e-10／atol=1e-12；同源带／不带百分位的原字段逐值相等。

归档响应文件名相对于 `statistics-responses/` 目录。

本地入口为`make test-raster-statistics-percentile-online-runner`及标准`make test-geopython-workflow`中的`test_online_statistics_percentile_fixture.py`；已同步Online registry、changed gate、独立workflow与固定矩阵／删除断言变异检查。

## 整幅栅格多百分位独立 Hosted 验收

`raster-statistics-percentiles-workflow`，沿[共同要求](#共同验收要求)。

固定16成功：原统计不请求列表、同源单元素P50对照各1条；端点／常用分位／小数分位／源像元逆序4条；奇数／偶数总体、常量重分类／原两类重分类4条；原生Int64／UInt64 NoData邻接2条；显式第二波段覆盖、单有效、全无效及缺定位4条。共14条多项请求及2条原字段／单元素对照。完整结果逐项用独立标量排序及Fraction确切二进制位置核验，跨六块含旋转源；P50真实对照、像元逆序及不同百分位合法同值不得被合并。全面逐项与单元素计算的一致性仍由Native覆盖，不虚称Hosted逐项重跑。

固定20类各中英文提交，共40准确失败：列表null／布尔／数值／字符串／对象／空6类，布尔项／字符串项／null项／嵌套列表项／对象项／越下界／越上界7类，重复／降序2类，波段0／越界／布尔／字符串及所选复数5类；节点拒绝须准确命中 analysis，入口拒绝按共同要求核验。既有波段／复数按原诊断契约精确核验。非有限JSON、旧单值参数、混合类型复数alpha、数值极限及IO／磁盘注入仍单列Native。

多项套件收尾须核全部源 Meta 及血缘快照。源夹具与新矩阵打包为只读 stdin Worker，依赖源码 hash 冻结，源码或原件漂移均失败；容器／镜像退出清理不弱化。

本地标准入口：`make test-raster-statistics-percentiles-online-runner`；Native夹具加入既有`make test-geopython-workflow`；Online、影响选择、手工workflow和严格矩阵登记同次接入。
