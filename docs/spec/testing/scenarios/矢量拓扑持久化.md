## 拓扑构面、面叠面缝、悬点与线叠持久化（vector-topology-persistence）

### 拓扑持久化公共要求

主场景及多距缓冲、面界提取与诊断、线端修剪、参数诊断、近接、延伸、吸附、顶点提取、面邻、差集、融合、相交、节点提取、重合规整及其组合 case 使用独立手工 Hosted Linux x86_64，入口 `make test-online ONLINE_SUITE=vector-topology-persistence`。共用隔离生命周期、NFS 归属核验及 GeoPython 产品默认入口，限当次非默认 Tenant、同一普通 User 和 600 秒。精确 11 项权限为 `develop.task.read`、`develop.task.execute`、`develop.data_read.execute`、`develop.data_write.execute`、`system.execution_authorization.create`、`meta.catalog.read`、`meta.scan_task.read`、`meta.scan_task.execute`、`meta.lineage.read`、`monitor.execution.read`、`manager.data_item.read`。Engine 登记独立，登记后撤基础设施 Token，各次运行使用独立会话。

算法与准入见[矢量算子契约](../../workflow/矢量算子契约.md)，成果、失败和退出另沿[共用核验](Manager与空间成果.md#成果与退出的共用核验)。以下按各 case 明示的源、端口与数量执行。

| 主题 | 拓扑共同断言 |
| --- | --- |
| 保存与扫描 | `mode=fail`，稳定 outputs 和 `lineage_facts.outputs` 均为 `write_mode=create`。每成果恰一次精确自动扫描，公开 `tenant_id/triggered_by` 为同 Tenant／User 的严格正整数，缺失或重复均失败。禁止补扫或用私有字段代替。物理＝Meta 且严格正整数，GPKG 文件与唯一 child 分开。 |
| 血缘 | `input.<读取节点ID>` 按端口名精确绑定 locator，各 `output.<保存节点ID>` 同样逐端口核对 locator，拒缺项、重复、额外及端口错绑。各实际输入→成果为当前 execution 的 active derive，Monitor 与 facts 一致。文件边与行级 source_id／members 分开，业务来源不写 Meta 技术字段。 |
| 回读与保持 | 手写坐标、属性、类型、行序和关系，独立原生 OGR 读回，禁止以产品算法、舍入、容差或精度网格造期望。runner 用同一端口类型与计数断言核 API 和地图，未知端口、行数不符、错类型或篡改均拒绝。存储 FID 与业务 ID 分开，浏览器前后比源 Meta、源和成果字节／大小／SHA。 |
| 真页面 | 每次导航用页面自身响应经 `browserAPIFromResponse` 核当前 User／Tenant／11 权限，不继承旧 Token、mock 或注入图对象。GPKG 用唯一 `child_name` 和标准 EWKB，核完整属性、原坐标与实际 OpenLayers 要素。显示用独立球面墨卡托 3857→4326→3857 精确比较。微几何仍须保留，亚像素分辨能力另验。 |
| 失败与收尾 | 计算失败阻断下游保存，零发布、零新增扫描与输出 facts，源与旧成果不变，无跨文件回滚承诺。`incomplete` 只作阶段证据，完整成功需最终 Owner 与浏览器结果。领域、NFS export／owned root、Runtime／registry、部署及 Infra 分别核零残留，清理失败即门禁失败。合成原件可归档。独立 case 通过不计主场景重验，Quality、修复、容量和真实 T4 各按自身证据认定。旧业务及容量矩阵独立运行，维持手工入口及原调度范围。 |

Runner 通过本轮临时 JSON 文件向 Playwright 交接完整场景证据，子进程环境只携带文件路径。子进程退出即清理该输入文件，原始报告、截图及失败取证按各场景规则另行归档。交接不裁剪证据，报告仍逐项核对本轮身份、成果、血缘及页面断言。

### 主场景的独有几何断言

除构面／修复的原CRS84外，下列GPKG均EPSG:3857；线源显式唯一非空字符串`route_key`、面叠显式唯一非空`parcel_id`，`note`等原属性保持。各算子的完整输入拒绝／空批／输出Schema归正式契约，此处固定输入与精确结果如下。

| 分支 | 固定计算与独立断言 |
| --- | --- |
| 构面／修复 | GDAL核四面／四dangle；自交面检查→修复→复查后仍两行MultiPolygon，各含两三角面，原属性不变，修复前false／原因、后true／Valid Geometry。GeoJSON保留CRS84声明，Meta为OGC:CRS84、无虚构EPSG SRID，地图`direct_renderable/not_transformed`，不临时选CRS。 |
| 严格参考吸附 | 五输入线／六参考线、米单位，tolerance=.75核原始位置上限／严格边界／等距XY、不插点或吸向段内部，属性／行序／XY／CRS不变。tolerance=1.25另DAG须以Owner固定`snapping produced invalid geometries`整批失败。 |
| 面叠 `check_polygon_overlap(id_field=parcel_id)` | 十二有效面→七对MultiPolygon／Float64面积：五普通重叠／包含／全重复、一含两面部分且排接触线的多部件交集、一精确2^-40（约9.09e-13）微叠。核双ID／顺序／每对唯一；共边／共点／孔内不输出，不忽略微面积。 |
| 面缝 `check_polygon_gap(input_gdf,coverage_gdf)` | 七待查＋七显式覆盖面→八Polygon稳定排序：内／边缺各一、双孔缺口一、待查孔一、点接触及独立多部件三、2^-40微缺一。范围孔是合法留白，完全覆盖／范围外不报，覆盖重叠及源重复不重复报。核原坐标／孔／顺序／Float64 gap_area；两源血缘不可漏／互换，不自动填补。 |
| 悬点 `check_dangling_points(id_field=route_key)` | 十二有效线／多线→十七Point＋source_id，含孤立／连续链／T形／闭环／反向重复／内部重合／多部件及2^-40断口。闭环／T连接不报；同点重复线保留双来源，同源多部件同点仅一次。OGR GetPoints/GetX/GetY逐坐标／来源／原行序核，不用生产打断／计度造期望。 |
| 线叠 `check_line_overlap(id_field=route_key)` | 十六有效线／多线→九MultiLineString＋source_id_a/source_id_b/overlap_length；覆盖部分／包含／反向重复／三要素逐对、多部件排点接触、2^-40正长、源内折返去重及不同采样顶点。孤立自叠／点接触／交叉／间距2^-40平行线不报。长度按原单位，用手写坐标及独立线段长度核。 |
| 线内自叠 `check_line_self_overlap(id_field=route_key)` | 十五有效线／多线→八MultiLineString＋source_id/overlap_length：折返／三次经过／不同分段／多部件正长叠／2^-40／夹零段折返／同向重复部件／重复闭环。同源同位置只计一次长度；普通闭环／点自交／近邻／单零段／仅端点接触／两个独立重合源不报。 |
| 线交 `check_line_intersection(id_field=route_key)` | 十八有效线／多线→十Point＋双ID：三线同点三对、T形／端点、线点混合中的独立点、重复多部件两交点及间距2^-40双点。重合段端点／近邻／单源自交不报；拒丢点／重复／错配／微点舍入／CRS篡改，双ID仍绑定同一源文件，不虚构双文件血缘。 |
| 线内自交 `check_line_self_intersection(id_field=route_key)` | 十六有效线／多线→十五Point＋source_id：蝴蝶结／重复到访／跨部件接点／重合覆盖外支线点／重合与独立点并存／微距双点／不同源同XY／跨部件闭环四角。正常折点（含中间零段）、同部件闭环首尾、重复分段／相邻折返覆盖、自叠内部及端点支线、两不同源仅互交不报。原生Point不经默认GeoJSON截断；按源序／XY排序，拒全层去重或错误覆盖点。 |

三幅 Point 图核共享蓝色非透明前景，排除底图水域，另十二幅线面图核绿色。分别记录 `point_pixels/green_pixels`，保持原产品样式。面叠／面缝像素取实际可见区域，完整微几何仍须存在。

**交点打断**：`split_line_intersections(id_field=route_key,scope=all)`以十七有效线／多线生成四十三LineString，保留全部原属性、可空note／Int64 grade，追加source_id及从1起part_no/segment_no。手写预期覆盖十字／T／端点／逆向多部件／正常闭环接缝／2^-40片段／重复顶点，以及同源蝴蝶结与跨源同时切分、反向自交闭环原接缝、同XY多次经过的独立路径位置、同源跨部件交会和切点重复原顶点。原方向／每顶点／源部件序／类型／null／编号必须相等，不按全源XY去重漏切；正长重合仍整批拒绝，沿Native负例，不另加T4失败DAG。文件血缘不代片段来源。浏览器须真实控件选每页50，再用同locator／child／page=1／page_size=50页面响应核43行及全部OL属性／方向／坐标，不注状态／另API代页面；旧between T4不认证all。

### 面邻检查独立普通用户场景（polygon-adjacency）

原生类型与传输数值分开核验：物理 GPKG 的 Integer64、Real、NULL 和 Meta 结构仍按原声明严格检查；JSON 数值按对应字段语义检查，Real 可由 JSON 整数或小数表达，必须有限且与原生预期精确相等，不接受 bool、字符串、缺失或非预期 NULL，不使用容差或舍入。整数身份仍须为精确安全整数，不把浮点、bool 或超安全整数当作身份。归档回归必须经过真实 JavaScript JSON parse/stringify 往返，不能只用保留 Python float 类型的自造夹具。

发布文件名不决定 GPKG 内层名。成果须只有一个原生层，将物理层名、Meta 唯一 children/native table 与预览请求 child_name 逐项绑定；不得硬编码发布文件 basename 为内层名，也不为匹配执行单改写产品层。普通用户身份、完整组成、严格统计及精确新建目标要求均不变。

诊断截图在复制操作后重新定位完整失败面板，并核对原因、必要字段和复制入口均在实际视口内；DOM 有文本或剪贴板正确不替代截图可视性。OpenLayers 源 CRS 与视图 CRS 相同时精确保留原坐标，含 2^-40 微边的两个端点，不用 WGS84 中转、epsilon 或亚像素不可见性解释数据退化；原件、API、OL 数据和实际像素证据分别核验。
