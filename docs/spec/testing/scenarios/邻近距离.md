## raster-proximity-persistence

部署、身份、预算及通用清理按[公共前提](Manager与空间成果.md#独立持久化专项公共前提)，Runner 与 Native 分层按[验证入口](Manager与空间成果.md#独立持久化专项验证入口)。标准入口为 `make test-online ONLINE_SUITE=raster-proximity-persistence`。

### 单位与网格

已登记投影米制 Int32 多波段及美制测量英尺 UInt32 TIFF，分别执行 `raster_load → raster_proximity → raster_save`。两源均为北向无旋转方形网格；输出保留源网格及 CRS，距离统一为米制 Float64／NaN，沿 COG 保存。美制测量英尺按 `1200/3937` 换算为米。

完整像元核验覆盖显式波段、合法零／负分类／UInt32 最大分类值、跨块、无效目标、部分透明和无效区域可跨越。

### 独立距离核验与扫描血缘

独立 oracle 对每个有效目标中心穷举欧氏距离，不调用产品变换、下包络或 GDAL 距离算法；核对完整像元／mask、单位、网格／CRS、COG／金字塔及 artifact／物理／Meta 严格相等的正整数大小。

只手工扫描两份精确源，两个当前执行各自自动扫描成果；核对同用户／租户、Monitor 及各 DAG 仅自身实际源输入的 active derive 血缘。

### 失败、清理与验收边界

非法波段及无有效目标失败不得发布或新增扫描；每次源物理／Meta 与先前成果不变、退出清理沿公共前提，另须核验产品 Runtime／registry／镜像。

本专项不认证测地距离、成本／路径、旋转／非方形网格、容量或 Manager 绘制。固定版本 Hosted 结果与未覆盖范围见[验收基线](../../../next/栅格算子体系后续专题.md#二当前验收基线)；仅手工触发，入口登记不代表 T4 通过，不外推为当前 HEAD 已重跑。

矩形及正交旋转两套的 Develop 入口拒绝归档双语 HTTP 400，核参数精确路径与执行清单无新增。distance 节点核当前公私执行身份、准确诊断和反向语言不改写。两阶段均核无发布／扫描／派生，保留原成果全检、600 秒及退出清理。

## 非方形像元邻近距离独立验收

固定 `7bee7ae1e` 的[共享 Execution Runner](https://github.com/pampa0629/addp/actions/runs/45868134201/job/140076227200) 实际运行 `make test-execution-online-ci-runner`，通过 160 项登记、42 项共享准备及隔离身份 Go T1。覆盖两点通视与矩形、正交旋转邻近距离的共用编排和回执取证。同一固定提交的 [Linux Native](https://github.com/pampa0629/addp/actions/runs/45868134201/job/140076227588)在 Ubuntu 24.04／GDAL 3.8.4 实际运行 `make test-geopython-workflow`，22,112 项通过、141 条警告、1587.24 秒，失败、跳过和筛除均为 0。独立 NetCDF 另有 109 项通过。同一提交的[平台一致性](https://github.com/pampa0629/addp/actions/runs/45868134201/job/140076227220)实际运行 `make test-platform-preflight` 和 `make test-platform-checks` 并通过。三套独立 Hosted 的物理成果、准确拒绝、扫描与执行血缘仍按各自原件验收。

`raster-proximity-rectangular-persistence`；沿[水文／分区共同要求](Manager与空间成果.md#水文与分区统计专项共同要求)。16COG涵横纵比例使最近反转、小数步长、两英尺、raw第二波段、NoData/mask/alpha、零负／UInt32、跨块／单行列／原方形对照；52 次双语拒绝（Develop 入口 10、distance 节点 42）。独立枚举目标预期，968全检，16COG／源／冻结数组及hash归档，数值极限／私文件破坏仅Native。

正交旋转扩展不改16/52/968／600秒，仅同步实际双语准入：rotated_x/rotated_y是非正交剪切、orientation是单轴镜像，仍须当前节点准确拒绝；本suite只证北向矩形成果，不补认旋转Hosted。

## 正交旋转网格邻近距离独立保存

`raster-proximity-orthogonal-persistence`：Hosted／NFS、同源默认产品Runtime、普通User原12权限、4CPU／2GiB／无额外swap、600秒，不重试／扩预算。18 COG链覆盖原北向三单位对照、90／180／270度及斜向正交方形／非方形、真实最近目标反转、第二波段／零负目标／NoData／mask／alpha／跨块及概览；60 次双语拒绝（Develop 入口 10、distance 节点 50）。

成功递增全检、失败各重读18成果，共1251检查。独立世界向量枚举核完整仿射／CRS／米制距离／mask，逐份核COG／artifact＝物理＝Meta正整数、扫描父执行／User／Tenant／Engine、当前血缘／Monitor、源旧保持及全清理。归档18原COG／SHA256大小清单／冻结期望；数值极限、私有故障注入／等距目标身份只认Native。
