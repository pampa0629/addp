## FTP 普通 User 消费（ftp-consumer-flow）

选择 `ftp_case=node-glb` 可单独验收目录授权。套件先签发指向 `models/glb` 的直属节点读取 Grant，再在该目录新建一个自包含 GLB。普通账号通过 Manager 下载原模型与新模型，逐字节核对内容。撤权后使用同一下载地址重试，同时核对平台拒绝和 FTP 服务端对该文件的下载计数。证据写入 `ftp-node-read.json`，清理由原隔离夹具负责。`ftp_case=full` 保留原有模型消费套件。

**当前缺口。** 直接 Grant 与业务批准沿[5.5.5](../../addp授权上下文规范.md#555-直接授权业务批准与明确交接)，来源并集／撤销及源 Deny 退役沿[生命周期](../../addp授权上下文规范.md#553-责任变化与访问规则生命周期)、[IAM 迁移](../../../../system/docs/IAM数据模型与迁移规范.md#持续节点-grant-与源-deny-退役2026-11-02)。FTP Runner 仍有退役 Deny Permission／建立释放接口／回执断言，须清除并用新源码重验；旧 Deny／解除／单目标唯一有效 Grant 的详细步骤不再作为操作指引。历史成功不证明当前授权链路闭环，本轮只整文档、不改实现。

手动 Hosted Linux x86_64，FTP 自有固定 SFTPGo 镜像／唯一初始化、随机口／账号／私有 CA／数据状态卷。Business 只私有 Engine 描述，独立 Provisioner 正式登记；消费前移除其 Token。表格消费六项 `system.engine_catalog.read`、`meta.catalog.read`、`meta.scan_task.execute`、`meta.scan_task.read`、`manager.data_item.read`、`manager.content.read`；模型另加 `manager.derived_artifact.create/read/delete`和 `manager.data_item.update`为十项，不增任务编辑／Monitor／通用 `system.execution_authorization.create`。

API 与 Console 同 Tenant／User／完整 Permission；每次导航／重载取该页真实受保护请求重新绑凭据，401 不改夹具身份／Cookie／重放。独立 `sourceInitializer`以 `ADDP_ONLINE_FIXTURE_SOURCE_ACCESS_TOKEN`及既有引擎授权管理员角色，System 核完整组成再正式签／读／撤 Grant，浏览器不带登记或办理 Token，不写 Grant 表／旧许可初始化。

**表格基线。** FTP 账号根／examples 保中文、空格、百分号；Facts 路径／大小准确、不虚构 ETag。examples 只做既有 CSV／JSON／Parquet 三字段 deep；每格式三行 ID／中文名／金额 API 及页面完整，重新扫描身份稳定，真实按钮原名／大小／SHA 对独立种子。

**来源与预算。** 三来源各七转换模型＋一直接 GLB，共 24 份，逐来源独立报 FTP／`nfs_profile`／`minio_profile`，缺一不计全套。场景 1200 秒，产品冷构建 Job180 分钟、现有单 worker、实时转发日志，中断先停构建进程组再清理；不换 Runner／工具／样例或跳镜像。固定 `5e813a584`旧 900 秒超时：FTP／NFS 已完成，MinIO glTF 组成恢复后撤权／删除未完成；旧 341／661／877 秒仅预算校准，不认整套通过。单请求／产品超时不随预算修改，超新预算仍失败。

标准 `make test-ftp-online-runner`，业务 `make test-online ONLINE_SUITE=ftp-consumer-flow`／唯一 `online-hosted-ftp-gate.sh`；Common／Meta／System／Manager T1、PG T2／System 前端／标准 IAM 迁移分层取证。CSV／JSON／Parquet 历史见[证据索引](../验收证据索引.md)，协议双架构／builtin／Hosted／个人环境各认，不由本地／排队或一个来源成功外推全部 profile。

### DAE 精确组成

固定自有 Collada1.4.1 厘米三角形＋PNG，basic 完整 XML／原贴图声明／精确清单；GLB 独立核米制换算、几何、真实 UV／材质／嵌入像素，源 ZIP 精确成员。FTP／NFS 扩展独立于 MinIO 旧结果。组成变化用新名 `changed.png`，不放宽为整目录；与 3DS 共同验证旧 Grant 拒新组成、旧产物隔离、恢复原组成后缓存复用及最终撤权。

### IFC／3DS 与通用生命周期

FTPS 真实读 `models/ifc/model.ifc`、`models/3ds/model.3ds`和 `models/3ds/texture.png`，不复制 NFS 充 FTP。models 仅强制 basic、变更只重扫相关目录；examples deep 不补模型组成，事实不全即失败、不 deep 兜底。IFC 固定几何只要求唯一主项／类型／路径，不伪造 `format_info.ifc.scan_complete`；3DS 须完整有界结构标记、原贴图声明／必需组成。

### OBJ／MTL 精确组成扩展

三来源静态 OBJ，一个 DataItem 含主 OBJ、两份同目录且名含内部空格 MTL、各引用子目录同 basename 异色 PNG，共五相对成员；ZIP 逐原字节、不能 basename 合并。basic 及执行重核 `composition_complete/material_libraries`，不 deep 猜、MTL 不是贴图；拒嵌套 MTL／链接／不完整声明，PNG／JPEG 限定。

页面两色／缓存不新增 execution；GLB 两材质绑定两三角、UV／六顶点／2×1 几何及两 PNG 像元／源字节。只改一 MTL 图片声明、不改主 OBJ，重扫后旧 Grant 拒、旧产物不能借新边界授权放行；其余沿共用生命周期。原 Manager MinIO OBJ／DAE 也用同精确批准入口，结果仍按原 suite 分别认定。

### 模型原始读取授权收敛与 STL 三来源 profile

原始内容的三个出口 `storage-stream`、`storage-assets`、`downloads/file`，按批准前／有效／最终撤销逐主文件及已确认依赖核：前后源拒绝且无内容，获准后原字节／完整逻辑 ZIP，不借旧 EA／Resource Ticket。`raw_source_reads`只出口／格式／原路径／状态／获准摘要，无凭据／拒绝正文；Engine 版本、组成缺失、核查到打开间撤权／服务失败／Ticket 不能变 Allow，由 System／Manager T1/T2 另证，非模型范围不扩大。

真实下载按钮必须当前 User Bearer、无 Cookie／ticket，保存文件来自本次浏览器，独立核字节／附件头／建议文件名；401／403／取消无保存／成功提示，不能以调试器空响应体或额外 API 替实际文件。单文件逐字节，multi ZIP 逐原相对成员／长度／SHA，拒重复／额外／加密／损坏，不以主文件大小代 ZIP。

STL 固定 ASCII 单 solid 三角，basic `format_info.stl.composition_complete=true`及唯一 model ref，不伪 deep `scan_complete`；重核并暂存同一已核字节，总量 64MiB，超限拒，不目录复制或旧挂载。每来源生成前基础 STL 页原字节／真渲染且零转换，再页面生成自包含 GLB／重开／撤权拒绝／定义历史保留／成果与暂存删。GLB 无外部 buffer/image URI 或 image/texture 引用，可默认材质；独立核唯一三角位置／索引／实例变换后几何／有限 bounds，不以顶点数代几何。未声明单位／CRS 不反写，多 solid／任意 STL／超限不由固定样例追认。

### NFS／MinIO IFC／3DS／DAE／OBJ 精确组成 profile

各来源独立 Engine／源／工件。NFS 只自有 Linux Hosted 的只读导出，退出删导出／目录，不改个人 NFS；Provider 读源、Runtime 只受控暂存不接宿主路径。`make test-common-nfs-integration`核 Facts／full／Range 及根内外／目录软链／FIFO 共同拒绝。MinIO 自有标签／随机回环／临时存储、正式登记；DAE 桶根／嵌套前缀都识别，PNG/JPEG 依赖逐项，deep 摘要不造／覆组成。

直接自包含 GLB 在三来源独立验，不进生成／成果删除列表：basic 唯一主项、授权前／撤后三出口 403、获准字节同；同名换合法 GLB2 外部 URI、不重扫仍拒，恢复后可读。页面当前 User、无 ticket/cookie、真三角渲染／Range／按钮保存、零转换；旧五／六格式回归不删。

原件名称三层分验：Content-Disposition 解码原名、Blob 链接 `download`属性、浏览器建议名。前两逐字同源；固定 Chromium 首空格 GLB 建议 `_原名 %.GLB`仅浏览器观察，不归平台改名。先留实际保存件再断名；独立 Runner 逐字节及 ZIP 路径／成员核验，缺层／改名／非 Blob／损坏均失败，不追认旧失败。

### glTF multi 三来源 profile

静态 core glTF2.0 主 manifest＋确认外部 buffer／PNG/JPEG 组成同一 multi，三原始出口与执行共用精确边界；拒不完整、主清单变更、越界／软链、未知扩展／未授权依赖，不读目录余项。

固定红蓝两三角面板、两子目录同名 PNG、首空格／字面百分号 buffer；ZIP 精确四成员／路径／字节，GLB 两材质／UV／场景尺寸／嵌入 PNG 像元。真实按钮／两色渲染／重开及组成变化／撤权／两类删除沿共用矩阵逐来源验。data URI／bufferView 图／版本扩展 URI 长度反例归格式／Runtime 门禁，不推任意模型、动画／大场景或容量。

### FBX 严格单主文件扩展

三来源 Binary7400 静态无贴图，basic 完整结构／唯一 model 主 ref；授权只读持久事实，EA／KindFile 暂存及三原始出口同身份，不父目录授权，SKP 仍不准入。

独立核 GLB 几何／材质／实例变换，无媒体／动画／蒙皮／形变；页面生成／缓存／按钮原件／名称／Range 各自取证。同路径／大小／旧完整事实下改未准入版本，三出口都拒，恢复后仅原边界恢复。旧 box／vCube 转换或基础预览不证新严格 profile，不放宽格式来保旧夹具；来源拒绝与转换失败分开。
