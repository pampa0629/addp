#### 隔离夹具与身份边界

`make test-online ONLINE_SUITE=pg-source-authorization` 仅使用 GitHub Hosted disposable、正式 IAM、共享生命周期及既有 PG 业务源；不连接个人库。办理者、消费者、业务确认者及组织维护者职责分离：消费者沿原 Meta 基础扫描／目录、Manager 读取功能，不获签发／委托；集中扫描、范围刷新及 Transfer 功能仅按各切片明确授权，数据 Grant 不代表引擎管理权。

所有人员 Role Scope 精确绑定当前 `tenant_id`／tenant；缺失、跨 Tenant、Platform 及携带遗留字段的 Department／Project Group Scope 均拒绝。组织事实独立核 `organization.departments`／`project_groups`。成员退出不改角色／功能 Permission，不删除组织 Grant；仅退出阶段按正文重认证，其他阶段沿原凭据和期限，不为通过断言增权或换身份。

#### 公共清理与证据要求

PG 各切片及下文 MinIO 专项共用。身份、阶段、预算及资源范围沿各自正文，NFS 沿自身场景。

- **准备与归属**。办理／消费身份分开。操作前私有登记本轮命令、接收方、目标及任务。成败或中断均收尾，未知或部分结果只按当轮归属与精确目标核对回收，拒删外来对象。任务、锁及源恢复沿专项。
- **清理与证据**。当轮有效来源逐主体归零，保留签发／撤销／到期历史。领域、Hosted 源容器与账号、Infra 分别取证，清理失败整套失败。报告只留身份引用、状态、计数／行数及安全摘要，凭据限 owner-only 文件或进程内存。[T4 数据、超时与清理](../T4-Online验收规范.md#数据超时与清理) · [报告约束](../T4-Online验收规范.md#报告)
- **PG 标准入口**。`make test-pg-authorization-online-runner` 覆盖确定性反例和生命周期，由 Online／Platform 纳入。真实 T4 按固定源码与实际回执认定，首过前只手动，专项范围与门禁分层见各节。

### PG 整引擎导航

复用原 PG 完整套件、普通 User 和正式 Grant API；120 秒扫描、45 秒根 Grant／75 秒到期观察不变。按[公共身份与清理](#隔离夹具与身份边界)执行，不替代两段浏览器、1500 串行及原 90 秒七档负载。

整引擎序列按[共同断言](#整引擎导航共同断言)；PG 独有要求是自有 Business 容器创建真实空 schema，basic 为零 DataItem／一个节点，未来表与原表均真实读两行，旧命令重放不复活。精确路径／命令预登记，物理空 schema 随独占容器销毁。

**负载凭据与审计。** 并发前、90 秒窗口外沿 Client Credentials 取得同一 Manager Runtime／Tenant 的机器 Token，核 ServicePrincipal 与原准备身份相同，仍为 5 分钟有效期。窗口内人员／机器凭据固定、401 不重试、不延长有效期；不能无限复用前段 Token。七档采样与唯一未授权批量对照共用该 Runtime，人员分别为 reader／outsider；完整审计含 2640 次采样及唯一 403。对照按独立真实请求窗口核唯一 403，采样按原七档窗口／数量／唯一请求身份核 200，不按状态丢弃其他记录；查询上限多留一条发现超量，不加请求或预算。

本次 PG Hosted 不包含 NFS／MinIO 整引擎 T4；它们按下述独立版本认定，不启用 CPU 切换。

| 在途拒绝 | PG 冻结两精确项并同时锁两表，不猜顺序。原生活动证一次 exact lookup 已准入后撤两来源或等到期，再解锁；该单元可结束，下一单元拒绝。Meta SQL 精确 `namespaces=0, tables=1, workspace_detection=0, other=0`，保账号全量及逐语句归属，不扣猜测探测或删旧统计。取消／依赖故障也阻后续，新 Grant 不扩冻结计划。 |

失败抛原异常，按[公共清理](#公共清理与证据要求)收权、核执行终态，另释放源锁、删精确夹具并核源字节不变；不动个人扫描，共用 helper 确定性检查不代 T4。

### 审计尾延迟诊断

共用[采样与收尾](#读取裁决性能采样约束)。限 Hosted 取证，保持认证、裁决、连接、事务、池与同步审计。阈值、日志安全和池等待归因见[AuthContext 解析诊断](../../../../system/docs/IAM数据模型与迁移规范.md#authcontext-解析诊断)。

| 观察层 | 证据与归因 |
| --- | --- |
| 数据库／宿主 | 采 `pg_stat_activity` 等待类、事务／查询时间、阻塞 PID、WAL／DB I/O／checkpoint 累计及 Linux 磁盘／I/O pressure。仅新隔离 Infra 开 `track_io_timing`／`track_wal_io_timing`，保持 fsync、同步提交、权限及持久审计。缺样不作零等待。 |
| 规则 SQL（CPU 对照） | System 原完成日志记录规则墙钟区间与原 SQL 返回的后端 PID，无新增往返或谓词变更。按请求 ID 核唯一完成及查询区间，再以同 PID／SQL 类／区间归属活动。缺日志或计时即失败；只留区间、ID／PID、活动数、等待类。无活动样本不证明无等待，次数不折算等待时长。 |
| 两次身份解析 | 路由认证、Meta 返回后规则快照复核各一次，Meta 前复用入口事实，无第三次解析或零时长 `pre_meta`。逐请求核事务进入、会话、部门／项目组／角色权限、内存投影与退出的纳秒墙钟，缺段／次数错即失败。仅留耗时，含驱动和调度。 |
| Access Token 与驱动（CPU 对照） | 原查询行返回服务端耗时，与 GORM 墙钟配对。服务端从 PG 命令起点到行求值，含等待／调度，微秒精度以纳秒表示。两次解析均核配对和段内边界，差值不归特定进程调度。不开 PG 语句日志。 |
| Go 墙钟分段 | 当前连接按调用 `QueryContext` 前、调用至首行预读返回、返回至 GORM `Scan` 结束分段，完整非负且服务端行求值耗时不超中段。pgx stdlib 返回前预读首行，中段无法单独量化 socket 收包；后段含解码、扫描、关闭和 Trace，无法单独量化扫描 CPU。 |

**4／3 vCPU 对照**。原 PG Job 手工运行，同 VM、同提交，先 4 核，再以干净检出和全新夹具跑 3 核。每组 90 秒，仅跑[七档中的单目标 1／5／10](#小规模并发与两目标批量性能样本)，沿原轮次、样本数、业务及旁观／撤源拒绝断言。报告记 `single_target_cpu`，完整负载标 `not_run`，常规串行与七档另验。

准备、元数据撤权检查、采样后授权和清理均在 4 核运行。仅 3 核组的采样／观察窗口下线一核，成败或可处理中断均先恢复并留在线状态。准入、恢复、断言、清理或 HTTP 日志匹配缺项即失败。固定先后与重置夹具只说明 3–4 核敏感性。两组诊断开销单列，禁与无观察器旧基线推收益。WAL／I/O 同涨不证单请求因果，未复现不证峰值修复。

### 授权生命周期与来源

PG 各阶段沿[隔离身份](#隔离夹具与身份边界)。访问结果用真实 Manager 预览取证，System read-check 只取裁决证据。来源并集与成员退出均核旁观者和相邻表拒读。成败均[逐主体收权、核零并留历史](#公共清理与证据要求)。已验范围见[固定版本证据](#规则与分版本证据)。

#### 单表授权生命周期

普通表依次核无权拒读、限时 Grant 实读、拒重复签发、精确 `basic + force` 后身份／边界保持、撤销和自然到期。直接批准期间，相邻已扫描表始终拒读。到期前后同一消费凭据，禁止调时钟或以撤销代替到期。

#### 个人与组织来源

IAM 先建成员关系再签会话，分开同权限成员与旁观者。同一 DataItem 核个人／部门／项目组并集，全部记录按直接接收主体过滤。节点／单项与父／子节点独立签撤，撤一来源保持其余，最后来源撤销或到期才拒读。原编号重放不续期／复活，禁个人排除或 Deny-only 路径。

#### 成员退出与 API 重新登录

租户管理员沿既有角色，用正式 IAM API 依次结束部门、项目组关系。每次退出后旧 Token 在 AuthContext 和 Manager 均 401。原账号正式重登录后授权版本前移，Principal、Tenant Membership 与四项消费 Permission 保持。退出只移除继承，组织 Grant 和直接历史保留。API 与实页均核仅余项目组时读两行、退出最后组织后拒读。

#### 成员退出后的浏览器刷新

同一 Console／Manager 会话重读遇 401 自动刷新，每次 Refresh Cookie 仅轮换一次，Console／iframe 的身份与新 Token 收敛，原 iframe、路由及选择保持。末来源消失时数据项级拒绝并清旧行，无重复登录或页面级 Forbidden。协调仅传本轮标识／阶段，Playwright 原输出与失败附件留 Secret 目录，公开仅状态和计数。业务批准与其他引擎另验。

#### 读取功能权限反向门禁

业务确认 User 的 AuthContext 保 Catalog 确认权限，缺 `manager.data_item.read`。办理者仅签限时单表 Grant，前后核绑定完整且有效；Manager 返回 `403/permission_denied`，无数据及元数据。禁止用撤权、源规则或 Security 拒绝充数。显式撤本 Grant 并核历史，账号权限及凭据保持。

#### 新成果初始授权

仅 `pg-source-authorization`、Hosted 标记、`addp_online` 同时满足时，PG fixture 授登记连接账号 `public` schema `CREATE`，新表归创建连接账号。禁授已有表 INSERT／UPDATE／DELETE、所有权或超级用户权，其他 suite 只读。分验数据库准入、功能 Permission、DataItem Grant；建表失败不计授权拒绝。

授权与工作区后启 Transfer Backend／Worker，同一消费 User 仅补创建／读取／执行／删除及派生 Execution Authorization 功能。System／Meta／Transfer 各用独立 OAuth Client。限时精确源 `metric_people` 同步到随机唯一 PG 表，关任务自带扫描，Meta 仅一次 basic 子执行识别该叶子。消费者不获签发／委托。

物理成功后后台自动签发唯一 `task_production` Grant，绑定原执行、DataItem／边界、人类来源及独立机器签发者，期限等于唯一输入来源。禁止用机器 Token 直接触发签发。成果实读两行、旁观拒绝；撤源后仍可读成果，撤成果后拒绝。

签发／撤源／撤成果共用随机成果名字面量 `table_search`，省略会含节点 Grant 的 `catalog_path`。逐项核 typed path、execution、产出来源、接收方，截断或外来项即失败。未知响应限已捕获任务的执行与该候选集。先撤源 Grant，再核清可能丢回执的成果 Grant，最后删定义；表随独占容器销毁。成果按自身固定版本 T4 认定。

#### Catalog 集合的确定性验证

真实 Catalog PG＋受控 AuthContext 经 HTTP 核同 Tenant 项目组成员且有功能权可访；退出后列表／详情拒绝，集合及成员条目保留。部门可见性另限条目，缺功能权的成员也不可读写。OAuth、PG 内容读取各按 T4 认定。

### 读取裁决性能采样约束

串行、七档与 CPU 对照共用原隔离身份及 Grant，保持业务、浏览器与收权断言。归因见[尾延迟诊断](#审计尾延迟诊断)。

- **身份与实际读取**。各轮／单元前后核同一 AuthContext、完整 Grant 历史、Meta 指纹和组成边界，凭据只在内存比较。PG 预览核精确列、值和行数，无权／撤销／到期拒绝。已知 `total` 须准确，未知须 `total=null` 且 `has_more=false`。[分页契约](../../../../manager/docs/数据预览语义协议.md#表格预览分页)
- **计时与统计**。固定入口 `POST /api/v1/system/engine-access/read-checks/manager-pg-preview` 成功只返回有效 `observed_at`。只作裁决，实读另验。计时为 GatewayClient HTTP 至 JSON 解码的毫秒往返，含身份解析及 Meta 查询。勿用作纯规则 SQL 或整次预览耗时，禁与旧服务端整数毫秒直接比较。留原值及预热／成功／失败计数，正式成功样本按 nearest-rank 算逐轮及合并 P50／P95、列轮间范围。保留异常值，禁加性能阈值。
- **观察器与收尾**。当轮 `addp_online` 只读连接按 50ms 目标间隔采样，限 95s／2000 样本／32MiB，绑定请求／单元窗口与审计 ID，无 SQL、参数、用户值或凭据。漂移、非预期拒绝、传输／响应异常及超预算均失败，留已采计数。禁额外延时、刷新身份或重试。先关观察连接和线程，再收权并[清理](#公共清理与证据要求)。
- **分层证据**。`make test-pg-authorization-online-runner` 验确定性准入、采集和失败清理。真实查询及资源证据归同次 PG Hosted，业务通过按独立断言认定。仅用当轮夹具与测试授权，保持 suite、入口、依赖、权限和生产 API。

### 依赖故障、直接授权与内容变化

仅由同一 Hosted 协调器在当轮隔离环境按标准启停。核监听关闭、同构建新进程、其他 Owner 未重启。保原身份、凭据、权限、源边界及生产同步周期；失败也恢复并按[公共收尾](#公共清理与证据要求)清理。旧 `c8977cecb` 的结果、原件、清理与缺口见[旧许可模型证据](#规则与分版本证据)。System 并发 T2、Runner、T4 分开认定。

#### Security 首次保护投影

同源 Security 先于 Manager Ready。新建 Tenant 后、首次 Meta 扫描前，`online-api.wait_manager_read_boundary` 经正式 Manager 入口有界等待精确 Engine 投影。只等初始化 `security_protection_required`；其他拒绝、畸形或超时均失败。投影就绪才核 System Grant 拒绝，禁止跳过保护、补 checkpoint 或加消费权。

#### Meta 事实依赖离线与恢复

持有效 Grant 停 Meta，事实查询和预览均须 503，禁止原生回退、假报未扫描或替代授权。恢复无重扫，保原身份、批准摘要与历史，原 Grant 实读恢复、邻表仍拒绝。撤原 Grant 再核拒读。组成扩大、列授权另验。

#### Catalog 业务批准闭环

前段结束后为原无权邻表启 Catalog，限单表、不启 Asset／Portal、不扩引擎。负责人限目录读取、盘点、编目及共享确认，办理者另有办理权。沿基础扫描自动建档、责任／边界、确认及办理 API。Catalog／System 各自 OAuth 受理、签发，请求绑定业务批准和 Meta 边界。脚本不得持机器 Token、直写批准／Grant 或配置旧逐项许可。

仅确认时拒读；签后核 DataItem 指纹、边界、接收方、期限、唯一历史及 Manager 实读，旁观仍拒绝。沿 System 原路径显式撤权，同参及撤后重放禁重发、续期或复活。

#### Catalog 可选依赖离线与恢复

停 Catalog 后原 Grant 仍可实读、System 历史不变。新办理报模块／代理不可用且零 Grant；合格办理者另显式授权旁观者，实读后撤销。离线撤原 Grant 即拒预览；恢复后原请求重放不复活，离线失败请求无受理／签发。禁止自动转直接授权、重扫、改启用声明或增角色。停机前已受理的请求可沿原窗口续办。

#### 普通表内容变化

Business 自有单表按固定增／改／删与基线恢复逐次精确 `basic + force`，保 Meta ID、fingerprint、边界与 Grant 历史，有效 Grant 实读变化及恢复值。撤后变更、重扫、重放均不恢复权，旁观及邻表仍拒绝，退出恢复基线。限 single 内容更新；同身份组成扩大、列授权、multi／whole 另验，边界变化匹配归 System PG T2。

- **技术来源**。1440px／900px 核 API 引擎名／类型、项名／类型和完整路径。双列宽度、长指纹省略、悬浮／聚焦全文、Tab 移出关闭及刷新恢复沿 Console T3 共用 helper。
- **共享历史与候选**。核确认的接收方姓名、可选账号编码和“当前账号”，刷新保持。候选核姓名／登录名，只读选择当前账号，禁止发业务命令。
- **失败与报告**。warning/error 或 API 失败均失败，仅首次匿名 Refresh 401 可单列至多一次。唯一 `addp.enterprise-catalog-publishing-browser/v3` 绑定本确认，来源、双视口、刷新、当前账号的布尔断言须齐全且类型正确，出现共享命令即失败。真实页面覆盖按原 Runner T4 认定。

#### 弃用与责任变更

同夹具 `curated → deprecated → curated`。弃用时用现有 User 增／移可选技术负责人，保持弃用状态和业务定义、语义、可见范围、来源。撤弃用不恢复认证。旧版本 `409 catalog_entry_version_conflict` 零副作用。跨部门发现与权限交集归 Catalog PG T2。

#### 普通只读共享受理

业务负责人须有显式共享确认和独立办理 Permission，使用管理员预置的有效引擎管理委派。沿正式准备、Catalog／System OAuth 反查和首次受理，禁读取、初始化或修改直接授权配置。

| 核对面 | 独有断言 |
| --- | --- |
| 期限与绑定 | 请求十分钟，办理窗口自首次受理起至多五分钟。同参重放保持完整绑定、受理时间与截止时间。 |
| 冲突 | 同决定号换用途、同办理号换决定均 `409 catalog_sharing_decision_conflict`。原决定／回执及编号计数保持；允许操作审计，以数据库实际计数为准。 |
| 恢复与身份 | 丢弃已提交响应只验调用方恢复，服务间断网与进程重启另验。User Token 调机器反查或受理须拒绝，pending、错绑定或核清失败均失败。 |

#### 恢复清理与审计留存

成败均沿[T4 清理要求](../T4-Online验收规范.md#数据超时与清理)收尾，变更只用正式 API。临时编目、弃用与责任变更须在 finally 恢复并回读完整聚合，保留审计和并发版本。写响应未知先查状态，禁重发原命令；恢复失败整套失败。临时资产与目录独立执行[下架、删除和零残留核验](#资产发布与临时资源清理)。保留永久 PG 源及稳定夹具。业务决定、核清办理、System 回执、自动 Grant 和签发审计留在专用 Tenant。

### OAuth 自动签发的只读观察

按决定、受理、签发分别取证。原 User 正式受理，生产 Catalog 自身 OAuth 自动签发，脚本禁止借机器身份写 Grant。System owner 夹具仅在回环 `addp_online` 用只读可重复读事务，按精确 Tenant／Engine／请求号观察。禁止初始化身份、迁移、写入或作为人类 API、Catalog 副本及访问裁决。

`grant_write` 须证明原受理窗口内恰一 Grant 和一条成功审计，重放后签发时间与审计次数保持。`source_content_read` 标为 `not-run`。

`make test-online-runner` 核确定性协议和准入，`make test-system-iam-postgres` 核真实 PG 只读查询及拒写。完整 OAuth 按原手工 T4 实际执行认定。

| --- | --- |

### 服务发布与应用草稿验证

非管理员检测输出契约，发布私有主 Query Service `commerce-order-analysis` 与同契约未授权服务 `commerce-order-analysis-denied`，用主服务 Consumer Descriptor 创建草稿并查询。SQL 只 JOIN 既有表，排除姓名、邮箱、电话、地址。MySQL `BOOLEAN` 暴露为 `TINYINT`，仅把已知语义的 `active_customer` 发布为 `bool`，Service 按冻结契约归一化 `0 | 1`。

- **API**。核 `order_no` cursor、五类动态筛选、decimal／boolean／timestamp／null 及完整有限 CSV，核无 SpatialInfo 时 Map 不可用。
- **编辑器**。同一草稿依次打开两个正式 Component 编辑器，核 Table 两行及 Chart canvas。无空间契约时页面不显示 Map。
- **契约漂移**。浏览器经正式 Service API 改主服务的公开默认字段，使 `contract_fingerprint` 变化。刷新同一应用后须告警并阻断预览，API 读回的持久快照仍为旧指纹。沿正式编辑入口，无额外 Workbench 执行 API 或测试旁路。

### API 消费方身份与数据面

管理员仅建一个授权主服务的消费方和一枚 API Key。完整 Key 仅在进程内存，报告、日志及错误均排除该值。

| 请求 | 必须返回 |
| --- | --- |
| 主 Query Service | 200 |
| 同 Tenant、同契约未授权 Query Service | `403 api_consumer_service_denied` |
| `GET /api/v1/system/tenant/api-consumers` | `401 api_consumer_control_plane_denied` |
| 删除消费方后，旧凭据访问主服务 | 45 秒内变为 `401 api_consumer_credential_invalid`，超时失败 |

覆盖限表内请求，规则见[Gateway 认证边界](../../../../gateway/docs/gateway架构说明.md#2-路由平面)。45 秒为本场景上限；Gateway 正缓存和 Service 逐请求复核见[缓存与撤销](../../../../gateway/docs/gateway架构说明.md#4-缓存与撤销)。

### 临时资源收尾

`finally` 按当轮捕获 ID 删除消费方（凭据级联失效）、草稿和两个 Query Service，核各资源 404 与上表撤销结果。Host Gate 停 Fixture 及全套 ADDP。已发布应用的运行态归 Outdoor 双服务场景，清理禁止强删旁路。

## NFS FileGDB 整容器授权（2026-10-29 接入范围）

[授权目标契约](../../addp授权上下文规范.md#557-dataitem-授权的统一目标契约)定义 whole／精确组成。源 Deny 步骤与 Permission 已退役，见[退役规则与历史证据](../evidence/数据保护与执行血缘历史证据.md#退役规则与历史证据)；根范围和元数据准备见[独立根导航阶段](#nfs-整引擎导航固定-08484e4e7-完整-hosted-已通过)。

[原始成员](../evidence/数据保护与执行血缘历史证据.md#nfs-filegdb-原始成员授权--hosted-t4-通过)、[整目录 ZIP](../evidence/数据保护与执行血缘历史证据.md#nfs-filegdb-整目录-zip-下载--hosted-t4-通过)、[浏览器保存／截图时序](../evidence/数据保护与执行血缘历史证据.md#nfs-filegdb-浏览器保存--同响应字节验收)、[单元格／切换](../evidence/数据保护与执行血缘历史证据.md#nfs-filegdb-子表单元格与切换--hosted-t4-通过)各按固定版本核检查数、首败、清理及缺口。新模型和分页各需独立证据，检查数按版本认定。

### 接入与身份

手工 `manager-internal-artifact-lineage`／`filegdb-authorization`，限 NFS／GeoPython；确定性入口为 `make test-manager-online-runner`。消费 User 沿原六项读取／扫描／执行观察，独立 source initializer 办整项 Grant。旁观者同 Tenant，仅有 `manager.content.read`、`manager.data_item.read`，无 Grant 或组织关系。保持原账号和权限，额外树观察权仅属根导航。

- **整项身份**。Meta basic 识别一个 whole DataItem，`.gdb` 仅一叶，清单只读、不列碎片。精确项批量选节点仅展已识别项，排除未来独立项。签前重核事实和资格，服务端 `scope` 绑定 NFS／DataItem／FileGDB 根及规则，新增子表保持摘要。错根、越界、缺事实或组成不全即拒绝，禁浏览器自造 scope。
- **挂载**。Runtime 仅挂当轮只读 NFS 客户端，禁挂宿主源目录。`noac`／`soft` 仅用于测试。
- **旁观反例**。原／新增子表各核主账号读成功、同 locator 旁观 403 无内容、主账号仍读。各用原凭据，主 Grant 历史与来源保持，旁观关系为空；核 `ungranted_account_initial_child_denied`、`ungranted_account_new_child_denied`。缺功能、跨 Tenant、匿名或 Security 未就绪均不能充数。

### 内容读取与下载

子表、成员流／`storage-assets`、逐成员 Range 和 ZIP 统一按当前 User 重核整项 Grant、撤销／到期、Security 及实际 Runtime 根。成员读取保持授权；父只展示 Meta 索引，basic 未索引记未知，禁 Service 身份补读。原／新增子表的读取及 ZIP 均核无权、获权、撤权及自然到期，获权时核成员字节与 Range，旁观及故障恢复沿各自断言。

ZIP 能力要求 `requires_current_user=true` 且实际可下载，限本格式。独立物理快照核 `.gdb` 根、层次、原名、成员集、CRC、逐成员 SHA-256 与附件头，核原字节，完整接收才保存。API 与页面均沿上述四种状态，临时包检查归[故障恢复与清理](#故障恢复与清理)。

### 浏览器渲染与保存

真实 Console／Manager iframe 使用原 User 与整项 Grant。每操作恰一次请求并核精确 locator 及当前身份；下载只用 Bearer，禁 Cookie／URL 凭据，证据排除 Token。导航零业务／授权写，前后源、Grant 历史及来源保持。禁止替换响应或改内部状态。

| 切片 | 独有断言 |
| --- | --- |
| 单元格／切换 | 按 label／value 核 `initial_points` 两行，真实选择器切 `added_points` 一行并清旧行。核页内／总数与各次请求成功，留两截图及 DOM 单元格，证 `real_browser_child_cells_and_switch`。 |
| 分页／复位 | 保原 2＋1 行，仅新增阶段添 23 行 `paging_points`。默认 20，首 0–19／次 20–22，首→次重读；切 added 再回 paging 复位首／20。核逐格值、当前／总数、页码、前后按钮、清旧、截图和每请求 child/page/page_size。`real_browser_child_pagination_and_reset` 独立取证，旧 24 项及切换通过不能补证，原读／下载／撤权／到期保持。 |
| 保存／拒绝 | 四阶段仅获权保存，独立解 ZIP 沿物理快照核验。三拒绝均须同 locator 403、页面报错、无成功提示或下载事件，缺一失败。 |
| 同次响应 | 复制同一次页面 fetch 响应，原响应交页面，副本与保存 ZIP 逐字节比、分别归档，复核成员／CRC／大小／摘要。禁用可能重发 URL 的 Playwright `response.body()`，禁止额外请求、网络替换或修改产品；副本缺失、失败、重复或字节异均失败。 |

### 故障恢复与清理

仅独占部署强退 Manager／断 NFS，保原源及 Grant，恢复后仍按原授权读取。断前路径可读，断后须有界 I/O 失败；`mounted_path` 仍读通、超时或仅观察到停止均失败。不可用与 403 分别认定，禁产品重试、看门狗或故障收权。

SIGKILL 仅覆盖已持本轮临时 Grant 的子进程；整机／Runner 失联另验。存活外层与 Hosted 生命周期按预登记收权，核撤销史、有效来源归零、旁观无有效关系及自有源／NFS 导出销毁；临时身份随部署销毁。逐请求及最终核 Manager 无临时 ZIP 句柄，成败均核领域收权。清理失败即整轮失败，设施销毁不能补领域证据。
