## T0-T1

T0–T1 不依赖运行中的 ADDP 服务或开发业务库，重复执行后无外部残留。需 Online 条件的测试只在专用门禁显式开启并拒绝意外 Skip；下列专项中的真实来源 T2、受控页面 T3 与正式身份验收分别认定。

| 通用边界 | 必须断言 |
| --- | --- |
| 环境隔离 | Infra 单测的 Docker 与监听查询均取夹具事实，不混用真实 lsof；真实端口另由解析回归核验。观测夹具先清父环境的个人观测选择／部署路径／传输配置，再设显式输入。 |
| T2 开关隔离 | 模块执行平台 T0／Go T1 前移除 `*_POSTGRES_TEST_DSN`、`ADDP_*_INTEGRATION`；仅对应 T2 步骤保留，禁止单测绕 owner 锁清共享库。 |
| 浏览器源码 | 按模块 ESM 契约从 stdin 用 `node --check --input-type=module` 校验，在确定性测试／夹具编译前拒绝非法语法。Node 主版本取根 `.node-version` 并核实际二进制，不以目录或文件模式返回0代验。 |
| 生命周期 | T1 覆盖 starting→registered、registered→recovering→registered、拒绝→failed、取消→stopped及限时注销；未注册／recovering 的 Worker／Scheduler 不领取，恢复后无需重启。 |
| Backend 就绪 | `/health/live` 无外部调用；自身检查通过的 `/health/ready` 返回200并独立报告注册状态，Not Ready业务路由返回 `503 module_not_ready`。 |

专项保留：

- GeoPython：失败即时输出完整 nodeid、setup／call／teardown及 traceback，继续原集合并保留最终非零汇总。唯一 conftest hook 的分布式报告由控制端输出；独立子pytest证明先失败诊断先于后续执行。不得筛例、重试、提前结束或扩大 Linux Job 60分钟预算。
- GeoPackage：CRS 拒绝夹具显式用 `srs_id=-1`，独立核 `gpkg_contents`／`gpkg_geometry_columns`／SRS／OGR；OGR可有合成工程CRS，但GeoDataFrame须为 `None`，不依赖 CreateLayer 默认。保留0号未定义地理SRS、双层精确绑定、自定义无EPSG、原拒绝／不保存／三成果OGR及源与旧成果不变。见[load字段契约](../workflow/矢量算子契约.md#load-文件字段类型契约)、[Requirement 11](https://www.geopackage.org/spec/#r11)，不扩大Hosted证据。
- Business PostgreSQL只读Compose渲染：原命令／环境、单次15秒、只读挂载与禁自动建认证目录不变。独立进程组超时仅回收当次组，封闭阶段／耗时／状态诊断，不泄露命令／配置／stderr／凭据／端点／路径／PID；非零、取消或清理未确认仍失败，不接管daemon。沿原指标配置入口及 `make test-dev-lifecycle`；[历史超时](evidence/Monitor部署与前置诊断历史证据.md#compose-配置超时)尚不由回收修正证明根因或Linux同轮闭环。
- Metrics固定窗口探针：私有目录准备／编译最多180秒，实际及Go执行上限60秒，Job20分钟不变。编译失败不运行遗留产物，执行失败不重试；CPU／进程／HTTP／磁盘／IO／网络／文件系统／inode断言与清理完整保留。

Runtime依赖／SDK及专项入口见[Owner补充门禁](Owner补充门禁.md#addp-owner-补充门禁)。

### Go HTTP 追踪第一批本地验收

原标题保留供旧链接定位。产品规则统一沿[Trace契约](../addp平台运行观测规范.md#65-分布式追踪与日志关联二期第一批)、[HTTP质量契约](../addp平台运行观测规范.md#64-http-接口质量分阶段接入)及[正式身份本机闭环](../addp平台运行观测规范.md#正式身份的本机隔离闭环)；本节只列测试独有断言。真实T2、本机正式身份、Hosted T4、容量／长时留存分别报告，实际结论见[Monitor历史证据](evidence/Monitor历史证据.md)。

确定性夹具不安装依赖、启动真实服务或开启新窗口；复用既有owner／runner／CI。首败不由后继成功或清理覆盖，不加重试、补读、请求、等待或资源额度。安全诊断仅限有界闭集，不保留正文、路径、端点、命令或凭据，不从候选分类推定根因。

#### HTTP 质量、来源与页面

产品指标、部署和停源语义沿[HTTP契约](../addp平台运行观测规范.md#64-http-接口质量分阶段接入)及[停源历史趋势](../addp平台运行观测规范.md#停源实例的-http-历史趋势)。专项断言保留：

- Common Python／Agent／Copilot核唯一中间件及正式注册、Trace开关独立、全量完成／未完成／后台错误、在途回落及模板隐私；512组合／4 MiB越限整源失败，独立Registry无默认CPU／RSS。
- `make test-monitor-metrics MONITOR_METRICS_TEST_ARGS=--case=http-quality` 及默认all核真实SDK／HTTP SD／mTLS／Prometheus、一分钟窗口、缺样／身份串用拒绝、告警／签名重试／恢复／清理；Trace另报，输入沿原登记，无Hosted旁路。
- 调度内核核失败后保留完整恢复额度、晚切换、不突发／补发／借额／重启用、三源总量／模板轮转；预算回执缺失／损坏／错归属／早退／未启动源均拒绝，零分母或缺样不恢复告警，固定窗口沿原promtool T2。
- 启动回执覆盖复制至身份发布，安装诊断64 KiB；先造导入负缓存再模拟安装，经真实bootstrap可导入，不运行pip或借现成依赖。ImportError仅白名单版本／组件；首源失败仍核两源，Docker替身验证唯一down含 `python-http`、私有目录清除且首败非零。
- 两源唯一256 MiB tmpfs核 `exec/nosuid/nodev`，缺标志／读取失败禁止安装启动，原生扩展先成功再导框架；两份requirements各取正式四项HTTP依赖，保留extras／约束，拒缺／重／串用。单挂载通过不代验Linux实链。
- 页面核七汇总／六排行及顺序、自然趋势与画布数值；篡改、无有效趋势、陈旧Agent拒绝。canonical query一致后重载，核单iframe；存活／停源分回执，同页刷新清旧值／详情／空汇总排行趋势，退在线列表不强造离线行。
- 停源历史核当前User精确授权、注销／lease、未知冲突／同址换实例、绝对离线前区间／登记保留边界、缺样与零、URL恢复及撤权清图。Linux T2须读取停源前已存样本，不能用存活历史／空数据代验。

### 线拓扑手工容量基线

`make test-vector-topology-capacity` 仅由 `.github/workflows/vector-topology-capacity.yml` 手工选择，不进入日常／夜间负载或重复业务T4。小样本、篡改、资源／profile／身份／清理及登记沿 `make test-geopython-workflow`、`make test-vector-topology-capacity-runner` 与既有Python CI。本页定义独有容量矩阵；结果只认固定构造的通过档及首超限档，不认证最大容量、稳定吞吐、任意线网或SLA。

| 预算 | 串行每档一次，4 CPU／2 GiB、memory-swap=memory／`swap.max=0`；worker启动至生成、完整读取／源oracle／计算／全保存／独立OGR全重载／末轮源不变共180秒，构建／就绪另记，Job90分钟。超时终止该容器，不重试／扩预算／减样／删oracle或改算法制造通过。 |
| 完整内容 | 固定字段宽度、业务ID、EPSG:3857整数XY，FID不替业务ID；闭式预期不调用生产几何／求交／去重／图遍历。核全坐标／类型／XY/M／有效性／来源序方向、Schema／NULL／Int64／Boolean subtype／CRS，源内存与文件哈希不变。 |
| 读取与dtype | 每表一次流式OGR，绑定索引／原生getter／NULL，核全部值／Python类型／FID；固定属性编码器只初始化一次，`sort_keys/ensure_ascii`／空格／实际浮点与冻结旧标量摘要逐字节一致，旧参考仅小样本测试不作运行切换。核typed NULL／大整数／Boolean／Unicode及真实污染，不用源提前失败充目标拒绝。`grade`为OGR Integer64，load后无NULL仍为pandas `Int64`，不兼容NumPy int64／Float64／object；源摘要含索引类型名值，核>`2^53`贯穿输出。见[load字段契约](../workflow/矢量算子契约.md#load-文件字段类型契约)。 |
| 计量 | 保存源码／实际编译代码绑定、阶段耗时、worker RSS高水位、cgroup CPU／OOM／swap及原0.25秒外部样本。`memory.peak`为容器启动以来累计峰值，不称阶段／纯计算峰值；`memory.current`阶段最大样本只称采样峰值，没样本记未观测。 |
| 证据／退出 | 全摘要、大小／SHA、checkpoint、失败日志与清理；大文件／旁文件退出即删，摘要不证明离线重读。只清所属容器／registry／唯一标签／目录，保留普通缓存、不全局prune。超时／OOM／不符均失败；清理成功才继续余档，清理失败停，任一失败使总门禁非零。 |

`case`默认 `all`；仅 `profile=normalize-chains` 可显式选 `compose-grid-512-normalize-chains`，经 `TOPOLOGY_CAPACITY_CASE`／`--case` 透传。错配在Docker前拒绝，报告保留 `case_selection` 与实际计划；单档不算该版本十五档，也不证明同Runner收益。

线内自叠每源≤2048原始候选对分批，原逐段索引、配对顺序、精确去重及一次融合不变；Native核少于／等于／超过2048、跨批源去重、完整顺序与异常不保存。变更后容量另报，历史源码／镜像／版本／Runner差异不得冒充受控对照。

#### 显式观测与旧新对照

| 显式profile | 独立计划与汇总条件 |
| --- | --- |
| `observation` | `TOPOLOGY_CAPACITY_PROFILE=observation make test-vector-topology-capacity`：仅十万稀疏自叠，同Job／Runner／镜像按ABC、BCA、CAB各三次，共九容器。A仅共同外部采样；B增收集／融合计时、次数、输入片段数；C再增0.25秒内部采样／进度JSON，退出恢复生产函数、不替换计算。A/B无内部样本记null不填零；准备／归一／计长含总计算，共同六阶段不归差分。 |

comparison要求 `fetch-depth: 0`，缺历史失败不回退。归档旧代码仅测试输入，不进产品兼容路线；保留两份模块／来源哈希、仅三定义变更的AST核验，旧RootFS=原层＋唯一COPY，入口／环境／cwd相同，worker在预算内读实际模块／收集器hash。错绑／额外差异／版本输入结果不一致均拒绝。小样本、频率／缓存／Runner漂移限制外推，历史Runner不替代对照，不认证其他拓扑、密集长线或SLA。

## T2

真实且可丢弃的基础设施必须由标准owner入口拥有完整生命周期，任何破坏性操作前核身份，拒开发／生产库；仅清当次Schema／唯一标识事实并核零残留，拒意外Skip。CI独占Service随Job销毁。
