# ADDP 追踪与日志关联

[返回平台运行观测总入口](../addp平台运行观测规范.md#65-分布式追踪与日志关联)

SDK 传播、采样与容量、读取授权、查询交互、执行短阶段／Link 和正式身份本机闭环以本专题为权威正文；共同身份、权限与交付边界见[总规范](../addp平台运行观测规范.md#三对象与模块边界)。章节号沿用总规范编号，命令在仓库根目录执行。


现行范围包括已登记 Go backend/ingress 同步 HTTP、[Agent／Copilot Python 同步 HTTP](#python-同步-http-追踪接入第二批)及[Orchestrator→Develop bounded 短阶段／Trace Link](#执行短阶段与-trace-link第三批)。接入／未支持边界由各专题维护。数据库／SQL Span、浏览器采集、真实 72 小时保留／删除、长期合并和生产 HA 不由本节补证；本机、正式身份闭环、Hosted T4／T5 沿[分项证据](../testing/evidence/MonitorTrace与日志历史证据.md)，条款不授权实跑或代表已验。

唯一路径为 Common Go／Python SDK→Alloy OTLP→Tempo，Monitor 读 Trace、System 沿 Loki 授权日志。Go Common Router 工厂独占服务端追踪／请求关联，Common Client／Gateway 复用唯一传输并保留 Context、超时、TLS、响应流；Python ASGI／HTTPX 归其共享内核。Trace 不另设指标路径或推算全量 QPS，计量沿 [6.4](HTTP接口质量.md#addp-http-接口质量)。

Gateway 外部入口重建 W3C Trace Context，内部同步传播 traceparent，不传播 baggage／外部 tracestate 或向平台外泄漏上下文。request_id 入口生成、约束格式并内部继承，trace/span ID 不证明身份。同步调用边仅由可信来源、实际匹配的 Client/Server Span 证明，parent-id、目标名、注册关系不能补造边；执行 Link 沿其专题，不冒充调用边。

公共身份／HTTP 属性仅取正式模块／角色／启动实例、模板、有限方法／状态及固定错误，阶段字段沿专题白名单。不采集完整 URL、Host、转发头、SQL、正文、原始错误、Token、用户／租户身份。日志从 Context 取 trace_id/span_id，校验长度／十六进制／非零后仅作 Loki 结构化元数据、不作索引；精确过滤绑定模块／实例、正文权限、游标指纹。

### 共同预算与 HTTP 保留口径

| 范围 | 契约 |
| --- | --- |
| 生产端 | 已结束 Span 异步导出，队列最多 2048，满计丢弃、不阻业务；导出超时／退出刷新有界，关闭／配置失败不改 Ready。 |
| HTTP 保留 | 服务端失败沿 6.4 优先，4xx 不自动算失败；Server 请求 ≥1 秒优先，普通成功 5%，例行成功健康／心跳不留，遥测导出不递归追踪。阶段保留见专题。 |
| 等待／分配 | 120 秒、10000 待决 Trace、采样后 100 Span/秒；错误／慢／普通依次分配 70%／20%／10%，不保证任意负载都留全部错误或 5% 普通请求。超长、迟到、队列满、限额、重启的不完整性须计数。 |
| 部署／存储 | 沿 Alloy v1.10.2 支持参数，不提前裁剪 Trace 字节／增加 Kafka；初始 Alloy 1 CPU／1 GiB、单进程 Tempo 2 CPU／2 GiB，内存保护与硬限分开，共享故障不称物理隔离。Tempo 72 小时、独立 MinIO bucket／凭据及 20 GiB 硬配额，另预留约 5 GiB 工作空间（非文件系统硬限）；容量优先、不保证任意负载均留满。日志仍 168 小时。 |
| 查询 | 默认 15 分钟、最长 1 小时、最多 100 条 Trace；整次 1000 Span／2 MiB JSON，单个上游响应也 ≤2 MiB，共享五秒、单主体 2／单 Monitor 8 并发，无任意 TraceQL／端点／标签／属性查询。 |

容量公式为 `保留 Span/秒 × 实测平均压缩字节/Span × 259200 秒 × 索引/冗余系数`。预算示例：100 Span/秒、512 字节、系数 1.5 约 18.5 GiB；1 KiB 未计额外开销已超 20 GiB。50 请求/秒、每请求八 Span、普通 5% 约 20 Span/秒，错误／慢请求另占预算；10000 待决在 120 秒下约容纳 83 条新 Trace/秒，超出须有丢弃证据，不当作已保留。上线前按实测大小、吞吐、丢失和存储占用复核；示例／小样本不是容量证据，须独立核对[隔离容量基线](#隔离容量基线)。查询代理另限 0.25 CPU／128 MiB，日志／MinIO 复用成本另计。

列表明细采用唯一有界并发路径：每请求最多四个明细读取，System 当前 User 裁决、Tempo 搜索／明细合计最多八个活动上游调用；仍占原主体／Monitor 请求数及五秒总额。结果保序，Span／参与实例／JSON 累计检查；任一失败／耗尽即取消剩余读取并等待工作者退出，不返回部分或尚未整体授权的数据，不靠增时、缩小原抽查数或扩大 CPU 配额掩盖失败。串行读取首败及复验见容量证据。

## 隔离容量基线

本地 disposable 专项仅适用于固定三 Go 进程 Gateway→Monitor→System、每请求五 Span 的同步 HTTP 链；沿 SDK 属性白名单，不注入正文／膨胀属性，不运行 Hosted 或连接个人服务。普通 T2 不隐式执行容量负载，入口为 `make test-monitor-traces MONITOR_TRACES_TEST_ARGS=--capacity`。

| 档次 | 持续时间与真实入口负载 |
| --- | --- |
| 常态 | 600 秒、50 请求/秒，普通／5xx／≥1 秒慢请求为 90%／5%／5% |
| 预算边界 | 600 秒、70 请求/秒，比例 60%／30%／10% |

慢请求实际等待 1.1 秒，恒定速率调度、并发最多 64，不以积压后突发补发掩盖入口不足。入口速率、请求结果和实际保留速率分列，不从采样反推业务吞吐。

- **预算**：模型保持 120 秒等待、10000 待决、100 Span/秒、72 小时 TTL、20 GiB bucket 配额；全部当次运行容器（含发生器）合计硬限 ≤6 CPU／6 GiB，生产 Alloy 1 CPU／1 GiB、Tempo 2 CPU／2 GiB 不变，不在宿主无配额施压。总时限 40 分钟；每轮检查全部当次卷实际分配后等五秒，记录完整实际间隔及间隔内超量。达到 2 GiB、退出／OOM、失败或采样中断即停清理并判失败；2 GiB 是停止线、非文件系统硬限，不放宽条件补完成。
- **完整性**：每档发送后等真实尾采样／自然落盘，不缩 TTL、等待或切块、不直写对象。记录生产端队列／导出失败，Alloy 接收／决策／导出／早退，Tempo 接收／拒绝／刷块，块／索引对象字节、MinIO 物理分配及 WAL／本地块／其他卷峰值；经授权路径抽查五 Span／两条匹配边。传输丢失、早退、OOM、负载不足、未完整落盘、缺关键计数或样本不足均失败；策略内未采样／配额舍弃另报，不当遥测故障或全量保留。
- **外推**：取完整落盘档次中最大的物理字节/保留 Span，含块、索引、MinIO 元数据／分配开销。短测未覆盖长期合并峰值时加一份完整副本作保守上界，不称合并实测；实测速率的场景预测另列，预算上界按 `max(100, 实测最大保留速率)` Span/秒 × 259200 秒 × 单位成本 × 副本系数。20 GiB 留 20% 余量，总预测 ≤16 GiB 才满足容量条件；工作空间另对照 5 GiB 预留、不纳 bucket 配额。超线须给同模型最大可承载速率，不靠提高丢弃率过关。

2026-10-21 两档本地基线通过：72000 请求、78540 保留 Span 自然落盘，两次二十条完整查询 4.69／1.97 秒；以 226.83 字节/Span、100 Span/秒、双份副本外推 72 小时约 10.95 GiB，低于 16 GiB。维持初值与采样目标。[容量证据](../testing/evidence/MonitorTrace与日志历史证据.md#http-追踪隔离容量基线本地)保留私有冻结源码标识（非 Git SHA）、原始报告、查询首败／复验、清理及共享宿主重叠限制；[原历史入口](../testing/evidence/Monitor历史证据.md#http-追踪隔离容量基线本地)仍可定位。

原报告须留固定输入摘要、每档时段／样本量、物理／逻辑字节、公式、成败及退出零残留。短测只证明该 HTTP 链、属性、版本、资源及单节点存储模型，八 Span 示例不是实测；不外推任意大小／链深、长期增长、独占宿主性能、实际 72 小时留存／过期物理删除、长期合并或生产 HA，后者仍待独立验证。

## 采样定义与 Trace 读取授权

采样定义由 Monitor 维护为不可变版本：首批容量模型为 v1，[执行短阶段契约](#执行短阶段与-trace-link第三批)升级为 v2；当前入口读取 policy.json 并把实际策略写入报告，历史 v1 容量结论不证明当前 v2 已验。Infra 生成唯一 Alloy 配置并记录版本，无策略编辑／热发布控制面。端点、证书、资源／存储额度归部署输入，不以环境变量并列维护采样策略。版本发布／门禁、配置意图、运行生效和投递确认分别认定。Tempo WAL 时间容差由尾采样等待加 180 秒生成（首批 300 秒），覆盖结束 Span 的尾采样／导出／入库延迟，不沿恰好 120 秒默认值导致历史窗口漏查。

OTLP 沿独立 TLS／认证及部署来源约束，不开放任意写入。Trace 查询须非委托 Platform User 及独立 `monitor.trace.read`，默认授既有平台系统管理员；逐请求由 System 按当前 User 裁决；读取每条 Trace 须核验全部所涉模块／实例及 Link 目标，任一无权／不可裁决整份 Trace 拒绝，历史不以当前租约 UP 为条件。日志另需 `platform.module_log.read`，正文归 System 独立授权；Tenant 不开放平台链路，浏览器不直连 Tempo。以下入口共用 6.5 的查询时限、大小、并发和授权约束。

调用关系只从同一有界查询内实际匹配跨度派生，不存第二份调用事实；展示窗口、采样限制和不完整性，不推根因、血缘或部署关系。查无 Trace 不单独判为未采样／过期／丢弃，能力故障与未找到分开。异步任务沿执行短阶段契约自建 Trace、用 Link 关联，不延长创建请求 Span。

### Trace 筛选与时间窗口

筛选栏按模块、时间、Trace ID 排列，窄屏换行；模块选项来自 System 已授权目录，只表示已登记、不保证启用 Trace／有样本。选择／清空模块立即提交，实例列表回第一页并清除原实例、时间及 Trace 详情，由 Console 单历史恢复筛选。观测层由实例／关联深链传入，普通列表默认 backend，不另设层选择器。

完整规范 Trace ID 自动精确查询，无须模块／实例；清空后可按已选实例查。已选模块仅有一个授权实例时自动查，多实例一次选一个运行实例 ID；无实例且无 Trace ID 时，时间条件等待后续定位。

| 时间方式 | URL 与查询窗口 |
| --- | --- |
| 相对 | 默认最近 15 分钟，可选 30 分钟／1 小时；URL 仅存预设、默认省略，刷新／返回按当次查询时刻重算 |
| 历史 | 只选开始，结束取开始后 15 分钟与当前时刻较早者；与相对预设互斥，清空历史开始恢复最近 15 分钟 |
| 显式／入口深链 | 恢复原 start／end，不滑动／扩窗；服务端一小时上限及保留期约束不变 |

同身份、同实例、同筛选下，实例内“查看调用链”仅切换下方列表／详情，保留顶部标题、返回实例按钮、筛选／时间、实例表及分页内容与布局，不重读实例信息；“返回调用链列表”回到该实例的调用链列表及原窗口。无实例的精确定位在输入框回显查询 ID，实例内详情 ID 只在摘要显示；全局定位详情可返回运行实例列表。

刷新、筛选／实例／权限变化沿读取、取消与失效清除规则，迟到响应不覆盖新上下文，不留失效授权数据。未命中、实例不明或服务故障保留表单／输入、清旧 Trace，并区分提示、允许编辑重查；一次查询由路由、身份变化或显式操作触发，不依赖 iframe 可见性。只有实例列表成功返回空集才显示“无匹配实例”。

### 当前页调用链样本检查

“本时段调用链”仅异步检查已授权当前页最多 10 实例，先呈列表，再显示检查中／有样本／本时段未发现／暂无法确认；不扫全量或后台轮询。唯一批量入口 `GET /platform/traces/samples?instance_ids=...&start=...&end=...` 要求同组显式起止、1—10 个不重复 System 实例记录 ID，不接受 TraceQL／扩展筛选，不新增权限。

整批占单主体 2／单 Monitor 8 名额中的一个，共用五秒绝对截止、100 参与实例／1000 Span／2 MiB 投影及最多八个活动上游调用；批内至多两实例并发、每实例只搜一个候选。候选经明细、全部参与实例及 Link 目标授权核验才为 `has_samples`；成功但无候选为 `not_found`，只表示本时段没有已保留样本。候选不可读／超预算／读取失败／未知为 `unavailable`，不由首候选失败推无样本或继续补扫。

身份／权限失效整批失败并清前端状态；只返回实例记录 ID／状态和 start／end／queried_at／policy_version／coverage，不扩身份或计调用链数量，超时／整体失败显示“暂无法确认”，不冒充空样本。每批冻结顶部时段，点击实例携同组显式 start／end 入列表／详情，不重新滑动；刷新／翻页／换时段重查，取消旧请求、隔离迟到结果。单实例自动查询、精确 ID 和 5xx 深链沿原入口，已有详情不额外批查。

### HTTP 5xx 样本联动

在线 HTTP 实例选接口后，从已读趋势的同一起止、实例、精确方法／模板跳转；趋势超过一小时须先选可查范围。`http_method`／`http_route` 必须成对并指定实例；实例、角色、方法、模板、500–599 须命中同一 HTTP Server Span，且完成于窗口内。Tempo 先按同 Span 搜索，Monitor 再按明细／权限核验，返回整条已授权调用链，仅代表已保留样本。

详情先列“所选接口的 5xx”，再列从命中 Span 沿已观测父子关系及匹配调用边可达的最深失败 HTTP Server Span，同深度取时间线顺序。无匹配边、仅失败 Client 或只在别支失败时省略下游项；各项提供定位／原权限日志，和最长下游项指向同 Span 时合一行。它们表示已观测失败位置，不证明根因；普通查询／详情沿原规则。

### 精确 Trace 定位与日志入口

`GET /platform/traces/{trace_id}` 可省 `instance_id`，省略时仅向 Tempo 点查该 ID 一次，不枚举实例／扩窗。沿上述逐项授权，无权或归属不符整份拒绝、沿未找到语义；实例列表、行内详情及因果 Link 仍保留实例约束。

精确 Trace 未找到且页面仍有本次 User 已授权明确实例时，保留模块／实例／筛选／完整 Trace ID；有 `platform.module_log.read` 才显示“查看该实例关联日志”。只跳 System 现有实例日志页，传原实例、Trace ID 和同次点查的显式起止；相对窗在点查前冻结，不等点击再滑动。零日志预取、不读其他实例／枚举模块，不因未找到授其参与实例读取权；System 重核所选实例及正文权限。

404 只说明当前条件无可读保留链路，不代表完整 Span 或确定未采样；无明确实例的全局 ID 不猜日志归属／显示入口。查询中、503、401／403、实例列表失败或无效响应均清旧入口，切换查询／身份与迟到响应沿失效规则。

### Trace 详情摘要与时间线

普通详情先显示入口结果、整链耗时、已观测失败和时间线。失败摘要取最深非 Client 失败节点，无此节点则取时间线首个失败 Client；显示模块、接口／执行阶段及状态，可定位 Span／按原权限查日志。多失败 Span 不等于多个独立故障，优先定位不等于根因。

外部总报告旁独占创建 0600 的 `<report-stem>-browser-first-failure.json`，仅将空文件绑定原浏览器容器；首败同步写入并 fsync，最多 2048 字节，最终报告引用同一回执。不放入退出销毁的部署目录，不等 finally／清理后才保存；无首败保持空文件、不作通过证明。写入失败仅 `filesystem_error`，不重试／覆盖原失败。观察或写入前硬终止仍可能无证，缺失为未知、不补写；私有完整回执沿原 finally 生成并销毁。原浏览器 240 秒／容器 300 秒及整轮预算不变；诊断开销计入，受控门禁不替代真实窗口。

既有 bounded query 请求首败冻结为 `bounded_query_failure`，清理前写入总报告，清理失败不覆盖。样本只为 success／failure，操作只为 `develop_definition_create`、`orchestration_definition_create`、`orchestration_execute`、`parent_execution_read`、`diagnostic_child_execution_read`、`child_execution_read`、`monitor_tree_read`；类别仅 `http_status`、`transport_failed`、`invalid_json`、`response_shape`、`request_failed`。状态取同次请求异常，稳定码仅接受小写字母开头的字母／数字／下划线，其他为 unknown，不补状态；只定位请求边界、不证明根因。不存 URL／参数／正文／异常／令牌／身份引用，不加请求、等待或重试。确定性门禁逐操作注入失败，核对首因、安全投影及请求序列不变。

### 凭据与产品准备

Trace fixture 只在私有 prepare 创建 0600 最小 `openssl.cnf`，含无交互 req／dn、CA 的 SKID／AKID；原九次 OpenSSL 子进程局部环境绑定，六次 req 显式 `-config`，不继承／修补宿主配置、切换工具链或改全局环境。保留 RSA 2048、一天有效期、CN、CA／keyUsage、用途、SAN／EKU 和权限；CA 显式 `subjectKeyIdentifier=hash`、`authorityKeyIdentifier=keyid:always`，叶扩展为 `subjectKeyIdentifier=hash`、`authorityKeyIdentifier=keyid,issuer`，不依赖版本默认或兼容分支。

原 16 步仅记录 prepare、ca_server/source/query、各身份 csr／sign／tls、publish_ca、render、finalize。退出封闭 JSON 最多 2048 字节，只含 schema、已完成／当前步骤及 none／openssl_command_failed／timeout／filesystem_error／renderer_rejected／unknown；配置创建失败归 prepare／filesystem_error。仅从本次 fixture 原捕获流读取，缺失、超限、冲突、非规范或乱序明确不可用；不存异常／参数／路径／证书／密钥／环境，不加命令、等待或重试，不改退出码／清理。未产生完整回执仍按原失败，不追填旧报告。

`make test-monitor-traces-local-runner` 的故障注入不执行真实凭据命令；受控离线 T1 用缺失环境配置路径验证覆盖，实际执行原九次生成，核对用途／名称／算法／有效期／信任拒绝及目录销毁。离线组 60 秒、材料／输出峰值 1 MiB、含验证读取最多 24 次命令；缺 OpenSSL 即失败。随 Platform consistency 生命周期执行，不启动 Docker、个人服务／身份或真实窗口，仅证明证书前置。

产品配置先校验，再启动同一组独占依赖，对当次库执行 `scripts/infra/init-postgresql.sql`、`ON_ERROR_STOP=1` 初始化扩展／schema，实际就绪后才构建业务；不另建依赖或在预检建身份／执行任务。依赖运行时先停构建器，以 2 CPU／3 GiB、两个 Go 编译线程编译；随后恢复 1 CPU／2 GiB 构建器，确认同容器运行且非 OOM 才清除计划停止状态，守卫核对并存配额。镜像构建后只替换同一私有 Compose 的实际不可变 ID；Trace 查询代理保持 T2 的宿主所有者私有证书与 capability 限制，一次性容器退出状态留至统一清理，非零／OOM 拒绝。

MinIO 复用当前提交 `scripts/infra/Dockerfile.minio` 固定 MinIO／mc 发布版本及源码提交：核验缓存镜像不可变 ID、Linux ARM64、两个二进制版本／嵌入提交，同 ID 用于卷测量、真实 MinIO 和两个存储初始化步骤。缺失／不符即拒绝，不冷构建或接管现有服务；后端、runtime-log 和前端仍由当前提交标准构建，核验／部署／等待计入原窗口。

### 产品构建分类与增量观测

以下仅复用当次 `product_image_*` 已捕获输出和原命令，HTTP／Trace 共用 `public_build`，不额外读取 Docker／Registry／网络／APT 源文件或加探针。分类只留固定原因／失败步骤、已知产物输入名、Dockerfile 行号和有界 HTTP 状态／进程退出码。正常非零构建整份分类输入最多 128 KiB、紧凑 UTF-8 JSON 诊断最多 4 KiB；整份超限记 `over_budget`，不截尾当完整。缺失／不唯一明确不可用；不输出日志、任意符号、URL、路径、凭据。这是解析／回执上限，不是原捕获流硬上限。原退出码、output_sha256、首因、采样／资源／清理保持，身份／业务正文不进入构建分类。

### 卷检查点与清理后取证

原同一次 Docker exec 测量管道前后仅输出固定进入／返回标记，沿独占捕获流、command_id／run_id／phase 归属，不拼其他输出。成功须唯一、有序、完整标记及数字／错误校验，不保留旧纯数字成功路线；返回不证明 `du` 成功／完整统计。失败仅解析已捕获残片最多 4 KiB，检查点与卷归属摘要合计 512 字节；缺失 not_observed，冲突／畸形 invalid，超限 over_limit，读取失败 unavailable，不推测未执行／送达／故障点。

完整检查点帧至多 4 KiB、16 条诊断，只识别明确 du 路径消失格式及当次只读挂载表的规范 `/space/<编号>`，按编号记固定卷类别、缺失卷根／后代计数和 run_id 域的规范路径集合 SHA256。不存路径、卷名、诊断原文或凭据；混合、缺失、截断、越界、歧义、超限均未知，只证明缺失位置、不推断删除者。诊断用原四秒余量，耗尽即停；失败诊断／取消实耗单列计实际总耗时，不重置截止或反转首因。成功解析也须在原截止内，不加请求／容器／线程／探针／proc 读取／跨 VM 校时或改 API 协商、原测量顺序／互斥。

资源守卫首败导致同阶段精确构建命令取消时，只在取消前冻结该命令已解析增量摘要及原捕获文件大小，绑定 run_id／phase／command_id／单调时间、校验样本与命令时序；不补读正文或用取消后输出回填。缺失、未读尾部、截断、归属冲突或步骤不唯一均未知，沿 4 KiB／CPU 预算，取证故障不替换守卫首因。

仅获准 HTTP `compile-checkpoints` 的 `product_compile` 或 `full` 镜像阶段，在完整检查首败为卷测量超时、报告／命令同 run 且清理确认零残留后，允许一次原私有 Docker 端点的只读 `docker events`：限定当次测量容器名／所有权标签、容器类型及 `exec_create`／`exec_start`／`exec_die`；原宿主锚点前后各两秒，首尾墙钟偏移差 >50 毫秒、缺锚点／异常边界记未知。命令三秒，事件输入 ≤64 KiB／256 条，取消沿原有界回收；发生在原验收／清理计时结束后，不改变原结论／预算。

容器名、标签、容器 ID、`execID`、固定命令、顺序全部一致且无竞争才留一组候选，缺退出事件单列。只存宿主 command_id、固定状态、事件类型／纳秒时间、容器／exec ID 哈希及 exec 启动路径哈希；缺失／歧义／截断／查询失败均未知。候选不证明宿主唯一归属或已进入扫描，后者仍由原检查点证明。恢复超时代理关联和镜像 inspect 超时取证沿[HTTP 取证规则](HTTP接口质量.md#启动交接与失败取证)，均不重发原请求或改判历史失败。

<a id="volume-checkpoint-follow-acceptance"></a>

随行采集仅附着以后另行获准的原专项隔离生命周期，不新增入口／采集器／选项／编排，当前无有效窗口即待授权；不为取证重建、重试或附着个人／其他会话对象。新增业务／压测／构建次数／Docker 请求均为零，编译至少 12 次完整样本只从原 report 离线核验，不改运行断言或延时补样、借空闲样本。共享所附运行全部截止／清理／资源预算，不另加 120 秒或 40 分钟。确切 helper／卷集、固定源码／输入摘要及原命令端点共同归属，残片 4 KiB／摘要 512 字节，不跨命令／阶段拼接。

固定输入、真实归属、最小样本、完整统计／检查点、预算和清理全部满足，才判“真实采集链路通过”。未复发不证明修复；复发仍首败停止，完整取证不算稳定性通过。未见标记是未观测、返回不是 du 成功，均不单独裁决 CLI／daemon／VM 根因；采集、繁忙稳定性、根因、正式页面分列。历史自检／繁忙授权不构成新随行运行授权。

### 采样命令时序与清单读取

每轮保留阶段、容器／卷数及列表、inspect、状态、helper 准备、卷／私有目录扫描、最终校验步骤实耗；命令记录创建、等待、输出及取消，不由外层计时覆盖已完成／失败步骤。仅固定操作／状态／数值，不存正文、环境、inspect 或凭据；耗尽位置不等于该操作独自耗时四秒。

命令记录整数单调端点：进入、创建前后、观察退出、输出结束、判定、命令结束、取消开始／结束；PID 只在创建成功后有值。耗时取端点差，不由舍入步骤反推；观察退出不是内核实际退出。等待仅沿原 `p.wait`，以 `min(0.05, deadline-now)` 有界轮询，检查片不超过 50 毫秒，不固定睡满 50 毫秒。`wait_poll` 每命令 ≤512 字节，字段 `calls`、`timeouts`、`timeout_overrun_total_ns`、`timeout_overrun_max_ns`；calls 含成功／TimeoutExpired／其他异常，后两项仅对 TimeoutExpired 累计／取最大 `max(0, 调用包围区间单调耗时 − 当次传给p.wait的timeout)`，不足 50 毫秒不按 50 算，无超时计零，取消的一秒等待不纳入。不存逐次／异常／命令／环境，不从总等待扣它推 daemon 时间或认定调度／退出／唯一根因。计量开销计原四秒／600 秒，首因照常传播，旧报告不补算。

2026-11-17用户确认资源采样的最小等待收敛：仅将同一轮容器清单与卷清单两个既有读取重叠，替换原串行清单路线。复用pending_command、原Unix socket／CLI、标签过滤、编译详情参数与请求签名，每次仍各一次；只在同一采样锁及同一绝对4秒截止内启动两个CLI子进程，不新增线程／请求／采样／重试。两清单完整读取及子进程回收之后，才进入原编译暂停、inspect、状态校验、builder卷合并、全部卷与私有目录测量；不重叠du，不缓存上一轮值，不减少检查对象。清单阶段最多两个采样子进程，不能与后续并行私有目录测量叠成第三个；原严格／普通模式、资源停止线、最长开始间隔和整轮预算保持。此条仅修改上述两清单的发起／等待顺序与并发峰值，不推广到其他命令或改变既有轮询、测量和取消期限。

每项清单显式绑定独立step、command_id及单调端点，记录可重叠的耗时，不把两项耗时相加冒充整轮耗时；观察退出仍不等于内核实际退出。任一观察到失败、到期或启动第二子进程失败，按原TERM一秒／KILL一秒上限回收尚存子进程，取消清理单列且不延长成功采样截止；原首失败及其命令诊断冻结，另一取消失败不能替换。未确认停止的清单子进程保留引用，外层清理先有界KILL／确认，仍未停止则不删除私有目录并报告清理失败；守卫线程未确认结束时同样停止删除，防止后继清单仍在启动。原同签名重叠拒绝保持，不同签名只限此明确清单组。清单不是原子快照，不从并发推导更强一致性；对象／卷集变化沿当次清单及原builder挂载规则验证。共享Lifecycle的Trace和HTTP确定性入口必须同批验证；原历史超时不追认修复，真实运行仍单独确认。

### 跨层归属与独立诊断预算

准备、采样、清理的归属列表调用均登记 command_id、run_id、固定操作、phase、PID 和规范化请求签名；本地 command_id 不是服务端请求 ID。同签名重叠拒绝，不以无界锁延长采样，不改标签过滤、原 Unix socket／CLI 或 API 协商。可靠关联须当次标签、方法／路径／查询签名、无重叠请求对、顺序、校准区间一致且未被其他命令占用；准备／清理不算成功采样，不按时间邻近强配 ping／inspect／缺失或重叠记录。登记容量有界、超限拒绝而非静默丢弃，清理后报告包含全部归属命令。

校时前须有当前可核对版本依据，证明 Docker Desktop apiproxy 时间戳为请求处理而非接收／落盘；路径／请求文本／时间相近不足证明。语义不明即停，不发送自检或加代理／VM 容器。只校代理日志时间轴，不证明 VM 内核同步或 daemon 耗时。独立只读探针用唯一随机标签、不建对象，以宿主命令起止包事件估偏差，不假设往返对称或用业务匹配反向拟合；每组前后区间取保守外包络，宽 >50 毫秒、矛盾／跳变、轮转断档、多解均失败，不放宽容差。

归档离线判定只读同 run 已有命令登记、目标编号和连续时段归一化事件，最多 4104 条命令／8208 条事件，不读实时状态或存原文；目标须完整成功的归属列表命令。无独立校时／版本依据时，仅同签名开始／返回唯一成对、落入目标包围区间且无竞争可记唯一候选，缺失／多解／断档／冲突未知。可靠关联另须当前事件语义、覆盖区间的宿主单调／墙钟锚点、独立前后校时及 50 毫秒／跳变／一对一校验；已给但无效校时不得降级候选。仅留固定状态／原因及适用的代理跨度，跨层分段须对应边界／可靠时钟，daemon 分段另须同请求进出记录；独立归档不改采样首因／结论。

### 页面路由与门禁归属

根 Nginx 模块页复用请求时 DNS，去模块前缀并保留子路径／查询；缺模块应代理失败，不用虚假 Backend／其他页面代替。仅构建 Console／System／Monitor 页面和根 Nginx，原六 Backend、身份／执行／采样／Trace／日志断言不变。真实 Nginx 路由 T2 核对缺模块 502、嵌套路径／参数／静态资源，共享同一检查；独占回显服务不算正式身份／业务闭环。

准入、守卫、采样、身份与清理确定性测试归既有 Platform／owner，公共 workflow 拒绝真实人工入口；按影响分别走 Go、IAM／owner PostgreSQL、Trace T2、生命周期及前端标准门禁，详见 [T0–T3 专项](../testing/T0-T3测试规范.md#trace-传播查询与容量)。未运行／失败／跳过不算通过；本机闭环不覆盖 Hosted、容量重跑、定时、其他 Runtime、continuous、SQL Span、真实 72 小时或生产 HA。
