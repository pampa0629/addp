| 口径 | 契约 |
| --- | --- |

| 窗口与聚合 | 固定 1/5/15 分钟窗口，默认 1 分钟；QPS 是完整窗口边界的请求计数增量／窗口秒数，失败率为同窗口失败增量／请求增量，平均响应时间为耗时增量／请求增量。跨实例先合计计数和直方图桶，再计算均值或 P95/P99；禁止平均百分比或分位值。并发独立读取活动请求 Gauge。 |
| 有效性 | 要求来源身份、本次启动、HTTP 采集启动边界、当前租约、采集新鲜度及完整窗口证据。真实无请求时 QPS 可为 0，失败率、平均/P95/P99 无值；缺样、过期、未接入、采集失败和中心不可用分别表达，不能补零或恢复告警。 |
| 查询与管理 | 仅固定目录和有界实例/接口筛选，接口排行按平均耗时或 QPS 返回前 10 个有完整窗口的模板，预算更小时收紧数量；复用现有超时、并发、序列及点数预算，不开放任意 PromQL、标签或端点。规则、事件、通知复用 Monitor 唯一平台协调器及事务 outbox；新类别显式订阅，旧目标不自动扩订。 |

本节确认统计与职责契约；当前实现/接入及 T1–T4 证据按后续专题分别记录，不能由内核存在推断产品入口和告警已经开放。

接口质量规则绑定 System 模块名与 `backend|ingress` 角色，可进一步固定路由模板/方法及 QPS、失败率或平均耗时指标。规则创建时通过当前 User 的一个真实实例核验模块及角色，之后从同一授权身份投影选择当前实例，不绑定临时端点或退出实例。新实例、规则配置或查询策略变化重新积累窗口；无有效来源及缺样均保持未知，不恢复旧事件。阈值及恢复阈值、连续时长显式配置，新建规则停用，启用/编辑/删除使用 CAS；活动事件阻止删除。统计读取使用独立 `monitor.http_observation.read`，规则使用 `monitor.platform_http_rule.read/create/update/delete`，各写入还须读取权。默认仅现有平台系统管理员获这些权限，不创建运维角色或责任台账。

HTTP 事件类别为 `http_quality`、主体为模块，触发/恢复沿同一平台协调器与 outbox；阈值和实际实例证据保留在事件，不以配置编辑改写恢复条件。通知协议为 `addp.platform-http-alert/v1`，只传模块、角色、规则、模板、指标、阈值与有界采样证据；现有目标不自动订阅新类别，未配目标仍保存事件。HTTP 规则最近评估中，已启用的精确模板平均耗时规则达到配置的连续触发条件时标记“持续慢接口”，不设置隐藏的统一慢阈值。确认和抑制不改变采样结论，通知复用现有签名、限次重试与人工重投。

## 停源实例的 HTTP 历史趋势

首期沿同一个 `GET /platform/http_trends`，以一个 System 登记 ID 和显式绝对 `start/end` 读取。非委托 Platform User 须同时通过 Monitor 的 `monitor.http_observation.read` 及 System 逐请求的 `platform.module.read` 精确实例裁决。复用已有 System 记录的启动实例 ID、模块、角色、进程启动、首次登记、采集声明及离线事实。正常注销用停止时刻，租约超时用 System 的失联判定时刻。恢复续租不重建过去的在线区间。历史读取不使用当前采集身份投影、今天解析的源地址或其他实例的声明。

已离线实例只在请求终点严格早于 System 离线判定时刻时读取历史。超出该边界保持 `not_active` 和空观测，提示重新选择。历史回看外边界为距服务端查询锚点 7 天，复用原可收紧的范围、5 秒总期限及并发、指标、序列和点数预算。完整统计窗口的起点不得早于进程启动、首次登记与回看下界的最晚者。保留原评估网格，边界外的点、缺样、身份或窗口校验未通过的点为 null；活动请求数沿原瞬时采样口径。历史读取不将没有采集证据的零填入曲线。TSDB 体积限制可能提前淘汰，范围内缺数据仅表述为无可用历史样本。

Monitor 在授权后通过固定指标、固定范围，从 Prometheus 受控模块／角色／启动实例标签的已存身份样本定位唯一历史采集序列，复核进程启动时间。出现多个采集地址或不一致的身份事实时拒绝归属；禁止使用当前 DNS、重新探测原端点、用模块名接续重启后的实例或向浏览器泄露地址。之后复用同一 HTTP 指标表达式及两端采样、计数器重置、采集完整性校验。查询保持 `collection.state=not_active`，趋势回执以 `history_state=available|no_data|outside_instance|outside_retention` 单独解释历史可用性。实时摘要、接口排行、告警评估、恢复和通知继续沿当前来源，历史样本不参与裁决。

Console 导航和页面标题使用「HTTP 监控」。模块筛选从 System 持久模块定义取可搜索单选项，选择或清空模块、切换观测层或实例范围立即按原条件提交并回到第一页；统计窗口沿原范围切换。当前页复用服务监控的模块卡片，同模块实例分开展示。在线实例常显 QPS、失败率与 P95，卡内展开其余指标；排行和趋势沿既有实例入口。刷新保留当前页卡片直至新结果返回，授权失效或读失败时清除旧数据。

HTTP 监控默认在线，显式切换已停源实例后用原 System 分页条件查询，复用原趋势图；固定 5 分钟／1 小时／24 小时从离线前最后一个整秒反推。选择后 URL 绑定原登记 ID 和绝对区间，重载不滑动窗口或替换实例。离线视图只显示历史趋势，按既有请求生命周期清理撤权和实例切换后的旧数据。

## Python 全量 HTTP 质量：已确认接入边界

### ASGI 计量、来源与权限

Common Python 唯一 ASGI 观测入口向全量 HTTP 指标和可选 Trace 提供生命周期事实，替换仅 Trace 中间件，不叠加计量路径。指标不依赖 Trace 开关／采样；正常响应在最后 body 成功发送时结束，取消、超时、写失败或异常只结束一次。Ready、认证拒绝、404、健康请求均计量，正文／流式消息原样透传，响应完成后的后台异常不改 HTTP 结果。当前接入 Agent／Copilot 单进程 backend，不接 WebSocket／其他 Runtime。

复用 `addp.process-metrics/v1`、进程实例／启动时间、`ADDP_PROCESS_METRICS_DEPLOYMENTS` 和开发启动单元计划；来源只发布身份、启动时间及与 Go 同名／同桶／同维度的 HTTP 指标，Python CPU／RSS／cgroup 不在此范围、不补零。服务器启动成功后才交正式 ModuleRegistration，来源故障／配置失败／关闭不改变业务 Ready 或同实例不可变声明；每副本独立地址、证书、实例及 Registry，不多进程共享。

私有 Registry 经独立 mTLS HTTPS `/metrics` 暴露，仅 GET、无 query／正文，不挂业务端口；证书、显式地址、固定 IP 准入、采集身份及唯一 HTTP SD 沿既有链路，新增来源占原预算。开发／产品部署同批支持 Agent／Copilot，不新增配置路线、用户权限／角色或 Monitor 公开 API。统计／规则沿 Platform 权限和当前 User 实例裁决，Tenant 发布服务质量仍归 Service。

每进程最多 512 组详细标签，方法／状态／错误为有限值，route 仅框架模板；超限锁存采集失败至进程退出，停止增加组合但业务继续，不截断／合并模板冒充完整。单次输出 ≤4 MiB，应用指标缓存／序列化 ≤16 MiB（非进程 RSS 硬限），采集处理单并发、等待／关闭有界；中心仍为 20000 样本／10 MiB／五秒及原查询预算，失败／缺样不得恢复告警。

### 编译阶段回执与调用归属

标准入口创建回执时固定唯一 `case`，完整序列为：

| case | 唯一 `compile_stages` 序列 |
| --- | --- |
| `http-quality` | `gateway_control → process_source → resource_windows → http_query → http_alert` |
| `mtls-preflight` | `gateway_control → resource_windows`（真实 Gateway 协议夹具与资源窗口，业务请求为零） |

未知／缺失／中途改变 case 拒绝，不兼容旧回执或保留 `process_compile`／直接编译旁路，不以短预检代完整 HTTP。Gateway 通过 `run_owned_compile`，准备最多 180 秒且受工作剩余截止约束；其他编译沿原参数、cwd、环境与期限，共用当次私有缓存／临时目录及进程归属、采样锁、暂停／确认／恢复／清理内核，阶段顺序以表为准。无回执的其他专项仍沿原有界调用，不扩预算。

每阶段最多一次开始／观察结束，分别记单调纳秒与实际退出码：未开始 `not_started`，仅开始／超时或取消未见返回 `incomplete`，非法、倒退、越序或前序未成功即启动后序为 `invalid`；不补造结束、覆盖前序或回填历史阶段成功。Python 负信号退出码与 shell 的 128 加信号语义分开，不充作同一内核事件。

失败保存采样起点、命令开始／观察退出的原始单调秒端点，与编译纳秒同属宿主时钟、不由舍入耗时反推。`compile_stages_at_sample_read` 仅表示获采样锁后读回执所见，退出最终 `compile_stages` 不能回填为失败时状态；两 case 仍各须全部阶段完整成功。取证异常不覆盖业务／编译／du 首因，阶段不证明删除者。

### Go 进程组与稳定读取

全部编译由同一受管 Go 内核启动，子进程独占当次会话／进程组并先自停；持采样锁登记阶段、组长 PID／出生身份（Linux tick、Darwin 起始时刻摘要）、会话／组及直接调用者后才恢复。组长退出须持锁回收，采样期间不释放 PID 身份。Linux `/proc` 与 Darwin 原生 ps／会话调用只读固定身份／状态，最多 4096 个 PID 目录、64 个当次成员、每份 stat ≤4 KiB；超限拒绝。组长／调用者／UID／出生／组／会话不符不得发信号；回执发布复用当次有界元数据锁，防止编译／提前清理互相覆盖，不引入全局锁／按进程名猜测。

四秒绝对截止从等锁前起计。获锁后对已登记组只发一次 SIGSTOP，须两次连续清单成员集一致、全部存活成员停止，变化／未知／超时即失败；随后原范围完整采样，根目录缺失不补零。finally 始终尝试恢复同一自有组并确认存活成员退出停止态；从四秒内预留 50 毫秒恢复，最终恢复／判定也须按时。确认无存活写者的退出组保留身份至持锁回收，下一阶段不越锁启动，不重试 du／换组补读；恢复错误不覆盖更早 du 首因，暂停／确认／恢复实耗及固定结果另列。

confirmation 只保留原组清单读取的尝试／完整返回数、成员集变化数、末次尝试起点及末份完整清单的单调起止、R／S／D／T／t／Z／X／I／other 状态计数；不存成员 PID／出生列表、原始状态、命令／路径。未完整返回或未进入确认留空，不加清单／信号，诊断计原四秒。D 等非停止状态不因此安全，缺取证不证明已停、vfork 或超时根因。

仅暂停确认持续 ≥100 毫秒且当前完整清单仍有 D 成员时，允许每次暂停采一组等待位置：复用该清单（≤64 成员）聚合组长／其他成员九类状态及 D 父→T／t 子的直接关系，不存身份或推未见祖先。仅 Linux 对各 D 成员读一次 wchan（每份 ≤128 字节，达上限整份 over_budget、不截断分类），在同一已打开 proc 目录前后核对出生／UID／会话／组／D 状态；身份／状态变化、消失、无权、读失败、空／无效／0／未知分别封闭记录，不重试／提权。原符号只在内存按白名单分为进程启动等待候选、I/O 等待候选、通用 completion 等待或 other，输出类别／角色／关系计数及组单调起止；仅候选、不唯一证明 vfork／I/O，Darwin 为 not_supported、不加替代探针。

上述逐次读取前后检查同一四秒截止，耗尽记 deadline／剩余未尝试数，不补读；缺失／不完整不改变全成员停止要求，较早等待位置不替代最终清单。HTTP 查询／告警调用者仍计原 180 秒编译墙钟，Common 来源计整体工作截止，暂停不扣时。取消／超时／异常先恢复、再 TERM／必要时 KILL 并回收同组；清理已接管时调用者只回收子进程，不再启动／发布成功。未确认归属／回收不得删私有材料或称零残留，恢复／回收超时仍失败并继续强制清理，不重置清理期限。本协调仅限当次 Go 组，不扩到产品服务／其他进程；修正可变临时树采样竞态不等于直接观测到历史删除者。

### 目录失败的安全取证

`du -sk` 失败立即保留首因，不忽略短命文件、缓存／临时目录或缩小范围。命令局部固定 C 语言，只解析已捕获 stderr ≤4 KiB，超限明确标记并留字节数，不存前缀／截断冒充完整；这是解析上限，不是原子进程输出捕获硬限。CLI 文本类别限路径消失、权限拒绝、I/O、混合、未知、空、超预算，不作为 errno 或唯一根因。

`directory_objects` 在原 4 KiB 内另限八个非空诊断行，超限整组 over_budget；仅认严格 GNU／BSD 绝对路径，须属于当次私有根、无穿越／歧义引号／控制字符；只存位置类别和以 project 为域的相对路径 SHA256，不存路径／stderr／命令／环境／文件名／删除者。根为 root，第一层 go-cache／go-tmp／tmp／source／postgres-auth／tls／deployment／node-tls／control／query-tls 及任意深度后代依次归 go_cache／go_tmp／tmp／source／postgres_auth／tls／deployment／node_tls／control／query_tls，其他为 other；不按后代名称、近似前缀／临时命名推来源，不由旧 other 哈希回填新类。分类不增加文件系统读取或输入范围，不证明删除者／原子发布／根因，无法识别／越界／歧义／混合均明确记录。

只在原截止内对根作一次不跟随符号链接的存在性观察：directory／missing／other／unavailable，余量不足 deadline、不补探针。命令实耗、完整采样累计耗时及命令启动时余量均取同一单调时钟；诊断／序列化计四秒、不重置截止／互斥或覆盖首因。go_tmp 历史删除进程仍未确定，不用新诊断追认已清理运行。

### Python 来源准备与清理交接

两测试来源沿唯一入口封闭记录复制、依赖安装、导入、配置、指标监听、HTTP 就绪、身份发布、运行阶段；只含固定阶段／状态／错误类／数值。安装日志留当次容器临时目录，最多解析 64 KiB 已捕获内容，超限明确标记、不当捕获硬限；不输出日志／异常／路径／凭据或猜版本、放宽只读／UID／身份约束。安装到进程启动时不存在的依赖目录后先刷新导入器缓存，不以补装／改版本绕过。导入检查点、ImportError 组件类别仅固定白名单（未知 unknown），实际版本只读预声明发行包、短版本字符或 unavailable；不将入口检查点当唯一异常来源。

唯一 256 MiB `/tmp` tmpfs 显式 exec／nosuid／nodev，仅限两个隔离来源，保留非 root、只读根、cap_drop ALL、no-new-privileges 及原配额，不改宿主／产品挂载。安装前实读 noexec／nosuid／nodev 标志，noexec 或缺后两项即拒绝，仅留封闭布尔；安装后由扩展加载器实际导入 Pydantic Core 本地扩展，才进框架／业务，无两类证据不算启动通过。各自从 Agent／Copilot 正式 requirements.txt 唯一完整提取 FastAPI／Uvicorn（原 extras）／HTTPX／Pydantic 声明，约束原文不变；缺失／重复失败，不保留共用第三套版本／requirements。依赖文件纳入 Metrics 输入摘要和自然 CI 选择。

采样与清理共用当次私有预算目录文件锁：获锁后重核 project／私有目录及清理状态，发布清理标记后不再开始 Docker 读取；等在途完整采样退出释放锁后才删资源。采样取锁／重读计原四秒，清理等待／删除共享原 120 秒，不无锁删除、重试或忽略消失对象。若守卫已失败且同归属回执进入 mandatory cleanup，停止新采样、等待原清理，不再次 SIGTERM 打断；未进入／归属不符仍原取消路线。真实命令首因保留，释放锁仍强制清理，超期清零也不算整轮通过；该锁不扩到产品、daemon、开发服务。

两个已创建来源均须停止／检查退出，单项失败仍继续另一来源及发现范围恢复；清理错误另记，不由 finally 覆盖首因。down 必须启用同一 `python-http` profile 覆盖全部已创建服务，停止／退出检查不等于删除容器。阶段与清理回执归原预算报告，不新增运行入口。

确定性门禁覆盖两种编译序列及错 case、缺 Gateway、乱序／重复／前序失败拒绝、超时、采样暂停互斥、回收后再删除，以及目录分类／脱敏和 Python 来源准备／清理；原生 Linux／Darwin 信号／身份夹具与模型夹具分列。配置验证用 `make test-monitor-metrics-config`，预算及清理回归归既有 `make test-infra-runtime-log-lifecycle`；真实实链仅沿另行确认的自然 Linux `make test-monitor-metrics MONITOR_METRICS_TEST_ARGS=--case=http-quality`，不因条款或确定性门禁完成而新开窗口／手动重跑。历史记录和未覆盖项以[证据专题](../testing/evidence/MonitorHTTP质量与采样历史证据.md)为准，不将本节技术验收外推为正式身份页面或 Hosted／容量／长测结论。

## 正式 Python 后端与接口质量页面的本机隔离验收

### 入口、身份与部署范围

人工入口 `make test-monitor-http-local` 使用正式 Agent／Copilot 后端和 Console／Monitor 接口质量页；确定性入口为 `make test-monitor-http-local-runner`。真实入口拒绝 GitHub Actions／Hosted／容量／定时标记，运行须有当次明确授权。历史结果见[HTTP 质量与采样证据](../testing/evidence/MonitorHTTP质量与采样历史证据.md)，SDK Linux T2 不替代正式产品实测。

复用本机隔离生命周期、产品构建／Compose、IAM Bootstrap、真实密码／MFA／AuthContext、浏览器及清理内核，不复制实现或扩大 Trace 夹具权限。System-owned HTTP 身份夹具须同时核对私有目录、回环独占 PostgreSQL `addp_test` 和随机 `cluster_name`；不连接共享 addp-postgres、不直接签发会话或写授权表。Platform 系统管理员读取观测及 Copilot 配置；普通 Tenant User 仅持有 `agent.session.read`，安全管理员和 Tenant 为平台观测拒绝负例。`copilot.configuration.read` 不可放入自定义租户角色，不新增产品权限／角色。

当次独立网络仅含 System／Gateway／Monitor／Agent／Copilot 五后端，PostgreSQL／Redis／Prometheus、Gateway 内嵌指标私有 mTLS、Console／System／Monitor 前端及 Nginx；不启动模型／工具依赖或其他 Runtime。Compose 选择 `observability-metrics` 并叠加 Gateway 私有 mTLS 配置，缺所选服务即失败。产品卷保留原初始化选项，不统一覆盖 `nocopy`；TLS 输入沿受控复制、只读挂载。卷测量及 TLS 准备仅使用既定摘要的本地缓存 Nginx：只读核验仓库摘要、不可变 ID 和 Linux ARM64 后，以该 ID、`--pull=never` 运行；缺失、错配或读取失败即停，不拉取／换镜像或放宽 TLS。镜像准入不证明后续构建或进程已验。

### HTTP／Trace 共用资源与构建守卫

下列规则由两入口共用；Trace 的卷初始化与阶段配额另见[正式身份闭环](追踪与日志关联.md#正式身份的本机隔离闭环)。full 窗口含准备、构建、初始化、业务、浏览器和清理，最多 60 分钟，55 分钟停止新业务，清理须在 60 分钟内完成；首次失败即停，不重试或续窗。全部当次受控容器（含构建、运行、浏览器及辅助容器）合计硬配额不超过 8 CPU／12 GiB；卷、容器可写层及私有目录的实际分配合计达到 4 GiB 即停，源码、依赖、缓存和浏览器材料均计入，缺失大小不能按零处理；tmpfs 受容器内存硬上限约束。4 GiB 是停止线，不是文件系统硬配额。

每次完整检查从等待采样锁起使用同一单调四秒绝对截止，涵盖创建／等待命令、`inspect --size`、读取解析、状态与最终判定，重扫不重置；正常开始间隔最多五秒，实际间隔及超量须记录。OOM、非预期退出、资源读取／采样或业务断言失败均停止业务；清理关闭新采样并等待在途采样退出，不缩小统计范围。单镜像仍限 600 秒；取消、恢复和清理实耗分别记录，不借此延长成功截止。

`product_compile` 的 Go 编译复用原镜像、命令、挂载、标签和配额，创建／启动／等待共享原 2200 秒单调期限。按创建返回的完整 ID 启动，与采样共用锁；锁等待及启动确认合计四秒且受编译期限约束，确认后解锁、锁外等待退出码。启动失败／超时须先关闭采样准入再解锁，排队采样获锁后先检查停止状态；非零退出、状态缺失和既有首因均沿失败清理路径。

为避免运行中 Go 临时目录变化导致 `inspect --size` 失败，守卫只暂停同次列表中完整 ID、精确名称、角色均匹配的运行中编译容器；已创建／退出对象仍完整计量但不暂停。归属冲突、意外已暂停或其他不支持状态即失败。暂停对象继续计入配额，完整检查确认对象身份及全部容器／卷／私有目录。四秒中预留 0.5 秒恢复，锁等待、列表、暂停和测量最多 3.5 秒：发暂停前测量余量已耗尽则超时，尚有余量但不足 2.25 秒则以 `compile_pause_budget_insufficient` 首败，不发暂停／恢复、不写成功样本；恰好 2.25 秒允许暂停。该门槛不用于无需暂停的对象。

尝试暂停后，无论测量成败均用原四秒剩余时间尝试恢复同一对象，完整测量及恢复都按时完成才写成功。恢复失败仅在没有更早错误时成为首因；余量耗尽仍保留原首因并按归属清理、核验零残留。仅成功暂停后，将原宿主 `du -sk` 与原顺序的 Docker 只读测量重叠，复用命令内核、共享 3.5 秒截止，不增加线程或对象，结果各计一次；无需暂停时仍串行。各自 command_id／步骤耗时可重叠，延后等待 du 的区间从启动计至观察退出，不相加冒充整轮耗时。任一错误先取消回收其他测量，再在剩余时间恢复；子进程未回收不得恢复或删除测量目录。容器／卷清单的两读取重叠仅按[清单取证规则](追踪与日志关联.md#采样命令时序与清单读取)执行。

Go 编译成功后删除当次 `.cache/go-build` 前，先按完整内核预检（含锁／读取／解析四秒）；已有失败、预检失败或达到停止线不得先删缓存。删除复用 `sample_lock`，锁等待与可中止删除另限四秒，超时须终止并回收子进程，未退出不得解锁。预检／删除分别记时，采样自己的锁等待仍计原四秒；只删当次私有源码 Go 对象缓存，拒绝越界、符号链接及共享缓存，不重试、跳过或排除目录。

### 启动交接与失败取证

`compile_start_handoff` 是 HTTP full／compile-checkpoints 和 Trace 共用的唯一编译交接回执，紧凑 JSON UTF-8 最多 2 KiB。字段限 run_id、固定阶段、启动期限、请求锁／获锁／释放前后单调端点、启动尝试／结果，以及同一次 `docker start` 的 command_id、请求签名、宿主启动／等待／输出／判定／取消端点。释放前后只包围交接，不能当作精确解锁；宿主端点不证明 daemon 耗时。未到达为空，锁超时未启动时命令回执为空。签名由已核验完整 ID 计算但不保存 ID、PID、路径、参数、环境、墙钟或输出；缺失／冲突／类型非法／取证异常记不可用，超限明确标记，不以部分数据冒充完整。

Nginx 缓存准入只对原一次 `docker image inspect` 增加 `sampler_image_inspect`：GET、去 API 版本前缀并解码一次的固定镜像路径、空查询参数计算 SHA256；记录 run_id／command_id、结果、原五秒截止及宿主单调命令端点，命令前后以单调时间包围 UTC 墙钟采样，取消实耗另列。未到达为空，不保存参数、socket、环境或输出，不改变 API 协商。若获准窗口以该检查超时结束且清理完成，可立即只读摘取对应时间窗的现存 Docker Desktop 代理／daemon 日志，独立保留最小脱敏事件、覆盖与原行哈希；不重发、不占清理预算、不反转失败。daemon 到达须同请求入口证据，轮转断档、歧义、缺阶段边界或跨时钟关系不明均不可判定。

原 Go 恢复命令仅记录 `POST`、固定接口类别和完整当次 ID 派生的请求签名 SHA256，不保存 ID／路径／查询／原文。获准 HTTP 窗口以恢复超时为首因且清理零残留后，可在报告之外只读关联现存 VM apiproxy 日志：命令边界前后各两秒，固定日志及轮转副本最多 24 MiB、同签名最多 24 条事件；仅取消前唯一、有序、无同 run 竞争的开始／返回对可为候选。缺两端宿主锚点、轮转断档、不完整或超限均未知；没有独立校时与 daemon 对应边界时只能报告代理跨度，不能推断 daemon 到达／结果／分段耗时。旧报告缺签名不补造。卷检查点、构建取消和清理后 events 的封闭字段见[共用取证规则](追踪与日志关联.md#卷检查点与清理后取证)。

命令内诊断只复用原调用与输出，不新增进程、线程、Docker 请求／探针，不改变启动、采样、等待、暂停／恢复、取消／清理顺序和预算；异常不得覆盖首因或反转结论。`make test-monitor-http-local-runner` 与 `make test-monitor-traces-local-runner` 的确定性回归须覆盖归属、脱敏／上限、锁与截止、暂停门槛上下及等值、测量完成顺序／失败回收、缓存互斥和两个报告入口。真实运行另行授权。

### 私有证书与离线验证

仅在当次 certificates 私有目录（0700）生成 0600 最小请求配置，不读外部 include／provider／用户配置。所有 OpenSSL 子进程局部 `OPENSSL_CONF` 与 req 的显式 `-config` 指向同一文件，父进程／产品／Compose／系统环境不变。叶子签发保留既有 `-extfile`、三套独立 CA、RSA2048、一天有效期、显式 CA 约束、用途、DNS／实际来源 IP SAN；不依赖系统默认配置、不安装或降级工具。既有 phase 区分材料准备、CA／CSR／签发、配置生成和 Compose 投影，成功恢复外层阶段，失败保留确切步骤及首因；文件失败不误记为前一命令，不输出路径、参数、stderr 或秘密。

`make test-monitor-http-local-runner` 及自然 CI 核对配置缺失／污染、失败／超时、停止后续步骤和清理首因。离线证书 T1 调用同一 TLS 实现、配置渲染用受控替身，不调用 Docker、网络或产品身份：单并发、最多 40 条 OpenSSL 命令，含清理 60 秒，材料与在途输出预留合计 ≤1 MiB；单命令最多原十秒并扣减剩余总预算。核对链／CA 约束／用途／DNS／来源 IP 和错误 CA／用途／名称拒绝，缺工具、失败、超限或未执行不能按跳过通过。沿既有入口及登记检查准备依赖，不新增 workflow／版本路线。离线通过仅证明证书前置，不证明产品实链或历史失败命令的唯一归属。

## 公共 mTLS 前置复验：已确认收窄边界

2026-10-26 用户另行确认：先复用当次 Prometheus 容器执行 promtool，不增加临时 2 GiB 容器；来源证书按实际容器 IP 签发后，经 stdin 单次发布到当次来源容器的私有 tmpfs 并在容器内原子替换；Nginx 只从容器内路径加载证书，宿主挂载文件仅更新为下次启动的引导输入，不承担在线换证。验证实际呈送的叶子摘要及严格 IP 名称校验，失败仅输出封闭 TLS 子类。标准入口 `make test-monitor-metrics MONITOR_METRICS_TEST_ARGS=--case=mtls-preflight` 只执行公共配置／窗口语义／身份拒绝／发现与自然采样前置，通过或失败均清理并停止，不启动 Go／Python 业务请求或 Python 来源进程，不替代 HTTP 功能实链通过。

本次一次性窗口含准备和清理最多 20 分钟、4 CPU／4 GiB、卷及私有可写 2 GiB 停止线；完整资源检查仍限四秒，不忽略消失的容器。新增只读 TLS 连接最多四次、每次共享五秒绝对预算，不对失败连接重试；原 15 秒采样和 65 秒自然等待保持。实际叶子不匹配、TLS 失败、未知／缺失证据或守卫失败即停并清理，不自动进入后续功能验收、重跑或续窗；不运行 Hosted、容量或定时。
