# ADDP 工作流栅格算子契约

[返回工作流计算引擎接口规范](../addp工作流计算引擎接口规范.md)

## 栅格计算契约

GeoPython Workflow 使用 GDAL 实现栅格计算。公开输入继续使用 ResourceLocator，`raster_load` 派生 source-only 访问计划，`raster_save` 派生 target-only 访问计划，`raster_to_cog` 使用 source/target 计划；访问协议固定 `addp.workflow.access-plan/v1`。源、目标分别授权，凭据只在执行期传递。自包含 ERDAS Imagine IMG (`format=img`) 复用 `raster_load` 和 `raster_to_cog`；HFA 驱动与引用树检查通过前不读取依赖，RRD 引用列表（含内部 overview）、spill 和 dependent file 暂不支持。`raster_inspect` 仅提供受控 direct 的原生媒体摘要给 Meta，不进入工作流面板、不写产物或权限事实。单幅保存允许 TIFF 及普通 PNG/JPEG：`profile=geotiff/cog` 对应 `.tif/.tiff + format=tiff`，`png` 对应 `.png + format=png`，`jpeg` 对应 `.jpg/.jpeg + format=jpeg`。PNG/JPEG 明确不携带 GIS 定位、源 EXIF/GPS 或旁文件；首期像元／颜色准入及发布前原生校验见[栅格成果规范](../addp栅格计算与成果契约规范.md#21-公开资源和内部对象)。JPEG 质量为 `jpeg_quality=1..100`、默认 90，PNG 不降低原位深。COG 是 TIFF 的 profile，不是另一种格式身份；批量切片仍只输出 TIFF，IMG 写出暂缓。

`RasterDataset` 是执行工作目录内的私有、文件支撑对象，栅格输入/输出端口类型为 `raster`，不得通过 JSON 对象伪造或跨任务保存。公开参数仅经当前 DAG `$ref` 接收该对象。Runtime 对外只投影 width、height、band、CRS、transform、extent、nodata 和 overview 等摘要，不返回像元、临时路径或打开的 GDAL 句柄。成功和失败均清理工作目录；当前公共执行协议没有取消接口，不宣称具备主动取消能力。

栅格切片使用 `raster_tile(input_raster, tile_size=[像素宽,像素高]) → raster_tiles` 和 `raster_save_tiles(input_tiles, access_plan, profile, ...) → object` 两个节点。`RasterTiles` 是当前 execution 的私有源快照与切片网格描述，保存时逐片生成和编码，不同时物化整批中间文件。切片从左上角按行、列递增，不重叠、不重采样；保留边缘实际宽高和全无效切片。保留源数据类型、原始像元、NoData、mask、alpha、颜色解释与色表；有定位时平移完整仿射网格原点，缺失定位继续缺失，不复制源整幅金字塔作为切片金字塔。公开集合摘要只含源与切片尺寸、行列数和总片数，不能据此重建私有输入。

批量保存的公开目标仍为 `target_parent_locator + target_name`，其中 `target_name` 表示本批文件所在的子目录或 prefix，不表示一个 TIFF 数据项。切片键固定 `r<零基像素行偏移>_c<零基像素列偏移>`，文件名为 `<切片键>.tif`；不使用数组下标作为成果身份。每片沿用独立 TIFF/COG 文件、ResourceLocator 和大小事实，不新增整目录数据类型或 whole scope 解释。`create` 在写入前核验目标子目录/prefix 为空；`replace` 仅替换此次网格生成的同名切片，不清理其他文件。目标存储的读写授权分别覆盖存在性核验与发布，Runtime 不得自行扩大到目标范围之外。单幅与批量目标重叠的 DAG 必须在派发前拒绝。

Runtime 成功或部分发布失败的结果包含 `artifact_type=raster_tiles`、`total_tiles`、`completed_tiles` 及以切片键索引的 `tiles`，每个条目含文件名、像素窗口和单片成果摘要。切片或编码失败不发布该片；写入调用失败时，该片的发布结果标为未知，不能把它计为确认成功，也不能假定远端没有写入。整批失败保留此前确认发布的切片，并返回 `failed_tile` 与 `publication` 事实。公共 Python DAG 核心通过既有 `result/all_results/task_order` 保留显式部分成果，GeoPython 投影后才进入 execution；失败仍为 `failed`，不转换为成功。

发布已确认后发生的临时文件清理错误不能撤销该片的确认事实。若仍有未发布切片，`failed_tile` 指向下一片、`publication=not_attempted`；若全部切片均已确认，保留完整清单并省略这两个未发布事实字段，execution 仍为 `failed`。Develop 必须保留完整或部分已确认资源，不能把完整发布清单等同于执行成功；后续扫描和血缘继续遵守既有执行状态规则。

Develop 根据派发前授权的目标范围和经过校验的逐片清单生成实际 `produced_targets`；Runtime 提供的路径或 locator 不作为资源身份。批量节点稳定输出为 `outputs.<节点>.tiles.<切片键>.resource`，每片包含已有 `locator/type/write_mode`。执行输出 Schema 的 `tiles` 为同一资源 Schema 的命名映射；不为未知片数虚构静态输出端口。确认写入的部分成果进入执行专业结果与资源输出，整批状态仍失败；不能依赖整批成功才保留事实。每片自动扫描复用既有 Meta 链路，不扫描父 prefix 来代替逐片成果，不修改字段级血缘规则。失败发布的资源级派生关系遵循 Meta 的既有终态采集规则，不能将失败 execution 宣称为成功血缘验收。

Meta 对批量产物只读取已持久化的 `outputs.<节点>.tiles.<切片键>.resource.locator`，逐片匹配精确 file/object 请求。只有确认发布且进入稳定输出的切片可以继承父执行主体；任意嵌套字段、批量目标目录、兄弟文件和未确认切片都不能作为扫描依据。继续在创建事务中校验同租户 running Develop workflow、完整主体事实及调用方身份，不新增扫描入口或授权凭据继承，也不将切片解释为 whole scope。

加载、信息、COG 校验、重投影、重采样、裁剪、计算镶嵌、波段计算、统计和直方图在工作流中执行。统计与直方图按块全量读取；波段表达式仅允许 band 引用、数值常量和受限数组函数，传播无效像元，不执行任意 Python。空间变换要求可信 CRS 和 geotransform，缺失 CRS 时须明确补充；加载与信息读取保留缺失事实，不按坐标范围猜测。重采样尺寸和分辨率互斥；裁剪必须明确边界 CRS；计算镶嵌指定目标 CRS、分辨率及 first/last 重叠策略，可通过成对镶嵌节点组合多个栅格，输出 Float64，空白区域使用 NaN；复数波段拒绝进入数值分析及计算镶嵌。数值分析不承诺大整数逐位精度。

按尺寸重采样属于像素网格缩放，允许缺少 CRS 或 geotransform 的输入；输出宽高由 `size` 指定，不自动保持宽高比。有定位输入保留原 CRS，并按输出宽高缩放仿射变换的列、行向量，保持原四角覆盖面及旋转方向；缺失的 CRS、geotransform 与 extent 继续保持缺失，不向成果写入内部计算使用的像素定位。按分辨率重采样属于空间操作，必须具备可信 CRS 与 geotransform。尺寸、分辨率重采样和重投影共用 GDAL Warp 的插值与像元有效性规则：透明像元和源 NoData 不参与有效值计算，合法零值及有效的部分透明源像元仍参与计算；输出 alpha 由所选 GDAL 算法生成，不承诺其值原样保留。尺寸模式只在执行期内部像素坐标中计算，不公开新的坐标身份或 VRT 输入，不保留 Translate 尺寸插值的第二条计算路径。

多边形裁剪保留 alpha 波段，数据波段输出 Float64，并以 NaN 表达边界外、孔洞及源无效像元；拒绝复数波段，避免转换时丢失虚部。后续数值分析必须继续排除这些像元，不能把透明区域的填充值计入统计。裁剪按输入像元网格取边界范围，不把裁剪边界当作重新指定网格。

`raster_clip` 使用唯一的 `mode=inside/outside` 参数选择保留侧，默认 `inside`。区域内模式继续按边界范围裁剪；区域外模式保留源宽高、CRS 和完整六参数仿射网格（包括旋转），不重投影或插值。边界转换到源 CRS 后，在源网格上以 GDAL 默认像元中心规则栅格化，将边界覆盖的像元设为 NaN；Polygon 孔洞及 MultiPolygon 各部分以外的原有效像元保留。bbox 沿用已有 CRS 转换后的边界框语义。区域外模式允许边界不相交（保留原有效数据）或完全覆盖源（全无效成果）；不按剩余有效数据缩小输出范围。无效源 mask、NoData、非有限值及 alpha 覆盖不能被恢复，数据波段独立判断有效性，合法零及有效的部分透明像元保留原数值。输出为 Float64 数据波段及末尾 alpha，alpha 以 255/0 表达至少一个数据波段有效/全部无效，不保留源透明度大小、色表或颜色模型；复数及缺少可信空间定位的输入拒绝。mask 使用执行目录内同网格 Byte 文件，数据与 mask 按最多 512×512 分块读写；不新增整幅像元数组、公开 mask 或第二个裁剪算子。

多波段空间变换保留各数据波段独立的 NoData 有效性：一个波段无效时，其他有效波段仍可参与计算，整体 alpha 有效不能替代各波段的有效性。带 alpha 的输出必须保留数据波段的 NoData 声明及无效像元，不能将初始化零值当作有效数据。NoData 与 alpha 同时存在时，在统一目标网格上用各波段自身的 GDAL Warp 覆盖恢复 NoData，有限 NoData 与 NaN 使用相同的波段有效性规则，不能按像元值是否为零推断有效性；这些内部波段视图和覆盖成果只存在于执行工作目录。

多栅格数值计算采用显式对齐、波段组合、既有波段表达式这一条路径。`raster_align` 以 `reference_raster` 的 CRS、宽高及完整六参数仿射变换定义输出网格，保留旋转；参考栅格的像元值、mask 和 NoData 不参与计算。源范围之外填 NaN，源范围超出参考网格时裁去；不自动取交集或并集。源与参考均须有可信 CRS 和有限、可逆的 geotransform。对齐仍使用 GDAL Warp，直接写入预建的参考网格，不引入另一种插值实现。

`raster_update(input_raster, update_raster)` 按位置逐数据波段局部更新：更新源的有效像元覆盖基底，无效更新像元保留基底原有效值，二者均无效时写 NaN。两端须有可信 CRS、完全相同的宽高和六参数仿射网格（包含旋转）、语义等价的 CRS，以及相同数量的数据波段；不同网格先显式使用 `raster_align`，波段重排先使用 `raster_select_bands`。不隐式重采样、扩大基底范围或按波段名匹配。多个更新源通过双输入节点串联，后一次有效更新优先。输出为基底网格的 Float64 数据波段，不保留 alpha 透明度大小、色表或颜色模型；逐波段排除 NoData、mask、非有限值和透明区域，合法零及部分透明有效值不缩放。复数及 alpha-only 输入拒绝。沿用 512×512 分块、execution 私有新文件、workflow-only/read/raster 准入及既有保存节点；不改写基底、更新源或已保存资源，局部更新与保存节点的整文件 replace 是不同职责。

`raster_stack` 要求两个输入的宽高、六参数仿射变换完全一致且 CRS 语义等价，拒绝缺失定位或未对齐输入；先追加 `input_raster` 的全部数据波段，再追加 `other_raster` 的全部数据波段。多幅输入通过成对组合节点串联，沿用现有 `raster` 端口和 DAG 引用，无新的数组端口协议。随后 `raster_band_math` 的 `b1/b2/...` 按组合结果顺序计算，跨文件加权求和也使用同一受限表达式；一个引用波段无效则该表达式像元无效，未引用波段不影响结果。

对齐、组合与 `raster_select_bands` 均输出 Float64 数据波段，以 NaN 保存各波段独立的无效性，按既有数值分析规则读取源 mask、NoData、有限值及 alpha 覆盖。alpha 仅用于判断数据有效性，不作为数据波段自动追加，输出不保留透明度大小；合法零及部分透明的有效数据不改变数值。复数数据波段拒绝，数值转换不承诺大整数逐位精度。`raster_select_bands` 使用原输入中从 1 开始的 `bands` 序号，允许重排与重复，但禁止将 alpha 当成数据波段；无需空间定位并保留已有定位及缺失事实。`color_model=multispectral` 默认不声明颜色通道，`rgb` 必须选择恰好三个数据波段，依次标记 Red/Green/Blue，不缩放像元、不自动推荐最佳波段。RGB 文件生成与显示拉伸属于不同职责。栅格信息的逐波段摘要以 `color_interpretation` 返回 GDAL 颜色解释，供消费者核对通道。

`raster_reclassify` 将 `band`（默认 1）选定的数据波段按 `rules` 重分类，输出同网格 Float64 单波段。规则为非空 JSON 数组：精确值使用 `{"value": 1, "class": 10}`，区间使用 `{"min": 0, "max": 10, "class": 1}`，统一左闭右开，`null` 端点表示该侧无界；精确值可单独覆盖区间右端点。规则必须互不重叠且不重复，输入顺序不影响结果；拒绝未知字段、非数值、布尔值及非有限值。有效像元未命中规则时，默认 `unmatched=nodata` 写 NaN，可显式选择 `keep` 保留原值；源 NoData、mask 无效、非有限值及 alpha 覆盖无效的像元始终写 NaN，不能因保留原值而恢复为有效值。alpha 和复数波段不能作为分类数据，合法零与部分透明的有效值正常参与分类。保留源宽高、完整仿射变换、CRS 及定位缺失事实，无需补造 CRS；输出不复制原分类色表或透明度大小，数值转换仍遵循 Float64 精度边界。公开规则参数声明为 `array`、`item_type=object`，由已有参数面板还原 JSON 数组，不接受字符串化规则作为执行输入。沿用 512×512 分块与排序后二分检索，不为重分类增加执行协议或整幅影像读取路径。

DEM 基础地形分析使用 `raster_slope`、`raster_aspect`、`raster_hillshade` 和 `raster_contour`，输入为执行内 `raster`，显式必填 `elevation_unit=metre/foot/us_survey_foot`，可选 `band` 默认 1。高程换算分别使用 1、0.3048、1200/3937 米；若波段带有高程单位事实，必须与声明语义一致，不识别或冲突则拒绝。源必须是有可信 CRS 的二维投影坐标系、可逆北向网格（列分辨率正、行分辨率负、无旋转），CRS 水平线性单位必须可信且可换算为米；地理坐标和旋转网格先显式重投影。拒绝复数、alpha 高程波段及存储 scale/offset 非默认的高程输入，不能默默忽略编码换算。

前三项固定采用 GDAL Horn 3×3 邻域，水平单位由 CRS 派生，显式传递换算比例，不依赖 GDAL 版本的自动单位推断。NoData、mask、非有限值和无效 alpha 覆盖按已有规则先归一化，无效高程不填补；最外一圈及包含无效值的邻域输出 NaN。输出同宽高、CRS、仿射网格的单波段 Float64，保留 GDAL 算法的数值精度，源及已有成果不变。输入最小为 3×3，全无效输入返回全 NaN。`raster_slope` 的 `slope_unit=degree/percent` 默认 degree；`raster_aspect` 按投影横纵实际分辨率换算梯度方向，输出投影网格北为 0°、顺时针的 [0,360) 角度，平坦区域写 NaN，不与朝北混淆；`raster_hillshade` 的 `azimuth` 默认 315°、范围 [0,360)，`altitude` 默认 45°、范围 (0,90]，有效值采用 GDAL 常规晕渲的 1–255 灰度，不开放垂直夸张或其他变体，也不表示三维晕渲场景。

`raster_contour` 只生成二维等值线，最小输入为 2×2。`interval`（有限正米数，以 0 米为基准）与 `levels`（有限、严格递增且不重复的米制高程序列）二选一；不自动替换、排序或同时接受两种配置。使用 GDAL 等值线算法沿有效样本插值，不对无效高程补洞或生成分类面。输出既有 GeoDataFrame，源 CRS、LineString 几何、Float64 `elevation` 字段（米）；无等值线时返回同 Schema 的空结果。以现有矢量保存节点持久化，不新增栅格转矢量通用算子、输出身份或扫描旁路。四项均为 workflow-only、read 效果、raster 资源组；栅格结果沿用现有 `raster_save` 与 COG 主路径。 GDAL 调用依据 [DEMProcessing 与 ContourGenerateEx 官方 Python API](https://gdal.org/en/stable/api/python/utilities.html)；本规范显式冻结单位、边缘和输出规则，不随工具默认值变化。

区域内裁剪边界必须与输入栅格四角定义的实际覆盖面有正面积交集，不能只比较两者的外接矩形；仅接触边界、栅格完全落在多边形孔洞中、MultiPolygon 各部分均在覆盖面外时均拒绝执行。旋转栅格使用其实际四角覆盖面判定，不能将 extent 矩形的空白角落视为输入数据。多边形转换到源 CRS 必须成功后再判定交集；区域外模式不要求正面积交集，但仍验证边界及转换。

`raster_to_cog` 是唯一通用 COG 转换入口，声明 workflow/direct；Manager 通过同一访问计划调用并继续管理 `manager.raster_cog`，旧 TIFF 专用算子及 URI 参数契约删除。`build_raster_mosaic` 继续承担 Manager 目录型业务数据集职责。Develop 业务保存沿用 produced_targets、命名 ResourceLocator 输出、血缘与 Meta scan。图片瓦片与 Service 在线发布不属于本次栅格计算范围。

Python Runtime 的领域执行器负责内部对象、资源清理和结果投影；DAG、引用解析和异步状态复用 common-python 的 WorkflowRunner / ExecutionRegistry，不为栅格另建执行核心。

`raster_footprint` 提取有效像元覆盖的真实面轮廓，接收当前 DAG 的 `raster` 端口，输出既有 `GeoDataFrame` 端口。`bands` 省略时选择所有数据波段；显式选择须为非空、无重复的原始一基数据波段序号，alpha 不可作为数据选择。`validity=any/all` 默认 `any`（所选波段有效范围的并集），`all` 为交集。NoData、无效 mask、非有限数值、无效 alpha 均排除；合法零与部分透明的有效值仍参与。必须具备可信源 CRS 与有限可逆六参数仿射网格，复数数据及复数 alpha 拒绝，不补造定位。

轮廓按源完整像元方格的边界生成，采用四邻接，保留孔洞、分离面片、旋转及源 CRS，不自动做凸包、填孔、简化、重投影或插值。结果仅含 active geometry 列；非空结果为一条 MultiPolygon，全无效输入为带源 CRS 的空几何批。Polygonize 产生的自接触边界做面拓扑规范化，仅保留面部分，不扩张像元覆盖范围；无法表达面覆盖的数值定位拒绝。源像元按最多 512×512 分块、逐数据波段计算有效性，在执行目录内写 Byte 掩膜并用文件矢量化，临时栅格/矢量文件均随 execution 清理。源读取与 mask 计算不构造整幅数组；轮廓几何规模随有效边界复杂度增长，不能把块缓存预算解释为几何或进程总内存上限。该算子 workflow-only、read、资源组 raster；仅计算和 JSON 预览不生成持久输出、derive 或 Meta scan，保存另由已有受控矢量保存节点完成。extent 四角摘要仍保留原职责，不替代轮廓。

`raster_polygonize`（分类栅格转面）接收当前执行的 `input_raster` 和必填的一基数据 `band`，`connectivity=4/8` 默认 4；布尔值和浮点邻接参数拒绝。每个相同分类值的连通区域输出一行，Schema 固定为 Int64 `class_value` 与二维 MultiPolygon active geometry，源 CRS 保留。四邻接只通过像元边相连，八邻接包含角相连；角相连产生的自接触面做有效面规范化，仍作为同一区域的一条 MultiPolygon，不将不同连通区域按分类值全局合并。输出顺序和要素 ID 不作为业务身份。

分类值须为整数：原整数波段保留原生精度，拒绝超出有符号 Int64 的有效值；浮点存储允许精确整数值以衔接既有 Float64 重分类结果，但有效值须在 ±(2^53−1) 内且无小数，不能隐式截断连续影像、复数或无效 alpha。波段不能选择 alpha。NoData、无效 mask、非有限值、透明／无效 alpha 排除，合法零、负分类值及部分透明有效值保留。输入必须有明确 CRS 与有限可逆仿射网格，保留旋转、孔洞及分离区域，不插值、简化、填孔或自动重投影。全无效输入返回同 Schema、同 CRS 的空 GeoDataFrame。

实现复用统一波段有效性，按最多 512×512 读取，用精确分类值到紧凑整数编码的映射写执行内 Int64 分类文件及 Byte mask，提取后还原 Int64 分类值，避免 GDAL 字段输出经浮点转换丢失大整数；连通区域提取采用 [GDALPolygonize](https://gdal.org/en/stable/api/gdal_alg.html)；源文件不变，临时文件随 execution 清理。分类值映射和输出全部几何仍在内存中，分类数、区域数和边界复杂度可使内存增长，资源额度不代表固定内存保证。该算子 workflow-only、read 效果、raster 资源组；结果以既有 GeoDataFrame 端口流向矢量保存节点，不新增公开身份、Adapter、权限或扫描旁路。Native 保存验证和真实跨模块 T4 分别记账。

`vector_rasterize(input_gdf, reference_raster, field=None, burn_value=None, all_touched=False)`（矢量栅格化）仅接受带明确 CRS、有效二维 Polygon／MultiPolygon active geometry 的 GeoDataFrame。不得假定几何列名为 `geom`；拒绝缺失、空、无效、非有限坐标及 Z/M 几何，空批允许输出同参考网格的全 NoData 栅格。参考栅格必须有明确 CRS 和有限可逆仿射网格，矢量 CRS 必须语义相同；不同 CRS 先显式使用 `vector_reproject`，不隐式转换。输出沿用参考栅格完整宽高、CRS 与六参数仿射变换（包括旋转），不读取或继承参考像元值、NoData、mask、alpha、scale/offset 或颜色模型。

`field` 与 `burn_value` 严格二选一：前者为实际数值属性列的非空名称，后者为有限实数常量；拒绝布尔值、字符串数值、空值、复数、非有限值及不存在／重复／几何属性列。所有要素的取值均在烧写前校验，包括网格外要素；整数（含浮点存储的整数值）必须在 ±(2^53−1) 内，超范围明确拒绝，不静默舍入。输出为单波段 Float64，初始化全部 NaN 并声明 NaN NoData；合法零、负数及小数保留。

按 GeoDataFrame 当前行位置顺序烧写，后输入要素覆盖前者，不按索引标签或隐式排序改变优先级。`all_touched` 仅接受布尔值，默认 `False` 沿用 GDAL 像元中心覆盖，`True` 使用 `ALL_TOUCHED=TRUE`；孔洞不烧写，网格外部分自然截断，不扩展网格。精确边界行为遵循 [GDAL RasterizeLayer／ALL_TOUCHED 契约](https://gdal.org/en/stable/api/gdal_alg.html)，面边界恰好经过像元中心时 GDAL 未定义统一结果，不承诺跨版本一致的边界归属。输入矢量与参考文件保持不变，生成当前 execution 的文件支撑 `raster`，沿既有 `raster_save`／COG 路径持久化；不新增资源身份、API、权限、Adapter 或扫描路径。该算子 workflow-only、read 效果、资源组 raster；首期不含点线、自动范围、插值或完整 Int64 分类码往返。输入面及 OGR 烧写数据随要素／顶点数增长，文件输出不等于固定进程内存。Native 验证不计为新增真实跨模块 T4。

`raster_statistics(input_raster, band=1, percentile=未提供)`保持原有全量有效／无效计数、比例及min/max/mean/总体标准差对象；不请求百分位时不增加结果字段。可显式指定单个有限实数`percentile=p`，范围[0,100]，拒绝null、布尔、字符串、数组及非有限值；请求时增加Float64 `percentile`与`percentile_value`，全无效时后者为null，单个有效像元返回该值。原波段准入保持，所选复数数据及复数alpha不能参与数值分析。按存储值计算，不应用scale/offset；NoData在原生类型转换前判定，随后沿既有Float64数值边界排序，排除无效mask、非有限数据和非数据波段上的无效alpha覆盖，保留合法零、负值及部分透明有效像元。全量精确指不采样、不以直方图近似，不承诺任意精度整数输出。

百分位固定使用与邻域百分位相同的`h=(n−1)p/100`线性插值、确切二进制参数位置和数值保护；0／100为端点，50为有效总体的中位数。最多512×512读取，在当前execution私有目录生成排序段并进行有界缓冲的两路归并，不将整幅像元常驻内存，暂存文件数随分块数的对数增长。复用文件系统空间账本与2GiB安全余量，按最多两份全图Float64排序数据及文件块余量预检；空间不可读／不足明确失败，不新增队列、重试或配置。排序成功、参数或读取／写入／计算失败均清理本次暂存，不修改源或先前成果。原统计指标数学口径保持，不能表示为有限Float64的统计结果明确失败，不将非有限结果发布；不为新增百分位重写原统计矩算法。仅read/object结果，不生成RasterArtifact、发布或派生血缘；首期不含分区、多百分位、权重、自动分类及容量认证。Native／Linux／Hosted／页面分别记账。

`raster_zonal_statistics(input_raster, zones_raster, band, zones_band, percentile=未提供)`（栅格分区统计）须显式选择数值与分区的一基数据波段，不能选择 alpha；仅分析所选波段，拒绝所选复数数据或复数 alpha。两份输入必须有明确、语义等价的 CRS、相同尺寸和完全相同的有限可逆六参数仿射网格，含旋转；网格不符须先显式对齐，不隐式重采样或重投影。分区值沿用分类转面整数规则：原生整数保留精度、有效值须在有符号 Int64 内；浮点存储只允许 ±(2^53−1) 内的精确整数，支持重分类结果，不截断小数。

相同分类值全局合为一组，包括非连通区域，合法零及负分类值保留；分区自身的 NoData／mask／alpha／非有限值排除。数值有效性独立应用同一规则，部分透明且 alpha 大于零的像元仍参与；只有分区有效且数值有效的像元贡献统计。数值按存储值计算，不隐式应用 scale/offset。输出普通 DataFrame，按 Int64 `zone_value` 升序，每组包含 Int64 `total_count/valid_count/invalid_count`（总量只计本组有效分区像元，且总量等于有效加无效数值像元）和 Float64 `sum/min/max/mean/stddev`。标准差为总体标准差；组内没有有效数值时保留该组，五个统计字段为 null。分区全无效时返回相同 Schema 的空表，不生成不存在的分类。Float64 统计允许通常的浮点舍入；真正超出有限输出范围时明确失败，不发布非有限统计值。

实现复用最多 512×512 分块读取、整数分类校验和有效性，按分类累积缩放后的补偿和、中心二阶矩；均值由最终补偿和除以有效计数，方差先减固定源参考值再缩放，保留大基值上的小差异，源文件保持不变。内存随分类数及结果行数增长，块缓存不代表进程总内存上限。算子 workflow-only、read、资源组 raster；完整普通表在当前 DAG 内流向既有 `save`，公开响应仅为 `type=pandas_dataframe`、schema、row_count、最多 50 条 preview_rows、preview_limit 和 truncated 的轻量摘要，不在响应中塞入完整大表。保存、Meta 扫描、资源血缘及普通用户归属仍需各自真实链路验收；可选单个有限实数`percentile=p`，范围[0,100]，拒绝null、布尔、字符串、容器及非有限值；未提供时保持原九列及统计口径，提供时追加nullable Float64 `percentile/percentile_value`两列。每组按全部有效数值沿同一`h=(n−1)p/100`固定线性插值；0／100为端点，50为中位数，单值保持原值，无有效数值的组百分位为null，空表保留完整Schema。数值有效性先在原生类型判定，再转Float64计算，不承诺任意精度整数结果。百分位使用按精确Int64分类及Float64数值排序的私有分块归并；排序段数随读取块数对数增长，不为每个分区常驻像元数组或打开文件。最多两份每像元16字节排序记录及文件块余量计入原磁盘账本，保留2GiB安全余量；容量不足／不可读、读写或数值失败明确报错，成功失败均清理。完整结果沿原普通表／CSV路径，原有轻量预览限制保持。首期不含矢量分区百分位、多百分位、面积／权重加权或自动定位。Native、异步文件保存和真实跨模块 Hosted 证据分别记账。

`raster_focal_statistics(input_raster, band, window_size, method, percentile=None)`（栅格邻域统计）须显式选择一基数据波段、`window_size=3/5` 及 `method=sum/mean/min/max/stddev/mode/median/percentile/variety`，标准差为总体标准差；拒绝布尔或非整数窗口与波段、所选复数数据和复数 alpha，不能选择 alpha 为数据。只统计所选波段的原始存储值，不隐式应用 scale/offset，不受其他数据波段的值或 mask 影响。每个窗口包含中心像元，源 NoData、mask、透明／非有限 alpha 和非有限数据排除，alpha 大于零的部分透明像元有效。中心无效始终输出 NaN；有效中心的邻居只计实际存在的有效像元，边缘不补零，不填洞，单个有效像元的总体标准差为零。


`method=variety`为邻域分类种类数，扩展同一入口而不新增算子。固定3×3／5×5正方形窗口、包含中心，统计实际存在且有效的邻居中不同原始分类编码的数量，同类重复只计一次；与出现次数、众数、熵或生物多样性指数不同。沿mode的精确安全整数准入：所有所选波段有效分类须在±(2^53−1)内且无小数，原生NoData先判定再校验／转Float64，合法零、负分类和部分透明像元参与；不截断、不舍入、不应用scale/offset，未选波段不参与分类校验。中心无效保留NaN，无效邻居排除、图外不补零、不填洞；有效中心结果为1至实际有效邻居数之间的精确整数（最多9／25），全无效输入为全NaN。输出同尺寸单波段Float64／NaN，保留原CRS、完整仿射、旋转与定位缺失事实，清除分类源单位／色表／alpha大小／scale-offset；复用最多512×512含halo读取和同一有界窗口排序，内存随固定窗口／块增长，不常驻整幅数组。沿原COG及默认最近邻概览、只读权限与执行工作区清理，非法分类／波段／窗口、复数数据／alpha或非适用百分位参数严格失败，源及先前成果不变。原八种方法语义保持；首期不含自定义窗口、权重、米制半径、类别合并、填洞或熵指数。Native、本地异步保存、Linux全量和实际Hosted分别记账。

`method=median`为数值中位数滤波，复用同一入口、参数、逐块halo读取及COG保存。窗口包含中心，按实际存在且有效的邻居数值排序，奇数取中间值，偶数取中间两值的算术平均；允许连续值、小数输出、合法零及负值。在转换Float64前按原生类型判定NoData有效性，数值计算沿既有数值方法的Float64精度边界，不隐式应用scale/offset；中心无效为NaN，无效邻居排除，外缘不补零、不填洞。两中值的平均须避免有限大数相加的中间溢出，以及先分别除二造成不必要的次正规精度丢失；最终按Float64舍入，合法舍入零保留。每块最多25层核心窗口排序，内存随固定窗口和块大小增长，不读取整幅影像数组，不承诺固定进程总内存或任意影像容量。median本身不开放百分位参数；首期不含自定义窗口、权重或填洞；原六种方法语义保持，Native与实际Linux／Hosted／页面分别记账。

`method=percentile`扩展同一邻域统计入口，必须显式提供单个有限实数`percentile=p`，范围[0,100]，拒绝布尔、字符串、列表、缺失及非有限值；其他方法不得提供该参数。窗口仍为3×3／5×5，包含中心，原生类型判定有效性后沿既有Float64数值精度排序；中心无效保留NaN，无效邻居忽略，边缘只统计实际邻居。对n个有效值按升序排列为x[0]…x[n−1]，固定线性位置h=(n−1)p/100，i=floor(h)、j=ceil(h)、t=h−i，结果为(1−t)x[i]+tx[j]；p按输入Float64的确切值确定位置，不提供其他插值算法。p=0／100分别为最小／最大，p=50与原median逐像元一致，单有效值保持原值。插值须避免有限端点差值或加权和的中间溢出、极小权重提前变零及不必要的次正规精度丢失；沿原Float64舍入边界，合法舍入零保留。输出同网格／CRS的单波段Float64／NaN，保留旋转与定位缺失事实，复用有界halo读取及COG保存；原七种方法结果不变，不增加算子、权限、依赖或跨模块产品逻辑。首期不含自定义窗口、权重、采样、多个百分位同时输出或容量承诺，Native／Linux／Hosted／页面分别记账。

`method=mode` 为分类众数滤波，仍复用同一算子、参数与输出端口，不新增同类算子。所有有效原始分类值须为 ±(2^53−1) 内的精确整数，原生整型和重分类产生的 Float64 均可使用；连续小数、超范围整数或复数明确失败，不隐式舍入。每个包含中心的 3×3／5×5 窗口以实际有效邻居的出现次数选众数；并列且中心原分类在最高频集合中时保留中心，否则取该集合中的较小分类值。中心无效仍为 NaN；NoData／mask／alpha／非有限值排除、合法零和负分类保留、边缘不补零等规则与其他邻域方法一致。该方法保持原网格，不等同于重采样的 mode 算法；只按邻域频次，不检查相邻连通或多数比例，不填洞、不做边界清理和蚕食。

分类众数、分类蚕食和分类边界清理须先按所选波段的原生数值类型确定有效性并校验安全整数范围，再将有效分类转为 Float64 计算。Int64／UInt64 的 NoData 比较保持整数精度；不能先转换再比较，使有效的越界整数与相邻 NoData 混同而漏检。显式 mask 与 NoData 同时生效，不能用其中一项替代另一项；无效位置的越界存储值不参与分类校验。

`raster_proximity(input_raster, band, target_values)`（栅格邻近距离）显式选择一基数据波段及非空、互不重复的整数目标分类值列表；拒绝布尔、浮点目标、超出所选原生类型范围的目标值。所选数据波段限 Byte／Int8／UInt16／Int16／UInt32／Int32，不能选择 alpha 或浮点／复数／64 位整数，其他数据波段不参与；所选波段原始存储分类值不应用 scale/offset。合法零可显式列为目标，部分透明有效像元保留；NoData、mask 和无效 alpha 排除，复数 alpha 拒绝。若没有任何有效目标像元则整个算子失败，不返回全空伪成功。

`raster_recommend_band_combination(input_raster, bands)`（栅格三波段组合推荐，OIF）为只读统计建议，显式输入 3–16 个互不重复的一基数据波段，按波段序号规范排序；拒绝布尔序号、alpha 及所选复数数据／复数 alpha。以全部候选共同有效像元的固定交集进行全量、最多 512×512 分块统计，排除 NoData、mask、非有限值和无效 alpha，合法零及部分透明的有效数据保留；不读取未选择的数据波段，不隐式应用 scale/offset。按 `OIF=(σi+σj+σk)/(|rij|+|rik|+|rjk|)` 计算三波段组合的总体标准差／Pearson 相关评分，候选最多形成 560 个组合，不采样、不载入整幅。共同有效像元不足两个时失败；零方差波段排除评分并说明原因，不重新改变共同有效域；全部组合不可评分时失败。正分子且相关和为零的组合以 `score_status=unbounded`、`score=null` 表达并排在有限评分前，不能输出 JSON Infinity；有限评分降序，评分精确并列或多个无界组合按升序波段三元组排列。Float64 统计允许舍入，真实不可表达的统计值明确失败，不静默夹断或伪造建议。输出普通 object：`method=oif`、`strategy=full`、`value_domain=stored`、升序 `candidate_bands`、`common_valid_count/common_invalid_count`、`band_statistics`（band、mean、stddev、eligible/zero_variance状态）、按候选顺序的 `correlation_matrix`、`rankings`（rank、bands、score_status、score）、`excluded_combinations`（bands、reason=zero_variance）及 `recommended_bands`。涉及零方差波段的相关系数为 null，其余自相关为 1，每个三元组须进入排名或不可评分清单；CRS／旋转／定位缺失不影响纯像元统计，源保持不变。workflow-only、read、raster 资源组；推荐仅代表该评分，不分配 RGB 通道、不自动生成影像、不进行辐射校正，也不保证专题识别效果；用户显式采用并决定通道顺序，无新资源身份、权限或跨模块逻辑。

`raster_boundary_clean(input_raster, band)`（分类栅格边界清理）显式选择一基数据波段，拒绝 alpha、复数数据及复数 alpha；所有有效原始存储分类须为 ±(2^53−1) 内的精确整数，可接重分类 Float64。合法零、负分类及部分透明有效像元参与；源 NoData、mask、非有限值和无效 alpha 排除，不检查未选数据波段的分类值，不隐式应用 scale/offset。先全量分块统计原输入各分类的有效像元总数，同类非连通区域合并计数；数量越大优先级越高，数量相同时分类值越小优先级越高。优先级在后续两阶段冻结，不重新计数，不以分类编码大小或每个连通斑块的面积代替类别总量。

`raster_fill_depressions(input_raster, band, elevation_unit)`（DEM 填洼）显式选择一基高程数据波段与 `metre/foot/us_survey_foot` 单位，复用 DEM 的已知线性单位二维投影、北向无旋转网格准入；允许非方形像元。拒绝 alpha、复数数据／alpha、未知或冲突的高程单位及尚未应用的 scale/offset，不读取其他数据波段作为高程。原始有效值转换为米，溢出明确失败；NoData、mask、透明／非有限 alpha 及非有限高程排除，合法零、负高程和部分透明有效像元保留。

固定八邻接 [Priority-Flood（Barnes 等，2014）](https://doi.org/10.1016/j.cageo.2013.04.024)：图像外边缘以及八邻域紧邻任一原无效像元的有效像元作为开放出口，保持其高程；每个其他有效像元输出为所有通向开放出口路径中最大高程的最小值，且不低于其原高程。只抬高洼地、不降低高程，不增加 epsilon 坡度，允许生成平坦区。无效区不是需填充的洼地；内部无效孔洞也形成开放边界。1 行／1 列有效像元全部为边缘、保持等值；全无效输入成功输出全 NaN。

输出同尺寸单波段 Float64／NaN、米制高程，保留原 CRS 和完整仿射网格，不继承 scale/offset、alpha 大小或色表。输入按最多512×512读取，但全局高程、有效性／访问状态及优先队列仍随整幅像元数增长，不承诺固定内存或任意容量。唯一计算路径使用 Priority-Flood，临时归一化／输出文件在失败时删除，成功仅保留新结果；源和已有成果不变。workflow-only、read、raster 资源组，复用既有 `raster_save`／COG。不含流向、平坦区排水、汇流、最大填深、指定湖泊保留、挖沟或自动重投影；Native、Linux 和 Hosted 分别记账。

`raster_flow_direction_d8(input_raster, band, elevation_unit)`（DEM D8 流向）显式选择高程波段和 `metre/foot/us_survey_foot` 单位，复用填洼的 DEM 准入、单位归一和有效性规则；允许非方形像元。方向码固定为东1、东南2、南4、西南8、西16、西北32、北64、东北128。图像边缘及八邻接原无效覆盖的有效像元构成开放边界；有更低有效邻居时优先按高程下降量除以实际像元中心距离选最陡下游，并列取较小邻居行号、再列号；没有更低邻居的开放边界像元输出有效终点0。无效像元保持NaN，不穿越无效区，不用未知区外高程推断方向。

`raster_curvature(input_raster, band, elevation_unit, method='mean')`（DEM 曲率）支持`mean/profile/tangential/plan`；默认mean及原三种方法保留原公式、结果与失败规则。各方向方法定义如下；显式选择高程数据波段和metre／foot／us_survey_foot单位。复用唯一DEM准入：已知线性单位的二维投影、北向无旋转，允许矩形像元；垂直单位与CRS水平单位分别换算米。原始类型NoData／mask／alpha／非有限先确定有效覆盖；拒绝复数、alpha作高程、未应用scale/offset、未知或冲突波段单位，不重投影、重采样或平滑。

以中心为原点，x向东、y向北，像元中心米制间距为dx、dy，固定3×3九点等权最小二乘拟合含六个自由系数的曲面 `z=a*x^2+b*x*y+c*y^2+d*x+e*y+f`。减中心原始高程仅作数值平移，不强制曲面穿过中心，不约束自由常数f；整数差值先在Python整数域完成，避免Int64／UInt64相邻值浮点合并与减法溢出。p=d、q=e、r=2a、s=b、t=2c，采用凸起为正约定：

$$ H=-\frac{(1+q^2)r-2pqs+(1+p^2)t}{2(1+p^2+q^2)^{3/2}}. $$

平面（含倾斜平面）为0，凹碗为负、凸顶为正；鞍面的两主曲率可抵消为0，不据零值分类地貌。输出量纲为每米，GDAL单位字符串`1/metre`，不乘100或100000。使用同一等权拟合公式的闭式导数核，不引入逐像元SVD或外部GIS算法分支；以归一化梯度计算曲面平均曲率，降低平方造成的非必要溢出。米制步长须为可表示的严格正有限值；高程差、拟合导数或最终结果非有限时整次失败，不截断或改写为NoData，不承诺任意整数／十进制精确。

`method=profile`复用同一九点等权六系数拟合，计算沿最大坡降方向的竖直剖面曲率；方向反转不改变曲率。对非零梯度，记`g=sqrt(p^2+q^2)`、`u=p/g`、`v=q/g`，采用同样的凸正凹负约定：

$$ K_p=-\frac{r u^2+2suv+t v^2}{(1+p^2+q^2)^{3/2}}. $$

不设置坡度阈值。九个有效原始高程全部严格相等才视为完全水平平地，输出0；其余闭式拟合梯度p、q同时为0的中心输出NaN，包括对称山顶／洼底／鞍点和仅拟合为水平面的非平地残差。非零梯度的倾斜平面曲率为0；极小非零梯度继续计算，不按近零截断。以归一化梯度及按序缩放导数计算，避免非必要的平方溢出／下溢；差值、拟合导数或实际计算的剖面曲率非有限时整次失败，不用NoData掩盖数值失败。零梯度的NoData是方向未定义事实，不影响原mean模式的有效覆盖和数值。

profile沿用原显式波段／单位、完整有效九点、边缘／孔洞、小图／全无效、原网格／CRS、Float64／NaN、清除scale／offset／色表、512×512带halo分块和COG保存契约；没有可计算点仍成功全NoData。只增加既有算子的method参数与双语模式诊断，不新增算子、权限、依赖或跨模块逻辑。首期不含多尺度、平滑、地貌分类或容量认证。Native用独立最小二乘及第一／第二基本形式方向商、解析曲面核完整像元／mask，另核九点严格等高与其他零梯度、三单位、64位相邻高程、极端数值、跨块COG、双语失败、异步DAG保存和全部清理；Linux全量和Hosted分别由CI会话回传，不将本地结果外推为平台T4。

`method=tangential`复用同一完整有效3×3九点等权六系数二次拟合，计算沿等高线切向的曲面法向曲率。采用同样的横向凸正凹负约定，正值表示横向凸／发散、负值表示横向凹／汇聚，不将其直接解释为实际流量、侵蚀或地貌类别。对非零梯度，沿用`g=sqrt(p^2+q^2)`、`u=p/g`、`v=q/g`：

$$ K_t=-\frac{r v^2-2suv+t u^2}{\sqrt{1+p^2+q^2}}. $$

这里的方向为等高线切向`(-v,u)`，不是最大坡降方向；它与等高线水平投影的平面曲率定义不同，不提供别名或混用公式。非零梯度处`K_p+K_t=2H`作为独立一致性校验，不能用两项相减代替切向曲率的直接计算，以免非必要的消减误差。定义参考[Esri曲面参数说明](https://pro.arcgis.com/en/pro-app/3.6/tool-reference/spatial-analyst/how-surface-parameters-works.htm)，具体准入和数值规则以本文为准。

九个有效原始高程严格全相等才输出0；其他拟合梯度p、q同时为0的中心为NaN NoData，包括山顶／洼底／鞍点及非平地残差。非零梯度的倾斜平面为0，极小非零坡度继续计算，不设置近零阈值。沿用mean/profile的完整九点有效性、边缘／孔洞／小图／全无效、显式波段和三种高程单位、水平独立换算、投影北向无旋转矩形网格、原生64位相对差值、唯一512×512带halo读取和COG路径。输出原尺寸／网格／CRS、Float64／NaN和`1/metre`，清除scale／offset及色表；高程差／导数／结果非有限明确失败，失败清除私有输出。原mean/profile核与结果不改；非法method提示同步列出当前四种合法方法，无兼容字段或第二条计算路线。

首期不含多尺度、权重／平滑、自动地貌分类或容量承诺，不新增权限、依赖或跨模块产品逻辑。Native以独立九点最小二乘和第一／第二基本形式方向商、解析曲面核完整结果／mask、零梯度及极小非零坡度、三种单位／64位相邻高程、数值极限、跨块COG、双语准入／数值失败、异步DAG及全部清理；Linux全量与Hosted分别等CI会话回传，独立Hosted的准备和证据见[测试场景](../testing/scenarios/Manager与空间成果.md)，不把本地结果计为T4。


`method=plan`计算等高线在水平面内投影的有向几何曲率，沿同一完整有效3×3九点等权六系数拟合，采用横向凸／发散为正、凹／汇聚为负的约定。非零梯度处，记`g=sqrt(p²+q²)`：

$$ K_{plan}=-\frac{r q^2-2spq+t p^2}{(p^2+q^2)^{3/2}}. $$

这不是旧式曲率工具的平面方向导数，也不是曲面法向的tangential方法；不将结果解释为实际流量或自动地貌类别。`K_t=K_plan*g/sqrt(1+g²)`仅作为非零梯度处的独立一致性校验，产品直接计算plan公式，不以已算切向值换算作为第二条路线。正的统一高程比例与常数平移不改变理论平面曲率；水平坐标统一米制后输出`1/metre`。

九点有效原始高程严格全相等的完全水平平地输出0；其他拟合p、q同时为0的中心为NaN NoData。倾斜平面为0；极小非零坡度不设阈值、不平滑或截断大曲率。输入／米制步长／差值及导数准入沿原曲率；不可表示的非零结果或非有限结果整次明确失败，不能以NoData或零掩盖数值失败。计算以二进制缩放避免直接形成梯度三次方及非必要溢出／下溢，不承诺任意整数或十进制精确。

沿用显式高程波段与三种单位、二维已知线性单位投影／北向无旋转矩形网格、原始类型64位相对差值、完整九点有效性、原网格／CRS、Float64／NaN、清除scale／offset／色表、唯一512×512带halo读取与COG／最近邻金字塔保存。边缘或任一无效邻域为NoData，小图／全无效／无完整邻域成功全NoData。只扩展既有method与四种合法枚举的双语诊断，不新增权限、依赖、算子或跨模块产品逻辑，原三种方法结果保持。首期不含多尺度、平滑、地貌分类或容量承诺。独立等高线几何oracle、解析曲面与数值极限沿标准Native入口；Linux全量和Hosted分别等CI会话回传，不将本地结果计为真实T4，独立Hosted范围另行确认。


`raster_stream_to_vector_d8(input_raster, stream_raster, band, stream_band)`（D8 河网转矢量线）显式选择既有D8方向与0／1河网数据波段，完全复用河段编号的双输入准入、原始类型NoData／mask／alpha／非有限有效性、完整图校验及断流失败规则。仅已知线性单位二维投影、北向无旋转网格，允许非方形像元；不取有效覆盖交集或自动对齐。非法完整路线（包括非河网区）、未应用scale/offset、复数或alpha作数据波段均整次失败。

复用唯一河段编号主路径：源头与汇合像元开启新段，按所有起点行列顺序从1编号。每条线按下游顺序连接该段每个像元中心；上游线末端另补下游汇合中心，跨段D8边归上游线，下游线从同一汇合中心开始。合法开放终点止于中心，不延到图外或无效区。孤立河网单像元（无实际河网入流且无出边）使整次明确失败，混合输入也不忽略；单像元汇合终点仅作为入流线端点，不产生零长度线。保留既有link_id，跳过无出边的终点段后ID允许间隔；单像元段若有出边，形成两个中心的有效线。几何相邻或对角交叉不改变D8连通，不因几何交点新增节点、拆分或合并。

输出源CRS的二维LineString GeoDataFrame，固定字段 `link_id/from_row/from_col/to_row/to_col` 为Int64，行列均零基；`length_m` 为Float64，geometry为线。按link_id升序输出，每条线的起止行列对应实际首末中心。长度为横／纵／对角中心间步长之和，步长依原网格及CRS线性单位换算米，对角为hypot，不加半像元、不计算三维或测地距离；坐标、严格正步长或累加长度非有限、相邻中心精度坍缩均失败，不输出零长度线。空河网／全无效返回同Schema、源CRS的空表。复用既有矢量save／GeoPackage，不新建RasterArtifact。

workflow-only、read、raster资源组，归入范围处理；共享完整图／拓扑与河段编号，内存随像元数和顶点数增长，无新依赖或权限。首期不含简化／平滑、补线、阈值、自动重投影、级别或量级属性、多输出节点表及容量承诺。Native须独立逐边核每条实际河网D8边恰好一次，完整坐标／方向／ID／属性／米制长度、特殊单像元、交叉独立、双语失败及真实GeoPackage保存和清理；Linux／Hosted分别记账。

`raster_thin(input_raster, band, foreground_value)`（分类栅格细化）显式选择一基数据波段及单个前景分类；拒绝 alpha、复数数据／复数 alpha。所有有效原始存储分类及前景参数均须为 ±(2^53−1) 内的精确整数，允许合法零、负分类和重分类 Float64；不隐式应用 scale/offset。只有所选分类为前景，其他有效分类为背景，不按非零自动二值化。NoData、mask、无效 alpha、非有限像元及图外作为背景参与拓扑计算，输出原无效覆盖保持 NaN，不填洞或跨无效覆盖连接。

固定 Guo–Hall 八邻域两子迭代，每个子阶段读取不可变的全幅上一阶段快照，再同步删除；两阶段依次完成才判断整轮是否无删除，反复执行至收敛，不按块独立收敛或截断迭代。邻居按 E、NE、N、NW、W、SW、S、SE 编号 b0…b7；G1 为四个 `!b[i] && (b[i+1] || b[(i+2)%8])`（i=0,2,4,6）的和等于1；G2 为两组交错相邻对并集计数的较小值为2或3；第一阶段另要求 `!((b1||b2||!b7)&&b0)`，第二阶段另要求 `!((b5||b6||!b3)&&b4)`。仅同时满足条件的前景像元删除。规则依据 [Guo–Hall 算法参考实现](https://github.com/scikit-image/scikit-image/blob/v0.25.2/skimage/morphology/_skeletonize.py)，本实现复用 NumPy／GDAL，不增加依赖。

输出同尺寸单波段 Float64：保留的骨架为1、其他原有效像元为0、原无效为 NaN；没有前景命中输出有效零，全无效输入成功输出全 NaN。保留完整仿射网格、旋转、CRS 及定位缺失事实，不继承色表、alpha 大小或 scale/offset。按像元拓扑计算，不限制投影、旋转或像元长宽比；不承诺物理中心位置。每次带 halo 读取最多512×512，以两份磁盘快照控制内存，算子成功／失败清除快照及失败输出，execution 沿既有工作目录清理。workflow-only、read、raster 资源组，复用 `raster_save`／COG。首期不含多类别分别细化、自动阈值、剪枝、补线、平滑、宽度量测、矢量线输出或容量承诺；Guo–Hall 可保留局部小方块，不保证每处严格一像元宽。Native、Linux 与 Hosted 分别记账。


`raster_aggregate` 按必填整数 `factors=[列倍数,行倍数]` 从左上像元开始分组，逐数据波段执行必填 `method=sum/mean/min/max`，输出 Float64。倍数必须为 1–2147483647 的整数，拒绝布尔值与浮点倍数；输出宽高向上取整，边缘不足整块时只使用实际存在的源像元，不补零、不丢弃边缘。源 mask、NoData、非有限值和 alpha 覆盖无效的像元不参与计算，全无效组输出 NaN；合法零和部分透明的有效像元正常参与，各数据波段独立处理。alpha 不作为输出数据波段，不保留原分类色表、颜色模型或透明度大小；复数数据拒绝。求和结果超出 Float64 有限范围时写 NaN；均值先计有效数量及最大绝对值，按该尺度归一化后累加各值除以数量，再恢复尺度，避免直接求和溢出或微小值直接除以数量下溢造成不必要的丢失。

聚合属于原像素网格的整数分组，不调用重采样插值，也不按指定输出尺寸调整分组。保留源原点、CRS 与定位缺失事实；有仿射变换时，列向量乘列倍数、行向量乘行倍数，保持旋转方向。由于输出必须为规则网格，边缘不足整块时最终像元仍具有完整聚合像元的空间大小，输出矩形覆盖范围可超出源右侧或底侧；数值只来自源覆盖内的有效像元。无需补造空间定位。计算复用源 512×512 分块读取，以最多 512×512 输出单元累积单个数据波段，不把大倍数组或整幅影像一次读入内存；均值为两遍分块读取，其余方法为一遍。

`raster_mosaic` 使用唯一的有序 `input_rasters` 输入数组，至少两个当前 execution 的 `raster` 引用，不保留 `input_raster/other_raster` 双输入契约。公开参数元数据为 `type=array, item_type=raster, param_type=input`；每个元素仍为标准节点引用，不新增栅格集合实体。所有输入在同一个指定 CRS／分辨率的共同网格中完成一次镶嵌；`first/last` 按数组顺序选择重叠区的有效来源，顺序不能由依赖列表或图布局替代。Develop 画布支持集合输入的添加、删除与顺序调整，保存及重载必须保持元素顺序；普通单输入端口继续只允许一条连接。每个源经现有加载节点独立授权，资源输出、自动扫描及血缘沿用现有主路径。

统计、直方图和波段计算对数据波段同时应用 GDAL mask、nodata、有限值及 alpha 覆盖约束：alpha 为非有限值或不大于 0 时，对应数据像元无效；部分透明但 alpha 大于 0 的像元仍有效。不能因 alpha 为浮点类型而遗漏透明区域。显式选择 alpha 波段进行数值分析时，按该波段自身的 mask、nodata 和有限值处理，0 是合法覆盖值。



`raster_cut_fill(input_raster, after_raster, band, after_band, elevation_unit, after_elevation_unit)`（双DEM填挖方统计）显式指定施工前／施工后DEM及各自的一基高程数据波段和高程单位。两源沿用DEM单一准入：已知线性单位的二维投影、北向无旋转矩形网格，明确CRS、有限完整定位、不接受alpha或复数高程／复数alpha，所选波段scale/offset必须先显式应用，已声明波段单位不得与参数冲突。两份源CRS须语义等价、尺寸与六参数仿射网格须完全相同，不自动重投影、重采样或裁交。由调用者保证高程基准相同，不从二维CRS推断垂直基准或转换。

只统计两份所选波段共同有效像元；各源NoData、mask、透明／非有限alpha及非有限高程分别排除，alpha大于零的部分透明像元仍有效，合法零与负高程保留，其他数据波段不参与。施工后高于施工前为填方、低于为挖方、严格相等为不变，不设近零差阈值。两源各以既有`metre/foot/us_survey_foot`换算因子转换高程，水平像元面积按投影网格宽×高×水平米制换算因子平方；体积采用每像元竖直柱体高差乘水平投影面积，不代表斜面面积或三角网积分。

结果为一行普通DataFrame，固定Int64列`total_count/valid_count/invalid_count/cut_count/fill_count/unchanged_count`，Float64列`valid_area_m2/cut_area_m2/fill_area_m2/unchanged_area_m2/cut_volume_m3/fill_volume_m3/net_increase_m3`。总像元数为完整输入网格；有效加排除等于总数，挖／填／不变数之和等于共同有效数。挖填体积各非负，净增加量为填方体积减挖方体积，面积统一平方米、体积统一立方米。无共同有效像元明确失败，不把无数据写成零土方。

原生Int64／UInt64的NoData比较、高程差及混合数值类型保留原始精度，不先转Float64再相减。最多512×512窗口读取，以有限存储值和既有二进制单位因子作精确有理差值与累积，最终一次转换各输出为Float64；避免大基值微小高差丢失、中间溢出或抵消后残差丢失。最终面积／体积溢出、非零量下溢为零或像元面积不可表示时明确失败，不夹零或写非有限结果。文件与像元之外不建立新的资源事实，源与先前成果保持不变；复用已有DataFrame轻量预览和`save`表格保存节点，算子workflow-only、read效果、栅格统计分组，无新权限或跨模块产品逻辑。首期不含差值栅格、分区土方、常量设计面、松胀／压实系数或工程精度认证；Native／Linux／真实Hosted分别记账。

### DEM 地形位置指数（TPI）

`raster_tpi(input_raster, band, elevation_unit)`仅接收执行内raster，band与高程单位显式必填，复用DEM统一准入：二维投影、可信水平线性单位、北向无旋转可逆矩形网格，拒绝复数／alpha高程、复数alpha、未知或冲突的高程单位及未应用的scale/offset。输出同尺寸／原网格／CRS的单波段Float64，波段单位metre、NaN NoData，复用既有COG保存。允许任意正尺寸；无完整邻域或全无效时返回全NoData。

固定3×3窗口，以中心高程减去其余8点的等权平均（不包含中心），最后按显式高程单位换算米。仅当完整九点都满足有效像元规则时计算；图外、NoData、无效mask、无效alpha或非有限样本均使该中心为NoData，不插值或填洞；有效的部分透明样本参与。正值仅表示高于周边均值、负值表示低于周边；平地、倾斜平面、鞍点或其他恰好相等位置的零均合法，零梯度不排除，不设近零阈值，不据此自动分类山脊／谷地。

逐块带1像元halo，源读取最大512×512；保留原生整数及浮点的精确高差和邻域抵消，直到最终Float64转换，不先以Float64归一化高程。严格拒绝最终非有限结果及非零量下溢成零；无效邻域不因极端但有限的无关样本触发结果范围错误。首期固定像元窗口，不含米制半径、可变窗口、多尺度、标准化TPI、平滑、自动地貌分类或容量承诺。不改已有曲率、权限、执行协议或跨模块逻辑。

### DEM 地形崎岖度（TRI）

`raster_tri(input_raster, band, elevation_unit)`固定3×3 Riley算法：中心与其余8点高差的平方和开方，再以显式高程单位换算米，不除以8、不去除坡度或拟合趋势。结果非负，水平平地为合法零，倾斜平面通常大于零；不据此自动分类地貌。算法定义参考[GDAL Riley TRI](https://gdal.org/en/stable/programs/gdaldem.html#tri)。

显式高程波段及单位，复用DEM统一准入：已知线性单位的二维投影、有限可逆北向无旋转矩形网格，不自动重投影；拒绝复数高程／复数alpha、选择alpha、未知／冲突单位、未显式应用的scale/offset。单位沿用metre／foot／us_survey_foot，输出同尺寸、原网格／CRS的单波段Float64／NaN，波段单位metre，复用COG保存。

仅完整九点有效时计算；NoData、mask、透明／非有限alpha、非有限高程以及图外使中心输出NoData，部分透明且alpha大于零的有效样本参与，不补零、不填洞。任意正尺寸可输入，小图或全无效返回全NoData。最多512×512带1像元halo读取，跨块连续；原生Int64／UInt64的NoData和微小高差保留，精确累积平方差及二进制单位因子，仅最终平方根舍入Float64，避免不必要的中间溢出／下溢；最终非有限或非零量舍入成零时明确失败并清理私有成果。

算子workflow-only、read、栅格地形分析分组及raster资源组，输入／输出复用已有raster端口，无新权限、依赖、产品配置或跨模块逻辑；既有TPI和四种曲率结果保持。首期不含Wilson、可变窗口、距离半径、多尺度、标准化、平滑、地貌分类或容量承诺；Native、Linux全量、真实Hosted分别记账。

### DEM 地形粗糙度（Roughness）

`raster_roughness(input_raster, band, elevation_unit)`固定3×3，包含中心在内的九点最大原始高程减最小原始高程，再按显式高程单位换算米；结果非负，水平平地合法0、倾斜平面通常为正。不去除坡度或拟合趋势，不取半高差、中心到邻居的最大绝对差、TRI平方和或标准差。数学定义参考[GDAL Roughness实现](https://github.com/OSGeo/gdal/blob/v3.8.4/apps/gdaldem_lib.cpp#L2467-L2488)，不沿用其Float32输出或中间舍入。

显式高程数据波段与metre／foot／us_survey_foot单位，复用DEM统一准入：已知水平线性单位的二维投影、有限可逆北向无旋转矩形网格；拒绝复数数据／复数alpha、选择alpha为高程、非法／冲突或未知高程单位及未显式应用的scale／offset，不自动重投影。仅完整九点有效时计算，图外、NoData、mask、透明／非有限alpha或非有限高程使中心NoData，有效部分透明参与，不补零、插值或填洞。任意正尺寸可输入，小图／全无效或无完整邻域成功输出全NoData。

最多512×512带一像元halo读取，输出保留原尺寸／网格／CRS，单波段Float64、NaN NoData、metre单位，复用既有COG／最近邻概览。原生Int64／UInt64先确定有效性并保留精确排序和极差，浮点高差和二进制单位因子也保持至最终一次Float64舍入，避免大基值微差丢失与可表示结果的中间溢出。仅最终非有限或非零量舍入为零时明确失败并清理私有成果；次正规非零输出允许，原始无效邻域中的极端有限值不造成范围失败。

算子workflow-only、read、raster资源组与栅格地形分析分组，复用既有raster端口、保存及执行清理，不增加权限、依赖、配置或跨模块逻辑，原TPI、TRI和四种曲率保持。首期不含自定义窗口／距离半径、多尺度、平滑、标准化、自动地貌分类或容量承诺。Native／Linux全量／真实Hosted分别记账。

## GeoPython 栅格资源准入

GeoPython 从 System 的引擎实例资源策略读取进程共享运行/等待上限和 Tenant 额度。资源需求通过算子 `attributes.resource_groups` 显式声明，当前栅格为 `raster`；混合工作流按整个 execution 占用一次额度，`build_raster_mosaic` 与栅格 direct 调用使用同一额度，其内部 leaf/GDAL 线程预算仍由原领域策略控制。纯矢量工作流不计入栅格额度。公共 Python 核心统一提供有界准入，不另建栅格执行核心。

合法且已授权的工作流受理后仍返回 HTTP 202 和可查询 execution_id，等待时保持 pending，未实际执行前不创建私有栅格工作目录或加载数据。队列先领取最早且其 Tenant 额度允许的 execution，满载 Tenant 不阻塞其他 Tenant。总等待或 Tenant 等待满额时返回 HTTP 503、error_code=RUNTIME_BUSY，不创建 execution，不自动重试；同步 direct 满额立即返回同一繁忙错误，不转成异步任务。策略读取或校验失败时返回 HTTP 503、error_code=RUNTIME_POLICY_UNAVAILABLE，拒绝新的栅格调用，并暂停等待领取，已有运行自然结束；恢复权威策略后继续领取。

GeoPython 栅格 direct 请求必须提供顶层正整数 `tenant_id`，由 Manager 等任务 owner 从自身执行上下文传入；该身份用于额度记账，不代替既有数据授权。缺失身份返回 HTTP 400。资源策略每秒重新读取，并在每次栅格调用前刷新；读取失败保持暂停，恢复后继续派发。

System Runtime 策略解析接口仅供 addp-geopython 的 Platform Service Access Token 消费，资源身份由已注册 Runtime 的稳定连接身份解析，不允许调用方传入配置值。System 管理 API 的 Tenant 身份始终从 AuthContext 取得。Runtime `/health` 的栅格资源事实展示有效资源约束、当前活动/等待数、实际应用准入版本与实际 GDAL 缓存预算；这些诊断事实不授予权限，也不参与自动扩容。


### DEM 三维表面积统计

`raster_surface_area(input_raster, band, elevation_unit)`（DEM 三维表面积统计）复用DEM单一准入：显式一基高程数据波段和metre／foot／us_survey_foot，已知线性单位二维投影、有限北向无旋转矩形网格；水平与垂直分别换算米。不自动重投影，拒绝复数数据／复数alpha、alpha作高程、非法／冲突或未知高程单位、未应用scale／offset及不可表示的米制步长。原生NoData／mask／透明或非有限alpha／非有限高程排除，部分透明有效，合法零与负高程参与。

计算对象是每个相邻2×2像元中心构成的四边形，不是逐像元外框。按左上—右下和右上—左下两种对角线分别剖成两个三维三角形，以叉积模长的一半求三角形面积。每个面片的两种面积各自求和后，取较小值L、较大值H和平均值(L+H)/2；分别累计所有有效面片的L、H和平均值。较小／较大结果仅表示两种离散剖分的差异，不是实际地表面积误差上下界，不将整幅两种对角线总和再取min/max。只计四角全部有效面片，不跨孔洞，不平滑／填补或外扩；外缘不补半像元，因此平地投影面积为有效面片数×像元水平米制宽×高，不等于整幅栅格外框面积。该离散近似随分辨率变化，不作工程精度认证。

返回一行普通DataFrame：Int64列`total_quad_count/valid_quad_count/invalid_quad_count`与Float64列`projected_area_m2/surface_area_low_m2/surface_area_high_m2/surface_area_mean_m2/surface_to_projected_ratio`。总面片数为max(width−1,0)×max(height−1,0)，有效加排除等于总数；比值为平均表面积除以参与计算的投影面积，无量纲。水平平地三种表面积均等于投影面积且比值为1，倾斜平面为真实平面斜面积；不能用坡度栅格的已舍入值替代三角形。无有效面片（含任一维小于2／全无效／无完整四角）明确失败，不输出零表面积。

按面片左上角分块，带右／下1像元重叠读取，单次最多512×512，各面片恰计一次，内存随块增长。原生整数与浮点先作精确有理高差、米制长度及叉积分量，再在80位十进制精度下开方、分类与累积，最终转换Float64；不承诺任意实数精确舍入。最终任何非有限／不可表示面积或比值、非零量下溢为零均整次明确失败，数值失败不能改记NoData或被排除；无效面片不触发无关高程的数值错误。源和先前成果保持不变，复用现有普通表轻量预览与`save` CSV链路，无RasterArtifact、额外权限、依赖、配置或跨模块逻辑；workflow-only／read／raster资源组，归入栅格统计。首期不含矢量范围、分区表面积、外缘面积补偿、地球曲率、TIN输入、多尺度或容量认证。Native以独立高精度三维向量叉积、解析平面、对角差异、单位／64位微差／无效覆盖／跨块、双语准确失败及真实异步CSV保存清理验证；Linux全量与Hosted继续等待CI会话回传，独立Hosted已批准12成功／36双语准确失败／510成果全检、12原CSV及600秒，夹具准备与实际验收分别记账，范围见[测试场景](../testing/scenarios/Manager与空间成果.md#dem-三维表面积统计独立-hosted-验收)。


### 地形湿度指数 TWI

`raster_twi(input_raster, slope_raster, band, slope_band, slope_unit)`显式接汇流面积与坡度数据波段，`slope_unit=degree/percent`必填，无推断或默认值。面积采用计入自身的平方米口径，选中波段必须声明`m2`，不能把count当面积；已有`raster_flow_accumulation_d8(measure='area')`直接提供该事实。坡度单位事实为空时使用显式声明，非空则必须与声明一致；不自动识别外部栅格的生成算法或证明其水文来源。

两份输入须语义等价CRS、相同尺寸及完整六参数仿射网格；首期仅已知线性单位二维投影、北向无旋转且横纵边长严格相等的方形像元，不自动对齐。拒绝非法波段、复数数据／alpha、alpha作数据及未应用scale/offset。水平线性单位由CRS换算米，不改变面积波段的平方米口径。

固定`a=A/d`，以a的米制数值计算自然对数`ln(a/tanβ)`；d为米制像元边长，此宽度近似与米制口径不可由隐含配置改变。百分比坡度的tanβ为坡度值/100；角度要求0≤β<90°。任一输入自身有效区域内，面积≤0或负坡度／非法角度均整次失败，不能因另一输入无效而掩盖错误。NoData按原始数值类型判定；mask、透明或非有限alpha、非有限数据排除，部分透明有效。仅共同有效且坡度严格大于0处计算，零坡度NoData，极小非零值不设阈值；全无可计算像元成功全NaN。

计算采用80位Decimal的有界角度三角级数及对数，原始整数／浮点数与米制宽度保留精确比值后计算，避免非必要的弧度换算、正切、比值中间溢出／下溢；最终只舍入为Float64，不承诺任意精度超越数。结果允许负数及合法零，非有限或不可表示的非零结果明确失败并清除私有输出。同网格单波段Float64／NaN、单位`1`，清空scale/offset及色表，复用512×512分块、当前执行资源组和既有COG保存。局部去重仅在当前块内，不缓存实际成果。

不含多流向、土壤／透水率、降雨或湿地识别，不自动填洼或重算坡度，不改已有坡度／累积结果、权限或跨模块逻辑。算法定义参考[SAGA TWI](https://saga-gis.sourceforge.io/saga_tool_doc/9.12.0/ta_hydrology_20.html)，固定宽度及零坡度规则以上述首期契约为准。Native验证解析值／独立对数参考、两种坡度单位、水平单位、64位面积、覆盖、跨块COG、异步中英准确失败及清理；Linux与Hosted分别等CI回传，独立Hosted的固定范围及准备／执行证据见[测试场景](../testing/scenarios/Manager与空间成果.md#地形湿度指数-twi-独立-hosted-验收)，准备通过不计作实际平台验收通过。

### 水流功率指数 SPI

`raster_spi(input_raster, slope_raster, band, slope_band, slope_unit)`固定计算`(A/d)×tanβ`，不取对数或经验幂；A为计入自身、单位声明m2的汇流面积，d为方形像元米制边长。两源显式数据波段、degree/percent坡度、相同CRS／尺寸／完整网格，已知线性单位二维投影、北向无旋转方形像元。百分比值除以100得到正切；坡度单位为空沿显式声明，非空冲突失败。有效面积必须严格大于0，有效坡度非负、角度小于90；先分别核各源合法值，不以另一源无效覆盖绕过拒绝。

原生NoData／mask／alpha／非有限排除，部分透明有效像元保留；仅共同有效处计算，零坡度合法0，极小非零坡度不设阈值，无共同有效覆盖成功全NaN。拒绝复数数据／复数alpha、alpha作数据及未应用scale/offset。复用TWI唯一面积坡度准入／512×512原生分块与高精度正切路径；80位Decimal计算避免非必要中间溢出，下溢只在最终Float64转换严格检查。最终非有限或非零下溢失败并清理私有输出。输出同网格／CRS单波段Float64／NaN，单位metre，复用COG保存；原TWI公式及零坡度NoData结果保持。

SPI表达地形条件下的潜在侵蚀倾向，不表示实际功率、侵蚀量或泥沙量；不引入降雨、土壤、流量、多流向、自动对齐或新权限。定义参考[SAGA SPI](https://saga-gis.sourceforge.io/saga_tool_doc/9.0.0/ta_hydrology_21.html)，固定宽度和零坡度以上述契约为准。Native、Linux与Hosted分别记账，独立Hosted已批准14成功／52中英准确失败／833全检、14原COG及600秒，准备及执行分别记账，见[测试场景](../testing/scenarios/Manager与空间成果.md#水流功率指数-spi-独立-hosted-验收)。

### 分类栅格小斑块筛除

`raster_sieve(input_raster, band, min_pixels, connectivity)`显式选择一基数据波段、正整数最小斑块像元数和整数4／8邻接，无默认阈值或邻接。同原始分类的有效像元按所选邻接归为一个斑块；不相连的同类分别计数，跨分块连接必须合并。只处理原始像元数严格小于min_pixels的斑块，等于阈值保留。供体必须在所选邻接下直接相邻、且原始大小至少为阈值；按原始大小降序、分类值升序、斑块最前行列位置升序选择。统计与供体选择一次冻结，所有替换同步单轮输出，不重新统计、不经小斑块传递、不迭代。无合格供体则原值保留，包括仅邻接小斑块或被无效区包围的斑块。

分类采用原始存储值，所有有效值须为±(2^53−1)内精确整数，可接重分类Float64，合法零与负分类参与。不检查未选数据波段分类，不隐式应用scale/offset；拒绝alpha作数据、复数数据或复数alpha。原生NoData／mask／透明或非有限alpha／非有限数据排除，部分透明有效像元参与；原无效覆盖永久保持，不补洞、不跨无效区找供体。全无效成功全NaN，min_pixels=1输出等值结果且仍严格验证分类。

输出同宽高单波段Float64／NaN，保留完整网格（含旋转）、CRS和定位缺失事实，不继承色表／alpha大小／scale/offset。无投影或方形像元要求，阈值仅为像元数，不表示平方米。唯一逐行游程连通标记、等价合并、原始邻接供体及输出路径，源读取最大512×1；Int64像元标记存入execution私有文件，内存随行宽和临时游程／连通标记数量增长，仅标记文件为8字节/像元，另有既有私有输出，不作为总磁盘峰值或容量保证。成功／异常均关闭并清理标记，失败私有输出清除，不发布后续成果；沿现有COG／执行清理，无新权限、依赖或资源配置。

首期不含平方米阈值、指定分类保护、多轮迭代、最大搜索距离、矢量化。独立Hosted已批准6成功／28中英准确失败／189全检、6原COG及600秒，准备及运行见[测试场景](../testing/scenarios/Manager与空间成果.md#分类栅格小斑块筛除独立-hosted-验收)，实际Linux／Hosted交CI协调。Native、Linux、Hosted分别记账。小斑块与相邻大斑块的一般语义参考[GDAL Sieve](https://gdal.org/en/stable/api/gdal_alg.html#_CPPv415GDALSieveFilter15GDALRasterBandH15GDALRasterBandH15GDALRasterBandHiiPPc16GDALProgressFuncPv)；精确整数、冻结和并列规则以上述契约为准，不沿用GDAL隐式浮点取整。
