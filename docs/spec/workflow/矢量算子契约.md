## `load` 文件字段类型契约

GeoPython `load` 读取 `shp/geojson/gpkg/kml/gml/fgb` 空间文件及单文件 `parquet/feather` 时，以读取器提供的源 Schema 为类型事实。在转换为 pandas / GeoDataFrame 之前，将有符号与无符号整数按源位宽映射为 pandas 可空 `Int8/16/32/64`、`UInt8/16/32/64`，布尔映射为可空 `boolean`；无空值、含空值、全空及空批使用相同规则。整数不能先经过 Float64，禁止事后按数值整除特征猜回整型；大于 `2^53` 的整数及源类型边界必须保持精确。

空间文件唯一读取主线为 Pyogrio Arrow 读取与上述类型映射，不依赖 GeoPandas 默认引擎或 `PYOGRIO_USE_ARROW` 环境变量，也不回退到 NumPy / Fiona。Parquet 与 Feather 从已解析的本地文件流读取 Arrow Table，复用同一类型映射；非整型、非布尔字段继续由原生 Arrow→pandas 转换处理，不全表调用 `convert_dtypes()` 或统一改成 ArrowDtype。源 Schema 的实数即使全为 `1.0/2.0` 也保持实数，字符串、空串、空值、字段顺序、行序及既有索引值／名称／顺序不得因本次修复改写，实际整型索引列同样映射为可空整型；空间文件保留原始几何、Z/M、空值及 CRS，不默认把活动几何列命名为 `geometry`。

空间文件统一调用公开 `pyogrio.read_arrow`，以 Arrow Schema 的 WKB geometry 扩展标记识别几何列，保留普通字段名称、顺序、类型及值，不能仅凭列名或二进制类型推断几何。物理几何名存在时，须与 Arrow 几何列声明一致并原样保留；格式无物理几何名时，默认保留 Arrow 声明的几何字段名。全表只做一次上述 Arrow→pandas 映射，再按声明解码 WKB 并显式设置活动几何列，不经过会固定写入 `geometry` 的 GeoDataFrame 读取包装器，不保留旧读取分支。

GeoPackage 的 CRS 以实际读取图层的物理几何列登记为准。读取原默认图层，并按图层名和几何列名精确核对 `gpkg_geometry_columns`。标准保留的 `srs_id=0`（未定义地理）和 `srs_id=-1`（未定义笛卡尔）在 GeoDataFrame 中统一表示为 `crs=None`，即使驱动为其合成了可解析 WKT。其他 SRS 保持读取器原始 CRS，包括无 EPSG 标识的有效自定义定义；不按名称、WKT 字符串、坐标值或缺少 authority 推断未知，不赋默认 CRS 或重投影。只读核对登记，不改写文件，不增加图层选择参数或几何读取路径；确实无几何声明的表沿原规则返回普通 DataFrame。现有 GeoPython 门禁核对两个标准保留值、跨图层不串用、真实自定义 CRS 及顶点提取的未知 CRS 拒绝。

文件的显式 `geom_column` 为非空字符串：有物理名时只能精确引用该列，不能将其他业务列当几何；无物理名时可显式绑定逻辑几何名，只有声明的几何传输列更名，任何业务列均不改名。逻辑名与其他字段冲突、重复字段名、几何列身份声明与 Schema 不一致、无法唯一识别几何或无几何的表被要求绑定几何时，均明确失败，不覆盖、猜测、自动改名或降级读取。多几何声明首版拒绝，不扩多几何／多图层选择。确实无几何声明的表保持普通 DataFrame，即使存在名为 `geometry` 的普通业务列，也不自动提升成几何。

该契约保留同名普通业务 `geometry`／`wkb_geometry` 字段；不能以字段同名为由删除业务列或把 WKT／JSON／普通 BLOB 强行解码。格式原生声明的几何列和业务列若本身重名、无法在 DataFrame Schema 唯一表达，直接拒绝并提示调用方先明确源 Schema。数据库、内联 GeoJSON 及其他既有读取主线不因本次文件修复改变。

直接消费文件 `load` 结果的面积／长度／边界量测、按面积分流、泰森多边形和 WKT 导出均读取实际活动几何列，不按 `geometry` 文本选列；准入、计算、输出字段及单位以本页相应算子专节为准，未明确收敛者保持既有语义。量测／面积分流的活动几何列若与其固定结果列 `area`／`length`／`minx,miny,maxx,maxy` 重名，在计算前明确拒绝，提示用户先显式重命名几何列；已有普通同名结果列仍按原规则更新。聚合只排除活动几何，普通同名业务 `geometry` 字段可继续分组／统计。MySQL／Doris现有文本保存仅将活动几何列编码为WKT，普通同名字段不转换，缺失为NULL、空几何保留EMPTY；不增加数据库读写模式或空间类型承诺。

类型承诺以文件驱动实际提供的 Schema 为边界：不补造 KML 等格式未声明的整型，不恢复源文件已丢失的数值，不扩展既有多图层选择或 GeoParquet 空间解释能力。CSV、Excel、JSON、内联 GeoJSON、MongoDB 以及数据库读取的推断／Schema 策略不在此首批修复中；JSON 与浏览器大整数表示是独立边界。文件 `save` 消费正确的内存类型，不在写出时猜测修复；目标格式的原生表达限制仍须单独验证。

验证复用根 `make test-geopython-workflow` 已登记的 `test_io_operators.py`，覆盖源整数位宽／符号、空值与全空／空批、布尔、真实浮点及其他字段不被重分类、六类空间文件、外部无 pandas 元数据的 Parquet/Feather、保存重载独立 OGR/Arrow 核验及筛选／属性／拓扑 DAG 消费。现有 engines 影响选择、GeoPython GDAL CI 和依赖安装覆盖，无新入口或 Job；不重复已通过的业务 T4 或容量验收。

## `save` GeoPackage 业务字段与发布契约

GeoPython 通用文件 `save` 的 GeoPackage 单图层保存须将业务属性与存储主键分开。业务 `fid`／`FID`／`FiD` 保留原字段名、格式可表达的类型、空值与重复值，不把来源编号或 pandas 索引当成结果记录主键，不改名、删字段、去重或重编号业务值。驱动分配独立存储 FID；其列名按大小写不敏感规则避开全部业务字段及活动几何列，内部选择不新增公开参数。原字段顺序、逐行属性、几何／CRS保持，索引不额外落成业务字段，几何内容及原驱动物理几何命名规则保持。类型表达边界沿现有格式原生契约，不增加隐式精度转换或新格式支持。

GeoPackage 沿单一写入路线在目标父目录内创建本次独占临时目录，使用原目标图层名写入并关闭文件，重开确认GPKG驱动及完整行数、没有未收尾伴随文件后才发布。`mode=fail` 对既有目标（包括符号链接）准确拒绝；发布时以不可覆盖操作再次由文件系统裁决，防止检查后出现目标被覆盖。`replace` 仅在完整写入后原子替换普通文件；目录、符号链接及存在 SQLite `-wal/-shm/-journal` 伴随状态的目标拒绝，不能删除或操作其伴随文件。不支持文件 `append`，准确失败，不回退成替换。失败清理仅限本次独占临时目录；不删除目标、源或兄弟文件。已存在目标在写入／验证／发布失败时保持，成功后沿原save返回输入对象及现有成果声明，不新增资源、权限、重试、预算或跨模块逻辑。

保证范围是单个受控本地／NFS文件系统调用所提供的文件发布语义；不宣称跨文件／多图层事务、掉电持久性、进程强制终止自动清理或外部并发修改SQLite库的安全协调。若写入或清理失败必须报告失败，不能把残留文件计为成功成果；保存与清理同时失败保留首个业务失败和清理错误，发布后的清理失败明确说明已发布，不虚称回滚。其他空间格式、表目标及其保存路线保持。

验证沿根 `make test-geopython-workflow` 已登记公共I/O、分类频数和沿线采样文件：独立原生OGR／Arrow完整读取真实GeoPackage，核业务字段／存储FID分离、重复／空值／大整数／空批／字段碰撞、两项一源多行保存、写入／发布故障零残留、已有目标字节保护及新建竞争拒绝。现有GeoPython Native与CI路径登记覆盖，无新增长期脚本、入口或Job；Linux全量和Hosted继续由CI会话协调，不重跑旧任务或扩预算。

## 泰森多边形契约

`voronoi(input_gdf, mask_gdf, id_field)` 为唯一 workflow/read 入口，仍归“矢量处理 / 几何构造”，删除旧仅点输入、无来源的结果路线。源为唯一实际活动几何列和唯一列名的 GeoDataFrame，非空行仅接受有效非空有限二维 Point，不接受 MultiPoint、Z/M、缺失或无效几何；显式 id_field 须为本侧唯一非空非几何标量标识。原始 XY 完全相同的点整批拒绝，包括正负零等价，不按 ID、属性、行序选择供体，也不自动去重、聚合或吸附近点。

mask_gdf 必须显式提供，非空行仅为有效非空有限二维 Polygon/MultiPolygon，全部面求并形成唯一覆盖范围，保留孔洞及不连通区域；重叠或重复范围不重复输出，不要求范围业务 ID，也不复制其属性。两输入均须声明相同已知投影 CRS，水平线性单位须匹配、有限且为正，不隐式重投影、不按经纬度或球面距离计算。先完成两侧准入；空源或空范围返回保源完整 Schema 的空结果，另一侧非法不能因短路被忽略。

按全部源点生成平面最近站点分区，再与覆盖范围求交；范围外或孔洞内的源点同样参与竞争，不在计算前过滤。单个源点独占完整覆盖范围，无需至少两点；共线的不同点合法。范围内具有面部分的源点最多输出一行完整 Polygon/MultiPolygon，不拆不连通部件；仅边/点接触或无交集不输出，不设最小面积阈值。并列最近的边界可被相邻面的闭集共同包含，不以任意优先级制造缝隙或挪动分界线。结果不承诺环方向、起始顶点或分区部件的原生排列。

唯一默认 geodataframe 输出按原源点行序保留命中行，原活动几何列替换为分区面，保原列名、CRS、全部业务属性及来源标识的类型/null/值，重建 RangeIndex；不新增 source_id、分区编号或覆盖面字段，不把索引或存储 FID 当来源，不修改两输入。普通业务 geometry 列须与实际活动几何隔离保留；本版本不另输出原点副本或来源明细端口。

原生分区必须先在覆盖范围外包范围内完整构建，再在裁剪前以源点与原始分区的精确 covers 关系核对一对一归属，不依赖返回顺序或按裁剪后最近面猜来源。点索引/面索引仅筛候选，不以包围盒替代归属；原生结果数量、有效性或唯一绑定不符合要求时整批运行失败。使用既有 Shapely/GEOS 主线、零吸附容差，不为有序输出增加第二版本分支或原生依赖条件。覆盖范围、站点、分区及结果驻内存，不构造全体点×面配对矩阵，不承诺容量或大规模 SLA。

准入沿既有 v3 三个无 field 组合：voronoi/operator_input_invalid/input_gdf（点类型、结构、唯一来源或重复XY）、operator_mask_invalid/mask_gdf、operator_crs_invalid/无parameter。共享唯一诊断面板给出点位/标识、覆盖面和投影准入建议，不回显业务列名、ID、坐标、路径或原生正文。只将类型化准入事实转 INVALID_PARAMS，原生分区、绑定、求并、裁剪异常及非法结果仍 EXECUTION_FAILED。Python/Go/现行API YAML/双语及冻结节点绑定同次闭合登记，无新API、权限、协议版本、入口或Job。

验证复用根 GeoPython、共享Python/Go/前端与消费门禁，覆盖手写分区、乱序返回的源点绑定、单点/共线/范围外点、孔洞/多范围/极小面、属性类型及真实GPKG保存重载的独立OGR核验。纯计算不保存扫描，显式save沿现有源点和覆盖范围两输入的资源级追溯；不声称逐裁剪片段的贡献血缘。本轮不派发真实普通User T4，不重复已通过的业务T4或容量验收。

## 包含与相交筛选契约

`contains(input_gdf, gdf_b)` 与 `intersects(input_gdf, gdf_b)` 保留既有“矢量处理 / 空间关系”的 workflow/read 入口。逐 A 要素判断是否与任一 B 要素满足精确原生关系；命中仅保留一次 A，不按匹配数复制，不将 B 整体融合后判断。结果为 A 的原始行子集，保留全部列、类型、null、活动几何列名、原几何、CRS、索引及相对行序。不新增或覆盖 contains/intersects 布尔列，不输出 B 的属性、匹配明细或新的来源 ID；已有同名业务字段或活动几何列均原样保留。不要求唯一业务标识，不因同形不同源或重复索引而去重 A。

contains 使用拓扑 contains 而非 covers 或 contains_properly：B 没有点位于 A 外部，且双方内部存在交会；面不包含仅在其边界上的点或线，但可包含与其共边且内部位于其中的面，非空同一几何可包含自身。面孔洞内部不算包含。intersects 包括共点、共边、相交、重叠和包含。允许混合有效 Point/MultiPoint、LineString/MultiLineString、Polygon/MultiPolygon、GeometryCollection；结果保留完整 A，不生成交集几何，不设置精度网格、舍入、容差、吸附或修复。

两输入均为唯一列名、唯一实际活动 GeometryDtype 列的 GeoDataFrame；允许空批，非空行须为有效、非空、非缺失、有限二维 XY 几何，Z/M 明确拒绝。两输入使用语义相同、已知的二维地理或投影 CRS，不要求投影线性单位，也不隐式重投影或忽略轴序差异；地理 CRS 仍按输入坐标做平面关系判断，不增加跨日期变更线或球面语义。两侧先完整准入再判断空批，任一空批返回保留 A 完整 Schema 的空子集，另一侧非法不能因短路被跳过。

唯一主线逐 A 查询 B 空间索引候选，再执行真实关系判断，有一条命中即可保留；不构造完整 A×B 配对矩阵，不把包围盒命中当作实际关系。输入、索引和结果仍驻内存，不承诺固定容量。原生谓词或索引计算异常保持运行失败，不能伪装为参数错误或返回部分结果。

沿既有 v3 仅新增各算子的 operator_input_invalid/input_gdf、operator_reference_invalid/gdf_b、operator_crs_invalid/无 parameter，全部无 field；两侧输入原因均不要求来源 ID。共享面板沿同一展示入口使用空间关系专用的准入建议，明确可使用相同地理或投影 CRS，不改变叠加等既有算子的投影建议；不公开业务字段、值、坐标、路径或原生错误。Python/Go/API YAML/共享双语闭合登记同次完成，无新增协议版本、权限、API、入口或 Job。现有 GeoPython、共享 Python/Go/前端及受影响消费门禁覆盖；不派发真实 T4，不重复已通过的业务 T4 或容量验收。纯计算不保存或扫描，显式连接既有 save 时沿用资源级 A/B 输入追溯，不在成果中伪造逐对来源。

## `distance_to` 活动几何列

距离计算分别使用源图层与目标图层各自的活动几何列（active geometry），两个几何列名称可以不同，也可以同时存在名为 `geometry` 的其他列；不得按固定列名选择几何或改名覆盖其他列。结果沿既有主线复制源图层，保留源的活动几何名称、CRS、行序、索引与其他属性，并追加或更新数值 `distance` 列；两个输入均不改写。

源图层的活动几何列若名为 `distance`，必须在计算及写结果前明确报错，避免数值结果覆盖几何。错误提示应说明冲突并引导用户先手动重命名源几何列再执行，不自动改名，也不新增输出列名参数。目标图层的活动几何列名为 `distance` 不构成冲突；源图层已有普通数值 `distance` 列时，仍只在结果副本中更新该列。算子返回结构化领域错误，由执行适配层按既有工作流显示语言生成中英文提示，不新增语言状态或改写公共运行时的错误前缀。

两个输入（包括空批）均须声明相同、已知的投影 CRS，各自两个水平轴的线性单位换算因子须相同、有限且为正，沿用既有矢量拓扑算子的投影单位校验。CRS 按解析后的语义相等判断，不比较原始字符串；地理、地心、未知或不匹配 CRS 明确拒绝，并提示用户先显式重投影。仅单位同为米并不足以允许不同投影之间计算。

距离仍按原目标几何整体集合计算最近平面距离，数值单位就是该 CRS 的水平坐标单位：米制 CRS 输出米，英尺制 CRS 输出对应英尺，不默认米，不自动重投影或换算单位；也不表示椭球测地距离。两源几何、CRS 和属性保持不变。双方须为唯一列名且明确唯一实际活动几何的GeoDataFrame；保留既有非活动列（包括GeometryDtype列），只验证和计算各自活动几何，不能因非活动几何诱饵而改选或拒绝输入。多几何列的后续保存仍由save/目标格式能力校验，不在距离准入中暗删字段。每条记录须有效、非NULL、整体非EMPTY且有限二维XY；Point/线/面/多部件/GeometryCollection均可。全部坐标验证，不因某部件不贡献最近距离跳过非法坐标；合法非空集合内EMPTY成员不提供位置，不拆行或修改输入。空目标表（0行）拒绝，即使源也为空；空源表仍完成双输入结构、逐记录、几何列冲突、CRS和目标非空校验，再返回带float distance列的同Schema空源结果，不进入原生求并或距离内核。任一坏记录整批INVALID_PARAMS，不跳过、删行或用0/NULL/NaN/Inf补距离。

## `vector_reproject` 算子契约

`vector_reproject` 是空间坐标参考转换算子，只负责 geometry 批转换，不负责外部数据源接入、字段保留或写出。

```python
def vector_reproject(
    input_gdf: gpd.GeoDataFrame,
    source_crs: str = "",
    target_crs: str = "EPSG:4326",
) -> gpd.GeoDataFrame:
    ...
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
| --- | --- | --- | --- | --- |
| `input_gdf` | `GeoDataFrame` | 是 | 无 | 输入几何批。direct 调用时由 `binary_payload` 解码得到，workflow 调用时由上游节点传入。 |
| `source_crs` | `string` | 条件必填 | 空 | 源 CRS。若输入批本身没有 CRS，则必须显式提供。 |
| `target_crs` | `string` | 否 | `EPSG:4326` | 目标 CRS。GeoJSON 标准导出默认使用该值。 |

| 输出 | 类型 | 说明 |
| --- | --- | --- |
| `default` | `GeoDataFrame` | 转换后的几何批，只保留 geometry 和原有属性列；direct 二进制调用时由运行时重新编码为 `binary_payload`。 |

`vector_reproject` 的 direct 调用约定如下：

1. `binary_payload.content_type` 必须为 `application/vnd.apache.arrow.stream`。
2. `binary_payload.encoding` 必须为 `arrow`，且 Arrow 批只能包含一个 geometry 列。
3. geometry 列元素必须为 EWKB 二进制值，Arrow schema metadata 必须声明 `addp.geometry.encoding=ewkb`；HTTP `binary_payload.metadata` 中也必须声明 `geometry_encoding=ewkb`。
4. 算子只转换 geometry，不得接管 Transfer 的 load/save、checkpoint、属性字段重排或 GPKG 中间产物。
5. 失败时必须返回明确错误，不得静默退回原坐标。
6. 输出 `binary_payload` 仍为 Arrow + EWKB，只包含转换后的 geometry 列；输出 metadata 中 `source_crs` 和 `target_crs` 都应写入输出几何当前 CRS，不能继续保留输入 CRS。

## `crs_to_projjson` 算子契约

`crs_to_projjson` 是 CRS 定义表达转换算子，只把同一 CRS 的 WKT、ESRI WKT、Proj4 或 authority ID 规范化为 PROJJSON，不读取 geometry、不改变坐标，也不负责格式写出。

```python
def crs_to_projjson(
    crs_ref: str,
    definition_encoding: str = "",
    definition: str = "",
) -> dict:
    ...
```

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `crs_ref` | `string` | 是 | 平台 CRS 身份；支持 `EPSG:<code>` 或带定义的 `ADDP:CRS:<sha256>`。 |
| `definition_encoding` | `string` | 条件必填 | `definition` 非空时必须为 `wkt`、`esri_wkt`、`proj4` 或 `projjson`。 |
| `definition` | `string` | 条件必填 | 源 CRS 定义。只有 `EPSG:<code>` 可以省略并由 Runtime 本地 PROJ 数据库解析。 |

输出 `result` 固定为以下结构：

```json
{
  "crs_ref": "EPSG:3857",
  "definition_encoding": "projjson",
  "definition": "{...}"
}
```

direct 调用规则：

1. `execution_modes` 只声明 `direct`，请求和响应只使用普通 JSON，不使用 `binary_payload`。
2. 输入编码必须显式分派到对应 PROJ parser，不得使用启发式文本猜测。
3. `EPSG:<code>` 使用 Runtime 随附的本地 PROJ 数据库解析，Runtime 必须禁用网络 CRS / grid 获取。
4. EPSG 源定义必须和本地 authority 定义等价；冲突时失败。输出 PROJJSON 顶层 `id` 固定为输入 authority/code。
5. `ADDP:CRS:<sha256>` 必须带定义；输出顶层 `id` 固定为 `{"authority":"ADDP","code":"CRS:<sha256>"}`，不得因序列化变化重算平台 ID。
6. 输出必须是可解析的 JSON object、包含非空 `type`，并保持输入 `crs_ref`；失败不得返回原定义或伪造未知 CRS。

## 融合几何契约

`dissolve(input_gdf, id_field, group_fields)` 为唯一 workflow/read 入口，删除旧 by/隐式全局单输出路线。源为具有唯一真实活动几何和唯一列名的 GeoDataFrame，几何为有效非空有限 XY Polygon/MultiPolygon，使用已知投影 CRS 及匹配有限正水平单位，允许空批。显式 id_field 为唯一非空非几何标量列；group_fields 必须显式提供无重复的现有非几何列名列表，[] 表示全局融合，字段值仅为可哈希标量，空值合法。

分组按原始首次出现顺序编号，从1开始的 fusion_id 只在本次结果内有效。字段组合中的空值使用同一空组，不丢空值源、不填0或字符串；非空值按实际标量类型和值比较，不强制把数字、布尔和字符串互转。组内重叠、包含及几何重复允许，求精确面并集消除重复覆盖；不同组即使相互覆盖仍各自保留。每组输出一条完整 Polygon/MultiPolygon，不拆连通部件、不输出额外线点、不吸附、修复、重投影或舍入，不承诺原顶点次序。

双输出：默认 result 仅含分组列、fusion_id、member_count 及真实活动几何/CRS；member_count 统计原始要素行数，不是部件数或去重覆盖数。members 保留每个原始要素的全部业务属性、原始几何/CRS及原相对行序，追加 fusion_id 和保持原标识类型的 source_id，每个原始要素恰好一次；它表示组成员关系，不是每个融合碎片的逐段贡献。非分组属性不任取第一条、不汇总sum/mean；首版不增加数值聚合配置。固定fusion_id/member_count/source_id与源列或活动几何重名均拒绝，上游手工改名，不自动覆盖。两输出重建RangeIndex；空批返回完整双Schema空结果。

沿v3四个无field封闭组合：dissolve/operator_input_invalid/input_gdf，dissolve/operator_crs_invalid/无parameter，dissolve/operator_group_fields_invalid/group_fields，dissolve/operator_dissolve_fields_conflict/无parameter。公开诊断无业务列名、ID、坐标或GEOS正文，只有已证明的准入错误转INVALID_PARAMS；求并异常或无效结果仍EXECUTION_FAILED。Python/Go/API YAML/共享双语及冻结节点绑定同次登记。现有面缝检查不再调用旧高层dissolve，复用同一几何求并内核并保持其既有范围和空批语义，不要求面缝检查新增ID或分组参数。

## 联合叠加契约

`union(input_gdf, gdf_b, id_field, reference_id_field)` 为唯一 workflow-only/read 双面图层入口，中文统一为“联合叠加”。删除旧 `gdf_list` 多层迭代路线，不保留别名；要素拼接、全局融合不属于本算子。双方仅接受具有唯一真实活动几何的 GeoDataFrame，几何为有效非空有限二维 XY Polygon/MultiPolygon；批次可空。使用相同已知投影 CRS 和匹配有限正水平线性单位，双方显式指定唯一非空非几何标量来源列，不推断索引或 FID。

每层内部的不同要素不得正面积重叠，包含及完全重复同样拒绝；共边／共点允许。以真实拓扑内点交集维度判定，不使用面积阈值、舍入或精度网格，也不先融合后掩盖重叠。A、B 分别检查，即使另一侧为空仍须通过准入。错误明确指向 A 或 B；用户先用面叠检查定位，再显式治理，本算子不自动修复或去重。

唯一结果分为三组，按“双方交叠 → 仅 A → 仅 B”排序：交叠按 A 原位置再 B 原位置，每对完整面部分一条；仅 A 逐源减去整个 B 范围，仅 B 逐源减去整个 A 范围，各源所有剩余面部分一条，空结果省略。多部件不拆行，包含与完全相同的面正确分区，不额外输出共边线、共点或 GeometryCollection 的低维成员；不同结果可共边／共点，但内部不重复。空 A 保留 B、空 B 保留 A；双方为空仍保留完整结果 Schema。

保留双方全部业务字段及原来源列，追加固定 `source_id_a`／`source_id_b`；缺侧的属性和来源使用真正空值，不使用 0、空串或字符串 nan 占位。普通 NumPy 整数与布尔列按原位宽转相应 Pandas 可空整数／布尔表示（包括空结果），避免经 float64 丢失大整数；既有可空、浮点、字符串、分类、日期等类型保持。结果几何沿用 A 的活动几何列名及 CRS，重建 RangeIndex；B 的真实几何不作为业务字段复制。双方业务字段、A 结果几何名或固定来源字段冲突时明确拒绝，要求上游手动改名，不自动加后缀、覆盖或丢列。双方输入不变，不保证运算后的顶点次序或环方向。

与相交叠加复用双源几何／标识／CRS／字段准入主路径，同次补 v3 六个无 field 组合：union/operator_input_invalid/input_gdf、union/operator_reference_invalid/gdf_b、union/operator_crs_invalid/无 parameter、union/operator_overlay_fields_conflict/无 parameter、union/operator_input_overlap/input_gdf、union/operator_reference_overlap/gdf_b。两种同层重叠原因只向 union 开放；共享字段冲突文案统一为叠加分析，不改变既有 intersection 组合。Python、Go、API YAML、共享双语呈现及 Develop 冻结节点绑定同步，公开诊断不含源 ID、业务字段名、坐标或原生错误。只有已证明准入错误成为 INVALID_PARAMS，原生计算异常／非有限或无效结果仍为 EXECUTION_FAILED。

空间索引只筛选候选，实际交集与双向整体范围差集决定结果；不建立全量候选配对矩阵，不吸附、重投影或修复。全部源、索引、整体范围与成果驻内存，高密度配对可增长，不承诺容量。纯计算不保存／扫描或创建资源；显式连接既有 save，资源级血缘保留 A/B 两来源，行级来源由成果列表达，不写入 Meta 技术字段。沿既有标准 Native/协议/API/真实 GPKG 保存重载及独立 OGR、共享诊断和消费者门禁验证，现有 CI 自动发现覆盖，无新入口或 Job；不提前派发真实普通 User T4，不重跑旧业务 T4 或容量。

## 裁剪几何契约

## 拓扑构面契约

GeoPython `polygonize`（拓扑构面）位于“矢量处理 / 线网处理”，仅支持 workflow，效果为 `read`。唯一输入 `input_gdf` 是当前工作流的 GeoDataFrame：仅接受二维、坐标有限的 LineString / MultiLineString，使用实际 active geometry 列；非空批中的空值、空几何、无效线或 Z/M 输入明确拒绝，不能静默丢弃。允许空批，保留源 CRS（包括未定义事实），不自动重投影。

输出复用两个既有 `geodataframe` 端口：默认端口 `result` 每行一个 Polygon，仅含 `geometry`；`diagnostics` 为未参与构面的线段，字段为 `issue_type + geometry`，类型值为 `dangle`（悬挂或孤立余线）、`cut_edge`（两端相连但未参与构面的边）、`invalid_ring`（构面阶段发现的无效环）。两端口均保留源 CRS，空结果保留相同 Schema。诊断对应打断、去重后的线网，不承诺原始线 ID 追溯；余线可能是合法业务对象，不自动判为质量不合格。无闭合区域时返回空面及实际诊断，不补造面。

统一参数诊断沿既有 v3 只登记 `polygonize / operator_input_invalid / input_gdf`，无 `field`。仅将现有明确拒绝类型化：非 GeoDataFrame、缺少活动几何列、NULL、非 LineString／MultiLineString、空几何／空部件、Z/M、非有限坐标，或检查已判定无效的输入线。原生几何读取、检查、打断、构面或结果组装抛出的异常仍为 `EXECUTION_FAILED`。空批、无闭合区域以及 `dangle`／`cut_edge`／`invalid_ring` 仍由正常双端口返回。保持现有 CRS 规则，不把源 CRS 作为准入条件。失败节点的两个下游保存均不得执行。

## 重合规整契约

GeoPython `normalize_line_network(input_gdf, id_field)`（重合规整）位于“矢量处理 / 线网处理”，仅 workflow/read。输入为单个有效、有限二维 XY LineString / MultiLineString 图层，使用实际 active geometry 列。要求已知投影 CRS，两个水平轴具有相同有限正线性单位；不隐式重投影。拒绝非 GeoDataFrame、重复列名、缺失／空几何或空部件、非线、Z/M、非有限坐标及无效线，允许空批。`id_field` 显式指定现有非几何唯一非空标量列，不用索引或存储 FID 推断来源。内部自交／自叠、同源多部件以及跨要素的精确重合均可规整。

保留每个原始部件的各次线段出现，按全部原始顶点、真实点交会及重合的起止端点细分；普通折点和闭环原首尾同样作为原顶点形成边界。只对精确相交位置切分，不使用容差、精度网格、舍入、吸附、延伸或近邻回退。每个输出片段为具有两个不同 XY 端点的直线段，正反等价的片段只保留一份，不把平行近邻或仅部分重合的未细分段直接等同。连续重复坐标形成的零长度原段不生成边或明细，但原段编号仍按原始相邻坐标对计数，因此可以出现编号间隔；不修改输入坐标或源文件。不同采样顶点、完全重复、反向重复和同源多次经过均以实际精确覆盖规整；不连接相邻边或调用链路合并。

双端口均为 geodataframe，保留原 active geometry 列名和 CRS、重建 RangeIndex：

- 默认 `result` 每唯一边一行 LineString，仅有几何、Int64 `edge_id` 和 Int64 `occurrence_count`，不选主来源、不聚合／复制任何业务字段。边方向固定为端点按 XY 字典序较小者到较大者；边号按源行／原部件／原段／沿原段片段首次出现从1递增，只是本次双结果的关联标识。`occurrence_count` 计该边的原始经过次数，同源重复经过也计入，不是不同来源 ID 数。
- `members` 每次正长度片段经过一行，保留全部源列／类型及原 ID，几何为该片段按原始经过方向排列的两个端点，追加 `edge_id`、`source_id`（保持原标识列类型）、Int64 `source_part_no`／`source_segment_no`／`piece_no` 和 Boolean `is_reversed`。部件号、原始段号从1起，`piece_no` 在每个原始段内按原方向从1开始；明细按源行、原部件、原段和片段顺序输出。`is_reversed` 表示本次经过相对唯一边方向是否相反。各次经过均单独保留，不能按 source_id 去重或将多来源拼成字符串。

源列与上述任一固定输出字段（含 `occurrence_count`）冲突即整批拒绝，不覆盖或自动改名；空批保留双端口完整 Schema 和所有源列类型。`members` 是逐片段来源关系，不宣称零长度重复坐标已存入明细或可以仅凭唯一边重建原业务要素。原图层与业务属性不变，不把该规整结果自动判断为业务正确，不推断桥隧或层级。

唯一主线使用原始段空间索引筛选候选，在真实求交时直接绑定双方原始段的点和重合端点，随后按原段方向细分并精确去重，明细与唯一边在同一次遍历建立关联；不先融合再按近邻猜来源，不建立完整候选对矩阵。源段、索引、切点和双成果驻内存，高密度候选或经过明细仍可增长，不承诺固定内存或容量。纯计算不持久化、不扫描；两个端口分别连接既有 `save`，保留现有输出与血缘主线，不向 Meta 技术字段塞业务来源，不增加 API、权限、Adapter 或实体。

## 节点提取契约

GeoPython `extract_line_nodes(input_gdf, id_field)`（节点提取）位于“矢量处理 / 线网处理”，仅workflow/read。输入为单个有效、有限二维XY LineString／MultiLineString图层，使用实际活动几何列；已知投影CRS两水平轴须有相同有限正线性单位，不隐式重投影。显式id_field引用唯一非空非几何标量列，不推断索引或FID；上游拆分后须显式提供本级唯一ID，原来源列仍可保留。允许空批，拒绝重复列名、缺失／空几何或空部件、非线、Z/M、非有限坐标及无效／零长度线。

与链路合并共用端点线网准入：每原始LineString部件为一条边，只允许部件之间在双方原始端点处精确点接触。未打断T形／十字、端点落在线内部、单部件内部自交／自叠及任意正长度重合（完全／反向／部分重复、同源重复部件）整批拒绝，不隐式打断、去重或计作多条重合边。两条不同路径即使端点相同，只要没有重合且仅端点相接，仍各是一条边，不能按端点对去重。连续重复坐标不增加节点／度数；闭环原首尾正常接点不算自交。

每个部件的原始起端、终端各贡献一次端部关联；精确相同XY合并节点，degree为端部关联次数。闭环首尾同点输出一个节点、degree=2，保留两次端部明细；闭环原首尾接一支线时degree=3。一个完整闭环与拆为三条边的三角形拥有不同节点集合，不旋转接缝、不把普通内部折点提为节点；支线接闭环内部必须先显式打断。MultiLineString每部件独立计数，同源不去重、不强行连接；度数不是独立要素数、入出度或业务质量。使用精确平面XY，无容差、舍入、精度网格或桥隧推断。

双端口均Point geodataframe，保留原活动几何列名和CRS、重建RangeIndex：

- 默认result每节点一行，仅几何、Int64 node_id／degree。按源行、部件、起端后终端的首次出现顺序从1编号，仅关联本次结果；不挑选或汇总某个来源属性代表节点。

必须满足 `sum(result.degree)==len(members)==2*原始部件数`。源列与node_id、degree、source_id、source_part_no、end任一固定字段重名时按该固定顺序报首个冲突（含活动几何列），不覆盖或自动改名；结构／维度与有效性准入先于字段冲突，随后核来源ID、CRS和端点拓扑。空批保留双端口完整Schema。源不变，纯计算不保存／扫描，两端口分别接已有save，无跨文件事务承诺；资源血缘沿现有保存主线，行级来源留members，不新增API、权限或实体。

重复／重合输入先显式调用重合规整，再将result输入节点提取，以edge_id作为本级ID，节点度按唯一边计算；上游members保留原始各次经过，可用同次edge_id关联，不在节点提取隐式消费或复制该表。输入端点图、索引及双成果驻内存，高密度候选可增长，不承诺固定容量。

统一参数诊断复用v3，四类闭合组合：operator_input_invalid/input_gdf，operator_projected_crs_required/无parameter，operator_endpoint_network_invalid/input_gdf，operator_field_conflict/input_gdf且field仅上述五个固定名。已证明的准入事实类型化进入INVALID_PARAMS；原生计算异常不按正文归类，保留EXECUTION_FAILED。验证走根make test-geopython-workflow既有拓扑、元数据和协议文件，涵盖闭环、多部件、分支、不同路径相同端点、重复／交会拒绝、完整属性与双保存原生OGR核验、双语错误及失败无发布。Common Python／Go与共享诊断前端同步白名单及反例，沿现有根入口和自动CI覆盖，无新依赖、入口或Job；不重复已过业务T4／容量，不把Native保存称作新普通User T4。

## 链路合并契约

GeoPython `merge_line_chains(input_gdf, id_field, match_fields)`（链路合并）位于“矢量处理 / 线网处理”，仅 workflow/read。输入为单个有效、有限二维 XY LineString / MultiLineString 图层，使用实际 active geometry；已知投影 CRS 的两水平轴须具有相同有限正线性单位。不隐式重投影，拒绝缺失、空几何／空部件、非线、Z/M、非有限坐标、无效或内部非简单线。正常闭环首尾和连续重复坐标不算自交。不同原始部件之间仅允许双方端点处的精确点接触；未打断 T形／十字、端点落在另一部件内部、内部自交／自叠及任何正长度重合（含重复、反向重复）整批拒绝，不自动打断或去重。同源部件端点相接允许连接，来源相同本身不是连接理由；允许空批并保留双端口完整 Schema。

`id_field` 显式指定现有非几何唯一非空标量列，字符串不可全空白，不使用索引或存储 FID 替代。上游打断后原业务 ID 重复时，调用者须明确提供片段唯一标识，原来源列仍保留到明细。`match_fields` 必填且为无重复的现有非几何业务字段名数组，不能包含 `id_field`；明确传空数组表示仅按几何连接。各一致字段只接受标量值，采用同类型精确同值比较，不转字符串、不裁剪／忽略大小写、不设数值容差，两个缺失值一致，缺失与实值不同；不聚合、不取首值掩盖差异。未选择的业务属性不阻止连接，只在完整来源明细保留，不进入链路共同属性。

以原始 LineString 部件为边、其原始首尾 XY 为端点，先构造全图端点关联；闭环首尾同点计两次。全图度为二且两部件一致字段全部相同时才串联；度为一、属性不同或度大于二均停止，三岔／十字处不按名称、角度、长度或来源选主路。必须先核全图度，再判断属性，不可先按属性分组将分支伪装成度二。无距离容差、精度网格、舍入、短线删除、补缝或延伸，不推断桥隧和业务质量。

输出复用两个 geodataframe 端口：默认 `result` 每链一条 LineString，仅包含 `match_fields` 按显式顺序保留的共同属性及原 active geometry，追加 Int64 `chain_id` 和 `member_count`；`members` 每原始部件一行，保留全部原列／类型、原部件几何和原 ID，追加 Int64 `chain_id`、`member_no`、`source_part_no` 和 Boolean `is_reversed`。明细按链号及沿链部件顺序排列；部件号在每个原始源内从1起，沿链编号从1起。固定追加字段与任一源列冲突即拒绝，不覆盖或自动改名。两输出重建 RangeIndex、保留原 CRS，源图层不变；不将多个 ID 串成字符串或以一个来源 ID 冒充整链身份。

### 重合规整与链路合并的显式几何组合

首版复用既有算子，不新增算子、API、端口或业务实体：`normalize_line_network(source, id_field)` 的默认 `result` 输入 `merge_line_chains(..., id_field="edge_id", match_fields=[])`。空一致字段必须显式给出，表示业务属性差异不阻止几何连接；仍按全图端点度在分支处停止，无隐式吸附、补缝、简化或按角度选主路。规整输出的 `occurrence_count` 不作为一致字段，不因来源经过次数变化阻止连接；不从多来源中取首值／多数值、拼接或聚合业务属性。

三份成果配套保存，分别使用既有 `save`：

- `chains`：链路合并默认 `result`，仅实际 active geometry、Int64 `chain_id`／`member_count`，不提升原业务属性。`member_count` 是组成该链的唯一边数量，不是原要素数或原始经过次数。
- `chain_edges`：链路合并的 `members`，保留每条唯一边的原方向几何、`edge_id`／`occurrence_count`，追加所属 `chain_id`、链内 `member_no`、本级 `source_part_no`（唯一边为单部件，因此均为1）和 `is_reversed`（唯一边相对链方向）。每条唯一边恰好归属一条链。
- `edge_sources`：重合规整的 `members`，保持全部原业务列／类型及每次经过的原方向几何，包含 `edge_id`、原 `source_id`、原 `source_part_no`／`source_segment_no`／`piece_no` 与 `is_reversed`（原经过相对唯一边方向）。同源重复经过仍逐次保留。

仅用同次计算的 `edge_id` 连接两级明细，不靠 FID、坐标近邻或几何长度猜来源；链号／边号不宣称跨批稳定。两级 `is_reversed` 异或得到原经过相对最终链的方向；链内顺序取 `chain_edges.member_no`，原段内顺序取 `edge_sources.piece_no`。同名字段须按成果限定含义，原输入即使有业务 `chain_id`／`member_no` 仍只在 `edge_sources` 原样保留，不与本级技术链号／序号混写；本轮不生成扁平化关联表或新派生字段。规整原有保留字段冲突仍整批拒绝，不静默改名。

精确计数须满足：`sum(chains.member_count) == len(chain_edges)`；按边计的 `chain_edges.occurrence_count` 等于该边在 `edge_sources` 的经过行数，其总和等于 `len(edge_sources)`。链内每个有向片段须与本级边及原经过通过两级方向标记精确对应，原属性／NULL／Int64／Boolean／CRS不变；源内存与源文件不变。零长度原段沿规整契约不生成明细，原段号允许间隔，不承诺由三成果还原这些重复坐标。三成果的业务关系不塞入 Meta 技术血缘。

先沿现有 `make test-geopython-workflow` 的拓扑 Native 文件验证混合属性的共享边、四种方向组合、分支、闭环、多部件／同源重复、微小断口／零长度原段、空批、字符串／大Int64来源标识及三份GPKG完整原生重载；同次包含真实破坏反例，不调用生产算法生成期望。既有文件列表及 GeoPython CI 自动发现覆盖，不新增测试入口；此阶段不运行新的普通User组合T4、旧业务包或容量。按业务字段决定合并、共享边属性归并、扁平化来源表、组合T4与组合容量须另行讨论确认。

## 交点打断契约

GeoPython `split_line_intersections(input_gdf, id_field, scope="between")`（交点打断）位于“矢量处理 / 线网处理”，仅支持 workflow/read。输入为单个图层的有效、有限二维 XY LineString / MultiLineString，使用实际 active geometry，拒绝缺失、空几何或空部件、非线、Z/M 及非有限坐标；允许空批。要求已知投影 CRS 且两水平轴具有相同有限正线性单位，不隐式重投影。`id_field` 显式指定现有非几何唯一非空标量列，不以索引或存储 FID 替代来源。`scope` 仅接受精确字符串 `between`／`all`，不裁剪、改大小写或以布尔值推断。

## 线内自交契约

GeoPython `check_line_self_intersection(input_gdf, id_field)`（线内自交）位于“矢量处理 / 拓扑检查”，仅支持 workflow/read。输入及来源标识复用线交／线内自叠的校验：实际 active geometry、有效有限二维 XY LineString / MultiLineString、已知投影 CRS 且两水平轴具有相同有限正线性单位换算因子；拒绝缺失、空几何或空部件、非线、Z/M、非有限坐标和无效线，允许空批。`id_field` 为显式唯一非空非几何标量列，不推断主键或以行索引/FID替代来源，保留原类型。自交或回折本身不等于无效线，不因此拒绝。
