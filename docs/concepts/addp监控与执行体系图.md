# ADDP 监控与执行体系图

本文档展示 ADDP 平台的统一执行监控架构和跨模块任务追踪机制。

平台在现有执行监控和平台日志链路基础上扩展运行观测。节点身份、主机资源、进程自身指标及可选设施已实现；专业引擎/容器观测与分布式追踪尚待实施；本页既有执行事实不改为遥测存储。已实现契约见 [平台运行观测规范](../spec/addp平台运行观测规范.md)。
