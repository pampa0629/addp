## 导入预览组件

文件预览使用 `@common-ui/previews`，`GeoJsonPreview`／`TablePreview` 使用 `@common-ui-map`；依赖声明、别名与 Vue 去重统一见[共享前端架构](../ARCHITECTURE.md#使用方法)。本页维护共享组件的输入、展示和生命周期约束；服务消费与配置、Agent 协议分别以[渲染体系](../../../docs/spec/addp数据服务消费与数据应用规范.md#八渲染体系)、[A2UI Catalog](../../../docs/spec/addp智能体交互协议规范.md#七a2ui-catalog)为准。

以下片段只演示地图表格组件的导入。宿主从正式预览入口取得已授权响应并填入 `previewData`，成功取得数据后再挂载；组件导入不证明内容读取或数据保护已通过。

```vue
<script setup>
import { ref } from 'vue'
import { TablePreview } from '@common-ui-map'

const previewData = ref(null)
</script>

<template>
  <TablePreview v-if="previewData" :data="previewData" />
</template>
```

## 预览组件

文件与地图的导入、依赖归属沿[导入预览组件](#导入预览组件)；具体组件保留以下展示约束。

- **GeoJsonPreview** - GeoJSON 文件预览（带地图）
- **TablePreview** - 表格数据预览，支持空间字段渲染
- **ImagePreview** - 图片预览；普通 TIFF 消费 `object.attributes.format_info.tiff` 的完整页目录，经同源平台 `object.content.url` 的 `storage-stream` Range 地址按页解码，缺少页目录时提示深度刷新。最长输出边 1024 像素，源页上限 1600 万像素，页切换与卸载取消旧请求；原始下载仍为整个 TIFF。GeoTIFF 空间预览归既有地图组件。
- **MarkdownPreview / OfficePreview / PptxPreview / PdfPreview** - 文档预览组件；OfficePreview 统一处理 DOC、DOCX、RTF、WPS。旧式 DOC/WPS 与 RTF 解析器由 `common-frontend/basic` 单点维护并按需加载，DOCX 使用宿主直接声明的 `mammoth` 依赖；不得依赖仓库外本地路径或运行时远程资源
- `PdfPreview` 用 `ImageData` 缓存页面，创建和恢复画布均声明 `willReadFrequently: true`，使反复像素读取匹配 2D context 配置。Manager 确定性浏览器门禁覆盖三页绘制、不同页图像、原图缓存恢复和零 warning／error；真实 PPTX PDF 仍由原 Manager Hosted suite 验收，入口见[测试与验收导航](#测试与验收导航)。

`TablePreview` 的 `temporaryCrs` model 只用于源 CRS 未知时的本次地图展示，默认空值，可选择 EPSG:4326 或 EPSG:3857；共享 CRS registry 负责转换，响应数据保持不变。容器预览通过同一 model 传递声明，Owner 在当前预览上下文中临时持有，并在资源、child 或组件引用改变时同步清除。它不属于可持久化的 `tableState` / `viewState`，不得发送给元数据或视图保存接口；未绑定 model 的独立组件使用 Vue model 自身的局部生命周期。

地图预览、CRS registry、底图 profile 和 GCJ-02 展示适配规则见 [Map 前端组件说明](../../map/README.md)。

### 数值容器有界网格切片

本节按主题阅读：[输入与宿主](#网格输入与宿主职责) · [数值与掩膜](#网格数值与有效掩膜) · [取消与失败](#网格请求取消与失败) · [布局与验收](#网格布局与页面验收)。

#### 网格输入与宿主职责

`GridContainerPreview` 是变量／维度选择和原始网格的唯一共享实现，复用 `ContainerPreview` 的变量选择器与 `child-details`／`child-preview` 插槽。

业务模块只提供变量索引、`loadSlice` 及可选已确认空间范围插槽。宿主通过 `loadSlice(selection, signal)` 接收当前切片选择和取消信号，由宿主装配正式读取请求。Manager 的 NetCDF 和 GRIB 复用该实现，不借用 table 分页或新增数据类型，基本权限与源版本由 HTTP owner 校验。权限、精确目标、读取前后保护和源版本失败统一见[Manager 预览规范](../../../manager/docs/数据预览与资源树实现规范.md#一定位)，不因共享 UI 已可显示就扩大读取范围。

#### 网格数值与有效掩膜

数值以格式声明的模式保留文本和有效掩膜：NetCDF 为原存储值，GRIB 为原单位解码值；大整数不转 `Number` 着色。格式适用范围与模式分别沿[NetCDF 单文件只读](../../../docs/spec/builtin-formats/媒体与地图数据集.md#netcdf-单文件只读)、[GRIB2 单文件只读](../../../docs/spec/builtin-formats/媒体与地图数据集.md#grib2-单文件只读限定范围已验收)，不在组件专题重复维护格式准入矩阵。

#### 网格请求取消与失败

选择变化或离页取消在途请求，旧结果不显示。[共享网格组件](../../basic/src/components/previews/GridContainerPreview.vue)在选择或变量索引变化时取消旧请求、清除切片和旧错误，并通过请求序号排除迟到写回；卸载复用同一清理路径。返回的 `value_mode` 与当前变量不符时按失败处理。

仅当前仍有效且未取消的请求显示失败；旧请求的失败不覆盖新选择，失败不恢复旧切片。UI 取消不替代 Owner 的权限与源版本校验。

#### 网格布局与页面验收

变量属性、操作控件、网格和可选地图不得互相遮挡或被 flex 压缩为零高度，内容超过可用高度时由同一容器 body 滚动触达；网格自身保留有界滚动。

页面验收使用真实长度属性，同时核对按钮可点击、数值表首尾实际可见及可滚动触达，不能只断言 DOM 文本。标准入口与受控页面覆盖见[测试与验收导航](#测试与验收导航)。真实数值／掩膜、源变化、拒绝与清理分别沿[NetCDF Online 场景](../../../docs/spec/testing/scenarios/Manager与空间成果.md#netcdf-单文件只读)、[GRIB2 Online 场景](../../../docs/spec/testing/scenarios/Manager与空间成果.md#grib2-单文件只读)认定，不能因复用同一组件互相替代证据；未运行或未覆盖项不计通过。

## 数据服务结果渲染器

本节按主题阅读：[组件与宿主](#结果组件与宿主边界) · [完整性与上限](#结果完整性与展示上限) · [字段与时间](#字段呈现与时间上下文) · [展示属性](#图表展示属性与状态保持) · [主题刻度与标签](#图表主题刻度与标签) · [选择与验收](#结果选择事件与验收边界)。

### 结果组件与宿主边界

已发布数据服务的消费结果使用共享表格、分页及结果 renderer；子包与 Workbench Host 的职责统一见[共享渲染边界](../../../docs/spec/addp数据服务消费与数据应用规范.md#81-common-frontend-与-workbench-边界)。本页保留组件展示属性与事件约束：

- `basic/src/components/TabularResultRenderer.vue`：表格预览与有界结果的唯一基础表格实现，按显式列配置展示标量和结构化值；
- `basic/src/components/DataPagination.vue`：预览场景的唯一受控分页组件，只表达分页状态和变化事件，不决定客户端切片或服务端加载；
- `basic/src/components/ScalarValueRenderer.vue`：显示服务已返回的唯一行数值结果，不在浏览器求和、计数或猜测口径；
- `chart/src/ChartRenderer.vue`：展示 `bar | line | pie`，只使用服务已返回的明细值，不在浏览器聚合；
- `map/src/components/GeoJSONResultRenderer.vue`：只读取 Consumer Descriptor 明确声明的 geometry 字段和 CRS，并可使用显式 label、tooltip 与 `uniform | categorical | continuous` 受控主题样式；不猜测业务字段，不接受原始颜色或任意样式 DSL。

Manager 表格及容器预览、Develop 查询、Workbench 结果和 Agent UI 的 `TablePreview` 协议适配器复用上述基础表格，不另建 `el-table`、结构化值详情或单元格格式化实现。共享表格、受控分页和各宿主服务端／客户端加载策略统一见[表格预览组合边界](../ARCHITECTURE.md#表格预览组合边界)，不在本页重复维护。

### 结果完整性与展示上限

Value、Chart 和 Map 只接受单次查询得到的完整有界结果；`has_more=true` 时必须拒绝渲染，Value 还必须恰好一行，Chart 和 Map 还必须遵守各自结果上限。Workbench 等消费模块应在自己的 Renderer Host 中按需加载这些组件，不得复制 renderer，也不得把 Service、Outdoor 或其他 owner 的 DTO 写入共享层。

Chart 默认折线最多接受 1,000 行、柱形 500 行、饼图 20 行；宿主可通过展示属性 `maxRows` 显式指定笛卡尔图的完整结果上限（整数 1–1,000），不改变查询、不裁剪结果；饼图不可覆盖上限。折线和柱形保留 null 空点，折线不跨空点连线，饼图拒绝 null。资源观测的陈旧或缺失点由 owner 显式传入 null，不在共享图表中推断状态或补值。

### 字段呈现与时间上下文

时间字段支持 `month` 年月格式；`period` 格式只消费宿主显式解析的 `period_context`（`grain=total|month`、已本地化的 `total_label`）。全期显示该标签，按月使用当前语言年月格式，未取得上下文时显示空值占位。共享 renderer 不解析应用参数或猜测业务字段；宿主保留查询成功时的参数快照并负责范围说明。

字段显示名、单位、精度、时间格式和受控状态呈现统一由 `basic/src/utils/fieldPresentation.mjs` 解析。状态规则只允许精确匹配或数值比较，按声明顺序首条命中，并输出 `info | success | warning | danger` 语义状态；不接受表达式、函数或原始颜色。Table 与 Value 直接显示状态标签，Chart 只在 tooltip 中追加标签，Map 只在 popup 中显示标签，不能借此覆盖 Chart series 或 Map thematic style 的既有视觉编码。

字段呈现中的 `value_labels` 复用同一格式化器；类型、数量上限、精确匹配、null／未命中及原值保持统一见[有限值名称与动态维度](../../../docs/spec/addp数据服务消费与数据应用规范.md#8102-有限值名称与动态维度)。Workbench 只编排映射配置，不在 renderer 内猜测业务码，也不使用分页目录结果补全动态名称。

### 图表展示属性与状态保持

`maxRows`、`valueAxes` 及缩放属性（`zoomable`／`initialZoom`）由宿主直接提供，不进入 Workbench 持久化 `renderer_config`；Workbench 保持其 500 行消费契约。配置保存与共享 primitive 的分工沿[共享渲染边界](../../../docs/spec/addp数据服务消费与数据应用规范.md#81-common-frontend-与-workbench-边界)，不因宿主可传属性而开放保存。

ChartRenderer 的可选 `valueAxes` 展示属性用于笛卡尔图的一至两个显式数值轴，默认仍使用单轴。每轴声明 `measures`、可选显示名 `label` 及有限数值范围 `min/max`；必须恰好覆盖所有度量一次，同轴度量单位和精度相同，不接受 ECharts 配置透传。左右轴各自显示字段单位及刻度，tooltip、图例、null 断点和选择事件沿既有契约。`valueAxes` 不推断单位分组。

宿主可为折线／柱图设置 `zoomable=true`，使用共享图表的时间／类别缩放滑块。滑块仅改变本地可见范围，`filterMode=none` 保留全部原始行，不触发查询、聚合或补点；同一图表重绘保留相对缩放范围。宿主可通过 `zoom-change` 事件保存仅含 `start/end`（0–100）的临时视口，并以 `initialZoom` 在刷新重建时恢复；该属性仅初始化实例，不反向驱动正在拖动的滑块，范围由宿主在对象／查询范围／身份变化及错误时清空。默认不显示该控件。

### 图表主题刻度与标签

Chart 的坐标轴、图例、饼图标签和 tooltip 使用当前 ADDP 主题变量，主题变化后重绘 Canvas。单度量轴设置了显示精度 `precision=p` 时，最小刻度间隔为 `10^-p`；因此精度 0 的全零结果不会把小数刻度重复显示成整数。该约束只影响坐标轴，不舍入或修改服务返回的 series 数据；未指定精度及多度量轴仍使用自动刻度。

柱形图默认在柱形上方常显数值标签（包括零值），宿主可通过 `showValueLabels=false` 隐藏密集柱图的常显标签，tooltip 仍显示相同数值和单位，不改变原始结果、零值或 null。默认标签沿用字段呈现的单位、精度和当前语言数字格式，文字使用主题正文色；零值标签显示在基线上方，避免与横轴日期重叠。标签不追加状态文案，状态仍只在 tooltip 中显示，不改变原始数据或选择事件。

### 结果选择事件与验收边界

所有 renderer 都必须保留原始 rows 与 `row_index`。

结果 renderer 在用户选择当前结果时统一发出 `result-select`，payload 只包含 `{ row_index }`。`row_index` 始终指向宿主传入的原始 `rows`，renderer 不携带字段值、参数名、目标组件或查询片段；宿主负责根据自己的声明式配置解释选择。数据更新、resize 和重绘不得发出该事件。

`ScalarValueRenderer` 显式启用 `selectable` 时，鼠标点击或回车／空格返回 `result-select: { row_index: 0 }`，不改写原始值。

共享属性、Workbench Host 和实际服务消费分别沿[测试与验收导航](#测试与验收导航)验证；渲染成功不代替权限、参数快照、结果完整性或迟到响应处理验收，未运行或未覆盖项不计通过。

## 图查询结果

本节按主题阅读：[组件输入与消费范围](#组件输入与消费范围) · [共用主题](#共用图主题与状态保持) · [共用视口](#共用图视口与适应窗口) · [共用清理](#共用图生命周期与清理) · [验证分工](#图组件验证分工)。

### 组件输入与消费范围

`@addp/common-frontend/graph` 的 [GraphResultView](../../graph/src/GraphResultView.vue) 接收 `graphData`，展示查询结果的节点与关系，并提供工具栏和属性面板。

`GraphSchemaView` 通过 `schema` 接收节点标签、数量、属性名和关系类型组成的结构数据。该组件目前仅由共享包导出，尚无业务页面直接调用。

### 共用图主题与状态保持

两者复用同一标签配色函数；画布及各自的工具栏、图例、节点、关系线和详情面板使用平台主题变量。主题切换原位更新 G6 样式，保留当前布局、缩放／视口和节点／属性选择。

`readGraphTheme(element)` 和 `getContrastingTextColor` 是共享图主题读取及标签对比色工具，Graph 业务页面也从该包导入。

### 共用图视口与适应窗口

图查询结果与结构图的初次布局、窗口缩放和“适应窗口”统一使用共享 `fitGraphToViewport`，通过 G6 `onlyOutOfViewPort` 规则将自动适应缩放上限设为原始尺寸（1 倍），大图仍按容器和各自留白缩小并居中；手动滚轮可继续放大。

### 共用图生命周期与清理

两个组件均在数据及实际画布容器就绪后同步建立图实例和尺寸观察，支持初始空结果、延迟加载及清空后重载。每次替换数据或容器先取消待执行的尺寸更新、解除旧观察并销毁旧图，同时清除旧节点详情；组件卸载清理主题和尺寸观察。

### 图组件验证分工

`GraphResultView`：实际画布主题切换与 Graph 消费分别验证，标准入口见[测试与验收导航](#测试与验收导航)。

`GraphSchemaView`：真实组件浏览器夹具纳入既有 Develop E2E 自动发现，覆盖四种主题、节点点击事件、详情保留、容器缩放和卸载后重建。

组件浏览器夹具覆盖单节点、双节点、多节点图及窗口变化，查询工作台保留实际“适应窗口”按钮回归；测试沿用共享前端与 Develop 的现有门禁。生命周期浏览器回归纳入 Develop 的既有 E2E 自动发现。绘图与夹具回归不证明真实查询授权；查询失败后的宿主状态、旧结果清理和真实链路仍按[测试与验收导航](#测试与验收导航)分别验证，未运行或未覆盖项不计通过。

## 本体关系查看器

`common-frontend/graph` 的 `OntologyView` 是 Graph 与平台 Ontology 的唯一关系图渲染实现。

本节按主题阅读：[布局与容器尺寸](#本体布局与容器尺寸) · [连线与主题配色](#本体连线与主题配色) · [交互与视口](#本体交互与视口) · [更新与卸载](#本体更新与卸载) · [验证分工](#本体验证分工)。

### 本体布局与容器尺寸

默认使用层级布局；平台能力核实通过 `layout="grid"` 使用紧凑总览，避免大量并列条件将图拉长。网格防重叠与实际绘制共用同一节点尺寸；列数按实际可用宽度、节点宽度与间距计算，行数按当前概念数量计算，不按画布比例假定节点为正方形，也不使用额外增高的布局盒压缩标签。

画布只按可测量的实际容器尺寸初始化，紧凑布局在窗口变化后重新布局并适应边界。

### 本体连线与主题配色

自关联关系统一使用 G6 原生环线，避免普通曲线退化后箭头不可见、标签被节点遮挡；本体、结构图和查询结果共用边类型选择。默认节点、连线、继承关系与标签从当前容器的主题变量解析，显式本体配色保留，文字按填充色选取对比色。主题切换原位更新画布，不重建布局、重置视口或关闭详情；消费者只映射领域数据，不将主题快照写入实体配色。

### 本体交互与视口

标签分行，详情保留完整名称；共享工具栏提供缩放、原始大小和适应窗口。自动适应与查询结果、结构图及只读 DAG 共用[公共视口规则](#共用图视口与适应窗口)，手动缩放仍可放大。

### 本体更新与卸载

`entityTypes`、`relationTypes` 或 `layout` 变化时，[OntologyView](../../graph/src/OntologyView.vue) 销毁旧图并清空节点详情，在 Vue 更新完成、数据非空时按前述容器条件初始化。卸载时断开尺寸与主题观察，销毁图实例并清除引用。

### 本体验证分工

实际 G6 浏览器交互与 Graph 消费分别验证，标准入口见[测试与验收导航](#测试与验收导航)，具体核对布局、配色、视口保持、容器变化与卸载。静态源码或导航核对不代替运行验收，未运行或未覆盖项不计通过。

### 接入与宿主职责

`@addp/common-frontend/graph` 提供 `LineageViewer`、`createLineageApi` 和 `normalizeLineageGraph`，消费 Meta `GET /api/v1/meta/lineage/graph` 返回的 `{ nodes, edges }`，可在 Service、Manager、Asset 页面内嵌展示。请求函数由宿主注入，组件不处理 Token。

`LineageViewer` 填满宿主容器，宿主须提供有界的 flex 高度；宿主通过 `v-model:depth` 接收层数变化，以同一层数重查 API。未传入层数时组件显示 2 层，宿主可显式指定初始层数。共享组件负责交叉连线隔离、悬停/选中高亮和截断提示。

### 字段身份与证据语义

字段级视图由同一 `LineageViewer` 实现：宿主传入 `supportsFields` 和 `v-model:granularity`，调用原图 API 的 `subject_kind=data_item` 与 `granularity=field`，一次加载根表全部字段及其有界关系。字段按数据项和结构快照分组，连线对齐字段行。

节点 ID 包含数据项、字段名和结构快照 hash，字段名中的点号不拆分；每个根字段的 `field_lineage_status=unavailable` 明确表示证据不可用，不能解释为没有依赖。

### 绘图与高亮

血缘颜色在每次渲染时统一解析并传入节点和连线模型，不能逐连线读取 DOM 计算样式。

图形模型直接从当前粒度投影生成：字段级仅生成表卡展示模型，不先生成全部独立字段节点再丢弃；字段连线单次映射保留精确关系和锚点，不逐边扫描完整边列表。血缘连线统一使用水平三次贝塞尔曲线，控制点由当前端点计算；同高度端点自然呈直线，不保存布局生成的折线路由。方向箭头、交叉隔离、高亮与关系证据保持一致。

高亮按完整字段身份计算状态，每张表只计算一次字段高亮状态，并单次遍历图形；不得逐字段重复扫描整张表的图形列表。选中与悬停状态仅在实际变化时交给图引擎，避免对未变化的关系反复合并样式和重建箭头。

### 搜索布局与字段折叠

字段入口支持本地搜索；选中入口定位字段并高亮上下游。点击字段聚焦已加载的上下游关系，清除聚焦恢复全图，不逐字段发请求。

表卡的宽度、字段行和层间距采用紧凑布局，默认优先显示满足阅读字号的全图；适应窗口仍显示完整图，长字段名按文字宽度截断，悬停和详情提供精确全名。

表卡可拖拽，连线跟随字段行锚点；自动布局复用 `useDAGViewport`，重新排列卡片并适应窗口，保留当前选择。适应窗口保留手动坐标，自动布局、字段入口触发展开或重查图数据时重新排列；坐标不提交后端。

表卡可单独或批量收起字段；收起时显示字段数，保留全部精确关系并对齐摘要行，展开恢复字段行端点。手动折叠保持卡片左上角和视口；字段入口自动展开该字段的上下游表，触发展开时按新卡高重新布局、保持缩放并定位字段，防止长表覆盖相邻分支，其他表的折叠状态不变。

### 局部展开与执行跳转

血缘节点以 `hidden_upstream_count` / `hidden_downstream_count` 提示未显示的直接邻居；方向按钮触发 `expand`，业务页面通过现有图接口请求局部展开。节点主体查看详情，`view-execution` 由业务页面调用共享 Monitor 导航。局部展开保留原始根节点、缩放和展开节点的位置。

### 主题全屏与生命周期

主题切换仍按当前主题重新渲染。主题、语言切换保留手动坐标、视口、当前选择及折叠状态；全屏切换同样保留折叠状态，重查图数据后恢复展开。

支持原生全屏查看，进入/退出不重建图或重置视口；全屏下仍可搜索、选择字段、拖拽与自动布局。Basic 的 `useElementFullscreen` 统一处理血缘和 Office 预览的全屏状态、失败及卸载清理，Console 沿用现有 iframe 全屏权限。

### 权限过滤与失效清理

[局部展开](#局部展开与执行跳转)的邻居数只包含当前有权查看但尚未展开的节点。`permission_filtered=true` 单独表示当前查询边界上确有关系因权限被隐藏，查看器明确提示这一原因，不展示隐藏身份、数量或占位节点，也不将其解释为显示截断或字段没有来源。宿主重新核验、请求失败或身份边界改变时应清空旧图，并丢弃旧请求的迟到响应。

血缘图形契约、宿主 API／权限过滤和真实链路的验证分工统一见[测试与验收导航](#测试与验收导航)；在途请求处理复用[请求取消与迟到响应隔离](页面状态与导航.md#请求取消与迟到响应隔离)。

## Agent UI 协议组件

本节按主题阅读：[协议与事实](#协议适配与事实边界) · [Markdown 正文](#markdown-正文与文件预览的组合) · [提交状态](#interaction-提交状态) · [配置预检报告](#transfer-配置预检报告) · [草稿快照](#transfer-草稿历史快照) · [依赖与认证](#消费依赖与流式认证)。

### 协议适配与事实边界

`agent-ui/` 提供 ADDP Agent 的共享协议适配层，使用官方 `@a2ui/web_core/v0_9` 和 `addp.catalog/v1`。声明式 props／action、未注册组件拒绝、安全上限与降级统一见[协议与安全](../../../docs/spec/addp智能体交互协议规范.md#71-协议与安全)、[当前组件](../../../docs/spec/addp智能体交互协议规范.md#72-当前组件)、[能力协商与降级](../../../docs/spec/addp智能体交互协议规范.md#73-能力协商与降级)，不在本页另列组件目录和数值上限。

A2UI wrapper 只做协议适配，业务事实仍经 ResultRef／Interaction 访问 Owner API；`ResourcePicker` 只提交当前 Interaction 已持久化的 locator 候选，不等同于实时 `ResourceTreePicker`。当前未开放 `GraphView`；组件扩展仍须由[稳定评测场景](../../../docs/spec/addp智能体评测规范.md#三场景契约)证明需求，不注册展示愿景的空组件。

### Markdown 正文与文件预览的组合

`basic/src/components/MarkdownContent.vue` 是 Markdown 解析、HTML 净化和代码块复制的唯一实现，接收正文字符串，支持正文持续追加、可选代码复制与换行展示。使用方直接按需导入该组件，不经基础包主入口引入预览依赖；不在模块中复制 `marked`、DOMPurify 或代码块渲染。共享组件不消费消息、草稿、运行状态或业务 API，不将 Markdown 转成 A2UI，也不执行代码或主动调用业务 API。

Agent 的 `MessagePartsRenderer` 只组合消息 parts、计划、A2UI 和执行引用，文本 part 委托 `MarkdownContent`；流式正文、取消后的部分正文及历史回放沿同一展示路径。`MarkdownPreview` 只保留文件投影、原始文本、截断提示和 Mermaid 编排，并组合同一个正文组件；聊天不因复用正文而加载或开放 Mermaid。原始参数与报告继续使用既有正式组件，不从 Markdown 重建事实。

组件、代码复制与渐进正文回归由 Agent 消费方验证，文件 Markdown／Mermaid 及原始文本由 Manager 验证；两者的标准入口见[测试与验收导航](#测试与验收导航)。

### Interaction 提交状态

`A2UISurface` 的宿主属性 `interactionDisabled` 表达当前不可提交 Interaction（例如归档、权限不足或正在提交），不进入 A2UI payload。共享澄清、资源选择及审批状态检查按钮以相同响应式状态禁用提交，Surface 同时拦截 `interaction.submit`；只读内容、详情展开及 `owner.open` 保持可用。解除禁用不重建 Surface 或改写候选、Interaction 身份，宿主与服务端仍独立验证接纳条件。

### Transfer 配置预检报告

`basic/src/components/TransferConfigCheckReport.vue` 是正式 Transfer 配置预检报告的唯一展示实现，接收受限报告投影，只读展示原始三态、检查时间、检查范围和完整字段诊断。`projectTransferConfigCheckReport()` 排除主体、哈希和结构绑定事实，不重算 Provider 结论。Transfer 向导只负责发起检查、失效清理和参数绑定；Agent 的 `TransferConfigCheckReport` A2UI wrapper 只负责订阅 props，不发请求或 action。公共词条、主题和窄屏行为统一维护于共享库；原向导的私有报告模板删除。实际组件与协议回归由 Agent／Transfer 分别验证，标准入口见[测试与验收导航](#测试与验收导航)。

### Transfer 草稿历史快照

`TransferDraftSnapshot` 对应既有 `platform-transfer-draft-check` 场景中的精确参数展示和后续只读解释，组合唯一 `TabularResultRenderer` 与 `JsonPreview`，不复制表格／JSON 渲染、不发 action 或请求。Runtime 提供绑定历史步骤和完整参数摘要的引用；组件从同一参数 JSON 提取源／目标定位、边界、装载方式、写入策略和映射数量，定位显示复用共享格式化器，不新增概要 props 或推测行粒度、物理类型及任务状态。完整引用、映射及参数放在可展开区域。Agent 既有前端门禁自动发现协议、双语、越界拒绝及真实 ChatView 的 SSE／刷新回放测试；后端引用身份隔离与损坏拒绝由 Agent eval 门禁覆盖。历史快照不等于 owner 当前事实或运行授权。

### 消费依赖与流式认证

消费模块必须在自己的 `package.json` 中声明 `@a2ui/web_core`、Vue、Element Plus 和 Zod 依赖，`common-frontend` 不保存独立 `node_modules`。

AG-UI 等基于 Fetch 的流式客户端使用共享 `createAuthenticatedFetch()`；当前会话 Token、刷新／单次重试和多标签页协调沿[认证请求规范](../../basic/composables/AUTH_USAGE_GUIDE.md#41-共享请求客户端)。模块不另写 Token 存储、刷新或重试路径。

```javascript
import { A2UISurface } from '@addp/common-frontend/agent-ui'
import { createAuthenticatedFetch } from '@common-ui'
```
