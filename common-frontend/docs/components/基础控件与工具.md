## 表单组件

- **StorageEngineForm** - 存储引擎配置表单（支持 PostgreSQL、MinIO/S3）
- **StatusAnnouncer** - 为校验、保存、执行等动态状态提供统一的辅助技术播报区域；播报时机、语义与避免重复提示的要求见[动态状态播报](../frontend-style/组件交互.md#4-动态状态播报)

## 字段提示

`FieldHelp` 接收已翻译的 `content`，是字段旁问号提示的唯一展示，复用Element Plus Tooltip，支持悬停与键盘焦点。它只承载补充说明；未完成或错误输入的校验反馈继续就近显示。服务监控筛选及共享RuntimeInstanceTimeFilter复用同一组件，组件不处理查询或权限。

## 主机筛选

`HostNodeFilters` 是 System 主机管理与 Monitor 主机列表的类型／纳管状态选择唯一实现，接受 `nodeKind`、`enabled`，通过 `change(key, value)` 提交规范值。`resolveHostNodeFilters` 只接受 `physical|virtual` 与字符串 `true|false`，省略表示全部；`false` 必须保留。调用方负责名称草稿、页码、权限与 API，不在组件读取数据或推导采集／电源状态。消费方沿既有 System／Monitor／Console 前端门禁验证。

## 服务参数输入

`ParameterValueInput` 是类型化服务参数输入的唯一控件，接受 `modelValue`、`controlType`、`options` 和 `disabled`。有限选项优先按契约呈现，名称按当前语言取 `labels`，只提交 `value`。Service 与 Workbench 负责各自的显式绑定和契约校验，不重复实现控件分支。

`ParameterCaption` 与 `parameterLabel/parameterDescription` 是参数名称及说明的唯一展示实现，读取 owner 提供的 `presentation.labels/descriptions`，跟随当前语言，不按参数名推断业务语义。Workbench 的应用自定义标签独立保存，服务说明从消费契约读取。

## 指标实现读取 SDK

`createModelMetricAPI(client)` 是 Model 指标实现读取的共享 SDK，复用当前用户认证 client，仅在调用 list/get 时发送请求。Service 的指标来源选择与 Model 自身列表共用此 SDK，不导入 Model 前端内部实现。`publishedMetricSources` 投影已发布修订摘要，不推断可执行状态；最终发布由 Service 后端 Model Client 重新校验。

## 业务域选择

`BusinessDomainSelect` 是业务域下拉选择的唯一展示组件，接收 `options` 和 `v-model`，透传 Element Plus Select 的禁用、加载、清空和事件。`buildBusinessDomainOptions(tree)` 按树的原始顺序生成 `{ id, name, code, depth, path }` 选项，`path` 是从根到当前节点的名称数组。模块保留数据读取与权限控制，不再各自展开树或渲染业务域选项。

默认全部展开，按父域在前、子域紧随的顺序展示，每层缩进 16px。名称本身不拼接空格或树形符号。搜索按名称、编码和路径匹配并展示完整路径，选中框仅显示名称，不保留缩进，悬停显示完整路径。`show-code` 仅在候选行显示编码；默认插槽用于“全部”等非业务域选项。远程分页入口使用 `businessDomainReferenceOptions(items)` 将 owner 返回的 `domain_path` 转换为展示选项，通过 `remote`、`remote-method` 使用 owner 的搜索，仍由同一组件展示层级与路径；分页缺少父选项时显示完整路径。

Standard 层级事实、父子域筛选语义和模块职责见[业务域交互规范](../frontend-style/组件交互.md#业务域选择)。消费模块浏览器回归由原有前端门禁负责。

## 可调整布局

- **useResizable** - 提供受最小/最大值约束的鼠标拖拽和键盘调整能力；分隔条按键、ARIA 与焦点要求见[分隔条交互规范](../frontend-style/组件交互.md#5-可拖拽分隔条)。右侧面板从左边缘拖拽时传入 `{ reverse: true }`，可用 `setSize` / `resetSize` 恢复布局

## 定时调度组件

- **ScheduleConfig**：统一 Cron 配置入口，支持内置或自定义预设、每天/每周/每月，以及显式启用的自定义 Cron 输入；可禁用、只读或使用紧凑布局。
- **ScheduleDisplay**：统一只读描述和空计划展示，跟随当前语言。

属性默认值、预设结构、工具函数返回值及后端校验边界只在[调度组件使用文档](../../basic/docs/ScheduleConfig.md)维护，避免重复示例与预设数量失去同步。

## 导入工具函数

```js
import {
  formatFileSize,
  formatDateTime,
  detectFormatByExtension,
  isGeospatialFormat
} from '@addp/common-frontend'

const size = formatFileSize(1024000) // "1,000.00 KiB"
const format = detectFormatByExtension('data.shp') // "shapefile"
const isGeo = isGeospatialFormat('shapefile') // true
```

## 工具函数

### 格式化

- `formatFileSize(bytes)` - 格式化文件大小
- `formatDateTime(dateTime)` - 格式化日期时间
- `formatCoordinate(coord, precision)` - 格式化坐标

资源数量展示复用 `basic/src/utils/formatters.js`：`scaleByteValue` 返回唯一 IEC 1024 进制量级、值和除数，`formatBytes` 可指定精度及当前语言；Map 的字节格式化入口转发此实现，`formatFileSize` 同样委托。`formatDurationSeconds` 将非负秒数转换为当前语言的日/小时/分钟/秒，最多三个非零分量，不依赖时区。`scaleDurationValue` 按非负秒数选择 second／minute／hour／day，返回值、单位编码和除数，保留小数；它与复合时长格式化共用唯一换算表，不读取时区。宿主按完整有效曲线选择固定量级，并自行提供本地化单位名；缩放不重新选级。Monitor 容量与时长曲线只做显示换算，不改写 API 的 bytes／seconds 原值。

### 格式检测

- `detectFormatByExtension(filename)` - 根据扩展名检测格式
- `isGeospatialFormat(format)` - 判断是否为地理空间格式
- `isTabularFormat(format)` - 判断是否为表格格式
- `isDocumentFormat(format)` - 判断是否为文档格式
- `isMediaFormat(format)` - 判断是否为媒体格式

### 类型工具

- `getFieldTypeLabel(fieldType)` - 获取字段类型的中文名称
- `normalizeFieldType(fieldOrType)` - 将数据库方言类型（包括参数化 decimal、geometry/geography）转换为平台规范字段类型；精度、空间子类型和 SRID 仍由字段事实单独保存

### 通用工具

- `deepClone(obj)` - 深拷贝对象
- `debounce(func, wait)` - 防抖函数，返回函数的 `cancel()` 取消未执行调用，供重置、离页及身份变化清理
- `createAutoFilter({ apply, enabled, visible, pause })` - 自动筛选调度唯一实现：`queue()` 合并300毫秒内输入并暂停旧刷新，`submit()` 立即提交，`enter(event)` 显式处理输入框Enter并忽略输入法组合／229事件、阻止重复原生提交，`cancel()` 取消草稿计时；`visibilityChanged()` 隐藏暂停、前台恢复，`dispose()` 离页清理，`pending` 供刷新调度排除待提交输入。业务页保留查询参数、权限及路由组合，不复制防抖生命周期。
- `throttle(func, limit)` - 节流函数

## 导入类型定义

```js
import { FieldType, FormatType, ResourceType } from '@addp/common-frontend'

console.log(FieldType.STRING) // "string"
console.log(FormatType.SHAPEFILE) // "shapefile"
```

## 类型定义

### FieldType

标准化字段类型（对应后端 `format.FieldType`）：

```js
FieldType.STRING    // 字符串
FieldType.INT       // 整数
FieldType.FLOAT     // 浮点数
FieldType.GEOMETRY  // 几何类型
// ... 更多类型
```

### FormatType

数据格式类型：

```js
FormatType.SHAPEFILE   // Shapefile
FormatType.GEOJSON     // GeoJSON
FormatType.CSV         // CSV
FormatType.EXCEL       // Excel
// ... 更多格式
```

### ResourceType

ResourceLocator 中的资源类型，完整枚举见[定位符类型定义](../../basic/src/types/resourceLocator.js)。例如：

```js
ResourceType.DATABASE  // 数据库
ResourceType.TABLE     // 表
ResourceType.OBJECT    // 对象
ResourceType.FILE      // 文件
ResourceType.BUCKET    // 存储桶
```
