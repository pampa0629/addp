## 颜色系统

### CSS 变量命名规范

所有自定义 CSS 变量使用 `--addp-*` 前缀；实际定义和值统一以[共享 theme.css](../../basic/src/styles/theme.css)为准，本页维护变量语义与用法。主题 class、配色覆盖与初始化见[主题接入](主题接入.md#主题-css-变量定义)。

#### 背景色变量

```css
--addp-bg-primary      /* 主背景色：页面、卡片、对话框等的主要背景 */
--addp-bg-secondary    /* 次要背景色：灰色区域、禁用状态、分隔区域 */
--addp-bg-sidebar      /* 侧边栏背景色 */
--addp-bg-header       /* 顶部导航栏背景色 */
```

#### 文本色变量

```css
--addp-text-primary    /* 主文本：标题、正文等重要文本 */
--addp-text-secondary  /* 次要文本：说明文字、辅助信息 */
--addp-text-tertiary   /* 三级文本：占位符、禁用文本、提示信息 */
```

#### 边框色变量

```css
--addp-border-color       /* 主边框色：分隔线、卡片边框、表格边框 */
--addp-border-color-light /* 浅边框色：次要分隔线 */
```

#### 阴影变量

```css
--addp-shadow-card       /* 卡片阴影 */
--addp-shadow-hover      /* 悬浮阴影 */
```

#### 品牌色变量

```css
--addp-primary-gradient  /* 品牌色渐变，具体配色由主题定义 */
```

#### 模块色变量

每个模块有独立的主题变量，用于模块卡片、图标等；配色随主题变化，以下仅列常用变量，完整清单见共享 CSS：

```css
--addp-module-system        /* System 模块 */
--addp-module-transfer      /* Transfer 模块 */
--addp-module-manager       /* Manager 模块 */
--addp-module-develop       /* Develop 模块 */
--addp-module-service       /* Service 模块 */
--addp-module-orchestrator  /* Orchestrator 模块 */
--addp-module-meta          /* Meta 模块 */
```

#### 交互状态色变量

导航菜单的选中／激活状态和链接使用 `var(--el-color-primary)`，悬浮背景使用 `var(--addp-bg-secondary)`；状态色变量与深色适配约束统一见[状态色使用](#状态色使用)。

### 颜色使用规范

布局背景、文本和边框使用 ADDP 变量，固定色值会阻断主题切换；交互状态使用本页约定的 Element Plus 状态变量。

#### ✅ 正确示例

```vue
<style scoped>
.page-container {
  background: var(--addp-bg-primary);
  color: var(--addp-text-primary);
  border: 1px solid var(--addp-border-color);
}

.secondary-section {
  background: var(--addp-bg-secondary);
  color: var(--addp-text-secondary);
}

.help-text {
  color: var(--addp-text-tertiary);
}

/* 空状态区域、预览面板等需要明确设置背景色 */
.empty-state,
.preview-content {
  background: var(--addp-bg-primary);
}

/* 链接和激活状态使用 Element Plus 变量 */
.nav-link.active {
  color: var(--el-color-primary);
}
</style>
```

#### ❌ 错误示例

```vue
<style scoped>
/* ❌ 禁止：硬编码颜色 */
.page-container {
  background: #ffffff;
  color: #303133;
  border: 1px solid #e4e7ed;
}

/* ❌ 禁止：使用 Element Plus 内部变量 */
.page-container {
  background: var(--el-bg-color);
}
</style>
```

### 状态色使用

对于成功、警告、错误、信息等状态色，**可以使用** Element Plus 的官方变量：

```css
var(--el-color-success)   /* 成功：绿色 */
var(--el-color-warning)   /* 警告：橙色 */
var(--el-color-danger)    /* 错误：红色 */
var(--el-color-info)      /* 信息：灰色 */
var(--el-color-primary)   /* 主色：蓝色 */
```

这些状态色由 Element Plus 适配深色模式；深色 CSS 的导入与 class 生效条件见[深色模式集成](主题接入.md#element-plus-深色模式集成)。不要在 ADDP 的 CSS 变量中重新定义这些状态色，直接使用 Element Plus 提供的变量即可。

## 布局规范

### 1. 页面布局

Layout 的 header、sidebar 使用 `--addp-bg-primary`，content、main-content 和 iframe 的 content-only 使用 `--addp-bg-secondary`；边框使用 `--addp-border-color`。不要在局部组件保留固定浅色背景，也不要因主题不同复制整套布局。

推荐使用 Flexbox 布局。下例仅用于顶层页面主容器：header、footer 不随正文滚动，正文是本例的滚动区域；插槽内容由 Owner 提供并按[国际化规范](../../../docs/spec/addp国际化开发规范.md#组件使用)生成。嵌套页面沿用宿主的可用高度与滚动区域，iframe 内容容器按[iframe 接入](主题接入.md#4-iframe-模式特殊处理)渲染，不复制顶层完整外壳。

```vue
<template>
  <div class="page-container">
    <header class="page-header"><slot name="header" /></header>
    <main class="page-content"><slot /></main>
    <footer class="page-footer"><slot name="footer" /></footer>
  </div>
</template>

<style scoped>
.page-container {
  display: flex;
  flex-direction: column;
  height: 100vh;
  background: var(--addp-bg-secondary);
}

.page-header {
  flex-shrink: 0;
  padding: 16px;
  background: var(--addp-bg-primary);
  border-bottom: 1px solid var(--addp-border-color);
}

.page-content {
  flex: 1;
  min-height: 0;
  overflow: auto;
  padding: 16px;
}

.page-footer {
  flex-shrink: 0;
  padding: 16px;
  background: var(--addp-bg-primary);
  border-top: 1px solid var(--addp-border-color);
}
</style>
```

任务定义列表或任务工作区的页头，统一把页面标题与主业务操作放在左侧，把“查看执行记录”放在右侧。执行入口必须复用 `common-frontend` 的 `MonitorExecutionsButton`，默认使用普通次要按钮；不得用不同图标、强调色或模块私有文案制造多个执行监控入口。单任务详情使用 `scope="task"`，并传入 `module + task-type + source-task-id`。

以下以 Quality 检查方案的现有词条与 `quality_plan` 任务身份展示页头接入；片段复用模块的 `t`，共享按钮已从公共入口导入。任务身份与跨模块跳转契约见[统一任务监控跳转](../components/页面状态与导航.md#统一任务监控跳转)，Quality 类型声明见[模块任务契约](../../../docs/spec/tasks/模块任务契约.md#模块任务类型)。

```vue
<template>
  <div class="page-header">
    <div>
      <h2>{{ t('quality.plan.title') }}</h2>
      <p>{{ t('quality.plan.subtitle') }}</p>
    </div>
    <MonitorExecutionsButton module="quality" task-type="quality_plan" />
  </div>
</template>
```

Monitor 是模块级执行列表的唯一页面。业务模块可保留单任务历史和领域结果详情，但返回执行历史时仍使用共享按钮，不得自行实现另一套通用执行表格、统计卡片或路由筛选器。

### 2. 间距规范

普通列表、检索和配置页应在正文外缘留白。新建或调整此类页面时，内容区默认留 24px 内边距，内容视口宽度不超过 700px 时收至 16px。标题、提示、筛选区、表格外框和分页对齐到同一条正文左边线。主要区块之间留 16px，控件组内部用 `gap` 保持间距，窄屏时允许换行。

同一层的页边距由一个容器负责。Console 负责外壳和 iframe 尺寸，模块的页面容器或该页面复用的 Layout 负责正文留白。若 Layout 已有页边距，子页面沿用即可。卡片内边距、表格单元格内边距属于组件内部间距，不能替代正文留白。

地图、画布、编辑器和分栏工作台可满幅展示工作区域；工具栏、筛选项及正文仍需在各自区域内留白。窄屏优先收紧内边距并换行，宽表格在自身区域内横向滚动。验收时分别在独立页面和 Console iframe 的常用、窄宽度检查两侧留白、区块间距以及页面是否出现横向溢出。

使用 8px 基础倍数进行间距设计：

```css
padding: 8px;     /* 小间距 */
padding: 16px;    /* 中间距（推荐） */
padding: 24px;    /* 大间距 */
padding: 32px;    /* 超大间距 */

margin: 8px;      /* 小间距 */
margin: 16px;     /* 中间距（推荐） */
margin: 24px;     /* 大间距 */
```

### 3. 圆角规范

```css
border-radius: 4px;   /* 小圆角：按钮、输入框 */
border-radius: 8px;   /* 中圆角：卡片、对话框 */
border-radius: 12px;  /* 大圆角：模块卡片 */
```

布局和主题的实机核对沿[主题验证清单](主题接入.md#验证清单)，需覆盖独立顶层入口与 Console iframe 的实际滚动和主题表现；国际化验证见[验证方式](../../../docs/spec/addp国际化开发规范.md#验证方式)。片段编译和静态样式检查仅证明语法与声明，实际覆盖按[测试规范](工程约束.md#测试规范)分别记录。

## 字体规范

### 1. 字体大小

```css
font-size: 12px;   /* 辅助文字 */
font-size: 14px;   /* 正文（默认） */
font-size: 16px;   /* 小标题 */
font-size: 18px;   /* 中标题 */
font-size: 20px;   /* 大标题 */
font-size: 24px;   /* 主标题 */
```

### 2. 字体粗细

```css
font-weight: 400;  /* 正常 */
font-weight: 500;  /* 中等（推荐） */
font-weight: 600;  /* 加粗（标题） */
font-weight: 700;  /* 特粗 */
```

### 3. 行高

```css
line-height: 1.5;   /* 正文（推荐） */
line-height: 1.2;   /* 标题 */
line-height: 2;     /* 疏松排版 */
```

## 图标规范

### 1. 图标来源

优先使用 Element Plus Icons：

```javascript
import { Edit, Delete, Plus, Refresh } from '@element-plus/icons-vue'
```

### 2. 图标注册

在 `main.js` 中按需注册：

```javascript
const icons = { Edit, Delete, Plus, Refresh }
for (const [key, component] of Object.entries(icons)) {
  app.component(key, component)
}
```

### 3. 图标使用

下例复用上节已注册的 `Plus` 和组件当前的 `t`。有文字的操作按钮由译文表达可访问名称，装饰图标不重复播报；纯图标按钮的可访问名称要求见[ARIA 规范](组件交互.md#2-aria-属性)。

```vue
<template>
  <el-button>
    <el-icon aria-hidden="true"><Plus /></el-icon>
    {{ t('common.add') }}
  </el-button>
</template>
```

## 响应式设计规范

### 1. 断点定义

```css
/* 小屏幕（平板） */
@media (max-width: 768px) {
  .sidebar {
    width: 100%;
  }
}

/* 中等屏幕（笔记本） */
@media (min-width: 769px) and (max-width: 1440px) {
  .sidebar {
    width: 300px;
  }
}

/* 大屏幕（桌面） */
@media (min-width: 1441px) {
  .sidebar {
    width: 350px;
  }
}
```

### 2. 移动端适配

虽然 ADDP 主要面向桌面端，但仍需考虑小屏幕设备：

- 使用 `vh`、`vw` 单位代替固定像素
- 使用 Flexbox 布局自动换行
- 隐藏次要信息，保留核心功能
