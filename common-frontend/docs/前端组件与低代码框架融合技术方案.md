# 前端组件外部集成参考

本文保留组件封装时需要核对的技术问题，不定义另一套前端框架、认证或发布流程。业务范围与未决事项见[外部组件化需求草案](addp前端低代码改造方案.md)。

## 已有实现

ADDP 现行前端使用 Vue 3。已有[只读 DAG 查看器](components/预览与结果展示.md#只读-dag-查看器)同时提供 Vue 入口与原生元素入口：`addp-dag-viewer` 将 `dag-data` JSON attribute 与数值高度转换为共享 `DAGViewer` 的属性，并使用同一份查看器样式。

实现见[原生元素封装](../dag/src/web-components/dag-viewer-wc.js)与[统一导出](../dag/src/index.js)。它可以作为复用单一渲染实现的参考，不能推定资源树、引擎表单、调度配置或外部平台适配已完成。

## 组件封装检查项

| 方面 | 需要明确的契约 |
| --- | --- |
| 属性 | HTML attribute 名称、JavaScript 属性、类型与默认值；复杂对象如何传入或序列化，不能把凭据放入 attribute |
| 事件 | 事件名、`detail` 数据、是否冒泡及是否跨 Shadow DOM；宿主如何订阅和取消订阅 |
| 生命周期 | 挂载、数据更新、尺寸变化、重新连接、卸载及异步请求取消；避免残留观察器、监听器与计时器 |
| 样式 | scoped / Shadow DOM 边界、共享样式注入、主题变量和宿主尺寸；不覆盖宿主全局样式 |
| 依赖 | 组件与宿主的 Vue、Element Plus、地图或图表依赖归属，按需加载及 Vue 单一实例 |
| 数据 | 组件由宿主提供数据还是自己请求；若请求，必须复用共享认证客户端，并按当前身份与资源上下文处理缓存 |
| 错误 | loading、空状态、权限拒绝、网络错误的展示与事件；用户可见文案国际化，不向宿主分发未经处理的内部错误 |
| 宿主集成 | 宿主平台是否支持自定义元素、属性面板与资源加载，是否需要专用设置器或元数据；须在目标平台验证 |

现有 DAG 元素只承担其已声明的适配职责；扩展其他组件前，先确认上表中真正影响该场景的契约，不把示例包装器变成通用运行平台。

## 开发与验证边界

- 在既有共享组件上封装，不重新实现相同交互；Vue 技术栈和依赖规则见[技术栈规约](../../docs/spec/addp技术栈规约.md)与[共享前端说明](../README.md)。
- 主题、布局与覆盖规则见[前端风格规范](addp前端风格设计规范.md)，语言初始化与文本见[国际化规范](../../docs/spec/addp国际化开发规范.md)。
- 数据请求复用[共享客户端](../../docs/spec/api/客户端集成.md)，跨站点使用场景先按[认证边界](../../docs/spec/addp登录认证的统一要求.md)确定合法会话，不另写静态 Token SDK、无身份 fetch 或仅按 URL 缓存用户数据的实现。
- 验证实际宿主中的属性更新、事件、主题/语言、空数据、尺寸变化、卸载与资源路径；打包成功不能替代宿主集成验收。
- 现有 DAG 的 owner 与浏览器门禁由其 README 维护；新增组件按[测试规范](../../docs/spec/addp测试与验收规范.md)接入已有标准入口，不复用个人开发服务作为确定性夹具。

## 外部旧组件

当前 ADDP 没有将 Vue 2 迁移或兼容构建作为本专题的实施前提。若未来实际客户带来旧组件需求，先单独确认范围并形成迁移方案；不在当前产品中预置 Vue 双版本、`@vue/compat` 或 React 重写路线。
