# 前端组件与低代码框架融合技术方案

## 📋 文档信息

- **创建日期**: 2026-01-16
- **方案版本**: v1.0
- **适用范围**: Vue 2/Vue 3组件集成到AMIS等低代码平台

---

## 1. 背景与问题

### 1.1 核心问题

1. **AMIS是否支持Vue组件？**
   - AMIS底层基于React开发，不原生支持Vue组件

2. **Vue 2组件能否集成到AMIS？**
   - 需要通过Web Components方案

3. **Vue 2和Vue 3能否在同一个AMIS中共存？**
   - 技术上可行，但不推荐

4. **如何将Vue 2组件迁移到Vue 3？**
   - 可以自动化迁移70-80%的代码

### 1.2 目标

- 将ADDP的前端组件（Vue开发）集成到低代码平台（AMIS等）
- 保持Vue技术栈不变（不重写为React）
- 提供对外产品化的标准组件

---

## 2. AMIS对Vue的支持情况

### 2.1 核心事实

**AMIS底层是React框架**：
- AMIS的自定义组件开发需要使用React语法
- AMIS的`@Renderer`装饰器、`BasePlugin`都是React API
- 不原生支持Vue组件

### 2.2 集成方式

虽然AMIS不原生支持Vue，但可以通过以下方式集成：

#### 方式1：AMIS的HTML组件

AMIS支持在JSON配置中嵌入任意HTML：

```json
{
  "type": "html",
  "html": "<div id='vue-app'></div>"
}
```

可以在这个容器中挂载Vue应用或Vue组件。

#### 方式2：Web Components

将Vue组件转换为Web Components（浏览器原生自定义元素）：

```json
{
  "type": "html",
  "html": "<addp-resource-tree api-url='${apiUrl}'></addp-resource-tree>"
}
```

**优点**：
- ✅ 浏览器原生标准，任何框架都能用
- ✅ AMIS、宜搭、飞书等低代码平台通用
- ✅ Vue 2和Vue 3都可以转换为Web Components

#### 方式3：社区适配器（不推荐）

社区有人开发了Vue-AMIS适配器，但需要在AMIS项目中引入Vue运行时，增加包体积和复杂度。

### 2.3 推荐方案

**Web Components方案**（方式2）是最优解：
- 平台无关，通用性强
- 性能好，体积小
- 开发体验友好（保持Vue语法）

## 3. Vue 2组件集成到AMIS

### 3.1 技术路径

```
Vue 2组件
    ↓ (使用@vue/web-component-wrapper)
Web Components
    ↓ (AMIS的html组件)
AMIS低代码平台
```

### 3.2 具体实现

#### 步骤1：安装依赖

```bash
npm install @vue/web-component-wrapper
```

**说明**：
- Vue 2没有原生的Web Components支持
- `@vue/web-component-wrapper`是Vue官方提供的包装器
- Vue 3有原生的`defineCustomElement`，不需要额外依赖

#### 步骤2：转换Vue 2组件

```javascript
// common-frontend/webcomponents-v2/src/index.js
import Vue from 'vue';
import wrap from '@vue/web-component-wrapper';

// 导入Vue 2组件
import ResourceTree from '@addp/common-frontend/basic/src/components/ResourceTree.vue';
import StorageEngineForm from '@addp/common-frontend/basic/src/components/StorageEngineForm.vue';

// 转换为Web Components
const ResourceTreeElement = wrap(Vue, ResourceTree);
const StorageEngineFormElement = wrap(Vue, StorageEngineForm);

// 注册为自定义元素
window.customElements.define('addp-resource-tree', ResourceTreeElement);
window.customElements.define('addp-storage-engine-form', StorageEngineFormElement);
```

#### 步骤3：构建配置

```javascript
// rollup.config.js
import vue from 'rollup-plugin-vue';
import resolve from '@rollup/plugin-node-resolve';
import commonjs from '@rollup/plugin-commonjs';

export default {
  input: 'src/index.js',
  output: {
    file: 'dist/addp-components-v2.js',
    format: 'umd',
    name: 'ADDPComponentsV2',
    globals: {
      'vue': 'Vue'
    }
  },
  external: ['vue'],
  plugins: [
    vue({
      template: {
        isProduction: true
      }
    }),
    resolve(),
    commonjs()
  ]
};
```

#### 步骤4：在AMIS中使用

```html
<!-- 1. 引入Vue 2运行时 -->
<script src="https://cdn.jsdelivr.net/npm/vue@2.7.16/dist/vue.js"></script>

<!-- 2. 引入ADDP组件包 -->
<script src="https://your-cdn.com/addp-components-v2.js"></script>

<!-- 3. 在AMIS配置中使用 -->
{
  "type": "page",
  "body": {
    "type": "html",
    "html": "<addp-resource-tree api-url='https://api.example.com/resources'></addp-resource-tree>"
  }
}
```

### 3.3 完整示例

**Vue 2组件**：

```vue
<!-- ResourceTree.vue (Vue 2) -->
<template>
  <div class="resource-tree">
    <el-input
      v-model="filterText"
      placeholder="搜索资源">
    </el-input>

    <el-tree
      :data="treeData"
      :filter-node-method="filterNode"
      @node-click="handleNodeClick"
      ref="tree">
    </el-tree>
  </div>
</template>

<script>
export default {
  name: 'ResourceTree',
  props: {
    apiUrl: String,
    accessToken: String
  },
  data() {
    return {
      filterText: '',
      treeData: []
    }
  },
  mounted() {
    this.loadData()
  },
  watch: {
    filterText(val) {
      this.$refs.tree.filter(val)
    }
  },
  methods: {
    async loadData() {
      const response = await fetch(this.apiUrl, {
        headers: {
          'Authorization': `Bearer ${this.accessToken}`
        }
      })
      this.treeData = await response.json()
    },
    filterNode(value, data) {
      if (!value) return true
      return data.label.indexOf(value) !== -1
    },
    handleNodeClick(data, node) {
      // 触发自定义事件
      this.$emit('node-click', { data, node })

      // Web Component中需要用dispatchEvent
      const event = new CustomEvent('node-click', {
        detail: { data, node },
        bubbles: true,
        composed: true
      })
      this.$el.dispatchEvent(event)
    }
  }
}
</script>

<style scoped>
.resource-tree {
  padding: 16px;
}
</style>
```

**转换为Web Component**：

```javascript
// webcomponents-v2/src/ResourceTree.js
import Vue from 'vue';

import ResourceTreeComponent from './ResourceTree.vue';

// 包装为Web Component

// 注册
customElements.define('addp-resource-tree', ResourceTree);

export default ResourceTree;
```

## 4. Vue 3组件集成到AMIS

### 4.1 技术路径

```
Vue 3组件
    ↓ (使用defineCustomElement)
Web Components
    ↓ (AMIS的html组件)
AMIS低代码平台
```

### 4.2 具体实现

#### 步骤1：转换Vue 3组件

```javascript
// common-frontend/webcomponents/src/index.js
import { defineCustomElement } from 'vue';

// 导入Vue 3组件
import ResourceTree from '@addp/common-frontend/basic/src/components/ResourceTree.vue';
import StorageEngineForm from '@addp/common-frontend/basic/src/components/StorageEngineForm.vue';

// 转换为Web Components（Vue 3原生支持）
const ResourceTreeElement = defineCustomElement(ResourceTree);
const StorageEngineFormElement = defineCustomElement(StorageEngineForm);

// 注册为自定义元素
customElements.define('addp-resource-tree', ResourceTreeElement);
customElements.define('addp-storage-engine-form', StorageEngineFormElement);
```

**对比Vue 2**：
- ✅ 不需要额外的`@vue/web-component-wrapper`依赖
- ✅ 代码更简洁
- ✅ 性能更好

#### 步骤2：Vue 3组件示例

```vue
<!-- ResourceTree.vue (Vue 3) -->
<template>
  <div class="resource-tree">
    <el-input
      v-model="filterText"
      placeholder="搜索资源">
    </el-input>

    <el-tree
      :data="treeData"
      :filter-node-method="filterNode"
      @node-click="handleNodeClick"
      ref="treeRef">
    </el-tree>
  </div>
</template>

<script>
import { ref, watch, onMounted } from 'vue';

export default {
  name: 'ResourceTree',
  props: {
    apiUrl: String,
    accessToken: String
  },
  emits: ['node-click'],
  setup(props, { emit }) {
    const filterText = ref('');
    const treeData = ref([]);
    const treeRef = ref(null);

    const loadData = async () => {
      const response = await fetch(props.apiUrl, {
        headers: {
          'Authorization': `Bearer ${props.accessToken}`
        }
      });
      treeData.value = await response.json();
    };

    const filterNode = (value, data) => {
      if (!value) return true;
      return data.label.indexOf(value) !== -1;
    };

    const handleNodeClick = (data, node) => {
      emit('node-click', { data, node });

      // Web Component需要用DOM事件
      const event = new CustomEvent('node-click', {
        detail: { data, node },
        bubbles: true,
        composed: true
      });
      // 在Web Component中，this.$el不存在，需要用getCurrentInstance
    };

    watch(filterText, (val) => {
      treeRef.value?.filter(val);
    });

    onMounted(() => {
      loadData();
    });

    return {
      filterText,
      treeData,
      treeRef,
      filterNode,
      handleNodeClick
    };
  }
}
</script>

<style scoped>
.resource-tree {
  padding: 16px;
}
</style>
```

#### 步骤3：构建配置

```javascript
// vite.config.js
import { defineConfig } from 'vite';
import vue from '@vitejs/plugin-vue';

export default defineConfig({
  plugins: [
    vue({

      external: ['vue'],
      output: {
        globals: {
          vue: 'Vue'
        }
      }
    }
  }
});
```

## 5. Vue 2和Vue 3在AMIS中共存

### 5.1 技术可行性

**✅ 理论上可行**：如果都转换为Web Components，可以共存

```html
<!-- 同一个AMIS页面 -->
{
  "type": "page",
  "body": [
    {
      "type": "html",
      "html": "<addp-resource-tree-v2></addp-resource-tree-v2>"
    },
    {
      "type": "html",
      "html": "<addp-schedule-config-v3></addp-schedule-config-v3>"
    }
  ]
}
```

**原因**：
- Web Components是独立封装的（Shadow DOM）
- Vue 2和Vue 3的运行时互不干扰
- 从AMIS角度看，都是普通HTML标签

### 5.2 严重问题

#### 问题1：双倍框架体积

```
页面需要加载：
├── React (AMIS核心) - ~40KB gzipped
├── Vue 2 运行时 - ~30KB gzipped
└── Vue 3 运行时 - ~40KB gzipped
─────────────────────────────────
总计：~110KB 仅框架代码
```

**额外负担：+175%**

#### 问题2：全局变量冲突

```javascript
// Vue 2
window.Vue = Vue2;

// Vue 3
window.Vue = Vue3;

// ⚠️ 后者覆盖前者
```

**解决**：使用命名空间
```javascript
window.VueV2 = Vue2;
window.VueV3 = Vue3;
```

#### 问题3：构建配置复杂

需要维护两套独立的构建流程：

```javascript
// rollup.config.js
export default [
  {
    // Vue 2组件构建
    input: 'src/vue2/index.js',
    external: ['vue2'],
    output: {
      file: 'dist/addp-components-v2.js',
      globals: { 'vue2': 'VueV2' }
    }
  },
  {
    // Vue 3组件构建
    input: 'src/vue3/index.js',
    external: ['vue'],
    output: {
      file: 'dist/addp-components-v3.js',
      globals: { 'vue': 'VueV3' }
    }
  }
]
```

#### 问题4：样式冲突

```css
/* Vue 2 + Element UI */
.el-button { /* 样式A */ }

/* Vue 3 + Element Plus */
.el-button { /* 样式B */ }

/* ⚠️ 可能互相覆盖 */
```

### 5.5 结论

**⚠️ 不推荐双版本共存**

虽然技术上可行，但：
- 包体积增加70-100KB
- 维护成本高（两套构建、两套文档）
- 用户需要记住组件版本
- 团队需要同时熟悉Vue 2和Vue 3

**推荐：统一到Vue 3**

## 6. Vue 2迁移到Vue 3

### 6.1 迁移策略

#### 策略1：渐进迁移（推荐）⭐⭐⭐

**步骤**：
1. 内部统一到Vue 3
2. 对外输出统一的Vue 3 Web Components
3. 避免维护两套代码

**优先级**：
- **高**：需要对外的核心组件（ResourceTree、StorageEngineForm、ScheduleConfig）
- **中**：频繁使用的内部组件
- **低**：很少改动的老组件

#### 策略2：使用兼容构建（过渡方案）

Vue官方提供了`@vue/compat`（兼容构建）：

```bash
npm install @vue/compat
```

```javascript
// vite.config.js
export default {
  resolve: {
    alias: {
      vue: '@vue/compat'  // 使用兼容版本
    }
  }
}
```

**特点**：
- ✅ Vue 2代码可以在Vue 3环境运行
- ✅ 控制台会警告过时的API
- ✅ 可以一个组件一个组件渐进迁移
- ⚠️ 最终还是要完全迁移

### 6.2 主要API变化

#### 1. 生命周期钩子

```javascript
// Vue 2
beforeDestroy() { }
destroyed() { }

// Vue 3
beforeUnmount() { }
unmounted() { }
```

#### 2. 事件系统

```javascript
// Vue 2
this.$on('event', handler)
this.$off('event', handler)
this.$once('event', handler)

// Vue 3
// 移除，改用emits配置
export default {
  emits: ['event'],
  methods: {
    trigger() {
      this.$emit('event', data)
    }
  }
}
```

#### 3. v-model

```vue
<!-- Vue 2 -->
<input v-model="value">
<custom-component v-model="value"></custom-component>
<custom-component :value.sync="value"></custom-component>

<!-- Vue 3 -->
<input v-model="value">
<custom-component v-model="value"></custom-component>
<custom-component v-model:value="value"></custom-component>
```

#### 4. Filters

```vue
<!-- Vue 2 -->
<template>
  <div>{{ date | formatDate }}</div>
</template>

<script>
export default {
  filters: {
    formatDate(value) {
      return new Date(value).toLocaleDateString()
    }
  }
}
</script>

<!-- Vue 3 -->
<template>
  <div>{{ formatDate(date) }}</div>
</template>

<script>
export default {
  methods: {
    formatDate(value) {
      return new Date(value).toLocaleDateString()
    }
  }
}
</script>
```

#### 5. $listeners和$attrs

```vue
<!-- Vue 2 -->
<template>
  <child-component
    v-bind="$attrs"
    v-on="$listeners">
  </child-component>
</template>

<!-- Vue 3 -->
<template>
  <child-component v-bind="$attrs">
  </child-component>
</template>

<!-- $listeners已合并到$attrs -->
```

#### 6. 插槽语法

```vue
<!-- Vue 2 -->
<template>
  <el-tree>
    <span slot-scope="{ node, data }">
      {{ node.label }}
    </span>
  </el-tree>
</template>

<!-- Vue 3 -->
<template>
  <el-tree>
    <template #default="{ node, data }">
      {{ node.label }}
    </template>
  </el-tree>
</template>
```

### 6.3 完整迁移示例

#### Vue 2组件（迁移前）

```vue
<template>
  <div class="resource-tree">
    <el-input
      v-model="filterText"
      placeholder="搜索">
    </el-input>

    <el-tree
      :data="treeData"
      :filter-node-method="filterNode"
      ref="tree">
      <span slot-scope="{ node, data }">
        {{ node.label | uppercase }}
        <el-button
          size="mini"
          @click.stop="handleEdit(data)">
          编辑
        </el-button>
      </span>
    </el-tree>
  </div>
</template>

<script>
import { eventBus } from '@/utils/eventBus'

export default {
  name: 'ResourceTree',
  props: {
    data: Array
  },
  data() {
    return {
      filterText: '',
      treeData: []
    }
  },
  watch: {
    filterText(val) {
      this.$refs.tree.filter(val)
    },
    data: {
      handler(val) {
        this.treeData = val
      },
      immediate: true
    }
  },
  mounted() {
    eventBus.$on('refresh', this.handleRefresh)
  },
  methods: {
    filterNode(value, data) {
      if (!value) return true
      return data.label.indexOf(value) !== -1
    },
    handleEdit(data) {
      this.$emit('edit', data)
    },
    handleRefresh() {
      this.loadData()
    },
    loadData() {
      // 加载逻辑
    }
  },
  filters: {
    uppercase(value) {
      return value.toUpperCase()
    }
  },
  beforeDestroy() {
    eventBus.$off('refresh', this.handleRefresh)
  }
}
</script>
```

#### Vue 3组件（迁移后）

```vue
<template>
  <div class="resource-tree">
    <el-input
      v-model="filterText"
      placeholder="搜索">
    </el-input>

    <el-tree
      :data="treeData"
      :filter-node-method="filterNode"
      ref="treeRef">
      <template #default="{ node, data }">
        {{ uppercase(node.label) }}
        <el-button
          size="small"
          @click.stop="handleEdit(data)">
          编辑
        </el-button>
      </template>
    </el-tree>
  </div>
</template>

<script>
import { ref, watch, onMounted, onUnmounted } from 'vue'
import { useEventBus } from '@/composables/useEventBus'

export default {
  name: 'ResourceTree',
  props: {
    data: Array
  },
  emits: ['edit'],
  setup(props, { emit }) {
    const filterText = ref('')
    const treeData = ref([])
    const treeRef = ref(null)
    const eventBus = useEventBus()

    // watch替代Vue 2的watch
    watch(filterText, (val) => {
      treeRef.value?.filter(val)
    })

    watch(() => props.data, (val) => {
      treeData.value = val
    }, { immediate: true })

    const filterNode = (value, data) => {
      if (!value) return true
      return data.label.indexOf(value) !== -1
    }

    const handleEdit = (data) => {
      emit('edit', data)
    }

    const loadData = () => {
      // 加载逻辑
    }

    const handleRefresh = () => {
      loadData()
    }

    // filter改为函数
    const uppercase = (value) => {
      return value.toUpperCase()
    }

    // 替代eventBus（使用composables）
    onMounted(() => {
      eventBus.on('refresh', handleRefresh)
    })

    onUnmounted(() => {
      eventBus.off('refresh', handleRefresh)
    })

    return {
      filterText,
      treeData,
      treeRef,
      filterNode,
      handleEdit,
      uppercase
    }
  }
}
</script>
```

**主要变化**：
1. ✅ `slot-scope` → `template #default`
2. ✅ `ref="tree"` → `ref="treeRef"` + `ref(null)`
3. ✅ `this.$refs.tree` → `treeRef.value`
4. ✅ `filters` → 普通函数
5. ✅ `beforeDestroy` → `onUnmounted`
6. ✅ `size="mini"` → `size="small"` (Element Plus)
7. ✅ `eventBus.$on/$off` → `useEventBus` composable
8. ✅ 添加 `emits: ['edit']` 声明

## 8. 最佳实践

### 8.1 组件设计原则

#### 1. 保持简单

```vue
<!-- ✅ 好 -->
<addp-resource-tree
  api-url="https://api.example.com"
  access-token="token">
</addp-resource-tree>

<!-- ❌ 避免 -->
<addp-resource-tree
  :config="{ url: 'https://...', auth: {...}, options: {...} }">
</addp-resource-tree>
```

#### 2. 使用标准事件

```javascript
// ✅ 使用DOM自定义事件（跨框架）
const event = new CustomEvent('node-click', {
  detail: { data, node },
  bubbles: true,
  composed: true  // 穿透Shadow DOM
});
this.$el.dispatchEvent(event);

// ❌ 仅Vue的$emit（在Web Component中可能不工作）
this.$emit('node-click', { data, node });
```

#### 3. 样式隔离

```vue
<style scoped>
/* ✅ 使用scoped避免污染全局 */
.resource-tree {
  padding: 16px;
}
</style>

<style>
/* ❌ 避免全局样式 */
.el-tree {
  /* 会影响页面中所有el-tree */
}
</style>
```

#### 4. 属性命名

```javascript
// ✅ 使用kebab-case（HTML标准）
<addp-resource-tree
  api-url="..."
  access-token="...">
</addp-resource-tree>

// 组件内部自动转为camelCase
props: {
  apiUrl: String,
  accessToken: String
}
```

### 8.2 性能优化

#### 1. 按需加载

```javascript
// 不要一次性注册所有组件
// ❌ 不好
import './components/ResourceTree'
import './components/StorageEngineForm'
import './components/ScheduleConfig'
// ... 50个组件

// ✅ 好 - 按需加载
const loadComponent = async (name) => {
  const module = await import(`./components/${name}.js`);
  return module.default;
};
```

#### 2. 懒加载依赖

```javascript
// ✅ 组件内部懒加载大型依赖
export default {
  async mounted() {
    if (this.needsChart) {
      const echarts = await import('echarts');
      this.chart = echarts.init(this.$refs.chart);
    }
  }
}
```

#### 3. 缓存API响应

```javascript
// ✅ 避免重复请求
const cache = new Map();

async loadData() {
  const cacheKey = this.apiUrl;

  if (cache.has(cacheKey)) {
    this.treeData = cache.get(cacheKey);
    return;
  }

  const response = await fetch(this.apiUrl);
  const data = await response.json();

  cache.set(cacheKey, data);
  this.treeData = data;
}
```

### 8.3 错误处理

```javascript
export default {
  setup(props) {
    const error = ref(null);
    const loading = ref(false);

    const loadData = async () => {
      try {
        loading.value = true;
        error.value = null;

        const response = await fetch(props.apiUrl);

        if (!response.ok) {
          throw new Error(`HTTP ${response.status}: ${response.statusText}`);
        }

        const data = await response.json();
        // 处理数据

      } catch (err) {
        error.value = err.message;
        console.error('Failed to load data:', err);

        // 触发错误事件
        const event = new CustomEvent('error', {
          detail: { error: err },
          bubbles: true,
          composed: true
        });
        // 分发错误事件

      } finally {
        loading.value = false;
      }
    };

    return { error, loading, loadData };
  }
}
```

## 9. 常见问题

### Q1: Web Components的浏览器兼容性如何？

**A**: 主流浏览器都支持：
- Chrome 54+
- Firefox 63+
- Safari 10.1+
- Edge 79+

对于旧浏览器，可以使用polyfill：
```html
<script src="https://unpkg.com/@webcomponents/webcomponentsjs"></script>
```

### Q2: Vue 2转Vue 3的主要难点是什么？

**A**: 主要难点：
1. **EventBus改造**（如果大量使用）→ 改为Composition API或Pinia
2. **Mixins改造**（如果复杂）→ 改为Composables
3. **第三方库兼容性**（如Vuex → Pinia，Element UI → Element Plus）

### Q3: AMIS中使用Web Components有限制吗？

**A**: 主要限制：
1. 无法使用AMIS的表单校验系统（需要组件自己实现）
2. 无法使用AMIS的数据域（需要显式传递props）
3. 样式可能需要手动适配AMIS主题

### Q4: 如何调试Web Components？

**A**:
```javascript
// 1. 开发模式下启用详细日志
if (process.env.NODE_ENV === 'development') {
  console.log('[ADDP Component]', 'mounted', props);
}

// 2. Chrome DevTools可以查看Shadow DOM
// Elements面板 → 展开#shadow-root

// 3. Vue DevTools支持检查Web Components（Vue 3.2+）
```

### Q5: Web Components的性能如何？

**A**:
- 首次加载：需要下载框架（Vue）+ 组件代码
- 运行时：与普通Vue组件性能相当
- Shadow DOM有轻微性能开销，但可忽略
- 建议：生产环境使用CDN + gzip压缩
