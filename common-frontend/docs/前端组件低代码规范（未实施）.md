# 前端组件物料参考（未实施）

本文从原 SuperMap Micro-Widget 参考中保留组件描述和编辑器集成的需求维度。这些字段是待评估的外部参考，不是 ADDP 已发布的 Schema、SDK、包名或运行时 API；不据此新增平台模块或另一套前端基座。业务前提见[外部组件化草案](addp前端低代码改造方案.md)。

## 组件包描述

| 参考信息 | 原参考中的字段或职责 |
| --- | --- |
| 包清单 | `name`、`code`、`version`、`description`、`packages`、`widgets`；原参考使用 `assets.json` 描述组件及依赖 |
| 包入口 | 导出组件实现与元数据；原参考使用 `index.ts`、`LibraryInfo` 组织组件列表 |
| 包声明 | `package.json` 的 `name/description/version/main/stylePath/files`、依赖声明与 `componentConfig` 分类信息；实际版本和依赖服从 ADDP 统一规约 |
| 依赖资源 | `name`、`version`、`code`、`loadType`、`urls`，以及原示例中的 script/npm 类型、库名与资源路径 |
| 使用说明 | 组件用途、安装、属性、事件和版本变更边界；交付时必须与真实发布产物一致 |

是否需要独立物料清单、分发格式和资源加载器，应在明确消费平台后决定。普通 npm 包、编辑器物料和运行时资源分别承担不同职责，不能因参考文件存在就视为 ADDP 已采用其协议。

## 单个组件描述

| 参考信息 | 需要表达的内容 |
| --- | --- |
| 组件标识 | `type` / `WidgetCode`、名称、说明、图标及分类，明确唯一性范围 |
| 属性与状态 | `props` / `IProps`、`state` / `IState`；类型、默认值、约束及宿主可配置范围 |
| 组件信息 | `info` / `WidgetInfo` 与实现入口；字段不能与业务数据、认证凭据混存 |
| 渲染器 | 依据属性组合既有 Vue 3 组件，声明真实事件和生命周期，不复制业务实现 |
| 设置器 | 属性面板、样式面板、拖入后的初始配置、预览配置，以及监听动作与触发事件 |

原参考中的示例组件尺寸、背景色、动画时长、颜色数组、内容与 render 回调只用于演示属性分类，不构成所有组件的必选接口。

## 编辑器配置需求

保留下列交互需求，具体控件、Schema 格式和编辑器实现待目标平台确认：

| 类别 | 原参考覆盖的能力 |
| --- | --- |
| 输入 | 文本、数字、多行文本、颜色、日期、滑块、键值对；类型、范围、精度、唯一性和校验提示 |
| 选择 | 下拉、单选、复选、开关、勾选框；静态或 API 选项、单选/多选与值类型 |
| 容器与布局 | 选项卡、折叠面板、Flex 布局、内容分组及可见条件 |
| 命令与提示 | 按钮、下拉按钮、说明提示、初始化与预览 |
| 数据配置 | API 来源、接口参数、表格列或图表字段的重复配置、排序和拖拽 |
| 事件配置 | 触发事件、监听动作、目标组件、参数和描述；参考字段包括 `label`、`tag`、`description`、`supportComponents`、`schema` |

不把特定编辑器的控件 DSL、插件基类或配置模板当作 ADDP 的共享组件规范。若需要对外设置器，先明确与既有组件 props/emits 的映射和唯一实现归属。

## 宿主能力需求

| 需求 | 原参考列举的能力；ADDP 约束 |
| --- | --- |
| 路由 | 获取当前路由、push、replace、新窗口打开；参考信息含 `path/hash/host/query/protocol/fullPath`，实际接入须服从 Console 与模块入口规则 |
| 运行环境 | 当前用户、编辑器模式、预览模式；用户与权限事实来自共享 AuthContext，不新增宿主自报身份 |
| 国际化 | 翻译、读取和切换语言；复用共享 Vue I18n 与 Console 语言同步，不新增 `this.i18n` 等平行运行时 |
| 样式 | 颜色、字体、字号、圆角、间距与隔离；使用 ADDP 主题变量，不另建 `--smw-*` 主题体系 |

外部参考中的包、Loader、Runtime、事件总线和公共方法尚未作为 ADDP 的产品契约落地；实际复用能力见[共享前端说明](../README.md)。需要实施时，应按[外部集成检查项](前端组件与低代码框架融合技术方案.md#组件封装检查项)确定最小契约，而非整体复制第三方工程。
