# Transfer 连接器使用指南

## 概述

Transfer 模块支持多种数据源连接器，包括关系数据库、文件系统和对象存储。每种连接器都实现了统一的 Reader/Writer 接口，可以灵活组合使用。

## 支持的连接器

### 数据库连接器

| 连接器类型 | Reader | Writer | 说明 |
|-----------|--------|--------|------|
| `mysql` | ✅ | ✅ | MySQL 数据库 |
| `postgresql`/`postgres` | ✅ | ✅ | PostgreSQL 数据库 |
| `jdbc` | ✅ | ✅ | 通用 JDBC 连接器 |

### 文件连接器

| 连接器类型 | Reader | Writer | 说明 |
|-----------|--------|--------|------|
| `csv` | ✅ | ✅ | CSV 文件（支持自定义分隔符）|
| `json` | ✅ | ✅ | JSON 数组格式 |
| `jsonl` | ✅ | ✅ | JSON Lines 格式（每行一个 JSON）|
| `file` | ✅ | ✅ | 通用文件连接器 |

### 对象存储连接器

| 连接器类型 | Reader | Writer | 说明 |
|-----------|--------|--------|------|
| `s3` | ✅ | ✅ | AWS S3 对象存储 |
| `minio` | ✅ | ✅ | MinIO 对象存储 |

## 使用示例

### 1. MySQL → PostgreSQL 数据同步

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "MySQL到PostgreSQL同步",
    "type": "sync",
    "mode": "batch",
    "batch_size": 2000,
    "source_id": 1,
    "target_id": 2,
    "config": {
      "source": {
        "driver": "mysql",
        "host": "mysql-host",
        "port": 3306,
        "database": "source_db",
        "username": "root",
        "password": "mysql_pass",
        "table": "orders",
        "query": "SELECT * FROM orders WHERE status = '\''active'\''"
      },
      "target": {
        "driver": "postgres",
        "host": "pg-host",
        "port": 5432,
        "database": "target_db",
        "username": "postgres",
        "password": "pg_pass",
        "table": "orders",
        "write_mode": "upsert",
        "conflict_key": "order_id"
      }
    },
    "mappings": [
      {"source_field": "id", "target_field": "order_id", "field_type": "int"},
      {"source_field": "customer_name", "target_field": "customer", "field_type": "string"},
      {"source_field": "amount", "target_field": "total_amount", "field_type": "float"}
    ]
  }'
```

**配置说明**：
- `driver`: 数据库类型（`mysql`, `postgres`）
- `host`, `port`, `database`: 数据库连接信息
- `username`, `password`: 认证信息
- `table`: 表名
- `query`: 自定义查询（可选，不指定则读取整张表）
- `write_mode`: 写入模式
  - `insert`: 直接插入（最快）
  - `upsert`: 存在则更新，不存在则插入
  - `replace`: 替换已存在的记录
- `conflict_key`: upsert 模式下的冲突键

### 2. CSV → PostgreSQL 导入

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "CSV文件导入数据库",
    "type": "import",
    "mode": "batch",
    "batch_size": 1000,
    "config": {
      "source": {
        "connector_type": "csv",
        "file_path": "/data/users.csv",
        "delimiter": ",",
        "batch_size": 1000
      },
      "target": {
        "driver": "postgres",
        "host": "localhost",
        "port": 5432,
        "database": "mydb",
        "username": "postgres",
        "password": "password",
        "table": "users",
        "write_mode": "insert"
      }
    }
  }'
```

**配置说明**：
- `file_path`: CSV 文件路径
- `delimiter`: 分隔符（默认逗号）
- CSV 第一行必须是表头

**CSV 文件示例**：
```csv
id,name,email,age
1,Alice,alice@example.com,25
2,Bob,bob@example.com,30
3,Charlie,charlie@example.com,35
```

### 3. PostgreSQL → JSON 文件导出

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "导出数据到JSON",
    "type": "export",
    "mode": "batch",
    "batch_size": 5000,
    "config": {
      "source": {
        "driver": "postgres",
        "host": "localhost",
        "port": 5432,
        "database": "mydb",
        "username": "postgres",
        "password": "password",
        "query": "SELECT id, name, email FROM users WHERE created_at > '\''2024-01-01'\''"
      },
      "target": {
        "connector_type": "json",
        "file_path": "/export/users_2024.json",
        "file_type": "json",
        "overwrite": true
      }
    }
  }'
```

**配置说明**：
- `file_type`: 文件格式
  - `json`: JSON 数组格式 `[{...}, {...}]`
  - `jsonl`: JSON Lines 格式（每行一个 JSON 对象）
- `overwrite`: 是否覆盖已存在的文件（默认 false，追加模式）

**JSON 输出示例**：
```json
[
  {
    "id": 1,
    "name": "Alice",
    "email": "alice@example.com"
  },
  {
    "id": 2,
    "name": "Bob",
    "email": "bob@example.com"
  }
]
```

### 4. S3/MinIO → PostgreSQL 导入

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "S3数据导入数据库",
    "type": "import",
    "mode": "batch",
    "batch_size": 2000,
    "config": {
      "source": {
        "connector_type": "s3",
        "endpoint": "http://minio:9000",
        "access_key": "minioadmin",
        "secret_key": "minioadmin",
        "bucket": "data-lake",
        "prefix": "raw/users/",
        "pattern": "*.json",
        "file_type": "jsonl",
        "region": "us-east-1"
      },
      "target": {
        "driver": "postgres",
        "host": "localhost",
        "port": 5432,
        "database": "mydb",
        "username": "postgres",
        "password": "password",
        "table": "users",
        "write_mode": "upsert",
        "conflict_key": "id"
      }
    }
  }'
```

**配置说明**：
- `endpoint`: S3/MinIO 端点（MinIO 必须指定）
- `access_key`, `secret_key`: 访问凭证
- `bucket`: 存储桶名称
- `prefix`: 对象前缀（目录路径）
- `pattern`: 文件匹配模式
  - `*`: 所有文件
  - `*.json`: 所有 JSON 文件
  - `*.csv`: 所有 CSV 文件
- `file_type`: 文件格式（`json`, `jsonl`, `csv`）
- `region`: AWS 区域（默认 `us-east-1`）

### 6. CSV → CSV 数据转换

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "CSV数据清洗",
    "type": "sync",
    "mode": "batch",
    "batch_size": 1000,
    "config": {
      "source": {
        "connector_type": "csv",
        "file_path": "/data/raw_users.csv",
        "delimiter": ","
      },
      "target": {
        "connector_type": "csv",
        "file_path": "/data/clean_users.csv",
        "delimiter": ",",
        "overwrite": true
      },
      "transforms": [
        {
          "type": "filter",
          "conditions": [
            {"field": "age", "operator": "gte", "value": 18},
            {"field": "email", "operator": "ne", "value": ""}
          ],
          "mode": "and"
        },
        {
          "type": "select",
          "fields": ["id", "name", "email", "age"]
        }
      ]
    }
  }'
```

## 连接器配置参考

### JDBC 连接器配置

**Reader**:
```json
{
  "driver": "mysql|postgres",
  "host": "localhost",
  "port": 3306,
  "database": "dbname",
  "username": "user",
  "password": "pass",
  "table": "table_name",
  "query": "SELECT * FROM table WHERE ...",
  "order_by": "id",
  "batch_size": 1000
}
```

**Writer**:
```json
{
  "driver": "mysql|postgres",
  "host": "localhost",
  "port": 5432,
  "database": "dbname",
  "username": "user",
  "password": "pass",
  "table": "table_name",
  "write_mode": "insert|upsert|replace",
  "conflict_key": "id",
  "buffer_size": 1000
}
```

### 文件连接器配置

**Reader**:
```json
{
  "connector_type": "csv|json|jsonl",
  "file_path": "/path/to/file",
  "file_type": "csv",
  "delimiter": ",",
  "batch_size": 1000
}
```

**Writer**:
```json
{
  "connector_type": "csv|json|jsonl",
  "file_path": "/path/to/output",
  "file_type": "csv",
  "delimiter": ",",
  "overwrite": true
}
```

### S3 连接器配置

**Reader**:
```json
{
  "connector_type": "s3|minio",
  "endpoint": "http://minio:9000",
  "access_key": "access_key",
  "secret_key": "secret_key",
  "bucket": "bucket_name",
  "prefix": "path/to/files/",
  "pattern": "*.json",
  "file_type": "json|jsonl|csv",
  "region": "us-east-1",
  "batch_size": 1000
}
```

**Writer**:
```json
{
  "connector_type": "s3|minio",
  "endpoint": "http://minio:9000",
  "access_key": "access_key",
  "secret_key": "secret_key",
  "bucket": "bucket_name",
  "prefix": "path/to/output/",
  "file_name": "output.json",
  "file_type": "json|jsonl|csv",
  "region": "us-east-1"
}
```

## 高级用法

### 组合多个数据转换

```json
{
  "transforms": [
    {
      "type": "filter",
      "conditions": [
        {"field": "status", "operator": "eq", "value": "active"}
      ]
    },
    {
      "type": "rename",
      "mappings": {
        "old_name": "new_name"
      }
    },
    {
      "type": "select",
      "fields": ["id", "new_name", "email"]
    }
  ]
}
```

执行顺序：Filter → Rename → Select

### 自定义 SQL 查询

```json
{
  "source": {
    "driver": "postgres",
    "query": "SELECT u.id, u.name, o.total FROM users u JOIN orders o ON u.id = o.user_id WHERE o.created_at > '2024-01-01'"
  }
}
```

### 批量大小调优

```json
{
  "batch_size": 5000,
  "config": {
    "source": {
      "batch_size": 5000
    },
    "target": {
      "buffer_size": 5000
    }
  }
}
```

建议值：
- 小数据量（< 10万）：1000-2000
- 中等数据量（10万-100万）：2000-5000
- 大数据量（> 100万）：5000-10000

## 常见问题

### 1. 文件路径问题

**问题**: 找不到文件

**解决**:
- 使用绝对路径，不要使用相对路径
- 确保 Worker 进程有读写权限
- 对于 Docker 部署，确保文件路径已挂载

### 2. S3/MinIO 连接失败

**问题**: 连接超时或认证失败

**解决**:
- 检查 `endpoint` 是否可访问
- 验证 `access_key` 和 `secret_key`
- MinIO 必须设置 `S3ForcePathStyle: true`（已自动处理）
- 检查网络防火墙规则

### 3. CSV 文件编码问题

**问题**: 中文乱码

**解决**:
- 确保 CSV 文件使用 UTF-8 编码
- 避免使用 Excel 的"CSV UTF-8"格式（可能有 BOM）

### 4. 数据类型推断错误

**问题**: 数字被识别为字符串

**解决**:
- 使用字段映射明确指定类型
- 对于 CSV，数字不要带引号

## 性能优化

### 1. 增加批量大小
```json
{
  "batch_size": 5000
}
```

### 2. 并发任务数
```bash
export CONCURRENT_TASKS=20
```

### 3. 使用 insert 模式（最快）
```json
{
  "target": {
    "write_mode": "insert"
  }
}
```

### 4. 减少数据转换
- 只转换必要的字段
- 尽量在数据库层面过滤（WHERE 子句）
