# Transfer 模块快速开始

## 简介

Transfer 模块是 ADDP 平台的数据传输模块，支持数据库之间、文件系统之间、以及跨系统的数据传输。

**核心特性**：
- ✅ **流批一体化**：统一的 API 支持批处理和流式处理
- ✅ **断点续传**：任务中断后可从上次位置继续
- ✅ **定时调度**：支持 Cron 表达式的定时任务
- ✅ **数据转换**：字段映射、过滤、类型转换
- ✅ **高并发**：基于 Asynq 任务队列，支持并发执行
- ✅ **可观测性**：实时进度监控、执行日志、性能指标

## 前置条件

### 1. 基础设施

确保以下服务已启动：

```bash
# PostgreSQL（数据库）
docker-compose up -d postgres

# Redis（任务队列）
docker-compose up -d redis

# System 模块（认证和配置中心）
cd system/backend && go run cmd/server/main.go
```

### 2. 环境变量

创建 `.env` 文件：

```bash
# 数据库配置
DB_HOST=localhost
DB_PORT=5432
DB_USER=addp
DB_PASSWORD=addp_password
DB_NAME=addp
DB_SCHEMA=transfer

# Redis 配置
REDIS_HOST=localhost
REDIS_PORT=6379
REDIS_PASSWORD=

# Transfer 配置
PORT=8083
CONCURRENT_TASKS=10
MAX_RETRIES=3
RETRY_DELAY=30s

# System 模块集成
SYSTEM_SERVICE_URL=http://localhost:8080
ENABLE_SERVICE_INTEGRATION=true
JWT_SECRET=your-secret-key
```

## 快速启动

### 方式1：开发模式（推荐）

```bash
# 1. 启动 API Server
cd transfer/backend
go run cmd/server/main.go

# 2. 启动 Worker（另一个终端）
cd transfer/backend
go run cmd/worker/main.go
```

### 方式2：编译运行（统一输出到 dist）

```bash
# 编译（release）
cd transfer/backend
GOOS=$(go env GOOS) GOARCH=$(go env GOARCH) \\
  go build -ldflags "-s -w" \\
  -o ../../dist/release/backend/transfer/${GOOS}-${GOARCH}/transfer cmd/server/main.go
GOOS=$(go env GOOS) GOARCH=$(go env GOARCH) \\
  go build -ldflags "-s -w" \\
  -o ../../dist/release/backend/transfer/${GOOS}-${GOARCH}/worker cmd/worker/main.go

# 运行（按平台路径替换示例中的 linux-amd64）
../../dist/release/backend/transfer/linux-amd64/transfer &
../../dist/release/backend/transfer/linux-amd64/worker &
```

### 方式3：Docker 部署

```bash
# 使用 docker-compose（在项目根目录）
make up-full  # 启动所有服务，包括 transfer
```

## 第一个数据传输任务

### 1. 获取 JWT Token

```bash
# 登录获取 token
TOKEN=$(curl -s -X POST http://localhost:8080/api/auth/login \
  -H "Content-Type: application/json" \
  -d '{
    "username": "admin",
    "password": "admin123"
  }' | jq -r '.token')

echo "Token: $TOKEN"
```

### 2. 创建数据源（在 System 模块）

```bash
# 创建源数据库资源
curl -X POST http://localhost:8080/api/resources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "MySQL源数据库",
    "resource_type": "mysql",
    "connection_info": {
      "host": "mysql-host",
      "port": 3306,
      "database": "source_db",
      "username": "root",
      "password": "mysql_password"
    }
  }'

# 创建目标数据库资源
curl -X POST http://localhost:8080/api/resources \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "PostgreSQL目标数据库",
    "resource_type": "postgresql",
    "connection_info": {
      "host": "postgres-host",
      "port": 5432,
      "database": "target_db",
      "username": "postgres",
      "password": "pg_password"
    }
  }'
```

### 3. 创建传输任务

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "用户数据同步",
    "description": "从 MySQL 同步用户数据到 PostgreSQL",
    "type": "sync",
    "mode": "batch",
    "batch_size": 1000,
    "source_id": 1,
    "target_id": 2,
    "config": {
      "source": {
        "table": "users",
        "query": "SELECT * FROM users WHERE status = '\''active'\''"
      },
      "target": {
        "table": "users",
        "write_mode": "upsert",
        "conflict_key": "id"
      }
    },
    "mappings": [
      {
        "source_field": "user_id",
        "target_field": "id",
        "field_type": "int"
      },
      {
        "source_field": "user_name",
        "target_field": "username",
        "field_type": "string"
      },
      {
        "source_field": "email",
        "target_field": "email",
        "field_type": "string"
      }
    ]
  }'
```

  "created_at": "2025-10-21T10:00:00Z"

## 创建定时任务

### 示例：每天凌晨2点同步数据

```bash
curl -X POST http://localhost:8083/api/tasks \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "每日用户数据同步",
    "type": "sync",
    "mode": "batch",
    "batch_size": 2000,
    "schedule": "0 0 2 * * *",
    "source_id": 1,
    "target_id": 2,
    "config": {
      "source": {
        "table": "users",
        "query": "SELECT * FROM users WHERE updated_at >= CURDATE()"
      },
      "target": {
        "table": "users",
        "write_mode": "upsert"
      }
    }
  }'
```

**Cron 表达式说明**：
```
秒 分 时 日 月 周

"0 0 2 * * *"      - 每天凌晨2点
"0 */30 * * * *"   - 每30分钟
"0 0 9 * * 1-5"    - 工作日上午9点
"0 0 0 1 * *"      - 每月1号凌晨
```

Worker 会自动加载并执行定时任务，无需手动启动。

## 高级功能

### 1. 数据过滤

在任务配置中添加过滤条件：

```json
{
  "config": {
    "transforms": [
      {
        "type": "filter",
        "conditions": [
          {
            "field": "status",
            "operator": "eq",
            "value": "active"
          },
          {
            "field": "age",
            "operator": "gte",
            "value": 18
          }
        ],
        "mode": "and"
      }
    ]
  }
}
```

支持的操作符：
- `eq` - 等于
- `ne` - 不等于
- `gt` - 大于
- `gte` - 大于等于
- `lt` - 小于
- `lte` - 小于等于
- `in` - 在列表中
- `not_in` - 不在列表中

### 2. 字段重命名

```json
{
  "config": {
    "transforms": [
      {
        "type": "rename",
        "mappings": {
          "old_field_name": "new_field_name",
          "user_name": "username"
        }
      }
    ]
  }
}
```

### 3. 字段选择（只传输部分字段）

```json
{
  "config": {
    "transforms": [
      {
        "type": "select",
        "fields": ["id", "name", "email"]
      }
    ]
  }
}
```

### 4. 断点续传

任务中断后，重试会自动从上次的 Checkpoint 继续：

```bash
# 查看任务的最新执行
curl http://localhost:8083/api/tasks/1/executions?page=1&page_size=1 \
  -H "Authorization: Bearer $TOKEN"

# 重试失败的执行
curl -X POST http://localhost:8083/api/executions/1/retry \
  -H "Authorization: Bearer $TOKEN"
```

## 故障排查

### 1. API Server 无法启动

**检查端口占用**：
```bash
lsof -i :8083
```

**检查数据库连接**：
```bash
psql -h localhost -U addp -d addp -c "SELECT 1"
```

### 2. Worker 无法连接 Redis

**检查 Redis**：
```bash
redis-cli ping
# 应该返回 PONG
```

**检查配置**：
```bash
echo $REDIS_HOST
echo $REDIS_PORT
```

### 3. 任务执行失败

**查看执行日志**：
```bash
curl http://localhost:8083/api/executions/1/logs \
  -H "Authorization: Bearer $TOKEN"
```

**检查数据源连接**：
```bash
# 在 System 模块测试连接
curl -X POST http://localhost:8080/api/resources/1/test \
  -H "Authorization: Bearer $TOKEN"
```

### 4. 任务卡住不执行

**检查 Worker 状态**：
```bash
ps aux | grep transfer-worker
```

**检查队列状态**：
```bash
# 连接 Redis 查看队列
redis-cli
> LLEN asynq:default
```

## 性能优化建议

### 1. 调整批量大小

根据数据量和网络状况调整：

```json
{
  "batch_size": 5000  // 默认 1000，大数据量可以增大
}
```

### 2. 增加并发数

修改 Worker 配置：

```bash
export CONCURRENT_TASKS=20  # 默认 10
```

### 3. 使用合适的写入模式

```json
{
  "config": {
    "target": {
      "write_mode": "insert"  // insert（最快）、upsert、replace
    }
  }
}
```
