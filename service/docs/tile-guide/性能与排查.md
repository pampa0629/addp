# 瓦片服务：性能与排查

[返回使用指南](../瓦片服务使用指南.md)

先区分动态空间表、静态业务 PMTiles、动态缓存与客户端显示，再判断需要优化哪一段。性能测量与报告沿[验收方法](../testing/验收方法与排查.md#性能测量)，源数据侧变更由资源 owner 按受控流程执行，发布动作不自动修改源表。

## 源数据与瓦片参数

- 检查真实 SRID、几何有效性、数据范围、图层密度和查询计划。空间索引、统计信息及源侧权限都须核对实际来源；普通几何索引不必然覆盖 ST_Transform 后的表达式，不能仅凭索引名判断已命中。
- 简化几何、预计算 3857 列或使用物化视图可能降低读取成本，也会改变来源、存储、刷新责任或可见细节。先确认业务精度、视图维护与发布依赖，不在使用指南中提供直接改写业务表、TRUNCATE/COPY 或触发器安装脚本。
- extent/buffer 在精度、边缘裁剪、瓦片大小和开销间权衡；表单参数与执行器缺省值沿[动态空间表说明](发布与管理.md#动态空间表)核对，其他组合需测实际画面和载荷，不作为通用场景标准。
- 逐段记录 SQL/来源等待、生成、对象读取、网络、解码和渲染耗时，区分空瓦片、失败及保护拒绝。连接池大小、并发与部署位置按证据调整，不为单次慢请求直接固定为另一组全局参数。

## 缓存与数据更新

动态缓存、静态业务 PMTiles 与 Manager 快显缓存分别管理；存储路径、TTL、X-Cache 及清理触发点唯一见[缓存架构](../architecture/瓦片发布与缓存.md#动态缓存与过期边界)。新鲜度按[读取验证](../testing/瓦片协议.md#空瓦片缓存与访问)核对，管理操作按[清理验证](../testing/瓦片协议.md#图层操作与缓存清理核对)留证，不以调参或操作提示代替结果。

实时或批量数据变化后，分别核对发布依赖、源数据变化与缓存失效。数据库通知须与正式订阅、失效链路接通；不能用 pg_notify、手工对象删除或新的旁路脚本替代正式 owner 的失效与保护屏障。

预热、定期清理、分层保留与更新后失效仍需明确目标资源、范围、容量和正式入口，并核对来源授权及在途读取保护。业务 PMTiles 的替换和发布快照也须单独处理，不按动态缓存 TTL 推导无限期或自动刷新语义。

## 观测、安全与后续范围

| 事项 | 使用与验证边界 |
| --- | --- |
| 指标 | 请求速率、延迟、错误率和来源耗时按真实采集核对；动态缓存命中率先按[响应标记语义](../architecture/瓦片发布与缓存.md#动态缓存与过期边界)区分读取路径与统计分母，不混入静态读取。示意 Prometheus 定义不表示指标或报表已登记。 |
| 日志 | 记录可定位服务/图层、坐标、缓存结果、来源等待及错误的脱敏上下文；沿[统一运行日志规范](../../../docs/spec/addp模块服务运行日志规范.md)查可信实例与权限，不依赖固定文件或容器名。应用日志不等于操作审计。 |
| 限流与配额 | 按实际入口确认调用主体、范围、阈值与拒绝语义；配置保存或一段中间件示例不等于整条瓦片链路已经受控，不新增第二套通用限流实现。 |
| 来源更新 | 源表优化、统计维护、批量更新或视图刷新各有 owner 和验证范围，不能通过发布图层自动执行。 |

## 常见问题

| 现象 | 核对顺序 |
| --- | --- |
| 地图空白 | 先按[入口边界](../architecture/瓦片发布与缓存.md#元数据链接与公开入口)区分直连与统一公开入口，核对状态码与载荷类型，排除 HTTP 200 实为 Console 页面；再看 MVT 内部图层、几何类型/属性、范围和层级，最后检查样式及底图。静态空瓦片不必为 404/204。 |
| 很慢 | 区分源查询、ST_Transform、密度/裁剪、缓存读取、网络与解码；结合配置、实际路径和异步写入结果分析，不能只根据响应标记归因。 |
| 内容旧或不符 | 核对发布配置、真实几何列/SRID、源数据和 PMTiles 依赖，再按[缓存架构](../architecture/瓦片发布与缓存.md#动态缓存与过期边界)区分过期、管理清理与安全失效。 |
| 401/403 | 按[私有访问与跨域](客户端接入.md#私有访问与跨域)核对身份、Tenant、入口和来源保护，区分 CORS 与授权。 |
| 404 | 区分未挂载路由、服务/图层不存在与管理 Tenant 隔离；页面动作按[图层管理契约](../tables/tile_service_layers表.md#排序启用与管理)核对。 |
| 400 | 按[瓦片错误分支](../testing/瓦片协议.md#空瓦片缓存与访问)检查格式、整数或矩阵集；不预设动态/静态路径的数值越界状态相同。 |
| 500/503 | 按[失败定位](../testing/验收方法与排查.md#失败定位)检查 Ready/注册、来源及真实错误，不将内部错误一律归为基础设施离线。 |

方法、载荷、状态和编码检查见[瓦片协议测试](../testing/瓦片协议.md)，报告按[标准入口与证据](../testing/验收方法与排查.md#标准入口与证据)记录命令、版本、资源范围和未验证项，不把现场日志或旧样例规模写成长期能力结论。
