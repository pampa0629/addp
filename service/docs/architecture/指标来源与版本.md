区分 Model 修订、QueryService 管理并发版本、消费契约版本及不执行数据的查询预览。

页面操作见[查询服务创建与详情](管理界面与模块协作.md#查询服务创建与详情)，实际取数与认证见[查询与要素协议](../testing/查询与要素协议.md)；本页编译预览的独有约束及验证入口见[执行查询预览](#执行查询预览)，证据分层沿[标准入口](../testing/验收方法与排查.md#标准入口与证据)。

## 来源选择与发布

指标来源的界面加载、失败重试与过期响应隔离见[指标来源选择](管理界面与模块协作.md#指标来源选择)；本节维护发布时的精确修订引用、服务端复核与冻结结果。

提交仍只走 `POST /api/v1/service/query` 的 `config_type=analytical + metric_source {implementation_id, revision_id}`。前端列表只辅助选择；Service 通过已有 Go Model Client SDK 在创建时重新校验精确修订、依赖与计划，禁止提交引擎、SQL 或参数／输出覆盖。Service 不增加 Model 启动探测、数据库访问或模块内部导入，不新增指标发布代理接口。此入口与 Model 工作区发布使用同一创建链路。

指标来源引用可显式选择 `result_kind=details`，只接受 Model 同修订声明的去重明细计划，省略为汇总。每个 Query Service 固定一种结果；消费字段、保护血缘、游标和依赖 hash 均从选定冻结包派生，执行期仍须按[统一执行契约](查询发布与执行.md#统一执行契约)基于实际 Provider 的 ReadSet／OutputLineage 完成授权与保护核验。Workbench 不重算或直接访问 Model，汇总与明细的绑定、取数、分页和对账须分别留证，不将一种结果的成功外推为另一种已验收。

输出格式展示与普通编辑的页面规则统一见[已保存协议与普通编辑](管理界面与模块协作.md#已保存协议与普通编辑)；格式支持与消费契约不由新建表单默认值推导。

## 版本、并发与消费绑定

`PUT /api/v1/service/query/:id/metric-source` 是查询服务切换到确定指标实现修订的唯一命令，要求 `service.definition.update`；请求只接受 `metric_source` 与正整数 `version`。

`version` 是聚合根持久化的非空 BIGINT 管理并发版本，创建为 1，存量迁移补齐为 1；管理 DTO 返回最新值，不提供定义指纹字段。普通编辑、启停、删除、刷新快照与重绑均携带该版本，在租户范围内同一事务锁行、比较版本、写入并递增。

资源不存在或属于其他租户返回 404；陈旧版本返回 409 / `resource_version_conflict`，不得产生副作用。删除和刷新快照使用请求体 `{ "version": 1 }`。

`service_version` 仅表示计算消费契约，缺少依赖快照或稳定键时为空，供查询、游标与 Consumer Descriptor 使用。

重绑保留服务 ID、编码、访问控制与启停状态；管理版本不授予执行权，停用服务不自动启用。切换计算来源会改变 Consumer Descriptor 指纹，Workbench 须重新绑定并发布应用新修订。

启用条件沿[活跃消费契约](查询发布与执行.md#活跃消费契约)，停用时的编译预览边界见[执行查询预览](#执行查询预览)。页面重绑、启停与冲突恢复统一见[重绑、启停与版本冲突](管理界面与模块协作.md#重绑启停与版本冲突)。

指标查询每次通过 Model 验证绑定的精确修订与依赖，并校验当前引擎能力、本地 `CompilerIdentity`、请求参数和服务消费版本；撤回、依赖漂移或实现版本不匹配即拒绝，不选最新版。继续使用 `MODEL_URL` 与现有 Tenant Service Token 路径。

绑定修订的页面展示、权限与失败提示、显式刷新及过期响应隔离统一见[指标修订状态与刷新](管理界面与模块协作.md#指标修订状态与刷新)。展示不授予执行权，实际查询仍按本节实时复核。

## 执行查询预览

管理接口 `POST /api/v1/service/query/:id/execution-query` 接受既有 `QueryExecutionRequest`，要求当前租户的 `service.definition.read`，仅用于 analytical 来源。通过租户与 ID 读取服务，动态调用 Model Client SDK 验证绑定修订与依赖，再复用实际执行的中立结果计划包装与引擎编译路径；当前参数、结果筛选、排序、选择和游标均参与编译。返回语言、带占位符的查询文本、按计划声明顺序排列的类型化参数（值以规范文本或 null 表达，避免浏览器数字精度损失）、引擎名称/类型/ID、服务版本和指标实现/修订/结果种类。

预览不调用 PrepareQuery、Execute 或数据库 EXPLAIN，不执行业务数据查询，不证明运行权限、数据质量断言或真实查询已经通过；停用服务允许查看，来源缺失、撤回、依赖漂移和非法请求仍拒绝。响应仅投影上述字段，不含引擎连接配置，使用 Cache-Control: no-store。不在公开查询端点、Consumer Descriptor 或 Workbench 暴露原生查询，不保存生成 SQL 副本，也不允许编辑后执行。

页面操作、数据测试的区别与旧结果清理统一见[查看执行查询](管理界面与模块协作.md#查看执行查询)。验证使用 `make test-module MODULE=service`，并按涉及范围执行 Service 前端、PostgreSQL 集成与 Swagger 覆盖入口；校验编译器一致性、类型化参数、非法请求、Tenant 隔离和前端过期结果清除。
