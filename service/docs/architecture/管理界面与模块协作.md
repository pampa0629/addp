# Service 管理界面与模块协作

[返回核心概念与架构](../service核心概念和架构设计.md)

说明统一导航、领域表单、资源与参数共享，以及 API / Service / Repository 的职责。

## 统一入口与页面

Console 的服务菜单当前依次为查询服务、瓦片服务、图查询服务、服务注册、服务目录。模块内使用下表路径，Console 入口加 `/service` 前缀；服务目录是模块消费投影，不等于企业 Catalog 的身份与治理事实。

| 页面 | 模块路径 | 当前页面 |
| --- | --- | --- |
| 查询服务 | `/query-services` | `QueryServiceList/Form/Detail.vue` |
| 瓦片服务 | `/tile` | `TileServiceList/Form/Detail.vue` |
| 图查询服务 | `/graph-services` | `GraphQueryServiceList/Form/Detail.vue` |
| 服务注册 | `/services` | `RegisteredServiceList/Form/Detail.vue` |
| 服务目录 | `/catalog` | `ServiceCatalog.vue` |

创建、编辑和详情沿 Router 的 path 表达资源身份。独立访问沿 AuthContext 选择有权进入的默认页；iframe 与独立部署复用同一页面和导航契约。

## 查询服务创建与详情

查询创建页依次选择来源、配置来源、填写服务信息，当前来源包含物理表、SQL、确定的已发布指标实现修订。表与 SQL 的输出契约见[查询发布与执行](查询发布与执行.md)；指标来源选择见[下文](#指标来源选择)，发布与版本冲突见[指标来源与版本](指标来源与版本.md)。

表模式使用共享资源树和 Meta 事实；SQL 模式声明标量参数并检测真实输出字段，再显式声明非空唯一稳定键。服务信息包含名称、标题、描述、关键词、协议及访问设置。

查询服务详情中的执行引擎展示 System 返回的实例名称、类型和辅助编号；源存储引擎与查询运行时分别展示，不能用 `Engine #ID` 或 `Runtime #ID` 冒充名称。读取失败或不可见时明确提示，不阻止服务详情及查询使用。

查询详情的页面地址、DTO 地址与执行请求分别按[管理 DTO 与页面端点核对](../testing/查询与要素协议.md#管理-dto-与页面端点核对)验证；该专题维护地址来源、测试按钮与代理转发差异。

REST“测试”复用页面预览链路；请求地址、User Bearer 身份、失败提示与旧结果清理、展示端点的验收范围统一见[协议测试专题](../testing/查询与要素协议.md#rest-测试按钮与页面预览)，按[失败定位](../testing/验收方法与排查.md#失败定位)区分认证、授权、角色资格和保护拒绝。“[查看执行查询](指标来源与版本.md#执行查询预览)”只展示编译文本，不能当作数据测试通过。两者的状态与参数变化处理保持独立。

主查询详情 `/query-services/:id` 使用 `QueryServiceDetail.vue`，尚未集成血缘查看器；已有查看器位于 `/published-services/:id` 的 `PublishedServiceDetail.vue`，不能据此认定主查询入口已支持血缘。后端同步范围与实际验收统一见[发布血缘同步边界](查询发布与执行.md#发布血缘同步边界)，空图或数据查询成功均不证明血缘完整。

### 指标来源选择

仅进入指标来源选择页时，共享前端 Model Client SDK 才携带当前用户 Bearer 身份调用现有 Model 指标实现读取 API；只展示已发布修订，必须显式选择实现和修订，不默认选择最新版本。Model 不可用、无读取权限或列表为空时显示对应状态和重试入口；其他来源不发起 Model 请求，也不受其结果影响。退出选择页后的迟到响应不得覆盖后续选择。

验证入口为 `make test-common-frontend test-service-frontend test-model-frontend`；覆盖 SDK 路由、已发布修订投影、权限／不可用状态、过期响应隔离、精确修订提交及普通来源独立创建。运行结果按[标准入口与证据](../testing/验收方法与排查.md#标准入口与证据)记录，前端选择成功不代替服务端发布、真实取数或完整链路验收。

### 已保存协议与普通编辑

不以创建时的默认协议覆盖已保存服务的输出格式。指标服务详情和编辑页按已保存协议显示格式；编辑标题、描述等普通信息时不提交只读协议配置，避免将已有 JSON/CSV 服务收窄为新建表单的 JSON 默认值。

确定性断言见[指标来源前端回归](../../frontend/tests/publishedMetricSource.test.js)；支持格式与启用条件分别沿[协议支持](查询发布与执行.md#协议支持)、[活跃消费契约](查询发布与执行.md#活跃消费契约)。页面展示或提交夹具不代替[真实格式与消费验收](../testing/查询与要素协议.md#rest-query)。

### 重绑、启停与版本冲突

服务详情页复用已发布指标修订选择器切换来源；普通编辑页只修改服务基本信息。切换入口要求服务更新与指标实现读取权限，请求契约见[版本、并发与消费绑定](指标来源与版本.md#版本并发与消费绑定)。

详情页提供显式启用／停用操作；未绑定完整指标计划时不可启用，未启用时禁止数据测试并显示原因；不执行业务查询的编译预览仍可查看。版本冲突保留参数和本地输入，用户主动重新加载后再操作，不自动重试。

确定性页面行为见[生命周期前端回归](../../frontend/tests/queryServiceLifecycle.test.js)，数据库断言与未覆盖项见[迁移与持久化覆盖](../testing/验收方法与排查.md#迁移与持久化覆盖)；夹具不代替真实并发部署与消费链路验收。

### 指标修订状态与刷新

指标服务详情分开展示服务启停状态与绑定修订状态。复用共享 Model Client 对确切实现的读取，仅从绑定的修订 ID 解析修订号及 `draft|published|withdrawn` 当前状态；不取最新修订，不把 Service 的 `active` 当作可查询证明。已撤回明确提示新查询会被拒绝，已发布仍说明执行时必须校验依赖、引擎与权限；无 Model 读取权限、修订不存在和读取失败分别提示，不能伪装为已发布。支持显式刷新此只读状态，保留参数输入和服务配置；切换来源、权限变化及卸载后忽略迟到响应。此展示不授予执行权、不自动重绑或改变服务启停，实际查询继续由 Service 实时校验。普通表与 SQL 来源不发起该读取。验证沿用 Service 前端确定性测试、构建和已登记 CI 门禁。

## 瓦片与注册流程

瓦片创建先配置首图层，再填写服务信息和协议，最后显示完成结果。动态源使用真实表的几何字段和 SRID，静态源从资源树选择 Meta 已识别的 PMTiles，格式、层级和范围沿发布快照显示。界面上的 TMS 选项不构成对应路由已实现的证明。

前端唯一入口以 Console 为准：`/service/services`，模块内对应 `/services`。创建、详情、编辑分别使用 `/services/create`、`/services/:id`、`/services/:id/edit`，统一由 `RegisteredServiceList/Form/Detail.vue` 实现。管理请求通过唯一 `api/registeredService.js` 调用 `/api/v1/service/registered`；名称和端点字段为 `service_name`、`endpoint_url`，列表使用 `page`、`limit`、`search`。服务目录进入相同详情页，不保留重复页面、API 客户端或路由别名。

注册表单先收集程序标识、标题、上游端点和认证配置，再保存注册记录；显式开启的 OGC 自动刷新在创建后异步进行，失败与部分图层写入边界见[注册服务](../tables/registered_services表.md)和[注册图层](../tables/registered_service_layers表.md)。XYZ / REST 注册不承诺通用 TileJSON 解析或自动生成独立图层。

注册服务公开代理使用独立路径 `/api/service/registered/proxy/:id/*path`。代理与直连的适用条件、Service/Gateway 可达性及访问边界见[外部服务架构](../外部服务架构设计.md)；图层存储状态不能视为逐图层授权已接通。

## 注册页面交互与验收

注册管理验收覆盖列表、搜索与分页；WMS、WFS、WMTS、OGC API、XYZ、REST 创建及 none/Basic/Bearer/API Key 配置；详情、编辑、元数据刷新、健康检查与删除。当前编辑页的 `service_name`、`service_type` 和 `endpoint_url` 只读；认证类型与凭据按现行更新契约编辑，不能通过前端解锁只读来源字段绕过请求契约。

应检查必填与 URL 校验、加载/空数据/错误状态，以及失败后输入保留。详情与表单切换服务、身份或卸载后，旧响应不得更新当前内容；保存期间禁用输入，成功后更新离页保护基线，失败保持草稿。导航、字段和认证草稿的详细规则以[模块前端契约](../../CLAUDE.md#前端公开路由)为准。

注册详情的原始端点仅展示和复制 `endpoint_url`；浏览器上游认证、CORS 与实际消费按[原始端点与浏览器直连核对](../testing/注册服务与代理.md#原始端点与浏览器直连核对)验证。

注册详情当前展示图层名称、几何类型、单值 CRS 与启用标记，以及父服务 metadata；不单独呈现图层 BBox/TileMatrixSet 网格，也没有基于这些解析值的注册图层地图预览。字段保存与真实地图能力的检查统一见[注册图层能力核对](../testing/注册服务与代理.md#注册图层能力核对)。

前端确定性测试和构建使用 `make test-service-frontend`；正式页面的导航和 iframe 离页回归沿 `make test-console-frontend`。已有 HTTP 拦截夹具验证页面交互，不证明真实上游解析、代理可达性或凭据保护已验收；地图/数据预览、端点测试工具及监控/导入导出需求见[外部服务后续事项](../外部服务架构设计.md#后续事项与确认边界)。

## 模块分层与协作

| 层次或依赖 | 职责与入口 |
| --- | --- |
| [HTTP API](../../backend/internal/api/) | Handler、身份与 Permission、公开协议适配和响应。 |
| [业务 Service](../../backend/internal/service/) | 发布契约、查询执行、图层来源、第三方能力解析与代理。 |
| [Repository](../../backend/internal/repository/) | Tenant 资源条件、事务、版本与持久化。 |
| [模型](../../backend/internal/models/) | Query、Graph、Tile、Registered 及本模块配置/变化流。 |
| [前端 API](../../frontend/src/api/)与[页面](../../frontend/src/views/) | 领域表单和展示；复用共享资源树、参数展示及 Model Client。 |
| System、Meta、Model | 分别提供身份/Engine、资源与结构事实、确定的指标修订及计划；Service 不保存连接配置或反向治理副本。 |
| Gateway 与 Catalog | Gateway 提供统一路由；企业 Catalog 只消费专业 owner 提供的最小变化与摘要，专业定义仍归 Service。 |

执行引擎从 System 获取当前连接事实；表结构和空间信息通过 Meta 共享能力读取。普通表与 SQL 发布不因尚未使用的 Model 来源选择失败而被阻断。Graph、Tile、Registered 尚未形成与 QueryService 相同的稳定 Consumer Descriptor 时，不通过 Query 的目录接口输出它们的管理 DTO。
