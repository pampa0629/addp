# 三维模型与高斯泼溅预览说明

> 状态：当前实现说明。本文说明 Manager 对 `model_3d` 和 `gaussian_splat` 数据项的预览、快显任务、结果状态和 `preview_state` 协作关系。格式识别规则以平台 `docs/spec/` 为准，转换运行时以 `engines/model3d-workflow/README.md` 为准。

## 一、职责边界

Manager 只负责预览编排、任务定义、结果登记、内容出口和前端渲染材料组织。

Manager 不负责：

1. 在 Go 进程内解析 OSGB、FBX、OBJ 或高斯泼溅二进制。
2. 直接调用 `_3dtile`、`assimp` 或 KPlat 生成脚本。
3. 把 Manager 受管快显 artifact 自动升格为业务 data item。
4. 把快显能力、转换结果或渲染器状态写回 Meta attributes。

三维和高斯相关的重型转换统一由 `model3d_workflow` direct operator 承担。Manager 通过标准工作流运行时接口调用 operator，并根据结果登记 Manager 受管 artifact 或触发业务存储目标的 Meta scan。

## 二、数据类型与预览路线

| 数据项 | 预览路线 | 结果归属 |
| --- | --- | --- |
| `data_type=model_3d + format=glb` | 直接使用三维模型预览 | 源 data item |
| `data_type=model_3d + format=gltf + layout=multi` | `gltf_to_glb` 生成 GLB 快显后预览 | `manager.model_3d_quick_view` |
| `data_type=model_3d + format=fbx|obj|stl + layout=single` | 对应 operator 生成 GLB 快显后预览 | `manager.model_3d_quick_view` |
| `data_type=model_3d + format=osgb + layout=single` | `osgb_to_glb` 生成 GLB 快显后预览 | `manager.model_3d_quick_view` |
| `data_type=model_3d + format=osgb_scene + layout=whole` | `osgb_scene_to_3dtiles` 生成业务 3D Tiles，再预览目标 item | 业务存储 + Meta item |
| `data_type=model_3d + format=3dtiles + layout=whole` | 直接使用 3D Tiles 预览 | 源 data item |
| `data_type=gaussian_splat + format=ply|splat` | 基础预览可直接读取；也可生成 KPlat 受管快显 | `manager.gaussian_splat_quick_view` |
| `data_type=gaussian_splat + format=ksplat` | 直接基础预览 | 源 data item |

`.ksplat` 本身已经是前端目标渲染格式，不创建 KPlat 快显任务，不登记受管快显结果。它仍然通过 `manager.preview_state` 保存基础预览视角。

## 三、快显结果与业务结果

三维模型 GLB 快显和 3DGS - KPlat 快显是 Manager artifact：

```text
源 item
  -> Manager 快显任务
  -> model3d_workflow direct operator
  -> Manager infra MinIO
  -> Manager 结果表登记
  -> Preview 返回受控内容 URL
```

对应结果表：

1. `manager.model_3d_quick_view`：GLB 快显结果。
2. `manager.gaussian_splat_quick_view`：KPlat 快显结果。

OSGB Scene 转 3D Tiles 是业务数据准备：

```text
osgb_scene item
  -> model_3d_tiles_generation
  -> model3d_workflow: osgb_scene_to_3dtiles
  -> 目标业务存储 3D Tiles
  -> Meta deep scan
  -> 3dtiles item
  -> 3D Tiles 预览
```

3D Tiles 结果不进入 Manager 私有 artifact 表；其生命周期由目标业务存储和 Meta item 管理。

## 四、任务类型

| 任务类型 | 任务定义表 | 结果 |
| --- | --- | --- |
| `model_3d_quick_view_generation` | `manager.model_3d_quick_view_tasks` | GLB 快显 artifact |
| `model_3d_tiles_generation` | `manager.model_3d_tiles_tasks` | 业务存储中的 `format=3dtiles` item |
| `gaussian_splat_quick_view_generation` | `manager.gaussian_splat_quick_view_tasks` | KPlat 快显 artifact |

任务准入只看标准事实：`data_type`、`format`、`layout` 和必要 capabilities。`model_kind` 可用于展示和筛选，但不是第一版任务准入的必填条件。

## 五、预览状态

`manager.preview_state` 保存用户在当前 item 上的预览模式偏好和交互视角状态。它不是快显结果表。

`view_state` 只按显示模式和渲染域分组：

```json
{
  "basic_preview": {
    "map": {},
    "scene_3d": {}
  },
  "quick_view": {
    "map": {},
    "scene_3d": {}
  }
}
```

基础预览和快显各自保存视角，互不覆盖。三维模型、3D Tiles 和高斯泼溅都归入 `scene_3d` 渲染域；地图类预览归入 `map` 渲染域。
